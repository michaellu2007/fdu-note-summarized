    第一部分 · 幂法板书 7、11、12、13

    1.1 起点：$Ax=\lambda x$ 的三种情形

    整个特征值问题的出发点就是特征方程 $Ax=\lambda x$。按「谁已知、谁未知」分成三种情形：

    情形转化为什么问题解法
    ① $\lambda$ 已知，$x$ 未知齐次线性方程组 $(A-\lambda I)x=0$一般默认 $\lambda$ 不是重特征值，零空间一维
    ② $x$ 已知，$\lambda$ 未知超定的矛盾方程组 $Ax=\lambda x$转为最小二乘，得 Rayleigh 商
    ③ 两者都未知——幂法 / 反幂法（本文重点）

    情形 ② 的推导：Rayleigh 商从哪来

    把 $Ax=\lambda x$ 看成关于 $\lambda$ 的方程组：它是超定的（$n$ 个方程、$1$ 个未知量），一般无解，所以退而求其次解最小二乘

    \[ \min_{\lambda\in\mathbb{C}}\ \|Ax-\lambda x\|_2 \]

    由第 2 章的法方程，系数矩阵是 $x$，于是 $x^{*}(Ax-\lambda x)=0$，即 $x^{*}x\,\lambda=x^{*}Ax$，解出

    \[ \hat\lambda=\frac{x^{*}Ax}{x^{*}x} \]

    这就是 Rayleigh 商。它的意义是：给定一个近似特征向量 $x$，能给出使残量 $\|Ax-\lambda x\|_2$ 最小的那个 $\lambda$。后面幂法里用它来估计特征值，就是出于这个理由。

    一句话

    Rayleigh 商是「已知方向、反推特征值」的最优答案；幂法是「已知矩阵、反推方向」的迭代过程。两者互为对偶，这也是为什么幂法里总把 Rayleigh 商当作特征值的估计。

    1.2 幂法的基本思想

    先假设 $A$ 可对角化，即存在分解

    \[ A=Q\,\operatorname{diag}(\lambda_1,\lambda_2,\dots,\lambda_n)\,Q^{-1},\qquad Q=[q_1,q_2,\dots,q_n] \]

    并假定特征值按模严格分离：

    \[ |\lambda_1|>|\lambda_2|\ge|\lambda_3|\ge\cdots\ge|\lambda_n| \]

    取任一初始向量 $x^{(0)}$。由于 $\{q_1,\dots,q_n\}$ 构成一组基，存在系数 $\alpha_i$ 使得

    \[ x^{(0)}=\sum_{i=1}^{n}\alpha_i q_i \]

    假定 $\alpha_1\neq0$（这是后面收敛性定理的条件）。把 $A$ 反复作用上去：

    \[ A^{k}x^{(0)}=\sum_{i=1}^{n}\alpha_i\lambda_i^{k}q_i =\lambda_1^{k}\Big[\alpha_1q_1+\sum_{i\ge2}\alpha_i\Big(\frac{\lambda_i}{\lambda_1}\Big)^{k}q_i\Big] \]

    核心

    因为 $|\lambda_i/\lambda_1|<1\ (i\ge2)$，所以括号里第二项随 $k\to\infty$ 指数衰减到 $0$。于是

    \[ \frac{A^{k}x^{(0)}}{\lambda_1^{k}}\ \longrightarrow\ \alpha_1q_1 \]

    也就是说，$A^{k}$ 只把 $\lambda_1$ 对应的方向留了下来——因为那是被放大倍数最大的方向。方向收敛到 $q_1$，与初始向量的选取无关（只要 $\alpha_1\neq0$）。

    为什么不能直接这么算

    理论式子很漂亮，但实际算不了，有两个原因：

    1. 我们不知道 $\lambda_1$，没法除以 $\lambda_1^k$；
    2. 直接算 $A^k$ 的工作量太大，而且 $\lambda_1^k$ 会溢出或下溢。

    第一个问题的解决靠一个关键观察：

    \[ \lambda_1\ \text{只改变向量的模长，不改变方向} \]

    既然我们只关心方向，那就不必用 $\lambda_1$ 来控制模长，随便找一个「方便得到的常数」归一化就行（同时这也顺便解决了溢出问题）。第二个问题靠迭代：$A^{k}x^{(0)}=A\,(A^{k-1}x^{(0)})$，一步步乘过去即可。

    1.3 迭代格式

    \[ \begin{aligned} &\textbf{幂法迭代：}\\[4pt] &\quad \tilde x^{(k)}=A\,x^{(k-1)}\\[2pt] &\quad x^{(k)}=\frac{\tilde x^{(k)}}{\|\tilde x^{(k)}\|_\infty} \qquad(\text{用 }\infty\text{-范数归一化，即除以分量模最大值}) \end{aligned} \]

    特征值的估计用 Rayleigh 商：

    \[ \lambda^{(k)}=\frac{\big(x^{(k)}\big)^{*}A\,x^{(k)}}{\big(x^{(k)}\big)^{*}x^{(k)}} \]

    收敛判据用残量 $r^{(k)}=A x^{(k)}-\lambda^{(k)}x^{(k)}$（这正是板书第 13 张上的写法）：

    \[ \|r^{(k)}\|_\infty\le \tau\Big(\|A\|_\infty\|x^{(k)}\|_\infty+|\lambda^{(k)}|\,\|x^{(k)}\|_\infty\Big) \]

    为什么残量判据里带着 $\|A\|\|x\|$ 这一项

    因为判据是相对的：$A x$ 的舍入误差本身就在 $O(u\cdot\|A\|\|x\|)$ 量级。如果只要求 $\|r\|$ 小，在 $A$ 病态或尺度很大时会「假收敛」。带上 $\|A\|\|x\|+|\lambda|\|x\|$ 这个尺度，判据才有意义。

    1.4 收敛性定理与证明骨架

    定理（徐树方《数值线性代数》）

    设 $A$ 有 $n$ 个互不相同的特征值，满足 $|\lambda_1|>|\lambda_2|\ge\cdots\ge|\lambda_n|$，且模最大特征值 $\lambda_1$ 是半简单的（几何重数等于代数重数）。若初始向量 $x^{(0)}$ 在 $\lambda_1$ 的特征子空间上的投影不为零，则幂法产生的向量序列 $\{x^{(k)}\}$ 收敛到 $A$ 的一个特征向量，且数值序列 $\{\lambda^{(k)}\}$ 收敛到 $\lambda_1$。

    证明走 Jordan 分解的路子，骨架是这样：

    \[ A=PJP^{-1},\qquad J=\begin{bmatrix}\lambda_1& &\\ & \hat J\end{bmatrix} \]

    其中 $\hat J$ 是其余特征值构成的 Jordan 块对角阵。$\lambda_1$ 半简单意味着属于 $\lambda_1$ 的 Jordan 块只有一个（$1\times1$ 的）。于是

    \[ \rho(\hat J)=|\lambda_2|<|\lambda_1|=1\cdot|\lambda_1| \ \Longrightarrow\ \rho\!\left(\frac{\hat J}{\lambda_1}\right)<1 \ \Longrightarrow\ \Big(\frac{\hat J}{\lambda_1}\Big)^{k}\to 0 \]

    把 $P$ 和 $P^{-1}$ 对应分块：$P$ 的第一列是右特征向量 $q_1$，$P^{-1}$ 的第一行是左特征向量 $z_1^{*}$（因为 $P^{-1}A=\Lambda P^{-1}$，$P^{-1}$ 的第 $i$ 行 $z_i^{*}$ 满足 $z_i^{*}A=\lambda_iz_i^{*}$）。于是

    \[ \Big(\frac{A}{\lambda_1}\Big)^{k}\ \longrightarrow\ P\begin{bmatrix}1&\\ &0\end{bmatrix}P^{-1}=c\,q_1z_1^{*} \]

    这句话在说什么（一句话）

    它把「迭代 $k$ 步后方向会收敛」这个定性的说法，写成一个极限矩阵。写成矩阵之后，三件事一眼可见：收敛到哪（$q_1$ 的方向）、什么条件下收敛（$z_1^{*}x^{(0)}\neq0$）、多快（由 $|\lambda_2/\lambda_1|$ 决定）。

    拆解 ① · 为什么要除以 $\lambda_1^k$。$A^kx^{(0)}$ 本身按 $\lambda_1^k$ 指数增长（或衰减），序列根本不收敛，谈不上「极限」。除以 $\lambda_1^k$ 是把主导项归一化成 $1$，让剩下的部分才有极限。

    拆解 ② · 极限矩阵从哪来。对角化 $A=P\Lambda P^{-1}$，于是 $A^k=P\Lambda^kP^{-1}$，把幂次推进对角阵：

    \[ \Big(\frac{A}{\lambda_1}\Big)^{k}=P\begin{bmatrix} (\lambda_1/\lambda_1)^k&&\\&(\lambda_2/\lambda_1)^k&\\&&\ddots \end{bmatrix}P^{-1} \]

    第 $1$ 个对角元恒等于 $1$；第 $j$ 个是 $(\lambda_j/\lambda_1)^k$。因为 $|\lambda_j/\lambda_1|<1\ (j\ge2)$，它 $\to0$。所以中间那个对角阵 $\to\operatorname{diag}(1,0,\dots,0)$。

    拆解 ③ · 为什么「一夹」就只剩 $q_1z_1^{*}$（最容易跳过的一步）

    $P\cdot D\cdot P^{-1}$ 是个夹心结构，关键是要分两次算，不能一口气吞下去：

    • 先算 $PD$。$D$ 在右边，作用是「按列筛」。$D$ 只有第 $1$ 个对角元非零，所以 $PD$ 只保留 $P$ 的第 $1$ 列，其余列清零：$PD=[\,q_1\ \ 0\ \ \cdots\ \ 0\,]=q_1e_1^{\mathsf T}$。
    • 再右乘 $P^{-1}$。而 $e_1^{\mathsf T}P^{-1}$ 恰好取的是 $P^{-1}$ 的第 $1$ 行，也就是左特征向量 $z_1^{*}$。

    合起来 $PDP^{-1}=q_1z_1^{*}$（写成 $c\,q_1z_1^{*}$ 只是把归一化常数吸收进 $c$，对方向没有任何影响）。记忆要点：$D$ 在右边 ⇒ 筛掉 $P$ 的列；$D$ 在左边 ⇒ 筛掉 $P^{-1}$ 的行。这里 $D$ 只有一个非零元，所以最后只剩「第 $1$ 列 × 第 $1$ 行」这一项。

    拆解 ④ · 「秩一」和「值域 $=\operatorname{span}(q_1)$」是什么意思。$q_1z_1^{*}$ 是外积（$n\times1$ 列向量 × $1\times n$ 行向量）。对任意向量 $v$：

    \[ (q_1z_1^{*})\,v=q_1\underbrace{(z_1^{*}v)}_{\text{标量}} \]

    括号里是个标量，所以结果永远是 $q_1$ 的倍数。于是值域 $=\{tq_1\}=\operatorname{span}(q_1)$，一维；秩 $=1$；核 $=\{v:z_1^{*}v=0\}$。只要 $v$ 不落在这个超平面里，就会被「压」到 $q_1$ 方向。这就是「幂法把向量压向主特征方向」的几何含义——极限算子本身就是一个投影（差一个标量）。

    拆解 ⑤ · $z_1^{*}x^{(0)}\neq0$ 到底是什么条件。把 $x^{(0)}$ 按特征基展开 $x^{(0)}=\sum_jc_jq_j$，用 $z_i^{*}$ 左乘两边，利用双正交性 $z_i^{*}q_j=\delta_{ij}$，得

    \[ z_i^{*}x^{(0)}=\sum_jc_j\,z_i^{*}q_j=c_i \]

    所以 $z_1^{*}x^{(0)}$ 就是 $x^{(0)}$ 在 $q_1$ 上的系数 $c_1$。条件翻译成人话就是：初始向量必须在主导特征方向上有非零分量。若 $c_1=0$（$x^{(0)}$ 恰好落在 $z_1$ 的正交补里），主导项就「没被点燃」，迭代会收敛到 $q_2$ 去。这是个零测度的巧合，随机取 $x^{(0)}$ 几乎碰不上。于是整个收敛关系可以写成一个特别干净的式子：

    \[ A^kx^{(0)}\ \approx\ \lambda_1^k\,q_1\,\underbrace{(z_1^{*}x^{(0)})}_{\text{常数}} \]

    $\lambda_1^k$ 管模长，$z_1^{*}x^{(0)}$ 是常数系数，$q_1$ 是方向。方向只由 $q_1$ 决定，收敛速度只由 $|\lambda_2/\lambda_1|^k$ 决定。

    附注 · 双正交性 $z_i^{*}q_j=\delta_{ij}$ 从哪来

    上面用到了「双正交性」，但它其实一点都不神秘——就是矩阵求逆的定义式，逐元素写出来而已。

    一行证明

    记 $P=[q_1\ q_2\ \cdots\ q_n]$（列是右特征向量），$P^{-1}$ 的行是 $z_1^{*},z_2^{*},\dots,z_n^{*}$（左特征向量）。按「行 × 列」的乘法，$P^{-1}P$ 的第 $(i,j)$ 个元素就是「$P^{-1}$ 的第 $i$ 行」乘「$P$ 的第 $j$ 列」，即 $z_i^{*}q_j$。而 $P^{-1}P=I$，所以

    \[ z_i^{*}q_j=(P^{-1}P)_{ij}=(I)_{ij}=\delta_{ij} \]

    证完。没有别的来源。

    $z_i^{*}$ 为什么是「左」特征向量。从 $A=P\Lambda P^{-1}$ 两边左乘 $P^{-1}$ 得 $P^{-1}A=\Lambda P^{-1}$。取第 $i$ 行：左边是 $z_i^{*}A$；右边因为 $\Lambda$ 对角，等于把 $P^{-1}$ 的第 $i$ 行整体乘 $\lambda_i$，即 $\lambda_i z_i^{*}$。所以

    \[ z_i^{*}A=\lambda_i z_i^{*} \]

    关键：这是「双正交」，不是普通的正交

    $z_i^{*}q_j=\delta_{ij}$ 里的 $z_i$ 和 $q_i$ 一般不是同一个向量！

    • 正规矩阵（对称、Hermite、酉矩阵）：$z_i=q_i$，双正交退化成普通正交。
    • 一般矩阵：$z_i\ne q_i$，是真正的双正交。

    几何意义：$z_i^{*}q_j=0\ (j\ne i)$ 说明 $z_i$ 垂直于所有 $q_j$，即 $\{z_i\}$ 是 $\{q_i\}$ 的对偶基。

    具体验算（非对称，$z_i\ne q_i$）。取 $A=\begin{bmatrix}2&1\\0&3\end{bmatrix}$，$\lambda_1=2,\lambda_2=3$。解得 $q_1=\binom{1}{0}$、$q_2=\binom{1}{1}$，于是

    \[ P=\begin{bmatrix}1&1\\0&1\end{bmatrix},\qquad P^{-1}=\begin{bmatrix}1&-1\\0&1\end{bmatrix}\ \Longrightarrow\ z_1=\binom{1}{-1},\quad z_2=\binom{0}{1} \]

    验算：$z_1^{*}q_1=1$，$z_1^{*}q_2=1-1=0$，$z_2^{*}q_1=0$，$z_2^{*}q_2=1$ ✓。注意两件事：① $z_1=\binom{1}{-1}\ne q_1=\binom{1}{0}$，真不是同一个向量；② $q_1^{\mathsf T}q_2=1\ne0$，右特征向量自己之间也不正交。所以「正交」在这里指的是交叉关系（$z$ 对 $q$），不是同一族内部的关系。

    $z_i$ 到底是什么向量。对 $z_i^{*}A=\lambda_i z_i^{*}$ 取共轭转置，得 $A^{*}z_i=\bar\lambda_i z_i$，所以一句话：$z_i$ 就是 $A^{*}$ 的属于 $\bar\lambda_i$ 的右特征向量。（上例验证：$A^{*}=\begin{bmatrix}2&0\\1&3\end{bmatrix}$，解 $(A^{*}-2I)z=0$ 得 $z=\binom{1}{-1}$ ✓）

    为什么这个 $\delta_{ij}$ 很重要。① 它是展开系数的提取器：$x=\sum_jc_jq_j$ 两边左乘 $z_j^{*}$，只有第 $j$ 项活下来，得 $c_j=z_j^{*}x$——这正是上面拆解 ⑤ 里 $z_1^{*}x^{(0)}=c_1$ 的来处。② 它决定了特征向量的条件数 $c_i=\dfrac{\|q_i\|_2\|z_i\|_2}{|z_i^{*}q_i|}$：$z_i$ 与 $q_i$ 越接近平行，$c_i$ 越接近 $1$（对称矩阵 $c_i=1$，完美良态）；越接近垂直，$c_i$ 越大、越敏感。这就是 §2.4 反复用到的那个 $c_i$。

    拆解 ⑥ · 最后那句「$\|x^{(k)}\|_\infty=1\Rightarrow\lambda^{(k)}\to\lambda_1$」。

    • 为什么要归一化：$A^kx^{(0)}$ 的模长指数变化，不归一化序列既收敛不了、还会上溢或下溢。归一化是把「方向」这个唯一有意义的信息提出来。
    • 怎么拿到 $\lambda_1$：既然 $x^{(k)}\to\hat q_1$（$\infty$-范数为 $1$ 的某个固定特征向量），用 Rayleigh 商 $\lambda^{(k)}=\dfrac{(x^{(k)})^{*}Ax^{(k)}}{(x^{(k)})^{*}x^{(k)}}$ 就收敛到 $\lambda_1$，而且误差是 $O(\|x^{(k)}-\hat q_1\|^2)$——平方级小，所以 $\lambda$ 的精度远好于特征向量本身。也可以用更省事的分量比：取模最大的分量 $i$（$\infty$-范数 $=1$ 保证 $|x_i^{(k)}|=1$，不会除以一个小量），令 $\lambda^{(k)}=(Ax^{(k)})_i/x_i^{(k)}\to\lambda_1$。

    两个前提（考试常考）

    ① $\lambda_1$ 必须严格占优。整段推导用到了 $|\lambda_2/\lambda_1|<1$。若出现 $|\lambda_2|=|\lambda_1|$（例如 $\lambda_2=-\lambda_1$，像 $\operatorname{diag}(1,-1)$），那么 $(\lambda_2/\lambda_1)^k=(-1)^k$ 不收敛，幂法失效。这就是定理里把条件写成严格不等号 $|\lambda_1|>|\lambda_2|$ 的原因。

    ② 「$\lambda_1$ 半简单」这个条件的来处。若 $A$ 不可对角化（存在阶数 $>1$ 的 Jordan 块），$\hat J^k$ 里会多出 $k^m$ 这样的多项式因子，但指数衰减仍然赢（$k^m\epsilon^k\to0$），结论不变——只是需要 $\lambda_1$ 自己的 Jordan 块是 $1\times1$ 的，这就是「半简单」的作用。但若 $\lambda_1$ 本身就有重数（$\lambda_1=\cdots=\lambda_k$），下面的论证不再成立——见本节末尾「模最大特征值有重数时会怎样」。

    收敛速度

    从证明可以看出，收敛速度由 $\big(\hat J/\lambda_1\big)^k$ 决定，也就是由

    \[ \left|\frac{\lambda_2}{\lambda_1}\right| \]

    决定（该比值总小于 $1$）。它越接近 $1$，收敛越慢，而且算出的特征向量对扰动越敏感。特征向量的敏感性取决于模第一大与模第二大特征值的分离度。

    加速：位移（shifting）

    要对 $A-\mu I$ 用幂法。$A-\mu I$ 的特征值是 $\lambda_i-\mu$，模最大的仍然是 $\lambda_1-\mu$，但比值变成

    \[ \frac{|\lambda_2-\mu|}{|\lambda_1-\mu|} \]

    适当选取 $\mu$ 可以让这个比值明显小于原来的 $|\lambda_2/\lambda_1|$，从而加速收敛。

    模最大特征值不唯一时会怎样

    定理里有两条假设：$|\lambda_1|>|\lambda_2|$（严格占优）和 $\lambda_1$ 半简单。这一小节讲的是第一条假设被破坏时的情形：$|\lambda_1|=|\lambda_2|>|\lambda_3|$。

    机制：衰减论证断在哪里

    收敛证明的核心是靠 $|\lambda_j/\lambda_1|<1$ 让非主导项指数衰减。现在 $|\lambda_2/\lambda_1|=1$，这一项根本不衰减，它只是在复平面上沿单位圆旋转：

    \[ \frac{A^kx^{(0)}}{\lambda_1^k}=c_1q_1+c_2\underbrace{\left(\frac{\lambda_2}{\lambda_1}\right)^{k}}_{\text{模}=1,\ \text{不衰减}}q_2+O(\rho^k),\qquad \rho=\max_{j\ge3}\left|\frac{\lambda_j}{\lambda_1}\right|<1 \]

    $j\ge3$ 的项照样衰减到 $0$，但 $c_2\omega^kq_2$（记 $\omega=\lambda_2/\lambda_1$）赖着不走且一直在动，所以极限不存在——这就是「收敛性分析变复杂」的确切含义。

    什么时候还能抢救：$\omega$ 是单位根。若 $\omega=e^{2\pi ip/q}$（$\gcd(p,q)=1$），则 $\omega^q=1$，$\omega^k$ 只取 $q$ 个值并以 $q$ 为周期循环。此时整个序列仍不收敛，但按 $k\bmod q$ 抽子序列，$\omega^k$ 就退化成常数：

    \[ x^{(kq+r)}\ \longrightarrow\ \text{方向}\left(c_1q_1+c_2\omega^rq_2\right),\qquad r=0,1,\dots,q-1 \]

    $r$ 取 $q$ 个值即得 $q$ 个不同的极限方向——这就是「分裂成若干收敛到不同向量的子序列」的确切含义：子序列是按 $k\bmod q$ 分类的。反直觉的一点：这些极限方向是 $q_1,q_2$ 的混合，一般根本不是特征向量，所以连「收敛到哪个特征向量」都谈不上。（若 $\omega$ 不是单位根，如 $\omega=e^{i\sqrt2}$，则 $\{\omega^k\}$ 在单位圆上稠密，极限点是一整条连续曲线——连子序列收敛都没有。）

    经典例子逐项看。$A=\begin{bmatrix}0&1\\1&0\end{bmatrix}$：

    \[ \det(A-\lambda I)=\lambda^2-1\ \Longrightarrow\ \lambda_1=1,\ \lambda_2=-1;\qquad q_1=\tfrac{1}{\sqrt2}\binom{1}{1},\quad q_2=\tfrac{1}{\sqrt2}\binom{1}{-1} \] \[ \omega=\frac{\lambda_2}{\lambda_1}=-1=e^{2\pi i\cdot1/2}\ \Longrightarrow\ p=1,\ q=2 \]

    这个 $A$ 作用在向量上就是交换两个分量。取 $x^{(0)}=(1,0)^{\mathsf T}$，迭代变得极其简单：

    用公式验证：$x^{(0)}=\tfrac{1}{\sqrt2}q_1+\tfrac{1}{\sqrt2}q_2$，故 $c_1=c_2=\tfrac{1}{\sqrt2}$，于是

    \[ r=0:\ c_1q_1+c_2\omega^0q_2=(1,0)^{\mathsf T},\qquad r=1:\ c_1q_1+c_2\omega^1q_2=(0,1)^{\mathsf T} \]

    与图完全对上。

    陷阱：表现强烈依赖初始向量

    若初值恰好取成特征向量（如 $x^{(0)}=(1,1)^{\mathsf T}$），它是不动点，迭代老老实实停住，看起来「收敛得很好」。用随机初值则几乎必然撞上周期震荡——这种对初值的病态依赖本身就是失效的信号。

    具体一例（作业 P4）：$A=\begin{bmatrix}\lambda&1\\0&-\lambda\end{bmatrix}$

    取 $\lambda\in\mathbb{C}\setminus\{0\}$。直接平方，交叉项 $\lambda-\lambda$ 恰好消掉：

    \[ A^2=\begin{bmatrix}\lambda&1\\0&-\lambda\end{bmatrix}^{2}=\begin{bmatrix}\lambda^2&0\\0&\lambda^2\end{bmatrix}=\lambda^2I \]

    于是 $A^{2m}=\lambda^{2m}I$、$A^{2m+1}=\lambda^{2m}A$（等价地：最小多项式是 $t^2-\lambda^2$，即 $A$ 是 $\lambda^2I$ 的一个「平方根」）。代入幂法 $x^{(t)}=A^tx^{(0)}/\lVert A^tx^{(0)}\rVert$：

    \[ x^{(2m)}=\frac{x^{(0)}}{\lVert x^{(0)}\rVert}=:u,\qquad x^{(2m+1)}=\frac{Ax^{(0)}}{\lVert Ax^{(0)}\rVert}=:v \]

    序列严格以 $2$ 为周期，在 $u$、$v$ 之间来回跳，永不收敛；只有当 $x^{(0)}$ 本身是特征向量（$u=\pm v$）时它才是不动点。Rayleigh 商同样二周期振荡，一般两个值都不等于 $\pm\lambda$——这与上面图 5 的交换矩阵是同一个机制（两者相似）。

    注意 $A$ 的特征值是 $\lambda$ 与 $-\lambda$，二者互异，故 $A$ 可对角化：这里的失效与重根、亏损都无关，纯粹是模相等造成的，正好与下面「有重数」的情形互为对照。

    情形$(\lambda_2/\lambda_1)^k$ 的行为幂法结果
    $|\lambda_1|>|\lambda_2|$指数衰减到 $0$收敛 ✓
    $\omega$ 是 $q$ 次单位根以 $q$ 为周期循环$q$ 个收敛子序列，方向都不是特征向量
    $\omega$ 非单位根（如 $e^{i\sqrt2}$）在单位圆上稠密完全不收敛

    实际怎么处理。① 移位（shift）：取 $\mu$ 把两者分开，对 $(A-\mu I)$ 用幂法／反幂法。② 块幂法（子空间迭代）：用 $m\ge2$ 列组成块 $X^{(k)}\in\mathbb{R}^{n\times m}$，同时迭代 $X^{(k+1)}=AX^{(k)}$ 并做正交化，收敛的是整个不变子空间 $\operatorname{span}(q_1,q_2)$——模相等对子空间迭代不构成障碍。这正是 QR 方法的思想前身。

    一句话总结

    定理里把条件写成严格不等号 $|\lambda_1|>|\lambda_2|$，不是数学家的洁癖，而是实打实的必要条件：一旦相等，$(\lambda_2/\lambda_1)^k$ 就不再衰减，整个衰减论证立刻失效。

    附注 · 模最大特征值有重数时会怎样（作业 P3）

    上一小节破坏的是 $|\lambda_1|>|\lambda_2|$ 这条假设。定理里还有两条：$A$ 要有 $n$ 个互不相同的特征值，且 $\lambda_1$ 是半简单的。若

    \[ \lambda_1=\lambda_2=\cdots=\lambda_k,\qquad |\lambda_k|>|\lambda_{k+1}| \]

    则「模最大」这一条仍然成立（$\lambda_1$ 的模严格大于其余全部特征值），只是它不再单重。记 $E_{\lambda_1}$ 为 $\lambda_1$ 的特征子空间，分两种情形。

    情形一 · $\lambda_1$ 半简单（几何重数 $=$ 代数重数 $=k$）。把 $x^{(0)}=\sum_ic_iq_i$ 按特征基展开：

    \[ A^tx^{(0)}=\lambda_1^t\Big[\underbrace{\sum_{i=1}^{k}c_iq_i}_{=w}+\sum_{i>k}c_i\Big(\frac{\lambda_i}{\lambda_1}\Big)^tq_i\Big] \]

    括号里第一项 $w$ 是固定的（不随 $t$ 变），第二项按 $|\lambda_{k+1}/\lambda_1|^t$ 指数衰减。于是归一化后

    \[ \frac{A^tx^{(0)}}{\lVert A^tx^{(0)}\rVert}\ \longrightarrow\ \frac{w}{\lVert w\rVert},\qquad w=\sum_{i=1}^{k}c_iq_i\in E_{\lambda_1} \]

    结论：幂法仍然收敛，但收敛到的是 $E_{\lambda_1}$ 中由初始向量决定的那一个向量——一般不是特征向量（除非 $c_1,\dots,c_k$ 里只有一个非零）。注意 Rayleigh 商照样收敛到 $\lambda_1$：特征值求对了，特征向量没求对。收敛速度仍是 $|\lambda_{k+1}/\lambda_1|^t$。

    退化情形：若 $x^{(0)}\in E_{\lambda_1}$ 且 $k\ge2$，则 $A^tx^{(0)}=\lambda_1^tx^{(0)}$，序列原地不动，永远停不到单个特征向量上。

    情形二 · $\lambda_1$ 亏损（几何重数 $<$ 代数重数）。取一个 $k\times k$ 的 Jordan 块 $J=\lambda_1I+N$（$N$ 幂零，$N^k=0$）：

    \[ J^t=\sum_{j=0}^{k-1}\binom{t}{j}\lambda_1^{t-j}N^j\ \Longrightarrow\ \lVert J^t\rVert\sim\binom{t}{k-1}|\lambda_1|^{t-k+1}\sim t^{\,k-1}|\lambda_1|^t \]

    指数增长外面多了一个多项式因子 $t^{k-1}$。归一化后 $x^{(t)}\to N^{k-1}x^{(0)}/\lVert\cdot\rVert\propto e_1$，即 Jordan 块的「顶端」特征向量。所以方向仍然收敛到那个唯一的特征向量，但速度退化成代数速度 $O(1/t)$：$t^{k-1}$ 这个因子只能靠 $t$ 变大来「甩掉」，非主导项与主导项之比 $\sim 1/t$。

    一句话对照

    半简单 $\Rightarrow$ 几何收敛，但方向可能不对；亏损 $\Rightarrow$ 方向对，但只有代数收敛。两条路都拿不到「收敛到某个特征向量」这个结论——定理里「互不相同」和「半简单」都不是摆设。

    补救。① 降阶（deflation）：见下一小节，把 $\lambda_1$ 这一块从 $A$ 里剥掉，再对剩余矩阵用幂法；② 子空间迭代（正交迭代）：一次推进 $k$ 列 $X^{(k+1)}=AX^{(k)}$ 并做正交化，收敛的是整个不变子空间 $E_{\lambda_1}$——重数对子空间迭代不构成障碍，这正是 Krylov / QR 方法的思想来源。

    附注 · 现实中更常见的是「几乎亏损」

    精确亏损（$\lambda_1$ 的几何重数 $\lt$ 代数重数）在数值上很罕见；真正常见的是几乎亏损：另一个特征值就在 $\lambda_1$ 旁边，相距 $\varepsilon$。最简模型是

    \[ A=\begin{bmatrix}\lambda&1\\0&\lambda-\varepsilon\end{bmatrix} \]

    它的两个特征值 $\lambda$ 与 $\lambda-\varepsilon$ 互不相同，所以 $A$ 可对角化、并不亏损。直接算 $A^t$（代 $t=0,1$ 可验证）：

    \[ A^t=\begin{bmatrix}\lambda^t&\dfrac{\lambda^t-(\lambda-\varepsilon)^t}{\varepsilon}\\0&(\lambda-\varepsilon)^t\end{bmatrix} \]

    取最坏初值 $x^{(0)}=(0,1)^{\mathsf T}$，记 $r=(\lambda-\varepsilon)/\lambda$，则方向偏差为

    \[ \frac{x_2^{(t)}}{x_1^{(t)}}=\frac{\varepsilon\,r^{\,t}}{1-r^{\,t}} \]

    分两段看（当 $\varepsilon t\ll|\lambda|$ 时 $r^{\,t}\approx1-\varepsilon t/\lambda$）：

    • $t\ll|\lambda|/\varepsilon$：分母 $\approx\varepsilon t/\lambda$，比值 $\approx\dfrac{\lambda}{t}$ —— 与真亏损的 $1/t$ 完全一样；
    • $t\gg|\lambda|/\varepsilon$：分母 $\to1$，比值 $\approx\varepsilon r^{\,t}$ —— 转成几何衰减。

    实用结论

    交叉点在 $t\sim|\lambda|/\varepsilon$。$\varepsilon$ 越小，「像亏损」的阶段越长 —— 这就是幂法在近似亏损的矩阵上长时间卡住不动的原因，也说明实际观察到的收敛速度常比渐近速率 $|\lambda_{k+1}/\lambda_1|^{t}$ 慢得多。

    数值验证（$\lambda=1$）：$\varepsilon=10^{-3}$ 时 $t=100$ 的偏差 $9.50\times10^{-3}\approx1/t$；$t=10^{4}$ 时 $4.52\times10^{-8}$，与 $\varepsilon(1-\varepsilon)^{t}=4.52\times10^{-8}$ 几乎重合。

    1.5 求次大特征值：降阶（deflation）

    先说要干什么（动机）

    幂法只给你一个特征值：模最大的 $\lambda_1$。你还想要 $\lambda_2$。但你不能直接再跑一次幂法——$A$ 还是那个 $A$，模最大的还是 $\lambda_1$，跑一百遍还是 $\lambda_1$。

    所以必须先把 $\lambda_1$ 从问题里拿掉。这就是「降阶」。难点在于：$\lambda_1$ 不是一个能拧下来的零件，它是矩阵整体表现出来的性质，没法在 $A$ 里「删掉」一个数。

    破局的想法是：$\lambda_1$ 甩不掉，是因为它藏在 $A$ 的坐标系里。换一个坐标系，让它单独待在一个角落，剩下的事就与它无关了。

    具体做法是正交变换。设 $q_1$ 是已知的单位特征向量（$Aq_1=\lambda_1q_1$），在复数域上取 Householder 变换 $H$ 使得

    \[ Hq_1=e_1 \]

    为什么存在这样的 $H$：它是镜面反射

    Householder 变换 $H=I-2uu^{*}$（$\|u\|_2=1$）就是关于法向为 $u$ 的超平面做镜像。镜面反射有个基本能力：能把任意一个单位向量照到任意另一个单位向量。想让 $q_1$ 照到 $e_1$，只要把镜面放在两者的角平分面上：

    \[ u=\frac{q_1-e_1}{\|q_1-e_1\|_2} \]

    所以 $H$ 的存在性不是巧合，是镜面反射的基本几何。工程细节：若 $q_1\approx e_1$，$q_1-e_1$ 会相消得厉害，此时改用 $u\propto q_1+e_1$，代价是 $Hq_1=-e_1$——相位不影响结论（见下面「三个补充」的第 ① 条）。

    于是（$H^{*}$ 表示共轭转置，且 $H^{*}=H^{-1}=H$）

    \[ HAH^{*}=\begin{bmatrix}\lambda_1& *\\ 0&\hat A\end{bmatrix} \]

    为什么是「两边夹」$HAH^{*}$，而不是单边 $HA$

    只有 $HAH^{*}$ 才是相似变换（因为 $H^{*}=H^{-1}$），而相似变换保持特征值不变。单边乘 $HA$ 不是相似——特征值全变，那就白算了。

    这也是必须要求 $H$ 是酉矩阵的原因：只有酉矩阵同时满足 $H^{*}=H^{-1}$（相似，保特征值）与 $\|H\|_2=1$（不放大误差，数值稳定）。

    这个式子在说什么（先看含义，再看推导）

    把向量写成 $\begin{bmatrix}y_1\\y_{2:n}\end{bmatrix}$，乘开就是

    \[ \begin{bmatrix}\lambda_1&r^{\mathsf T}\\0&\hat A\end{bmatrix}\begin{bmatrix}y_1\\y_{2:n}\end{bmatrix}=\begin{bmatrix}\lambda_1y_1+r^{\mathsf T}y_{2:n}\\ \hat Ay_{2:n}\end{bmatrix} \]

    盯住下半部分：$\hat Ay_{2:n}$——它完全不知道 $y_1$ 的存在。后 $n-1$ 个坐标自己演化，第一个坐标爱怎么动都影响不到它们。所以后 $n-1$ 维是一个自成一体的子系统，它的特征值就是 $\lambda_2,\dots,\lambda_n$。

    这一步为什么不显然：只用了一个观察

    基本事实：一个矩阵的第 $1$ 列，就是它作用在 $e_1$ 上的结果。所以只要算出 $HAH^{*}e_1$，第 $1$ 列就出来了。

    而 $H$ 是按 $Hq_1=e_1$ 构造的，两边左乘 $H^{*}$（用 $H^{*}H=I$）立刻得到一把钥匙：

    \[ H^{*}e_1=q_1 \]

    剩下的就是一条链，每一步都是已知条件：

    \[ HAH^{*}e_1=HA\,(\underbrace{H^{*}e_1}_{=\,q_1})=HAq_1=H(\lambda_1q_1)=\lambda_1\underbrace{Hq_1}_{=\,e_1}=\lambda_1e_1 \]

    也就是说，$HAH^{*}$ 的第 1 列被锁死成 $\lambda_1e_1$——$\lambda_1$ 在顶上、下面全是 0。第 1 行没有约束，记作 $*$；右下角那块 $(n-1)\times(n-1)$ 就是 $\hat A$。

    手算走一遍（2×2，数字全列出来）

    取 $A=\begin{bmatrix}2&1\\0&3\end{bmatrix}$。上三角 ⇒ 特征值就是对角元：$\lambda_1=3,\ \lambda_2=2$，对应 $\lambda_1$ 的单位特征向量 $q_1=\tfrac{1}{\sqrt2}\binom{1}{1}=\binom{0.7071}{0.7071}$。

    ① 造 $H$。$u=\dfrac{q_1-e_1}{\|q_1-e_1\|_2}=\binom{-0.3827}{0.9239}$，于是

    \[ H=I-2uu^{\mathsf T}=\begin{bmatrix}0.7071&0.7071\\0.7071&-0.7071\end{bmatrix} \]

    ② 验证 $H$ 确实把 $q_1$ 送到 $e_1$：

    \[ Hq_1=\begin{bmatrix}0.7071&0.7071\\0.7071&-0.7071\end{bmatrix}\binom{0.7071}{0.7071}=\binom{1}{0}=e_1\ \checkmark \]

    ③ 做变换（这个 $H$ 恰好对称，$H^{*}=H$）：

    \[ HAH^{*}=\begin{bmatrix}0.7071&0.7071\\0.7071&-0.7071\end{bmatrix}\begin{bmatrix}2&1\\0&3\end{bmatrix}\begin{bmatrix}0.7071&0.7071\\0.7071&-0.7071\end{bmatrix}=\begin{bmatrix}3&-1\\0&2\end{bmatrix} \]

    结果：左下角是 $0$，$(1,1)$ 是 $\lambda_1=3$，右下角 $\hat A=[2]=\lambda_2$——完全对上。注意这里 $*=-1\ne0$，说明右上角那一块一般不为零（它不影响降阶，因为它不进入 $\hat A$）。

    为什么这就完成了降阶。$HAH^{*}$ 是块上三角矩阵，而块三角矩阵的特征值 = 对角块特征值之并：

    \[ \sigma\!\left(\begin{bmatrix}B_{11}&B_{12}\\0&B_{22}\end{bmatrix}\right)=\sigma(B_{11})\cup\sigma(B_{22}) \]

    补一行证明：这条规则从哪来

    块三角矩阵的行列式会因式分解（按第一块展开即可）：

    \[ \det\!\left(\begin{bmatrix}B_{11}&B_{12}\\0&B_{22}\end{bmatrix}-\lambda I\right)=\det(B_{11}-\lambda I)\cdot\det(B_{22}-\lambda I) \]

    特征多项式被拆成两个因子之积，根就是两边的根之并——这就是「特征值 = 对角块之并」的全部来源。代进我们的情形：

    \[ \det(HAH^{*}-\lambda I)=\det\begin{bmatrix}\lambda_1-\lambda&r^{\mathsf T}\\0&\hat A-\lambda I\end{bmatrix}=(\lambda_1-\lambda)\det(\hat A-\lambda I) \]

    所以 $\sigma(HAH^{*})=\{\lambda_1\}\cup\sigma(\hat A)$。又因为 $H$ 是酉矩阵，$HAH^{*}$ 与 $A$ 酉相似，特征值完全相同。于是

    \[ \sigma(\hat A)=\{\lambda_2,\lambda_3,\dots,\lambda_n\} \]

    这就是「降阶」的全部内容：对一个 $n-1$ 阶的小矩阵 $\hat A$ 跑幂法，就拿到 $\lambda_2$。已知方向 $q_1$ 被「摘掉」了，剩下的问题小一维。重复这个过程就能依次求出 $\lambda_3,\lambda_4,\dots$

    一个已经熟悉的类比

    这和高斯消元是同一件事。LU 分解把矩阵化成三角阵，而三角阵的特征值就是对角元——这个你早就懂了。降阶做的是同一件事，只不过手段换成酉变换（Householder）。必须用酉变换的两个理由：① 相似变换才能让特征值精确不变；② 酉矩阵不放大误差，数值稳定。

    再换个说法：像剥洋葱。每做一次降阶剥掉一层（一个特征值），剩下的问题小一维，重复 $n-1$ 次就拿到全部特征值。注意整个过程中你没动过 $\lambda_1$ 一个指头——它只是被「挪」到了第一个坐标上。

    三个补充（讲义常略，但自己写代码会踩）

    ① 相位不影响结论。实际构造时 $Hq_1$ 可能是 $\sigma e_1$（$|\sigma|=1$）而非恰好 $e_1$。但此时 $H^{*}e_1=\bar\sigma q_1$，代回去得 $\bar\sigma\lambda_1\sigma e_1=\lambda_1e_1$——结论一模一样，不用纠结符号。

    ② 想要 $q_2$ 的话不能直接照抄。若 $\hat Ay=\lambda_2y$，则 $HAH^{*}$ 的特征向量是 $v=\begin{bmatrix}\alpha\\y\end{bmatrix}$，其中 $r^{\mathsf T}$ 是 $HAH^{*}$ 第 1 行的后 $n-1$ 个元素，而

    \[ \alpha=\frac{r^{\mathsf T}y}{\lambda_2-\lambda_1} \]

    再回原坐标 $q_2=H^{*}v$。注意 $\alpha\ne0$ 一般成立——所以不是简单的 $H^{*}\begin{bmatrix}0\\y\end{bmatrix}$。只求 $\lambda_2$ 时 $\hat A$ 单独就够；要特征向量就必须带这个修正。

    ③ 为什么偏偏用 Householder。三个理由缺一不可：必须相似变换才能保住特征值；必须酉变换才能数值稳定（不放大误差）；Householder 能精确地把 $q_1$ 送到坐标轴上，而且 $H^{*}=H^{-1}=H$，$H$ 与 $H^{*}$ 是同一个矩阵，构造只需一次。

    一句话总结

    整条链只用了两个已知条件：$Aq_1=\lambda_1q_1$（$q_1$ 是特征向量）和 $Hq_1=e_1$（$H$ 的构造方式）。没有第三个。

    2.1 基本想法：对 $A^{-1}$ 用幂法

    幂法求的是 $A$ 的模最大特征值。如果改对 $A^{-1}$ 用幂法呢？$A^{-1}$ 的特征值是 $1/\lambda_i$，模最大的是

    \[ \Big|\frac{1}{\lambda_n}\Big|=\frac{1}{|\lambda_n|} \]

    也就是说，对 $A^{-1}$ 用幂法求出的，正是 $A$ 的模最小特征值 $\lambda_n$ 及其特征向量。这就是反幂法（inverse iteration）。

    迭代格式

    \[ \begin{aligned} &A\,y^{(k)}=x^{(k-1)} &&\text{（解线性方程组，而不是求逆）}\\[2pt] &x^{(k)}=\frac{y^{(k)}}{\|y^{(k)}\|_\infty} \end{aligned} \]

    线性方程组用部分主元的 Gauss 消去法求解：先算一次 $PA=LU$，之后每步只是前代 + 回代两个三角方程组。

    代价：第一步 $O(n^3)$，后续每步只要 $O(n^2)$，因为 LU 分解可以反复利用。

    收敛速度由 $A^{-1}$ 的两个模最大特征值之比决定，即

    \[ \left|\frac{\lambda_n}{\lambda_{n-1}}\right| \]

    （$A^{-1}$ 的模最大、次大特征值是 $1/\lambda_n$ 与 $1/\lambda_{n-1}$，比值就是 $|\lambda_n/\lambda_{n-1}|$。）这是一个固定的常数，所以是全局线性收敛。

    2.2 带位移的反幂法

    实际应用中反幂法的主要用途不是「找模最小特征值」，而是求已知特征值对应的特征向量。假设已经得到某个特征值 $\lambda$ 的近似值 $\mu$，就对 $A-\mu I$ 用反幂法：

    带位移的反幂法（shift-and-invert）

    \[ \begin{aligned} &(A-\mu I)\,y^{(k)}=x^{(k-1)}\\[2pt] &x^{(k)}=\frac{y^{(k)}}{\|y^{(k)}\|_\infty} \end{aligned} \]

    其中 $A-\mu I$ 的 LU 分解（部分主元）事先算一次，后续每步复用。

    从收敛速度考虑，$\mu$ 应当尽可能接近 $A$ 的某个特征值。但这会让 $A-\mu I$ 接近奇异，使方程组 $(A-\mu I)y=x$ 非常病态。有意思的是——病态性并不影响收敛速度，而且当 $\mu$ 足够接近某个特征值时，往往一次迭代就能得到相当好的近似特征向量。下面两节解释这两件事。

    2.3 为什么 $(A-\mu I)^{-1}$ 会把最近的 eigenvalue「挑出来」

    这是你最想问的那一步

    为什么 $(\lambda_i-\mu)^{-1}\gg(\lambda_j-\mu)^{-1}$ 就意味着反幂法收敛到离 $\mu$ 最近的那个特征值？

    第 1 步：$A-\mu I$ 和 $A$ 有相同的特征向量。

    设 $A$ 的特征对为 $(\lambda_j,v_j)$，即 $Av_j=\lambda_jv_j$。则

    \[ (A-\mu I)v_j=Av_j-\mu v_j=(\lambda_j-\mu)v_j \]

    两边取逆（只要 $\mu$ 不等于任何 $\lambda_j$，$A-\mu I$ 就非奇异）：

    \[ (A-\mu I)^{-1}v_j=\frac{1}{\lambda_j-\mu}\,v_j \]

    所以 $(A-\mu I)^{-1}$ 的特征值是 $\dfrac{1}{\lambda_j-\mu}$，而特征向量一个都没变，还是 $v_j$。

    第 2 步：把初始向量展开，反复作用。

    设 $\{v_1,\dots,v_n\}$ 线性无关，把 $x^{(0)}$ 展开为

    \[ x^{(0)}=\sum_{j=1}^{n}c_jv_j \]

    连续作用 $k$ 次 $(A-\mu I)^{-1}$：

    \[ (A-\mu I)^{-k}x^{(0)} =\sum_{j=1}^{n}\frac{c_j}{(\lambda_j-\mu)^{k}}\,v_j \]

    第 3 步：提出主导项。设下标 $i$ 是使 $|\lambda_i-\mu|$ 最小的那个（即 $\lambda_i$ 是离 $\mu$ 最近的特征值），把 $i$ 项提出来：

    \[ (A-\mu I)^{-k}x^{(0)} =\frac{1}{(\lambda_i-\mu)^{k}} \Bigg[\;c_i\,v_i+\sum_{j\neq i}c_j\Big(\frac{\lambda_i-\mu}{\lambda_j-\mu}\Big)^{k}v_j\;\Bigg] \]

    第 4 步：看括号里第二项的极限。

    归一化之后，决定方向的正是括号里各项的相对大小。对每个 $j\neq i$：

    \[ \Big|\frac{\lambda_i-\mu}{\lambda_j-\mu}\Big|<1 \iff |\lambda_i-\mu|<|\lambda_j-\mu| \]

    而 $i$ 的定义正是「使 $|\lambda_j-\mu|$ 最小的下标」，所以对所有 $j\neq i$ 这个不等式都成立。于是括号里的第二项指数衰减到零：

    \[ \Bigg[\;c_i v_i+\underbrace{\sum_{j\neq i}c_j\Big(\frac{\lambda_i-\mu}{\lambda_j-\mu}\Big)^{k}v_j}_{\to\,0}\;\Bigg]\ \longrightarrow\ c_i v_i \]

    结论

    $(A-\mu I)^{-k}x^{(0)}$ 的方向收敛到 $v_i$，其中 $i$ 是使 $|\lambda_i-\mu|$ 最小的下标——也就是离位移 $\mu$ 最近的那个特征值。

    用一句话概括这条链：

    \[ \underbrace{|\lambda_i-\mu|\ \text{最小}}_{\text{离 }\mu\text{ 最近}} \iff \underbrace{\big|(\lambda_i-\mu)^{-1}\big|\ \text{最大}}_{(A-\mu I)^{-1}\text{ 的模最大特征值}} \iff \underbrace{\text{幂法收敛到 }v_i}_{\text{反幂法输出}} \]

    顺带得到两个结论：

    • 收敛速度是 $\max_{j\neq i}\big|\frac{\lambda_i-\mu}{\lambda_j-\mu}\big|$。$\mu$ 越接近 $\lambda_i$，这个比值越小，收敛越快。极端情形 $\mu=\lambda_i$ 时，理论上一次回代就给出精确的 $v_i$。
    • 如果 $\mu$ 恰好在两个特征值的中间（$|\lambda_i-\mu|=|\lambda_j-\mu|$），比值等于 $1$，不收敛——这就是「位移不能选在两个特征值正中间」的原因。

    放大多少倍：把每个分量单独算一遍

    上面的推导是「整体」的。真正好用的是一个逐分量的账本。设 $\{v_1,\dots,v_n\}$ 是 $A$ 的一组线性无关的特征向量（$Av_j=\lambda_jv_j$），把当前向量按这组基展开：

    \[ x=\sum_{j=1}^{n}c_jv_j \]

    那么「解一次方程组 $(A-\mu I)y=x$」也就是「乘一次 $(A-\mu I)^{-1}$」，每个分量各自乘上自己的倍数，互不干扰：

    \[ (A-\mu I)^{-1}x=\sum_{j=1}^{n}\frac{c_j}{\lambda_j-\mu}\,v_j =\sum_{j=1}^{n}g_j\,c_jv_j,\qquad g_j:=\frac{1}{|\lambda_j-\mu|} \]

    也就是说：$\mu$ 落在谱上的哪个位置，就等于给每个特征方向发了一个不同的放大倍数 $g_j$——离 $\mu$ 越近的方向，倍数越大。这才是「位移」这个词的字面意思：它不是把矩阵平移一下就完事，而是给谱上各个方向重新分配权重。

    举个数：$\lambda=(1,2,3,4)$，取 $\mu=3.9$（很靠近 $4$）：

    方向特征值 $\lambda_j$距离 $|\lambda_j-\mu|$放大倍数 $g_j=1/|\lambda_j-\mu|$相对目标方向（$\lambda_4$）
    $v_1$$1$$2.9$$0.345$$1/29$
    $v_2$$2$$1.9$$0.526$$1/19$
    $v_3$$3$$0.9$$1.111$$1/9$
    $v_4$$4$$0.1$$10$$1$

    目标方向 $v_4$ 被放大 $10$ 倍，而最强的对手（$v_3$）只被放大 $1.111$ 倍——一次迭代就把「信号/噪声」提高了 $9$ 倍。迭代 $t$ 次就是 $9^{t}$ 倍，$t=4$ 已经 $6561$ 倍。这就是反幂法「只要 $\mu$ 知道得准，几乎一步到位」的全部道理。

    一般地，设 $\lambda_k$ 是离 $\mu$ 最近的特征值（目标），$\lambda_m$ 是次近的（最强的对手），则目标分量与对手分量之比每步乘上

    \[ R=\frac{|c_k|\,g_k}{|c_m|\,g_m} =\frac{|c_k|}{|c_m|}\cdot\frac{|\lambda_m-\mu|}{|\lambda_k-\mu|}, \qquad\text{迭代 }t\text{ 步后为 }R^{t}. \]

    这一个式子就装下了反幂法的全部行为

    1. $\mu$ 越准，收敛越快。$\mu\to\lambda_k$ 时 $|\lambda_k-\mu|\to0$，$R\to\infty$。极限情形 $\mu=\lambda_k$ 时 $A-\mu I$ 奇异、方程无解，但它告诉我们：$\mu$ 只要准到机器精度，一次回代就够了。
    2. 初始向量必须有目标方向的分量。若 $c_k=0$，则 $R=0$，迭代多少次都抓不到 $\lambda_k$，最后收敛到的是「次近的那个」。（这和幂法要求 $\alpha_1\neq0$ 是同一件事。）
    3. $\mu$ 落在两个特征值正中间时 $R=1$，完全不收敛。$|\lambda_k-\mu|=|\lambda_m-\mu|$ 时两个方向同步放大，比例永远不变——这就是「位移不能取在两个特征值中点」的定量版本。

    还有一点值得记住：$R$ 里只出现距离之比，不出现 $\|A\|$、不出现条件数 $\kappa(A-\mu I)$。这就是 §2.4 那条「病态性不影响收敛速度」的雏形——放大的是所有方向的误差，而目标方向的误差放大得更狠，相对关系不变。

    最后，这个式子还解释了Rayleigh 商为什么是天然的 $\mu$：$\mu=x^{*}Ax/x^{*}x$ 是「给定方向、使残量最小」的最优特征值估计，而它的误差是 $O(\theta^{2})$（§2.6 第一块拼图）。把它代进 $R$：

    \[ R=\frac{|\lambda_m-\mu|}{|\lambda_k-\mu|} \ \approx\ \frac{\mathrm{gap}}{W\theta^{2}}, \]

    每步信噪比按 $\theta^{-2}$ 增长，于是夹角每步立方缩小。这就是 RQI 三次收敛的分量版解释，§2.6 会用夹角语言把它写严格。

    2.4 为什么病态性不影响收敛速度

    上一节说 $\mu$ 越接近 $\lambda_i$ 越好，但同时也让 $A-\mu I$ 越病态。直觉上「方程组解不准 → 特征向量也不准」，可实际上讲义指出：病态性放大的误差，恰好落在我们要的那个方向上。

    推导的思路是这样的。

    ① 计算的 LU 分解等价于扰动后的精确分解。设 $(A-\mu I)$ 的部分主元 LU 分解为 $\hat L\hat U$。由 Gauss 消去法的向后误差分析，计算解 $\hat y$ 满足

    \[ (A-\mu I+\Delta A)\,\hat y=x,\qquad \|\Delta A\|\le c\,u\,\|A-\mu I\| \]

    其中 $u$ 是机器精度。这就是「部分主元 Gauss 消去法是数值稳定的」这句话的准确含义：算出来的解，是某个轻微扰动后的方程组的精确解。

    ② 先把「计算解」和「精确解」的差写出来。记 $B=A-\mu I$，设 $w=B^{-1}x$ 是未扰动方程组 $Bw=x$ 的精确解。由 ① 知计算解 $\hat y$ 满足 $(B+\Delta A)\hat y=x$，于是

    \[ \hat y=(B+\Delta A)^{-1}x=\big(I+B^{-1}\Delta A\big)^{-1}B^{-1}x=\big(I+B^{-1}\Delta A\big)^{-1}w. \]

    把 $\big(I+B^{-1}\Delta A\big)^{-1}$ 按 Neumann 级数展开（$\|\Delta A\|$ 很小，级数收敛），只保留一阶项：

    \[ \hat y=w-B^{-1}\Delta A\,w+O\big(\|\Delta A\|^2\big). \]

    于是误差 $\delta:=\hat y-w$ 的一阶近似是

    \[ \delta\ \approx\ -B^{-1}\Delta A\,w. \]

    ③ 把误差按特征子空间分解。利用 $B=P(\Lambda-\mu I)P^{-1}$，即

    \[ B^{-1}=P(\Lambda-\mu I)^{-1}P^{-1}=\sum_{j=1}^{n}\frac{v_jz_j^{*}}{\lambda_j-\mu} \]

    （$z_j^{*}$ 是 $P^{-1}$ 的第 $j$ 行），可以逐项写出 $\delta$ 在 $v_i$ 方向上的分量 $\delta_i$ 和在其余特征子空间上的分量 $\delta_{\perp}$：

    \[ \delta_i=-\frac{z_i^{*}\Delta A\,w}{\lambda_i-\mu},\qquad \delta_{\perp}=-\sum_{j\ne i}\frac{z_j^{*}\Delta A\,w}{\lambda_j-\mu}\,v_j. \]

    现在看两者的量级。当 $\mu$ 很接近 $\lambda_i$ 时，$w$ 本身几乎就是 $v_i$ 方向（系数 $z_i^{*}x/(\lambda_i-\mu)$ 极大），所以 $\|\Delta A\,w\|\approx\|\Delta A\|\,\|w\|$。于是

    \[ |\delta_i|\ \approx\ \frac{1}{|\lambda_i-\mu|}\cdot\big(\text{与 }\Delta A\text{ 同量级的量}\big), \qquad \|\delta_{\perp}\|\ =\ O(\Delta A) \]

    （分母里只有 $|\lambda_i-\mu|$ 会趋于 0；$j\ne i$ 的那些 $|\lambda_j-\mu|$ 都是 $O(1)$，所以 $\delta_{\perp}$ 不被放大。）两者的比值是

    \[ \frac{|\delta_i|}{\|\delta_{\perp}\|}\ \approx\ \frac{1}{|\lambda_i-\mu|}\cdot\frac{1}{c_i} \]

    其中 $c_i$ 是特征向量 $v_i$ 的条件数——它在这里是个常数因子，来自「把 $z_i^{*}$ 坐标换算成 $v_i$ 方向的长度」这一步（$z_i$ 与 $v_i$ 不平行时，两个坐标系的换算就要损失一个 $c_i$）。

    一处容易误读的地方

    讲义原文写的是「记 $\hat y$ 在 $v_i$ 方向上的分量为 $\hat y_i$」，但从上面的推导可以看出：被 $1/|\lambda_i-\mu|$ 放大的不是解本身，而是误差。解 $w$ 的分量当然也很大（$z_i^{*}x/(\lambda_i-\mu)$），可那正是我们要的东西；真正的麻烦在于误差的分量同样被放大。

    所以正确的读法是：$\hat y_i,\hat y_{\perp}$ 应理解为误差 $\delta$ 的两个分量。定性结论完全不变，但这样读就不会觉得「凭什么解的分量跟 $\Delta A$ 同量级」了。

    关键

    当 $\mu\to\lambda_i$ 时，$|\lambda_i-\mu|\to0$，这个比值趋于无穷。也就是说：

    方程组越病态，误差就越大；但误差被放大的方向恰好是 $v_i$ 方向。而我们最终只取 $\hat y$ 的方向作为特征向量的近似——方向恰好是准的。所以

    \[ \text{病态性}\ \longrightarrow\ \text{误差大}\ \longrightarrow\ \text{但误差的方向正是我们要的方向} \]

    于是一次反幂法迭代就足以得到很好的特征向量。

    什么时候这个「幸运」会失效

    上面的分析用到了「单位特征向量 $v_i$ 良态」，即它的条件数 $c_i=\dfrac{\|v_i\|_2\,\|z_i\|_2}{|z_i^{*}v_i|}$ 很小（$z_i$ 是左特征向量）。如果 $v_i$ 本身病态（$c_i$ 很大），这套论证就不成立——此时再做第二次反幂法迭代通常也不会更好，因为误差已经污染了特征子空间本身。

    2.5 初始向量的选取：半次迭代法

    两种常用做法：

    1. 随机向量：用随机数生成，再按 $\infty$-范数单位化。
    2. 「半次迭代法」：利用已有的 LU 分解省掉一半工作。

    先说这里的 $P$ 是什么。带位移反幂法的第一步要解

    \[ (A-\mu I)y^{(1)}=x^{(0)}. \]

    我们手里有的不是 $A-\mu I$ 的 LU 分解，而是它的列主元（部分主元）LU 分解：

    \[ P\,(A-\mu I)=\hat L\hat U \]

    其中 $\hat L$ 是单位下三角阵，$\hat U$ 是上三角阵，而 $P$ 是置换矩阵（permutation matrix）——它记录的是消元过程中做的行交换。于是 $A-\mu I=P^{-1}\hat L\hat U=P^{\mathsf T}\hat L\hat U$，代入方程组得

    \[ P^{\mathsf T}\hat L\hat Uy^{(1)}=x^{(0)} \quad\Longleftrightarrow\quad \hat L\hat Uy^{(1)}=Px^{(0)} \]

    这就是「$\hat L\hat Uy^{(1)}=Px^{(0)}$」里那个 $P$ 的来处：它只是在把「换过行的 LU 分解」还原成原方程组时，把换行操作挪到右端去。

    $P$ 到底是什么：置换矩阵，管的是「行」不是「列」

    • $P$ 的每一行、每一列都恰好有一个 1，其余全为 0。
    • 左乘 $P$（即 $Px$）= 换行；右乘 $P$（即 $x^{\mathsf T}P$）= 换列。这里 $P$ 出现在 $Px^{(0)}$ 的位置，所以它换的是行，不是列。
    • 它是正交阵且 $P^{-1}=P^{\mathsf T}$，$P^{\mathsf T}P=I$。
    • 为什么会出现它：无主元的 Gauss 消去法在第 $k$ 步要拿 $a_{kk}$ 当除数，若它等于 0（或虽不为 0 但很小）消元就会中断，或把误差放大得离谱。所以每一步都在第 $k$ 列的第 $k$ 行及以下挑绝对值最大的元素换到主元位置——每换一次记一个置换矩阵，乘起来就是 $P$。
    • 如果行、列都换（全主元），则写成 $P(A-\mu I)Q=\hat L\hat U$，此时才真的有「列变换」；但全主元要搜索整个子矩阵，代价高，实用中一般只用列主元。

    半次迭代法的技巧。有了 $\hat L\hat Uy^{(1)}=Px^{(0)}$，正常流程是「前代一次 + 回代一次」。但如果把初始向量取成 $\hat L$ 的某一列、再按 $P^{-1}$ 换行，即

    \[ x^{(0)}=P^{-1}\hat L e_k\qquad(e_k\text{ 是第 }k\text{ 个单位向量}) \]

    那么 $Px^{(0)}=\hat Le_k$，前代方程变成 $\hat Lz=\hat Le_k$。而 $\hat L$ 是单位下三角阵，$\hat Le_k$ 恰好就是 $\hat L$ 的第 $k$ 列，这个方程的解一眼就是 $z=e_k$——前代不用算。于是只剩回代

    \[ \hat Uy^{(1)}=e_k. \]

    也就是说：初始向量不需要显式给出，第一次迭代只解「半次」线性方程组。这就是「半次迭代法」这个名字的来处。

    凭什么可以这样挑初始向量？

    这是本节最容易被一眼带过的一步。它其实是三件事拼起来的。

    ① $x^{(0)}$ 本来就是自由的。反幂法的迭代 $x^{(k+1)}=(A-\mu I)^{-1}x^{(k)}$ 只用到 $x^{(0)}$ 的方向——每一轮都要重新单位化，长度会被洗掉。收敛性只要求 $z_1^{*}x^{(0)}\ne 0$（别恰好落在与 $v_1$ 正交的那个超平面里），除此之外 $x^{(0)}$ 取什么都行。所以「把 $x^{(0)}$ 取成某个特定向量」不是额外假设，而是在动用本来就有的自由度。

    ② 但这份自由度是有价的：随手取就要付一次前代。若随手取 $x^{(0)}$（比如 $e_k$ 或随机向量），则 $Px^{(0)}$ 是个任意向量，$\hat Lz=Px^{(0)}$ 必须老老实实做一次前代，代价 $O(n^2)$。既然 $x^{(0)}$ 自由、而前代不自由，那就反过来问：有没有哪个 $x^{(0)}$，能让 $Px^{(0)}$ 恰好等于 $\hat L$ 的某一列？有——

    \[ \hat Lz=\hat Le_k\ \Longrightarrow\ z=e_k\qquad(\hat L\text{ 非奇异，解唯一}) \]

    把这个方程倒过来解就得到 $Px^{(0)}=\hat Le_k$，也就是 $x^{(0)}=P^{-1}\hat Le_k$。所以这个取法不是灵机一动，而是为了让前代免费，反推出的 $x^{(0)}$。一句话概括：这是拿自由度换计算量，不是拿精度换计算量。

    ③ 这样取出来的 $x^{(0)}$ 会不会太「有结构」，不像随机向量那样保险？这是最该担心的点，但三条理由都说不用担心：

    • 随机向量法同样给不出保证。随机取也可能（概率为 0、但并非不可能）落在 $z_1^{*}x^{(0)}=0$ 上。两种取法在这一点上地位完全相同——都是「几乎必然没问题」的工程做法，谁都没有证明。
    • $P^{-1}\hat Le_k$ 不是 $A-\mu I$ 的特征向量。它只有一个 1 和若干个乘子 $l_{ij}$，是个普通的有结构向量；$l_{ij}$ 的取值没有理由与 $A$ 的特征子空间对齐。万一某个 $k$ 不好，$n$ 个候选里换一个就行。
    • 这一步本来就只做一次。「半次迭代法」用在 $\mu$ 已经相当准、只差把特征向量算准的场合。此时 $A-\mu I$ 极度病态，而 §2.4 刚刚说明过：误差被放大的方向恰好是 $v_i$ 方向，方向是准的。起点是不是精确的特征向量，根本不影响结果。

    2.6 Rayleigh 商迭代（RQI）

    迭代格式

    \[ \begin{aligned} &(A-\mu^{(k)}I)\,y^{(k+1)}=x^{(k)}\\[2pt] &x^{(k+1)}=\frac{y^{(k+1)}}{\|y^{(k+1)}\|_2}\\[4pt] &\mu^{(k+1)}=\frac{\big(x^{(k+1)}\big)^{*}A\,x^{(k+1)}}{\big(x^{(k+1)}\big)^{*}x^{(k+1)}} \qquad\text{（Rayleigh 商）} \end{aligned} \]

    即：位移因子每步都用当前的 Rayleigh 商更新。它相当于「反幂法 + 自动寻找最优位移」。

    先把它和 §2.3 的分量账本对上：RQI 每一步做的事，说白了就是

    \[ x^{(k)}=\sum_jc_jv_j \ \xrightarrow{\ (A-\mu^{(k)}I)^{-1}\ }\ \sum_j\frac{c_j}{\lambda_j-\mu^{(k)}}v_j, \]

    目标是让「$\lambda$ 那一项」压过所有其它项。按 §2.3 的记号，每步信噪比乘上

    \[ R_k=\frac{|\lambda_m-\mu^{(k)}|}{|\lambda-\mu^{(k)}|} \ \gtrsim\ \frac{\mathrm{gap}}{W\theta_k^{2}}, \]

    （$\lambda_m$ 是次近特征值，$|\lambda_m-\mu^{(k)}|\approx\mathrm{gap}$；$|\lambda-\mu^{(k)}|\le W\theta_k^{2}$ 来自下面第一块拼图。）也就是说：$\mu^{(k)}$ 每准一个量级，放大倍数就大一个量级，而 $\mu^{(k)}$ 的误差本身又是 $\theta_k^{2}$——两次「平方」叠在一起，就是三次收敛。

    下面把同一件事换成夹角语言，写严格。

    收敛阶：为什么对称情形是三次

    先说清楚这段推导的来源

    讲义 PDF 5 §5.2 对 RQI 只写了一句结论——「局部二次收敛（若 $A$ 具有对称性，则有局部三次收敛）」，并注明是 Homework 07 Problem 04；今天板书第 3 张也只留下了 INVIT / RQIT 两个名字。所以下面这一整段推导是我按标准教材补的（Parlett《The Symmetric Eigenvalue Problem》、Golub & Van Loan 都有），不是老师课上讲的，也不是讲义原文。作业要你证的很可能就是它。

    设当前特征向量近似 $x^{(k)}$ 与真特征向量 $v$ 的夹角为 $\theta_k$。把它按特征基展开：

    \[ x^{(k)}=\cos\theta_k\,v+\sin\theta_k\,w,\qquad w\perp v,\ \|w\|_2=1 \]

    这里 $v$ 是单位特征向量；$w$ 是「错误方向」的单位向量，落在 $v^{\perp}$ 里；$\theta_k$ 就是误差角，$\sin\theta_k$ 度量错误分量的大小。

    第一块拼图：Rayleigh 商的误差为什么是夹角误差的平方

    讲义和板书都没给这一步，但它只有两行。把 $x^{(k)}$ 代进 Rayleigh 商，注意 $x^{*}x=\cos^{2}\theta_k+\sin^{2}\theta_k=1$：

    \[ \mu^{(k)}=(x^{(k)})^{*}Ax^{(k)} =\lambda\cos^{2}\theta_k+(w^{*}Aw)\sin^{2}\theta_k \]

    两边减去 $\lambda$，再用 $\cos^{2}\theta_k=1-\sin^{2}\theta_k$ 消去 $\lambda\cos^2\theta_k$：

    \[ \mu^{(k)}-\lambda=\big(w^{*}Aw-\lambda\big)\sin^{2}\theta_k \]

    这就是「平方」的全部来源——夹角只以 $\sin^{2}\theta_k$ 的形式出现，前面那个括号与 $\theta_k$ 无关。再用 $w^{*}Aw\in[\lambda_{\min},\lambda_{\max}]$（它是单位向量的 Rayleigh 商，必落在谱区间内）压一下：

    \[ |\mu^{(k)}-\lambda|\le W\,\sin^{2}\theta_k\le W\,\theta_k^{2}, \qquad W:=\max\big(|\lambda-\lambda_{\min}|,\ |\lambda_{\max}-\lambda|\big) \]

    $W$ 是谱的宽度。只要 $W$ 有界，就得到 $|\mu^{(k)}-\lambda|=O(\theta_k^{2})$。

    顺带记住：Rayleigh 商为什么总被用来估特征值

    上式其实说明了一件更强的事：Rayleigh 商的误差量级是 $\theta^2$ 而不是 $\theta$。所以特征向量只算到 $10^{-8}$ 的精度时，特征值已经准到 $10^{-16}$。这正是幂法（§1.4）和反幂法都用 Rayleigh 商来估计特征值的原因。

    第二块拼图：$\mathrm{gap}$ 是什么

    定义

    \[ \mathrm{gap}:=\min_{\substack{1\le j\le n\\ \lambda_j\ne\lambda}}|\lambda_j-\lambda| \]

    即目标特征值 $\lambda$ 到其余特征值的最短距离（特征值间隔，spectral gap）。对称情形下 $\lambda=\lambda_1$ 单重时，$\mathrm{gap}=|\lambda_2-\lambda_1|$（前提是特征值已按离 $\lambda_1$ 的远近排过）。$\lambda$ 是单特征值时 $\mathrm{gap}>0$。

    它为什么必然出现：算子 $(A-\mu^{(k)}I)^{-1}$ 作用在 $v^{\perp}$ 上时，把每个特征方向 $u_j$ 按 $1/(\lambda_j-\mu^{(k)})$ 缩放。当 $\mu^{(k)}\to\lambda$ 时，这些缩放因子中最大的那个是

    \[ \max_{j\ne 1}\frac{1}{|\lambda_j-\mu^{(k)}|}\ \approx\ \frac{1}{\mathrm{gap}} \]

    所以 $\|(A-\mu^{(k)}I)^{-1}w\|_2\lesssim 1/\mathrm{gap}$。换句话说，$\mathrm{gap}$ 就是「错误方向被放大多少倍」的倒数：gap 越大，$w$ 被放大得越少，收敛越快。

    而反幂法一步给出

    \[ y^{(k+1)}=(A-\mu^{(k)}I)^{-1}x^{(k)} =\frac{\cos\theta_k}{\lambda-\mu^{(k)}}\,v+\sin\theta_k\,(A-\mu^{(k)}I)^{-1}w \]

    （$v$ 是特征向量，所以 $(A-\mu^{(k)}I)^{-1}v=v/(\lambda-\mu^{(k)})$ 是精确的，没有误差。）于是「错误分量 ÷ 正确分量」的比值是

    \[ \frac{|\sin\theta_k|\cdot\|(A-\mu^{(k)}I)^{-1}w\|}{|\cos\theta_k|\big/|\lambda-\mu^{(k)}|} \ \lesssim\ \theta_k\cdot\frac{|\lambda-\mu^{(k)}|}{\mathrm{gap}} \ \lesssim\ \theta_k\cdot\frac{W\theta_k^{2}}{\mathrm{gap}} =O(\theta_k^{3}) \]

    分子的 $|\sin\theta_k|\cdot\|(A-\mu^{(k)}I)^{-1}w\|$ 是错误分量，分母 $|\cos\theta_k|/|\lambda-\mu^{(k)}|$ 是正确分量；中间用了 $|\cos\theta_k|\approx1$、$\|(A-\mu^{(k)}I)^{-1}w\|\lesssim1/\mathrm{gap}$，最后一步用了上一块的 $|\lambda-\mu^{(k)}|=O(\theta_k^2)$。

    所以 $\theta_{k+1}=O(\theta_k^3)$ —— 三次收敛。

    那 $W$ 和 $\mathrm{gap}$ 这两个常数怎么办

    上面的常数是 $W/\mathrm{gap}$，看起来不太干净。但当 $\theta_k$ 很小的时候，$w$ 主要由离 $\lambda$ 最近的那个特征方向组成，于是 $|w^{*}Aw-\lambda|\to\mathrm{gap}$、$\|(A-\mu^{(k)}I)^{-1}w\|\to1/\mathrm{gap}$——两处 $\mathrm{gap}$ 恰好抵消，得到 $\theta_{k+1}\approx\theta_k^{3}$，连系数都是 1。

    退一步说，即使 $W/\mathrm{gap}$ 不接近 1，它也只是个常数：收敛的「阶」恒为 3，与 gap 无关；gap 只影响常数和「三次收敛盆地」的大小。特征值成簇（gap 极小）时仍然是三次收敛，只是前面的系数很大、初值要选得更准。

    对非对称矩阵，Rayleigh 商不再有「误差是平方」这个性质，一般只有 $|\mu^{(k)}-\lambda|=O(\theta_k)$（一阶）。把它代回同一条推导，比值就退化成 $O(\theta_k\cdot\theta_k)=O(\theta_k^{2})$——二次收敛。这就是讲义那句「局部二次收敛（若 $A$ 具有对称性，则有局部三次收敛）」的来处。

    RQI 的四个坑

    1. 全局收敛性差：初值选得不好可能收敛到别的特征值，甚至不收敛。
    2. 每步 $O(n^3)$：位移每步都变，所以 LU 分解不能复用，必须重算。
    3. 减法相消：计算 $A-\mu^{(k)}I$ 时，$\mu^{(k)}$ 接近 $\lambda$ 会导致有效数字丢失。
    4. 越来越病态：$A-\mu^{(k)}I$ 逐次逼近奇异，解越来越不准。

    但第 3、4 条其实是「良性」的：病态性放大的误差方向正是我们要的 $v$ 方向，所以特征向量的方向仍然准，Rayleigh 商序列的收敛性基本不受影响——这正是 §2.4 那条分析的直接应用。

    补充：用 Schur 分解处理「只求某一个特征向量」

    设已知 $A$ 的 Schur 分解 $A=QTQ^{*}$（$Q$ 酉、$T$ 上三角）。由于 $Q$ 酉，

    \[ (A-\mu I)^{-1}=\big(Q(T-\mu I)Q^{*}\big)^{-1}=Q\,(T-\mu I)^{-1}Q^{*} \]

    所以只需对上三角阵 $T$ 做反幂法。若只想要第 $k$ 个对角元位置的特征向量，可以把右端向量取成只有一个非零分量（比如 $e_k$），那么回代过程中前 $k-1$ 个分量恒为零，只需解一个更小阶数的上三角方程组，最后在解的后面补零即可。这就是「利用三角结构只算一个特征向量」的技巧。

    板书 5（右半张）原文

    就这些。老师只写了「迭代法」这个名字和它的形状（构造一个序列，极限是解），没有给任何具体算法、也没有提收敛条件。下面这张对比表和「四个问题」是讲义 §3.0 的原文，课上没有写。

    方法典型代价问题

    稀疏性被破坏是致命的：一个稀疏矩阵做一步 Gauss 消元就可能变成稠密矩阵。虽然可以通过行列重排（例如把矩阵重排成带状或分块结构）来保住稀疏性，但这不是万能的。

    • 迭代法：按某种规则构造向量序列 $x^{(k)}$，使极限 $x^{*}$ 是 $Ax=b$ 的精确解。

    3.2 存储：COO 与 CSC讲义 §3.0.1

    维度超过百万级别的矩阵称为大型矩阵。稀疏矩阵一般按坐标方式存储。

    COO（Coordinate format）

    存 (行, 列, 值) 三元组，并且按列存储——因为列向量比行向量更常用。存储复杂度 $O(\mathrm{nnz})$，其中 $\mathrm{nnz}$ 是 number of non-zero elements。

    实际应用中是可以存储零元素的：因为要完全不存零元素也有代价——你得先把零元素识别出来。

    CSC（Compressed Sparse Column）

    从 COO 衍生出来，包含三个数组：

    数组长度内容
    values[]$\mathrm{nnz}$所有非零元素的值
    row_indices[]$\mathrm{nnz}$与 values[] 一一对应的行索引
    col_ptr[]$n+1$每列的起始下标（指针数组）；col_ptr[n] 是个哨兵，恒等于 $\mathrm{nnz}$

    values[] 和 row_indices[] 是两根等长的「平铺长条」——把所有非零元按列优先一个接一个排下去。可光看这两根长条，你怎么知道第 $j$ 列的元素是从第几个开始的？col_ptr[] 就是回答这个问题的那个数组。

    col_ptr[] 到底是什么：values[] 上的「切点」

    把 values[] 想成一根长条，col_ptr[] 记录的就是每一刀切在哪里：第 $j$ 刀切在第 $j$ 列的起始位置。$n$ 列需要 $n+1$ 个切点——因为 $n$ 个切点只能切出 $n-1$ 段，想切出 $n$ 段就必须多一个「收尾」的切点。

    于是第 $j$ 列在 values[] 里占据的是一个左闭右开区间：

    \[ \text{第 }j\text{ 列}\ =\ \texttt{values}\big[\ \texttt{col\_ptr}[j]\ ,\ \texttt{col\_ptr}[j+1]\ \big) \]

    这就是「最后一个元素指向最后一个非零元素的后一个位置」的含义：下标从 0 开始，最后一个非零元的下标是 $\mathrm{nnz}-1$，所以「后一个位置」就是 $\mathrm{nnz}$。它不是数据，是个哨兵（sentinel），专门给最后一列当右墙用。

    手算一遍（4 阶，$\mathrm{nnz}=6$）

    取

    \[ A=\begin{bmatrix} 1&&2&\\ &3&&\\ 4&&5&\\ &&&6 \end{bmatrix} \]

    按列优先（先第 0 列从上往下、再第 1 列……）数一遍非零元：

    $j$（列）该列的非零元（行号 : 值）在 values[] 中的下标
    0$0{:}1$、$2{:}4$0, 1
    1$1{:}3$2
    2$0{:}2$、$2{:}5$3, 4
    3$3{:}6$5

    把每一列「第一个元素的下标」抄下来，再在末尾补一个 $\mathrm{nnz}$，就是三个数组：

    \[ \begin{aligned} \texttt{values} &= [\,1,\ 4,\ 3,\ 2,\ 5,\ 6\,]\\ \texttt{row\_indices} &= [\,0,\ 2,\ 1,\ 0,\ 2,\ 3\,]\\ \texttt{col\_ptr} &= [\,0,\ 2,\ 3,\ 5,\ 6\,]\qquad(\text{长度 } n+1=5) \end{aligned} \]

    核对一遍：第 2 列的元素在 values[col_ptr[2] : col_ptr[3]] $=$ values[3:5] $=[2,5]$，对应的行号是 row_indices[3:5] $=[0,2]$ —— 正是 $(0,2)$ 处的 $2$ 和 $(2,2)$ 处的 $5$。✓

    每一列的非零元个数也不用另存，两个相邻切点相减就是：第 2 列有 col_ptr[3] − col_ptr[2] $=5-3=2$ 个。这正是「多存一个元素」换来的便利。

    一句话记住它：col_ptr = 逐列非零元个数的前缀和

    设 $\mathrm{cc}_j$ 为第 $j$ 列的非零元个数，则

    \[ \texttt{col\_ptr}[0]=0,\qquad \texttt{col\_ptr}[j]=\sum_{t\lt j}\mathrm{cc}_t,\qquad \texttt{col\_ptr}[n]=\mathrm{nnz} \]

    上例中逐列个数是 $[2,1,2,1]$，前缀和正好是 $[0,2,3,5,6]$。由此得到两条恒定成立的性质，也是最好的自检条件：

    • col_ptr[] 单调不减，且首项恒为 0；
    • 末项恒为 $\mathrm{nnz}$。

    同样的结构在别处叫别的名字：按行压缩时叫 row_ptr[]（这就是 CSR 格式）；SciPy 的 sparse.csc_matrix 把它叫 indptr。名字不同，东西一样。

    它为什么非要 $n+1$ 个：看 $y=Ax$ 的循环

    用 CSC 做矩阵-向量乘法，内层循环的上界正好是 col_ptr[j+1]：

    \[ \begin{aligned} &\text{for } j=0:n-1\\ &\qquad \text{for } p=\texttt{col\_ptr}[j]\ :\ \texttt{col\_ptr}[j+1]-1\\ &\qquad\qquad y[\texttt{row\_indices}[p]] \mathrel{+}= \texttt{values}[p]\cdot x[j] \end{aligned} \]

    如果 col_ptr[] 只有 $n$ 个元素，那最后一列就没有 col_ptr[n] 当上界，必须单独写成「一直到 $\mathrm{nnz}-1$」——凭空多出一个特例分支。把哨兵 $\texttt{col\_ptr}[n]=\mathrm{nnz}$ 存进去，所有列走同一套代码。这是数值软件里极常见的「用哨兵换掉边界判断」的写法。

    按 CSC 存储时，$y=Ax$ 和 $y=A^{*}x$ 都很容易写出来，但效率糟糕——因为间接寻址是低效的。其中 $y=Ax$ 是最重要的操作。

    3.3 为什么「矩阵-向量乘法」是核心讲义 §3.0.1

    这里有个漂亮的理论依据。由 Cayley–Hamilton 定理（任意复方阵都满足其特征方程）：

    Cayley–Hamilton 定理

    设 $p(\lambda)=\det(\lambda I-A)$ 是 $A$ 的特征多项式，则 $p(A)=0$。

    推论：若 $A$ 非奇异，记 $p(\lambda)=\lambda^{n}+a_{n-1}\lambda^{n-1}+\cdots+a_0$（$a_0=(-1)^n\det A\neq0$），由 $p(A)=0$ 可解出

    \[ A^{-1}=-\frac{1}{a_0}\big(A^{n-1}+a_{n-1}A^{n-2}+\cdots+a_1I\big) \]

    也就是说，$A^{-1}$ 可以写成 $A$ 的 $n-1$ 次多项式。于是解 $Ax=b$ 只需要把 $A$ 的幂次作用在向量上——也就是一连串矩阵-向量乘法，完全不需要显式形成 $A^{-1}$。

    这一点对稀疏矩阵尤其关键：讲义举了一个稀疏矩阵的例子，它的谱分解 $A=\sum_i\lambda_i v_iv_i^{*}$ 中的特征矩阵 $V$ 是稠密的，所以直接求谱分解不可行；但我们可以用幂法迭代收敛出前几个特征值和特征向量——Google 计算 PageRank 用的正是这个方法。

    这就是两部分内容的接口

    第一部分讲的幂法 / 反幂法，每一步只需要一次矩阵-向量乘法（反幂法多一个三角方程组回代）。而稀疏矩阵最擅长的事情恰恰就是「矩阵-向量乘法」。所以：幂法 / 反幂法是稀疏特征值计算的起点，也是 PageRank 这类大规模问题的实际算法。

    3.4 一维 Poisson 方程讲义 §3.0.2

    这一小节没有出现在今天的板书里，是 PDF 3 §3.0.2 的原文。它是第 3 章后面所有迭代法（Jacobi / Gauss-Seidel / SOR）的标准试验矩阵来源，所以值得先看一遍。

    考虑

    \[ -u''(x)=f(x),\quad x\in(0,1),\qquad u(0)=u(1)=0\ \ (\text{Dirichlet 边界条件}) \]

    用中心差分逼近二阶导数（两个差分式相减再除以 $h$）：

    \[ u''(x_i)\approx\frac{u_{i-1}-2u_i+u_{i+1}}{h^{2}} \]

    丢掉截断误差，改写成方程组：

    \[ -u_{i-1}+2u_i-u_{i+1}=h^{2}f_i,\qquad i=1,\dots,n \]

    即三对角方程组 $Tx=b$，其中

    \[ T=\operatorname{tridiag}(-1,\,2,\,-1)\in\mathbb{R}^{n\times n} \]

    $T$ 的谱

    \[ \lambda_k=4\sin^{2}\!\frac{k\pi}{2(n+1)}=2-2\cos\frac{k\pi}{n+1},\qquad k=1,\dots,n \] \[ v_k=\sqrt{\frac{2}{n+1}}\,\Big(\sin\frac{jk\pi}{n+1}\Big)_{j=1}^{n} \]

    （$v_k$ 的第 $j$ 个分量是 $\sqrt{2/(n+1)}\sin(jk\pi/(n+1))$。）

    由于 $T$ 是三对角且对称正定，它的分解有非常简洁的形式：

    • Cholesky 分解 $T=LL^{*}$：$L$ 是下双对角阵；
    • LU 分解：$L$ 是单位下双对角阵，$U$ 是上双对角阵。

    这个结构在后面分析 Jacobi / Gauss-Seidel / SOR 的收敛速度时会被反复用到。

    3.5 二维 Poisson 方程讲义 §3.0.3

    同样没出现在板书里，是 PDF 3 §3.0.3 的原文。

    转向二维情形：

    \[ -\Delta u= -\Big(\frac{\partial^{2}u}{\partial x^{2}}+\frac{\partial^{2}u}{\partial y^{2}}\Big)=f(x,y),\qquad u|_{\partial\Omega}=0 \]

    在 $n\times n$ 的网格上把两个方向的中心差分相加，得到五点差分格式（Poisson 方程的 stencil 是一个「十字」）：

    \[ -u_{i-1,j}-u_{i,j-1}+4u_{i,j}-u_{i+1,j}-u_{i,j+1}=h^{2}f_{i,j} \]

    截断误差仍然是 $O(h^{2})$ 级别。这给出一个含 $n^{2}$ 个未知量、$n^{2}$ 阶的线性方程组，紧凑形式是

    \[ (T\otimes I+I\otimes T)\,u=b \]

    其中 $\otimes$ 是 Kronecker 积。

    系数矩阵 $A=T\otimes I+I\otimes T$ 的性质

    • 与网格顶点的排列次序有关：改变次序会改变 $A$ 的形状，但可以证明特征值不变。
    • 块三对角阵；不看分块的话共有五条对角线上有非零元素，所以是稀疏的。
    • 不可约对角占优。
    • 对称正定。

    利用一维的结论，二维问题的特征值可以直接写出来：

    \[ \lambda_{k,l}=\Big(2-2\cos\frac{k\pi}{n+1}\Big)+\Big(2-2\cos\frac{l\pi}{n+1}\Big),\qquad k,l=1,\dots,n \]

    对应的特征向量是 $v_k\otimes v_l$，即把 $u_{k,l}$ 按列「拉直」得到的 $n^{2}$ 维向量。

    如果边界条件不是 Dirichlet 条件，只需在右端引入一个边界条件矩阵即可。

    3.6 迭代法总论：单步线性定常迭代法讲义 §3.1

    前面几节都在铺垫（存储、Poisson 方程），到这里才真正进入第 3 章的正题。好消息是：所有经典迭代法（Jacobi、Gauss-Seidel、SOR）都只是同一个模板的特例，而这个模板只有一行。

    迭代法的通用格式

    \[ x^{(k)}=Bx^{(k-1)}+c,\qquad k=1,2,\dots \]

    其中 $B$ 叫迭代矩阵，$c$ 叫常数项。给定 $x^{(0)}$，反复代入就得到序列 $x^{(0)},x^{(1)},x^{(2)},\dots$。全部理论都围绕一个问题：这个序列收敛吗？

    第一步：把 $A$ 拆成 $A=M-N$

    给定 $A\in\mathbb{C}^{n\times n}$，把它拆成

    \[ A=M-N \]

    对 $M$ 的要求是两条互相拉扯的条件：

    • $M$ 非奇异且容易求逆（每步迭代都要解一个以 $M$ 为系数的方程组，$M$ 越简单越好）；
    • $M\approx A$，也就是 $N=M-A$ 尽量小（$N$ 越小，迭代矩阵 $B=M^{-1}N$ 越小，收敛越快）。

    这两条是矛盾的——取 $M=A$ 时 $N=0$、一步收敛，可那等于直接解方程；取 $M=I$ 时求逆最便宜，但 $N=I-A$ 可能很大。所有迭代法的差别，就是在这两条之间选的折中点不同。

    讲义给的例子：Toeplitz（Hermite）分解

    把 $A$ 分成 Hermite 部分与反 Hermite 部分：

    \[ A=H+K,\qquad H:=\frac{A+A^{\mathsf H}}{2},\qquad K:=\frac{A-A^{\mathsf H}}{2} \]

    再取

    \[ M:=H+\alpha I,\qquad N:=-K+\alpha I\qquad(\alpha>0) \]

    $\alpha>0$ 是为了保证 $M=H+\alpha I$ 可逆（$H$ 是 Hermite 阵，加 $\alpha I$ 把谱整体右移）。验算一下：

    \[ M-N=(H+\alpha I)-(-K+\alpha I)=H+K=A\quad\checkmark \]

    这个拆法在实际中不常用，但它是「$M$ 取成 $A$ 的一个易求逆的近似」这个思路最干净的示范。

    第二步：从 $Ax=b$ 推出迭代格式

    \[ Ax=(M-N)x=b \ \Longleftrightarrow\ Mx=b+Nx \ \Longleftrightarrow\ x=M^{-1}Nx+M^{-1}b \]

    把这个恒等式改写成迭代式（把右边的 $x$ 换成上一轮的 $x^{(k-1)}$）：

    \[ x^{(k)}=M^{-1}N\,x^{(k-1)}+M^{-1}b \]

    对照通用格式，就得到

    \[ \boxed{\,B=M^{-1}N,\qquad c=M^{-1}b\,} \]

    为什么极限一定是解：自动成立，不需要额外条件

    设 $x^{(k)}\to x^{*}$，在 $x^{(k)}=Bx^{(k-1)}+c$ 两边取极限：

    \[ x^{*}=Bx^{*}+c \]

    而 $c=M^{-1}b$、$B=M^{-1}N$，两边左乘 $M$：

    \[ Mx^{*}=Nx^{*}+b\ \Longleftrightarrow\ (M-N)x^{*}=b\ \Longleftrightarrow\ Ax^{*}=b \]

    所以只要极限存在，它必然是 $Ax=b$ 的解。唯一要讨论的只是「极限存不存在」。

    讲义把这个性质写成：若存在非奇异阵 $G$ 使 $A=G(I-B)$、$b=Gc$，则称迭代法与 $Ax=b$ 相容（等价于 $Ax=b$ 与 $x=Bx+c$ 同解）。从实用角度讲，我们只对相容且收敛的迭代法感兴趣。显然，只要 $A$ 的对角元均非零，Jacobi 和 Gauss-Seidel 都与 $Ax=b$ 相容。

    符号约定：讲义的 $L$、$U$ 带负号

    讲义写的是

    \[ A=D-L-U \]

    其中 $L$ 的元素是 $-a_{ij}\ (i>j)$、$U$ 的元素是 $-a_{ij}\ (i\lt j)$，即

    \[ L=\begin{bmatrix}0&&&\\ -a_{21}&0&&\\ \vdots&\ddots&\ddots&\\ -a_{n1}&\cdots&-a_{n,n-1}&0\end{bmatrix},\qquad U=\begin{bmatrix}0&-a_{12}&\cdots&-a_{1n}\\ &0&\ddots&\vdots\\ &&\ddots&-a_{n-1,n}\\ &&&0\end{bmatrix} \]

    而很多教材写 $A=D+L+U$，那里的 $L$、$U$ 是真正的严格下三角与严格上三角部分。两套记号里的 $L$、$U$ 差一个负号，于是同一个迭代矩阵在两本书里长相不同（例如 $B_J$ 在这里是 $D^{-1}(L+U)=I-D^{-1}A$，在那套记号里是 $D^{-1}(A-D)$）。内容完全一致，只是符号。本文全程跟讲义。

    3.7 Jacobi 迭代法讲义 §3.1.1

    拆法：只保留对角

    取

    \[ D=\operatorname{diag}(a_{11},a_{22},\dots,a_{nn}),\qquad M=D,\qquad N=L+U \]

    也就是 $A=D-(L+U)$，即 $M=D$、$N=L+U$。$D$ 是对角阵，求逆就是取倒数——这是所有拆法里最省的一种。前提是 $a_{ii}\ne0\ (i=1,\dots,n)$，也就是「$A$ 的对角元均非零」。

    \[ Ax=(D-L-U)x=b \ \Longleftrightarrow\ Dx=(L+U)x+b \ \Longleftrightarrow\ x=D^{-1}(L+U)x+D^{-1}b \]

    于是

    \[ \boxed{\ B_{\mathrm{J}}=D^{-1}(L+U),\qquad c_{\mathrm{J}}=D^{-1}b\ } \]

    分量形式（实际写代码时用的就是这个）

    看 $Ax=b$ 的第 $i$ 行：

    \[ \sum_{j=1}^{n}a_{ij}x_j=b_i \quad\Longrightarrow\quad a_{ii}x_i=b_i-\sum_{j\ne i}a_{ij}x_j \]

    把右边的 $x_j$ 全换成上一轮的 $x_j^{(k-1)}$，就得到 Jacobi 迭代法的分量形式：

    \[ x_i^{(k)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}x_j^{(k-1)}\Big), \qquad i=1,2,\dots,n \]

    Jacobi 的招牌性质：所有分量互相独立

    注意上式右边只出现 $x^{(k-1)}$，一个 $x^{(k)}$ 都没有。所以 $x^{(k)}$ 的 $n$ 个分量可以同时、彼此独立地算出来——先算哪个都一样。这在现代硬件上意味着天然可并行（GPU 上一个线程算一个分量）。

    例：二维 Poisson 方程的 Jacobi 单步

    讲义在 §3.0 末尾就用二维 Poisson 方程演示了这一步（应用数值线性代数, 算法 6.2）。由五点型板

    \[ u_{i,j}^{(k+1)}=\frac{1}{4}\Big(u_{i-1,j}^{(k)}+u_{i+1,j}^{(k)}+u_{i,j-1}^{(k)}+u_{i,j+1}^{(k)}+h^{2}f_{i,j}\Big), \qquad h=\frac{1}{n+1} \]

    （$i,j=1,\dots,n$；$u_{0,\cdot},u_{n+1,\cdot},u_{\cdot,0},u_{\cdot,n+1}$ 是边界值，已知。）写成循环就是

    \[ \begin{aligned} &\text{for } i=1:n\\ &\qquad \text{for } j=1:n\\ &\qquad\qquad u_{i,j}^{(k+1)}=\tfrac14\big(u_{i-1,j}^{(k)}+u_{i+1,j}^{(k)}+u_{i,j-1}^{(k)}+u_{i,j+1}^{(k)}+h^{2}f_{i,j}\big)\\ &\qquad \text{end}\\ &\text{end} \end{aligned} \]

    这就是「矩阵-向量乘法是核心」的兑现

    把 $u^{(k)}$ 存成一个补了边界的 $(n+2)\times(n+2)$ 矩阵 $U$，把 $f_{i,j}$ 存成 $n$ 阶矩阵 $F$，则整个 Jacobi 单步就是一条 Matlab 语句：

    U(2:n+1, 2:n+1) = 0.25 * (U(1:n, 2:n+1) + U(3:n+2, 2:n+1) + U(2:n+1, 1:n) + U(2:n+1, 3:n+2) + h^2 * F);

    四个移位相加 = 四个邻居，再除 4、加 $h^2F$。这正是 §3.3 里 Cayley–Hamilton 论证想说明的事：只要 $y=Ax$ 写得快，迭代法就写得快。而这里连「矩阵」都没有显式出现——$A$ 只活在五个下标偏移里。

    别和「Jacobi 方法」搞混（那是 10.27 的内容）

    还有一个也叫 Jacobi 的方法——Jacobi 方法（旋转法），求实对称阵的全部特征值与特征向量（讲义 PDF 6 §6.3，见 10.27 课堂笔记 §4.2）。它迭代的是正交变换 $Q$（$A\to Q^{\mathsf T}AQ$），收敛判据是 $\operatorname{off}(A)\to0$；与本节的 Jacobi 迭代法（解 $Ax=b$，迭代解向量 $x^{(k)}$，判据 $\rho(B)\lt1$）除了名字没有任何关系。复习时先看清楚在讲哪一个。

    3.8 Gauss-Seidel 迭代法讲义 §3.1.2

    唯一的改动：用新值代替旧值

    回到 Jacobi 的分量形式。算第 $i$ 个分量时，$x_1^{(k)},\dots,x_{i-1}^{(k)}$ 已经算出来了，为什么还要用旧的 $x_1^{(k-1)},\dots,x_{i-1}^{(k-1)}$？

    把它们换掉，就得到 Gauss-Seidel 迭代法：

    \[ x_i^{(k)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\lt i}a_{ij}x_j^{(k)}-\sum_{j\gt i}a_{ij}x_j^{(k-1)}\Big), \qquad i=1,2,\dots,n \]

    即：已更新过的分量用新值，还没轮到的用旧值。

    矩阵形式

    把上式的「新值部分」和「旧值部分」分开写，就是

    \[ x^{(k)}=D^{-1}\big(Lx^{(k)}+Ux^{(k-1)}\big)+D^{-1}b \]

    两边左乘 $D$：

    \[ Dx^{(k)}=Lx^{(k)}+Ux^{(k-1)}+b \ \Longleftrightarrow\ (D-L)x^{(k)}=Ux^{(k-1)}+b \]

    由于 $D-L$ 是下三角阵（对角元非零，故非奇异），可以求逆：

    \[ \boxed{\ x^{(k)}=(D-L)^{-1}U\,x^{(k-1)}+(D-L)^{-1}b\ } \]

    即

    \[ B_{\mathrm{GS}}=(D-L)^{-1}U,\qquad c_{\mathrm{GS}}=(D-L)^{-1}b \]

    $(D-L)^{-1}$ 为什么便宜

    $D-L$ 是下三角，解 $(D-L)x^{(k)}=\text{右端}$ 就是一次前代，$O(n^{2})$（稀疏情形 $O(\mathrm{nnz})$）。所以 GS 每一步的代价和 Jacobi 同阶——不是「多花代价换加速」，而是「白捡的加速」。这正是它值得用的原因。

    例：红黑序 Gauss-Seidel

    GS 更快，但把并行性丢了。讲义给了补回来的办法（应用数值线性代数, 算法 6.4）——红黑序：

    • 把网格节点按坐标和的奇偶染色：红节点 $i+j$ 为偶，黑节点 $i+j$ 为奇。
    • 同色节点互不相邻，所以同一色的节点之间没有任何依赖，可以同时更新。
    • 于是：先用黑节点的旧数据更新所有红节点，再用红节点的新数据更新所有黑节点。
    \[ \begin{aligned} &\text{for all red } (i,j)\ (i+j\text{ even}):\\ &\qquad u_{i,j}^{(k+1)}=\tfrac14\big(u_{i-1,j}^{(k)}+u_{i+1,j}^{(k)}+u_{i,j-1}^{(k)}+u_{i,j+1}^{(k)}+h^{2}f_{i,j}\big)\\ &\text{for all black } (i,j)\ (i+j\text{ odd}):\\ &\qquad u_{i,j}^{(k+1)}=\tfrac14\big(u_{i-1,j}^{(k+1)}+u_{i+1,j}^{(k+1)}+u_{i,j-1}^{(k+1)}+u_{i,j+1}^{(k+1)}+h^{2}f_{i,j}\big) \end{aligned} \]

    两个循环内部都可并行，两个循环之间必须串行。既保留了 GS 的加速，又恢复了并行性——这是现代 GPU 上解 Poisson 类问题的标准做法。

    GS 比 Jacobi 快多少：二维 Poisson 的定量结论

    讲义给的是：求解二维 Poisson 问题 Gauss-Seidel 迭代更快，其每步迭代的效果相当于 Jacobi 迭代的两步；对大多数经典问题都是 GS 更快。（§3.3.2 会把这件事量化成「渐近收敛速度正好是两倍」。）

    但「GS 一定比 Jacobi 好」是错的

    讲义明确指出：$B_{\mathrm{J}}=D^{-1}(L+U)$ 与 $B_{\mathrm{GS}}=(D-L)^{-1}U$ 的谱半径之间没有任何必然联系。四种情形都可能出现：Jacobi 收敛而 GS 发散、GS 收敛而 Jacobi 发散、两者都收敛、两者都发散。讲义给了两个反例。

    反例 1：Jacobi 收敛，Gauss-Seidel 发散

    \[ A=\begin{bmatrix}1&2&-2\\1&1&1\\2&2&1\end{bmatrix},\qquad D=\begin{bmatrix}1&&\\&1&\\&&1\end{bmatrix},\quad L=\begin{bmatrix}0&&\\-1&0&\\-2&-2&0\end{bmatrix},\quad U=\begin{bmatrix}0&-2&2\\&0&-1\\&&0\end{bmatrix} \] \[ B_{\mathrm{J}}=D^{-1}(L+U)=\begin{bmatrix}0&-2&2\\-1&0&-1\\-2&-2&0\end{bmatrix} \]

    特征多项式 $\lambda^{3}$，特征值 $0,0,0$，谱半径 $\rho(B_{\mathrm{J}})=0\lt 1$ —— Jacobi 收敛。

    \[ B_{\mathrm{GS}}=(D-L)^{-1}U=\begin{bmatrix}0&-2&2\\0&2&-3\\0&0&2\end{bmatrix} \]

    特征多项式 $\lambda(\lambda-2)^{2}$，特征值 $0,2,2$，谱半径 $\rho(B_{\mathrm{GS}})=2\ge 1$ —— Gauss-Seidel 发散。

    反例 2：Gauss-Seidel 收敛，Jacobi 发散

    \[ A=\begin{bmatrix}2&-1&1\\1&1&1\\1&1&-2\end{bmatrix},\qquad D=\begin{bmatrix}2&&\\&1&\\&&-2\end{bmatrix},\quad L=\begin{bmatrix}0&&\\-1&0&\\-1&-1&0\end{bmatrix},\quad U=\begin{bmatrix}0&1&-1\\&0&-1\\&&0\end{bmatrix} \] \[ B_{\mathrm{J}}=D^{-1}(L+U)=\begin{bmatrix}0&\frac12&-\frac12\\-1&0&-1\\\frac12&\frac12&0\end{bmatrix} \]

    特征多项式 $\lambda\big(\lambda^{2}+\frac54\big)$，特征值 $0,\pm\frac{\sqrt5}{2}i$，谱半径 $\rho(B_{\mathrm{J}})=\frac{\sqrt5}{2}\ge1$ —— Jacobi 发散。

    \[ B_{\mathrm{GS}}=(D-L)^{-1}U=\begin{bmatrix}0&\frac12&-\frac12\\0&-\frac12&-\frac12\\0&\frac12&0\end{bmatrix} \]

    特征多项式 $\lambda\big(\lambda+\frac12\big)^{2}$，特征值 $0,-\frac12,-\frac12$，谱半径 $\rho(B_{\mathrm{GS}})=\frac12\lt 1$ —— Gauss-Seidel 收敛。

    所以「哪个更好」没有普适答案，必须逐个问题算谱半径。而下一节要做的，正是把「算谱半径」这件事变成可操作的判据。

    3.9 收敛的充要条件：$\rho(B)\lt 1$讲义 §3.2.1

    误差方程：把「收敛」化成一个矩阵幂

    设 $x^{*}$ 是 $Ax=b$ 的精确解。由相容性，$x^{*}$ 也满足 $x^{*}=Bx^{*}+c$。把两式相减：

    \[ \begin{aligned} x^{(k)}&=Bx^{(k-1)}+c\\ x^{*}&=Bx^{*}+c \end{aligned} \qquad\Longrightarrow\qquad \underbrace{x^{(k)}-x^{*}}_{=:\,e^{(k)}}=B\big(x^{(k-1)}-x^{*}\big) \]

    定义误差向量 $e^{(k)}:=x^{(k)}-x^{*}$，就得到极简的递推

    \[ \boxed{\ e^{(k)}=Be^{(k-1)}\ \Longrightarrow\ e^{(k)}=B^{k}e^{(0)}\ } \]

    也就是说：迭代法的全部行为，都被 $B$ 的幂次刻画完了。

    两个定理拼起来

    （数值线性代数, 引理 4.2.1）

    单步线性定常迭代法 $x^{(k)}=Bx^{(k-1)}+c$ 收敛的充要条件是

    \[ \lim_{k\to\infty}B^{k}=0_{n\times n} \]

    （因为 $\lim x^{(k)}=x^{*}\iff\lim e^{(k)}=0\iff\lim B^{k}e^{(0)}=0$，对任意 $e^{(0)}$ 成立。）

    （数值线性代数, 定理 2.1.7）

    定义 $A\in\mathbb{C}^{n\times n}$ 的谱半径

    \[ \rho(A):=\max_{1\le i\le n}|\lambda_i(A)| \]

    则对任意 $A\in\mathbb{C}^{n\times n}$，当且仅当 $\rho(A)\lt 1$ 时 $\lim_{k\to\infty}A^{k}=0_{n\times n}$；这也等价于 Neumann 级数 $\sum_{k\ge0}A^{k}$ 收敛（且收敛到 $(I-A)^{-1}$）。

    （数值线性代数, 定理 4.2.1）合起来

    \[ \text{单步线性定常迭代法 } x^{(k)}=Bx^{(k-1)}+c\ \text{收敛} \ \Longleftrightarrow\ \rho(B)\lt 1 \]

    这是整章最重要的一个式子。充要条件，不是充分条件。

    三条推论

    1. 收敛性只取决于迭代矩阵 $B$，与初始向量 $x^{(0)}$、常数项 $c$ 都无关。$x^{(0)}$ 只影响「要迭代多少步」，不影响「收不收敛」。
    2. $\rho(B)$ 越小收敛越快——这是 §3.3 定义「收敛速度」的出发点。
    3. $\rho(B)=1$ 时定理失效：序列可能收敛也可能发散（取决于初值），工程上不敢用，所以实际判据就是严格不等式。

    顺带把 $x^{(k)}$ 显式写出来

    由 $e^{(k)}=B^{k}e^{(0)}$ 与 $x^{*}=(I-B)^{-1}c$（当 $\rho(B)\lt 1$ 时 $(I-B)^{-1}=\sum_{j\ge0}B^{j}$ 存在），可以直接展开：

    \[ x^{(k)}=B^{k}x^{(0)}+\Big(\sum_{j=0}^{k-1}B^{j}\Big)c \]

    这个式子把两件事一次说清：第一项 $B^{k}x^{(0)}$ 是「初值残留」，它按 $B$ 的幂衰减；第二项是「迭代累积」，当 $k\to\infty$ 时趋于 $(I-B)^{-1}c=x^{*}$。收敛速度完全由 $B^{k}\to0$ 的速度决定。

    接下来四节：把「会不会收敛」补成「怎么判断、有多快、能不能更快」

    $\rho(B)\lt1$ 是充要条件，但要算谱半径就得求特征值，等于绕回原问题。下面四节把这条链补完：§3.10 先给可算的停止准则，§3.11 把判据从迭代矩阵 $B$ 搬到系数矩阵 $A$（三层递进：范数 → 对称正定 → 对角占优），§3.12 把收敛速度量化，§3.13 用松弛因子 $\omega$ 把速度再提一个量级。

    这四节都是讲义内容（PDF 3 §3.2.2、§3.2.3、§3.3、§3.4），课上没有讲——今天第 3 章在板书上只有 §3.1 那两行定义式，以及板书独有的 §3.14 迭代精化。

    3.10 误差估计：什么时候可以停讲义 §3.2.2

    §3.9 给的判据 $\rho(B)\lt 1$ 回答的是「会不会收敛」，但实际算的时候还有一个更急的问题：什么时候可以停。迭代法不可能真的跑到无穷次，所以必须能在「还没算出精确解」的前提下，估计出「现在离精确解还有多远」——这就是误差估计，它同时也就是终止条件的来源。

    困难在哪：误差是「不能用误差算的」

    误差向量 $e^{(k)}=x^{(k)}-x^*$ 里的 $x^*$ 正是我们要解的东西，所以 $\|e^{(k)}\|$ 根本算不出来。唯一的出路是绕道：用已经算出来的量——$x^{(k)}$、$x^{(k-1)}$，以及 $\|B\|$——把 $\|e^{(k)}\|$ 卡住。

    下面两条定理就是两条「卡法」。它们的共同前提都是 $\|B\|=q\lt1$（注意：这是范数小于 1，比 $\rho(B)\lt1$ 更强）。

    第一条界：用最初两步

    定理（数值线性代数, 定理 4.2.2）

    若迭代矩阵 $B$ 的范数 $\|B\|=q\lt 1$（根据谱半径定理，这保证了 $\rho(B)\le\|B\|\lt 1$，因而迭代法收敛），则误差向量的范数

    \[ \|e^{(k)}\|=\|x^{(k)}-x^*\|\le\frac{q^k}{1-q}\,\|x^{(1)}-x^{(0)}\| \]

    在实际计算中，定理中的相容范数 $\|\cdot\|$ 通常选用 $\|\cdot\|_1$ 或 $\|\cdot\|_\infty$（因为它们容易计算）。

    证明

    根据之前的结论，我们有 $e^{(k)}=B^ke^{(0)}$。两边取范数，即有

    \[ \|e^{(k)}\|=\|B^ke^{(0)}\|\le\|B\|^k\cdot\|e^{(0)}\|=q^k\|e^{(0)}\| \]

    剩下要估计的是 $\|e^{(0)}\|$。这里有个常用的技巧：把 $x^{(0)}-x^*$ 中间插一个 $x^{(1)}$，再用三角不等式拆开，让「相邻两次的差」和「误差」各出现一次。

    \[ \begin{aligned} \|e^{(0)}\| &=\|x^{(0)}-x^*\|\\ &=\|x^{(0)}-x^{(1)}+x^{(1)}-x^*\|\\ &\le\|x^{(0)}-x^{(1)}\|+\|x^{(1)}-x^*\|\\ &=\|x^{(0)}-x^{(1)}\|+\|Be^{(0)}\| \end{aligned} \]

    其中 $\|x^{(1)}-x^*\|=\|e^{(1)}\|=\|Be^{(0)}\|\le\|B\|\,\|e^{(0)}\|=q\|e^{(0)}\|$。代回去：

    \[ \|e^{(0)}\|\le\|x^{(0)}-x^{(1)}\|+q\|e^{(0)}\| \;\Longrightarrow\; \|e^{(0)}\|\le\frac{1}{1-q}\|x^{(1)}-x^{(0)}\| \]

    因此 $\|e^{(k)}\|\le q^k\|e^{(0)}\|\le\dfrac{q^k}{1-q}\|x^{(1)}-x^{(0)}\|$，命题得证。

    讲义自己的评注

    「上述定理给出的误差估计往往偏高，在实际计算时用它控制迭代次数的效果并不好。」

    原因有两层：① 它只用了最初两步的信息，而收敛过程中后面几步的信息更「值钱」；② 分子上的 $q^k$ 是最坏情形的衰减速度，实际误差常常衰减得更快。

    第二条界：用相邻两步（实用的那条）

    定理（数值线性代数, 定理 4.2.3）

    若迭代矩阵 $B$ 的范数 $\|B\|=q\lt 1$（同样保证了 $\rho(B)\le\|B\|\lt 1$，因而迭代法收敛），则误差向量的范数

    \[ \|e^{(k)}\|=\|x^{(k)}-x^*\|\le\frac{q}{1-q}\,\|x^{(k)}-x^{(k-1)}\| \]

    证明

    \[ \begin{aligned} \|e^{(k)}\| &=\|Be^{(k-1)}\|\\ &\le\|B\|\,\|e^{(k-1)}\|\\ &=q\|e^{(k-1)}\|\\ &=q\|x^{(k-1)}-x^*\|\\ &\le q\left(\|x^{(k-1)}-x^{(k)}\|+\|x^{(k)}-x^*\|\right)\\ &=q\|x^{(k)}-x^{(k-1)}\|+q\|e^{(k)}\| \end{aligned} \]

    于是有 $\|e^{(k)}\|\le\dfrac{q}{1-q}\|x^{(k)}-x^{(k-1)}\|$，命题得证。

    为什么这条才是有用的

    上述定理表明：在 $\|B\|=q\lt 1$ 的前提条件下，当相邻两次的迭代解 $x^{(k-1)}$ 和 $x^{(k)}$ 很接近时，$x^{(k)}$ 与精确解 $x^*$ 也很接近。在实际计算中，这个误差估计用来控制迭代次数（构造终止条件）是非常方便的。

    关键差别在于：定理 4.2.3 右边全部是可算的量——$x^{(k)}$、$x^{(k-1)}$ 都已知，$q=\|B\|$ 事先算一次就行。而定理 4.2.2 右边含 $q^k$，是个随 $k$ 变化的「最坏情形」因子。

    实用终止条件（由定理 4.2.3 直接得到）

    想保证 $\|e^{(k)}\|\le\varepsilon$，只要让

    \[ \|x^{(k)}-x^{(k-1)}\|\le\frac{1-q}{q}\,\varepsilon \]

    即可。注意这不是「$\|x^{(k)}-x^{(k-1)}\|\le\varepsilon$ 就停」——右边还要乘一个因子 $\frac{1-q}{q}$。$q$ 越接近 1（收敛越慢），这个因子越小，也就是必须迭代得更狠才能达到同样的精度，这符合直觉。

    （这一步「把误差界翻译成停止准则」是讲义没有明写的，属于我的补充；讲义原文只说了「用来构造终止条件是非常方便的」。）

    3.11 Jacobi 与 Gauss-Seidel 的收敛性：从 $B$ 转向 $A$讲义 §3.2.3

    §3.9 的充要条件 $\rho(B)\lt 1$ 虽然完整，但用起来很别扭：要判断收敛，就得先算出迭代矩阵 $B$ 的谱半径，而算谱半径本身和求特征值一样难——绕了一圈又回到原问题。这一节要做的，是把判据从「迭代矩阵 $B$」搬到「系数矩阵 $A$」上，因为 $A$ 是给定的，看它比看 $B$ 容易得多。

    这一节是三层递进：先用范数（最容易算），再用对称正定（几何直观），最后用对角占优（最实用）。

    记号（承接 §3.7、§3.8）

    对 Jacobi 迭代法记 $\begin{cases}B^{(1)}=D^{-1}(L+U)\\c^{(1)}=D^{-1}b\end{cases}$，对 Gauss-Seidel 迭代法记 $\begin{cases}B^{(2)}=(D-L)^{-1}U\\c^{(2)}=(D-L)^{-1}b\end{cases}$。

    讲义原话提醒：Jacobi 迭代矩阵 $D^{-1}(L+U)$ 和 Gauss-Seidel 迭代矩阵 $(D-L)^{-1}U$ 的谱半径之间并无直接联系（§3.8 的两个反例就是证据），但是它们的范数之间有一些联系。考虑到 $D^{-1}(L+U)$ 要比 $(D-L)^{-1}U$ 更容易计算，我们可以利用 Jacobi 迭代矩阵构造 Gauss-Seidel 迭代法的收敛条件，从而规避更复杂的计算。

    第一层：范数

    定理（数值线性代数, 定理 4.2.4）

    若 $\|B^{(1)}\|_\infty\lt 1$（这保证了 Jacobi 迭代法收敛），则 $\|B^{(2)}\|_\infty\lt 1$（这说明了 Gauss-Seidel 迭代法也收敛），且 Gauss-Seidel 迭代法的误差向量的范数

    \[ \|e^{(k)}\|_\infty=\|x^{(k)}-x^*\|_\infty\le\frac{\mu^k}{1-\mu}\,\|x^{(1)}-x^{(0)}\|_\infty \]

    其中

    \[ \mu=\max_{1\le i\le n}\left\{\frac{\sum_{j=1}^{i-1}|b_{ij}^{(1)}|}{1-\sum_{j=i+1}^{n}|b_{ij}^{(1)}|}\right\}\le\|B^{(1)}\|_\infty\lt 1 \]

    定理（数值线性代数, 定理 4.2.5）

    若 $\|B^{(1)}\|_1\lt 1$（这保证了 Jacobi 迭代法收敛），则 $\rho(B^{(2)})\lt 1$（这说明了 Gauss-Seidel 迭代法也收敛），且 Gauss-Seidel 迭代法的误差向量的范数

    \[ \|e^{(k)}\|_1=\|x^{(k)}-x^*\|_1\le\frac{\mu^k}{(1-\mu)(1-s)}\,\|x^{(1)}-x^{(0)}\|_1 \]

    其中

    \[ \mu=\max_{1\le j\le n}\left\{\frac{\sum_{i=1}^{j-1}|b_{ij}^{(1)}|}{1-\sum_{i=j+1}^{n}|b_{ij}^{(1)}|}\right\}\le\|B^{(1)}\|_1\lt 1,\qquad s=\max_{1\le j\le n}\left\{\sum_{i=j+1}^{n}|b_{ij}^{(1)}|\right\} \]

    这两条定理在说什么

    一句话：如果 Jacobi 迭代矩阵的（$\infty$-范数或 $1$-范数）小于 1，那么 Gauss-Seidel 一定也收敛。注意结论的强度不同——定理 4.2.4 得到的是 $\|B^{(2)}\|_\infty\lt1$（更强），定理 4.2.5 只得到 $\rho(B^{(2)})\lt1$（够用）。

    式子里那个 $\mu$ 看起来吓人，但它的作用很单纯：它是 $\|B^{(1)}\|$ 的一个「按行（或按列）细分」的版本，且 $\mu\le\|B^{(1)}\|$。把 $b_{ij}^{(1)}$ 想成「第 $i$ 个方程里邻居对它的影响权重」，$\mu$ 就是在衡量「对角元能否压住邻居」。这个形式和后面的对角占优是同一个思想，只是这里用的是 $B$ 的元素、那里用的是 $A$ 的元素。

    第二层：对称正定

    定理（数值线性代数, 定理 4.2.6）

    若 $A$ 是对称矩阵，且对角元均为正数（即 $a_{ii}\gt 0\ (i=1,\dots,n)$），则当且仅当 $A$ 和 $2D-A$ 都正定时 Jacobi 迭代法收敛。

    证明

    记 Jacobi 迭代矩阵为 $B=D^{-1}(L+U)=D^{-1}(D-A)=I-D^{-1}A$。由于 $A$ 对角元均为正数，故 $D=\operatorname{diag}(a_{11},\dots,a_{nn})$ 是一个正定的对角阵。我们可以定义

    \[ D^{\frac12}:=\operatorname{diag}\left(\sqrt{a_{11}},\dots,\sqrt{a_{nn}}\right) \]

    于是有

    \[ B=I-D^{-1}A=D^{-\frac12}\left(I-D^{-\frac12}AD^{-\frac12}\right)D^{\frac12} \]

    可以推出

    \[ \begin{cases} I-B=D^{-\frac12}\left(I-D^{-\frac12}AD^{-\frac12}\right)D^{\frac12}\\[4pt] I+B=D^{-\frac12}\left(2I-D^{-\frac12}AD^{-\frac12}\right)D^{\frac12} \end{cases} \]

    因为 $A$ 是对称阵，所以 $B$ 也是对称阵（因此 $B$ 的特征值均为实数）。我们知道 Jacobi 迭代法收敛，当且仅当迭代矩阵 $B$ 的谱半径 $\rho(B)\lt 1$，也就等价于 $|\lambda_i(B)|\lt 1\ (i=1,\dots,n)$，即等价于

    \[ -1\lt\lambda_i(B)\lt 1\quad(i=1,\dots,n)\qquad(\text{注意到 } B \text{ 的特征值均为实数}) \]

    即等价于 $I-B$ 和 $I+B$ 均正定，即等价于 $D^{-\frac12}AD^{-\frac12}$ 和 $2I-D^{-\frac12}AD^{-\frac12}$ 均正定（相似变换不改变特征值），即等价于 $A$ 和 $2D-A$ 均正定（合同变换不改变正定性）。命题得证。

    讲义这里有一处笔误

    讲义证明的最后一行写的是「即等价于 $A$ 和 $2I-A$ 均正定」，但同一页定理 4.2.6 的正文写的是「$A$ 和 $2D-A$ 都正定」。

    正确的是 $2D-A$：从 $2I-D^{-\frac12}AD^{-\frac12}$ 出发做合同变换，两边乘 $D^{\frac12}$ 得

    \[ D^{\frac12}\left(2I-D^{-\frac12}AD^{-\frac12}\right)D^{\frac12}=2D-A \]

    所以证明末行的 $2I-A$ 应为 $2D-A$（讲义内部自相矛盾，以定理正文为准）。

    定理（数值线性代数, 定理 4.2.7）

    若 $A$ 对称正定，则 Gauss-Seidel 迭代法收敛。或者更一般地，Hermite 正定矩阵 $A\in\mathbb C^{n\times n}$ 的 Gauss-Seidel 迭代法一定收敛。

    邵老师提供的证明（Hermite 正定情形）

    回顾 $A=D-L-U$，$A$ 的 Hermite 性保证了 $U=L^{\mathsf H}$，于是 Gauss-Seidel 迭代矩阵 $B=(D-L)^{-1}U=(D-L)^{-1}L^{\mathsf H}$。

    对于 $B$ 的任意特征对 $(\lambda,x)$，我们都有

    \[ Bx=(D-L)^{-1}L^{\mathsf H}x=\lambda x \;\Longleftrightarrow\; L^{\mathsf H}x=(D-L)\lambda x \]

    左乘 $x^{\mathsf H}$ 即得

    \[ x^{\mathsf H}L^{\mathsf H}x=x^{\mathsf H}D\lambda x-x^{\mathsf H}L\lambda x \;\Longleftrightarrow\; \bar\beta=\alpha\lambda-\beta\lambda \]

    其中 $\begin{cases}\alpha=x^{\mathsf H}Dx\\\beta=x^{\mathsf H}Lx\end{cases}$。因此我们有

    \[ \lambda=\frac{\bar\beta}{\alpha-\beta}=\frac{\operatorname{Re}(\beta)-i\cdot\operatorname{Im}(\beta)}{\alpha-\operatorname{Re}(\beta)-i\cdot\operatorname{Im}(\beta)} \]

    注意到 $A$ 是 Hermite 正定阵，因此对角阵 $D$ 的对角元均为正实数，于是我们有 $\alpha=x^{\mathsf H}Dx\gt 0$。此外我们有

    \[ \begin{aligned} 0 &\lt x^{\mathsf H}Ax\\ &=x^{\mathsf H}\left(D-L-L^{\mathsf H}\right)x\\ &=x^{\mathsf H}Dx-x^{\mathsf H}Lx-x^{\mathsf H}L^{\mathsf H}x\\ &=\alpha-\beta-\bar\beta\\ &=\alpha-2\operatorname{Re}(\beta) \end{aligned} \]

    要证明 $|\lambda|\lt 1$，只需证明 $(\operatorname{Re}(\beta))^2\lt(\alpha-\operatorname{Re}(\beta))^2$，即 $\alpha^2-2\alpha\operatorname{Re}(\beta)+\operatorname{Re}(\beta)^2\gt\operatorname{Re}(\beta)^2$，即只需证明 $\alpha(\alpha-2\operatorname{Re}(\beta))\gt 0$。而这根据前面 $\alpha\gt 0$ 和 $\alpha-2\operatorname{Re}(\beta)\gt 0$ 的结论可知是成立的。

    因此 Gauss-Seidel 迭代格式的系数矩阵 $B=(D-L)^{-1}L^{\mathsf H}$ 的任意特征值 $\lambda$ 都满足 $|\lambda|\lt 1$，这说明 $\rho(B)\lt 1$，因此 Gauss-Seidel 迭代法收敛。

    把两个定理放在一起看

    • 对称正定 ⟹ Gauss-Seidel 收敛，但 Jacobi 不一定（参见 Homework 11 Problem 02）。从这个意义来说，Gauss-Seidel 迭代法要优于 Jacobi 迭代法。
    • 但 Jacobi 收敛也不蕴含 Gauss-Seidel 收敛——§3.8 的第一个反例（$\rho(B_J)=0$ 收敛，$\rho(B_{GS})=2$ 发散）就是反例。

    第三层：对角占优（最实用）

    讲义在这里有一段很关键的「路线说明」：「从上述两个定理可以看到，对 Jacobi 迭代法和 Gauss-Seidel 迭代法收敛性的判别，已经从对迭代矩阵 $B$ 性质的研究转到对系数矩阵 $A$ 性质的研究上来了，这是一个很大的进展。然而矩阵正定性的判别并不很直观，所以要把对判别条件的研究再深入一步。为此我们引进两个定义。」

    定义（对角占优）

    设 $A=[a_{ij}]\in\mathbb R^{n\times n}$。

    • 若对任意 $1\le i\le n$，都有 $|a_{ii}|\ge\sum_{j\ne i}|a_{ij}|$，且至少对一个 $i$ 有严格不等号成立，则称 $A$ 是弱严格对角占优的。
    • 若对任意 $1\le i\le n$，都有 $|a_{ii}|\gt\sum_{j\ne i}|a_{ij}|$，则称 $A$ 是严格对角占优的。

    一句话：「对角线上的元素，压得住同一行其余元素之和」。严格对角占优 = 每一行都压得住；弱严格对角占优 = 每一行都压得住或打平，且至少有一行是真压住。

    定义（可约 / 不可约）

    设 $A=[a_{ij}]\in\mathbb R^{n\times n}$。若存在排列方阵 $P\in\mathbb R^{n\times n}$ 使得

    \[ PAP^{\mathsf T}=\begin{bmatrix}A_{11}&A_{12}\\&A_{22}\end{bmatrix},\qquad A_{11}\in\mathbb R^{r\times r},\quad A_{22}\in\mathbb R^{(n-r)\times(n-r)} \]

    则称 $A$ 是可约的；否则称 $A$ 是不可约的。

    为什么关心这个。若 $A$ 可约，则可将 $Ax=b$ 化为 $PAP^{\mathsf T}Px=Pb$，记 $\begin{cases}Px=y\\Pb=c\end{cases}$，即有

    \[ \begin{bmatrix}A_{11}&A_{12}\\&A_{22}\end{bmatrix}\begin{bmatrix}y_1\\y_2\end{bmatrix}=\begin{bmatrix}c_1\\c_2\end{bmatrix} \]

    利用前代的思想，我们可以先求解 $r$ 阶方程组 $A_{11}y_1=c_1$ 得到 $y_1$，再代入 $A_{12}y_1+A_{22}y_2=c_2$ 得到 $y_2$。这样就将求解一个高阶方程组的问题转化为求解两个低阶方程组——所以可约矩阵在理论上「不算难题」，可以拆开做。

    等价定义。若存在 $\{1,\dots,n\}$ 的两个非空子集 $S_1,S_2$ 使得

    \[ \begin{cases}S_1\cup S_2=\{1,\dots,n\}\\S_1\cap S_2=\emptyset\\a_{ij}=0\quad(\forall\, i\in S_1,\ j\in S_2)\end{cases} \]

    则称 $A$ 是可约的；否则称 $A$ 不可约。（直观：把下标分成两组，让「从 $S_1$ 到 $S_2$」的通道全部断开。）

    定义（不可约对角占优）

    设 $A=[a_{ij}]\in\mathbb R^{n\times n}$。若 $A$ 不可约，且是弱严格对角占优的，则称 $A$ 不可约对角占优。

    例如三对角阵 $T=\begin{bmatrix}2&-1&&\\-1&2&-1&\\&-1&2&-1\\&&-1&2\end{bmatrix}$ 就是不可约对角占优的。

    定理（数值线性代数, 定理 4.2.8）

    设 $A=[a_{ij}]\in\mathbb R^{n\times n}$。若矩阵 $A$ 严格对角占优，或不可约对角占优，则 $A$ 非奇异。

    证明

    设 $A$ 严格对角占优。（反证法）假设 $A$ 奇异，则 $Ax=0_n$ 有非零解 $x$。不妨设 $|x_i|=\|x\|_\infty=1$（即 $x$ 分量的最大模长是 1，对应下标为 $i$），则有

    \[ \begin{aligned} |a_{ii}| &=|a_{ii}x_i|\\ &=\Big|0-\sum_{j\ne i}a_{ij}x_j\Big|\\ &=\Big|\sum_{j\ne i}a_{ij}x_j\Big|\\ &\le\sum_{j\ne i}|a_{ij}|\,|x_j|\\ &\le\sum_{j\ne i}|a_{ij}|\cdot 1\\ &=\sum_{j\ne i}|a_{ij}| \end{aligned} \]

    这与严格对角占优性 $|a_{ii}|\gt\sum_{j\ne i}|a_{ij}|\ (i=1,\dots,n)$ 矛盾，因而 $A$ 非奇异。

    讲义这里有一处笔误

    讲义写的是「（反证法）假设 $A$ 非奇异，则 $Ax=0_n$ 有非零解 $x$」——两个半句自相矛盾：$A$ 非奇异时 $Ax=0$ 只有零解。反证法要假设的是 $A$ 奇异，这样才能推出存在非零解、才能走到矛盾。上面我已按正确的写法列出。

    设 $A$ 不可约对角占优。（反证法）假设 $A$ 奇异，则 $Ax=0_n$ 有非零解 $x$（不妨设 $\|x\|_\infty=1$，即分量最大模长为 1）。定义

    \[ S_1:=\{i:|x_i|=1\},\qquad S_2:=\{1,\dots,n\}\setminus S_1=\{i:|x_i|\lt 1\} \]

    （显然满足 $\begin{cases}S_1\cup S_2=\{1,\dots,n\}\\S_1\cap S_2=\emptyset\end{cases}$）

    显然 $S_1$ 不是空集。而 $S_2$ 也不是空集，这是因为：假设 $S_2$ 为空集，即 $x$ 的所有分量的模长都为 1，则对于任意 $i=1,\dots,n$，都有

    \[ \begin{aligned} |a_{ii}| &=|a_{ii}x_i|=\Big|0-\sum_{j\ne i}a_{ij}x_j\Big|\\ &=\Big|\sum_{j\ne i}a_{ij}x_j\Big|\le\sum_{j\ne i}|a_{ij}|\,|x_j|\\ &=\sum_{j\ne i}|a_{ij}|\cdot 1=\sum_{j\ne i}|a_{ij}| \end{aligned} \]

    即没有一个 $i$ 使得 $|a_{ii}|\gt\sum_{j\ne i}|a_{ij}|$ 严格成立，这与 $A$ 弱严格对角占优矛盾，因而 $S_2$ 不是空集。

    由于 $A$ 不可约，故必定存在 $\begin{cases}i\in S_1\\k\in S_2\end{cases}$ 使得 $a_{ik}\ne 0$。于是有（注意到 $|x_i|=1$ 和 $|x_k|\lt 1$）

    \[ \begin{aligned} |a_{ii}| &=|a_{ii}x_i|=\Big|0-\sum_{j\ne i}a_{ij}x_j\Big|\\ &=\Big|\sum_{j\ne i}a_{ij}x_j\Big|\\ &\le\Big|\sum_{j\in S_1\setminus\{i\}}a_{ij}x_j\Big|+\Big|\sum_{j\in S_2\setminus\{k\}}a_{ij}x_j\Big|+|a_{ik}x_k|\\ &\le\sum_{j\in S_1\setminus\{i\}}|a_{ij}|\,|x_j|+\sum_{j\in S_2\setminus\{k\}}|a_{ij}|\,|x_j|+|a_{ik}|\,|x_k|\\ &\lt \sum_{j\in S_1\setminus\{i\}}|a_{ij}|\cdot 1+\sum_{j\in S_2\setminus\{k\}}|a_{ij}|\cdot 1+|a_{ik}|\cdot 1\\ &=\sum_{j\ne i}|a_{ij}| \end{aligned} \]

    （注意严格不等号来自 $\begin{cases}|a_{ik}|\gt 0\\|x_k|\lt 1\end{cases}$）这与 $A$ 弱严格对角占优矛盾，因而 $A$ 非奇异。

    推论（数值线性代数, 推论 4.2.1）

    设 $A=[a_{ij}]\in\mathbb R^{n\times n}$ 是对称阵（即 $A^{\mathsf T}=A$），且对角元均为正数。若 $A$ 严格对角占优或不可约对角占优，则 $A$ 正定。

    证明

    对于任意 $\lambda\le 0$，考虑矩阵 $A-\lambda I$。显然 $A-\lambda I$ 也是严格对角占优或不可约对角占优的，因此 $A-\lambda I$ 总是非奇异的。表明 $A$ 的特征值均大于 0，即 $A$ 正定。

    「对角元均为正数」这个条件不能省

    因为严格对角占优或不可约对角占优只能保证对角元均非零，即 $|a_{ii}|\gt 0\ (i=1,\dots,n)$——对角线上的元素可以全是负的。所以对称 + 对角占优推不出正定，必须额外加上「对角元为正」。

    定理（数值线性代数, 定理 4.2.9）

    若 $A$ 严格对角占优或不可约对角占优，则 Jacobi 迭代法和 Gauss-Seidel 迭代法都收敛。

    证明

    「$A$ 严格对角占优或不可约对角占优」的条件保证了 $A$ 的对角元均非零，因而 $D$ 和 $D-L$ 都是可逆矩阵。

    先看 Jacobi 迭代法，记 $\begin{cases}B=D^{-1}(L+U)\\c=D^{-1}b\end{cases}$。（反证法）假设 Jacobi 迭代法发散，即 $\rho(B)\ge 1$，即存在 $B$ 的某个特征值 $\lambda$ 满足 $|\lambda|\ge 1$。于是 $A+(\lambda-1)D=\lambda D-L-U$ 也是严格对角占优或不可约对角占优的，因此 $\lambda D-L-U$ 非奇异。由

    \[ \lambda I-B=\lambda I-D^{-1}(L+U)=D^{-1}(\lambda D-L-U) \]

    可知 $\lambda I-B$ 也是非奇异的。这与「$\lambda$ 是 $B$ 的特征值」矛盾，因而 Jacobi 迭代法收敛。

    再看 Gauss-Seidel 迭代法，记 $\begin{cases}B=(D-L)^{-1}U\\c=(D-L)^{-1}b\end{cases}$。（反证法）假设 Gauss-Seidel 迭代法发散，即 $\rho(B)\ge 1$，即存在 $B$ 的某个特征值 $\lambda$ 满足 $|\lambda|\ge 1$。于是 $A+(\lambda-1)(D-L)=\lambda D-\lambda L-U$ 也是严格对角占优或不可约对角占优的，因此 $\lambda D-\lambda L-U$ 非奇异。由

    \[ \lambda I-B=\lambda I-(D-L)^{-1}U=(D-L)^{-1}(\lambda D-\lambda L-U) \]

    可知 $\lambda I-B$ 也是非奇异的。这与「$\lambda$ 是 $B$ 的特征值」矛盾，因而 Gauss-Seidel 迭代法收敛。

    命题得证。

    证明的手法值得单独记一笔

    两处反证用的是同一个套路：要证 $\rho(B)\lt1$，就假设 $|\lambda|\ge1$，然后造一个矩阵 $A+(\lambda-1)\times(\text{某个易处理的三角阵})$，证明它仍然是严格对角占优的，于是非奇异；再用一个恒等式把这个「非奇异」翻译回「$\lambda I-B$ 非奇异」，与 $\lambda$ 是特征值矛盾。

    关键是对角占优这个性质在「加一个对角扰动」下是稳定的：$\lambda D-L-U$ 的对角元被放大成 $\lambda a_{ii}$（$|\lambda|\ge1$ 只会让对角更占优），而非对角元没变。这是整个证明能走通的原因。

    两条更精细的比较（应用数值线性代数）

    • 定理 6.2：若 $A$ 严格对角占优，则 $\|B_{G,S}\|_\infty\le\|B_{\mathrm{Jacobi}}\|_\infty\lt 1$。表明此时 Jacobi 迭代法和 Gauss-Seidel 迭代法都收敛，且对于最坏问题来说，Gauss-Seidel 单步迭代的效果至少不比 Jacobi 单步迭代的效果差。（对于 $A$ 严格列对角占优，即 $A^{\mathsf T}$ 严格对角占优的情况，我们有类似的结论。）
    • 定理 6.3：若 $A$ 不可约对角占优，则 $\rho(B_{G,S})\le\rho(B_{\mathrm{Jacobi}})\lt 1$。表明此时 Jacobi 迭代法和 Gauss-Seidel 迭代法都收敛，且 Gauss-Seidel 单步迭代的效果要比 Jacobi 单步迭代的效果更好。

    讲义特意加了一句提醒：尽管上述结果表明在一定条件下 Gauss-Seidel 迭代法要优于 Jacobi 迭代法，但此结论对于一般的情况并不一定成立。（§3.8 的两个反例就是「一般情况」的证据。）

    3.12 收敛速度：$\rho(B)$ 到底有多快讲义 §3.3

    到这里我们知道了「会不会收敛」（$\rho(B)\lt1$）和「怎么判断」（看 $A$），但还缺一个定量的答案：$\rho(B)=0.9$ 和 $\rho(B)=0.99$ 差多少？要把误差降到 $10^{-6}$ 各需要多少次迭代？这一节给出「收敛速度」的定义，并在二维 Poisson 这个模型问题上把 Jacobi、Gauss-Seidel 的迭代次数算清楚。

    3.12.1 两个定义

    为什么不能直接比较 $\rho(B)$

    $\rho(B)$ 小就收敛快，这个直觉是对的，但它不能直接当速度用：$\rho$ 是「每步误差缩减因子的极限」，而极限是 $k\to\infty$ 才取到的。前几步的实际缩减因子可能和 $\rho$ 差很远（想想 §3.9 里那个 $\rho=0$ 的矩阵：一步就到精确解了，谈不上「每步乘 $\rho$」）。所以要先定义「$k$ 次迭代的平均表现」，再取极限。

    设 $x^*$ 是非奇异线性方程组 $Ax=b$ 的精确解。考虑与 $Ax=b$ 相容的单步线性定常迭代法 $x^{(k)}=Bx^{(k-1)}+c$ 产生的迭代序列 $\{x^{(k)}\}$。若该迭代法收敛，则其极限 $x^*$ 满足 $x^*=Bx^*+c$。定义 $x^{(k)}$ 的误差向量为 $e^{(k)}=x^{(k)}-x^*$。联立

    \[ \begin{cases}x^{(k)}=Bx^{(k-1)}+c\\x^*=Bx^*+c\end{cases} \]

    可得 $e^{(k)}=B\cdot e^{(k-1)}\ (k=1,2,\dots)$。于是我们有

    \[ e^{(k)}=B^ke^{(0)}\quad(k=1,2,\dots)\qquad\Longrightarrow\qquad \|e^{(k)}\|\le\|B^k\|\,\|e^{(0)}\|\quad(k=1,2,\dots) \]

    初始误差 $\|e^{(0)}\|$ 通常是未知的，因此通常用 $\|B^k\|$ 来刻画收敛速度。我们定义 $k$ 次迭代的平均收敛速度

    \[ R_k:=R_k(B)=-\frac1k\log\left(\|B^k\|\right) \]

    这个定义为什么这样写

    把 $\|e^{(k)}\|\le\|B^k\|\|e^{(0)}\|$ 改写成 $\dfrac{\|e^{(k)}\|}{\|e^{(0)}\|}\le\|B^k\|$，再开 $k$ 次方：

    \[ \mu:=\left(\frac{\|e^{(k)}\|}{\|e^{(0)}\|}\right)^{\frac1k}\approx\|B^k\|^{\frac1k}=e^{-R_k} \]

    所以 $R_k$ 的含义是：$\mu$ 是误差范数在 $k$ 次迭代中的平均缩减因子，而 $R_k$ 是它的「每步衰减率」（取了对数）。取对数是为了把「乘性」变成「加性」——$k$ 步的衰减率加起来就是 $kR_k$。$\mu$ 越小则 $R_k$ 越大，收敛越快。

    注意，若迭代法收敛，则 $\lim_{k\to\infty}\|B^k\|\to 0$，因此当 $k$ 充分大时，总有 $R_k\gt 0$。

    一般情况下，$R_k(B)$ 既依赖于 $k$ 又依赖于 $B$，因此计算起来很复杂。但如果 $B$ 是对称矩阵（或 Hermite 阵、或正规矩阵），则有 $\|B^k\|_2=(\rho(B))^k$，此时

    \[ R_k(B)=-\frac1k\log\left(\|B^k\|_2\right)=-\frac1k\cdot k\log\left(\rho(B)\right)=-\log\left(\rho(B)\right) \]

    此时 $R_k(B)$ 仅依赖于 $B$，不依赖于 $k$。

    设有两个迭代法，对应的迭代矩阵分别为 $B^{(1)}$ 和 $B^{(2)}$。若 $R_k(B^{(1)})\gt R_k(B^{(2)})\gt 0$，则我们称前 $k$ 次迭代中 $B^{(1)}$ 对应的迭代法比 $B^{(2)}$ 对应的迭代法收敛速度快。但可能对于某些 $k$ 有 $R_k(B^{(1)})\gt R_k(B^{(2)})$，而对另一些 $k$ 有 $R_k(B^{(1)})\lt R_k(B^{(2)})$，因此为了刻画整个迭代过程的收敛速度，我们自然考虑定义渐近收敛速度

    \[ R_\infty(B):=\lim_{k\to\infty}R_k(B)=-\lim_{k\to\infty}\frac1k\log\left(\|B^k\|\right)=-\lim_{k\to\infty}\log\left(\|B^k\|^{\frac1k}\right) \]

    讲义这里有一处笔误

    讲义原文写的是：「若 $R_k(B^{(1)})\gt R_k(B^{(2)})\gt 0$，则我们称前 $k$ 次迭代中 $B^{(1)}$ 对应的迭代法比 $B^{(2)}$ 对应的迭代法收敛速度慢。」

    应为「快」。因为 $R_k=-\frac1k\log\|B^k\|$，$\|B^k\|$ 越小（收敛越快）则 $R_k$ 越大。上面我已按正确的写法列出。

    定理（数值线性代数, 定理 4.3.1）

    给定 $\begin{cases}A\in\mathbb R^{n\times n}\\b\in\mathbb R^n\end{cases}$（设 $A$ 非奇异），考虑与 $Ax=b$ 相容的单步线性定常迭代法 $x^{(k)}=Bx^{(k-1)}+c$。我们有

    \[ R_\infty(B)=-\log\left(\rho(B)\right) \]

    成立。

    证明

    只需证明 $\lim_{k\to\infty}\|B^k\|^{\frac1k}=\rho(B)$ 即可。

    一方面（下界），因为 $(\rho(B))^k=\rho(B^k)\le\|B^k\|\ (k=1,2,\dots)$，所以

    \[ \rho(B)\le\|B^k\|^{\frac1k}\quad(k=1,2,\dots) \]

    另一方面（上界），对于任意 $\varepsilon\gt 0$，考虑矩阵 $B_\varepsilon=\dfrac{1}{\rho(B)+\varepsilon}B$。显然有 $\rho(B_\varepsilon)\lt 1$，于是有 $\lim_{k\to\infty}B_\varepsilon^k=O_{n\times n}$ 成立。因此存在正整数 $K$ 使得对于任意 $k\gt K$ 都有 $\|B_\varepsilon^k\|\lt 1$ 成立，即有 $\|B^k\|\le(\rho(B)+\varepsilon)^k$ 成立，即有

    \[ \|B^k\|^{\frac1k}\le\rho(B)+\varepsilon \]

    综上所述，对于任意 $\varepsilon\gt 0$ 和足够大的 $k$ 都有 $\rho(B)\le\|B^k\|^{\frac1k}\le\rho(B)+\varepsilon$ 成立。因此 $\lim_{k\to\infty}\|B^k\|^{\frac1k}=\rho(B)$，命题得证。

    这个证明的结构：上下夹逼

    「$\lim\|B^k\|^{1/k}=\rho(B)$」这个结论（Gelfand 公式）的证明是标准的夹逼：

    • 下界只用了一个事实：谱半径不超过任何相容范数，$\rho(B^k)\le\|B^k\|$；
    • 上界用了一个缩放技巧：把 $B$ 除以 $\rho(B)+\varepsilon$ 之后，谱半径严格小于 1，于是幂次趋于零矩阵，所以范数被压到 1 以下，还原回去就得到 $\|B^k\|\le(\rho(B)+\varepsilon)^k$。

    $\varepsilon$ 任意小 ⟹ 上下界夹到一起。这也解释了为什么渐近收敛速度由谱半径、而不是由范数决定：范数只影响前几步的常数，$k$ 次方根会把常数抹平。

    3.12.2 二维 Poisson 方程：三种方法的速度对比

    现在把上面这套用到 §3.5 的二维 Poisson 模型问题上，得到具体的数字。

    二维 Poisson 方程离散化得到的方程：

    \[ h=\frac{1}{n+1} \] \[ 4u_{ij}-u_{i-1,j}-u_{i+1,j}-u_{i,j-1}-u_{i,j+1}=h^2f_{ij}\qquad(1\le i,j\le n) \] \[ \Updownarrow \] \[ T_nU+UT_n=h^2F \] \[ T_n=\begin{bmatrix}2&-1&&\\-1&\ddots&\ddots&\\&\ddots&\ddots&-1\\&&-1&2\end{bmatrix},\quad U=\begin{bmatrix}u_{1,1}&u_{1,2}&\cdots&u_{1,n}\\u_{2,1}&u_{2,2}&\cdots&u_{2,n}\\\vdots&\vdots&&\vdots\\u_{n,1}&u_{n,2}&\cdots&u_{n,n}\end{bmatrix},\quad F=\begin{bmatrix}f_{1,1}&f_{1,2}&\cdots&f_{1,n}\\f_{2,1}&f_{2,2}&\cdots&f_{2,n}\\\vdots&\vdots&&\vdots\\f_{n,1}&f_{n,2}&\cdots&f_{n,n}\end{bmatrix} \] \[ \Updownarrow \] \[ T_{n\times n}\operatorname{vec}(U)=h^2\operatorname{vec}(F) \]

    其中

    \[ T_{n\times n}:=(I_n\otimes T_n+T_n\otimes I_n)=\begin{bmatrix}T_n&&&\\&T_n&&\\&&\ddots&\\&&&T_n\end{bmatrix}+\begin{bmatrix}2I_n&-I_n&&\\-I_n&\ddots&\ddots&\\&\ddots&\ddots&-I_n\\&&-I_n&2I_n\end{bmatrix} \]

    记 $A:=T_{n\times n}=D-L-U$（注意其中 $D=4I$）。Jacobi 迭代法计算模型问题的迭代矩阵和常数列为

    \[ \begin{cases}B=D^{-1}(L+U)=D^{-1}(D-A)=I-D^{-1}A=I-\left(\frac14I\right)A=I-\frac14A\\[4pt]c=D^{-1}b=\left(\frac14I\right)h^2f=\frac{h^2}{4}f\end{cases} \]

    考虑 $I-\frac14A$ 的结构：

    \[ I_{n^2}-\frac14A=\frac14\begin{bmatrix}2I_n-T_n&I_n&&\\I_n&\ddots&\ddots&\\&\ddots&\ddots&I_n\\&&I_n&2I_n-T_n\end{bmatrix} \] \[ \text{其中}\quad T_n=\begin{bmatrix}2&-1&&\\-1&\ddots&\ddots&\\&\ddots&\ddots&-1\\&&-1&2\end{bmatrix},\qquad 2I_n-T_n=\begin{bmatrix}0&1&&\\1&\ddots&\ddots&\\&\ddots&\ddots&1\\&&1&0\end{bmatrix} \]

    于是其迭代格式 $u^{(k)}=Bu^{(k-1)}+c$ 可表示为

    \[ u^{(k)}=Bu^{(k-1)}+c=\left(I-\frac14A\right)u^{(k-1)}+\frac{h^2}{4}f \] \[ \Updownarrow \] \[ u_{ij}^{(k)}=\frac14\left(u_{i-1,j}^{(k-1)}+u_{i,j-1}^{(k-1)}+u_{i+1,j}^{(k-1)}+u_{i,j+1}^{(k-1)}\right)+\frac{h^2}{4}f_{ij}\qquad(i,j=1,\dots,n) \]

    其中边界值 $u_{i,0}=u_{i,n+1}=u_{0,j}=u_{n+1,j}=0\ (i,j=1,\dots,n)$ 在迭代过程中不改变。总之，我们有迭代公式

    \[ \begin{cases}u_{ij}^{(k)}=\frac14\left(u_{i-1,j}^{(k-1)}+u_{i,j-1}^{(k-1)}+u_{i+1,j}^{(k-1)}+u_{i,j+1}^{(k-1)}\right)+\frac{h^2}{4}f_{ij}&(i,j=1,\dots,n)\\[4pt]u_{i,0}^{(k)}=u_{i,n+1}^{(k)}=u_{0,j}^{(k)}=u_{n+1,j}^{(k)}=0\end{cases} \]

    Jacobi 的谱半径。迭代矩阵 $B=I-\frac14A$ 的特征值为

    \[ \begin{aligned} \lambda_{p,q}(B) &=1-\frac14\lambda_{p,q}(A)\\ &=1-\frac14\cdot 2\left(2-\cos\left(\frac{p\pi}{n+1}\right)-\cos\left(\frac{q\pi}{n+1}\right)\right)\\ &=\frac12\left(\cos\left(\frac{p\pi}{n+1}\right)+\cos\left(\frac{q\pi}{n+1}\right)\right) \end{aligned} \]

    因此谱半径为

    \[ \begin{aligned} \rho(B) &=\max_{1\le p,q\le n}\left|\lambda_{p,q}(B)\right|\\ &=\max_{1\le p,q\le n}\left|\frac12\left(\cos\left(\frac{p\pi}{n+1}\right)+\cos\left(\frac{q\pi}{n+1}\right)\right)\right|\\ &=\frac12\left\{\max_{1\le p\le n}\left|\cos\left(\frac{p\pi}{n+1}\right)\right|+\max_{1\le q\le n}\left|\cos\left(\frac{q\pi}{n+1}\right)\right|\right\}\\ &=\frac12\left(\cos\left(\frac{\pi}{n+1}\right)+\cos\left(\frac{\pi}{n+1}\right)\right)\\ &=\cos\left(\frac{\pi}{n+1}\right)=\cos(h\pi)\qquad\left(\text{注意 } h=\frac{1}{n+1}\right) \end{aligned} \]

    因此 Jacobi 迭代法求解模型问题的渐近收敛速度为

    \[ \begin{aligned} R_\infty(B) &=-\log\left(\rho(B)\right)=-\log\left(\cos(h\pi)\right)\\ &=-\log\left(\sqrt{1-(\sin(h\pi))^2}\right)=-\frac12\log\left(1-(\sin(h\pi))^2\right)\\ &\sim-\frac12\cdot\left(-(\sin(h\pi))^2\right)\sim-\frac12\cdot\left(-(h\pi)^2\right)\\ &=\frac12\pi^2h^2\qquad(h\to0) \end{aligned} \]

    Gauss-Seidel 的谱半径。Gauss-Seidel 迭代法的迭代格式为

    \[ u^{(k)}=(D-L)^{-1}Uu^{(k-1)}+(D-L)^{-1}b \;\Longleftrightarrow\; u^{(k)}=D^{-1}Lu^{(k)}+D^{-1}Uu^{(k-1)}+D^{-1}b \]

    迭代矩阵 $B^{(2)}=(D-L)^{-1}U$ 的特征值 $\lambda$ 满足

    \[ \begin{cases}\lambda\xi_{i,j}=\frac14\left(\lambda\xi_{i-1,j}+\lambda\xi_{i,j-1}+\xi_{i+1,j}+\xi_{i,j+1}\right)\\\xi_{i,0}=\xi_{i,n+1}=\xi_{0,j}=\xi_{n+1,j}=0\end{cases} \]

    设 $\lambda\ne 0$，作变换 $\xi_{i,j}=\lambda^{\frac{i+j}{2}}v_{i,j}$ 可得

    \[ \begin{aligned} \lambda\xi_{i,j} &=\lambda\cdot\lambda^{\frac{i+j}{2}}v_{i,j}=\lambda^{\frac{i+j}{2}+1}v_{i,j}\\ &=\frac14\left(\lambda\xi_{i-1,j}+\lambda\xi_{i,j-1}+\xi_{i+1,j}+\xi_{i,j+1}\right)\\ &=\frac14\left(\lambda\cdot\lambda^{\frac{i-1+j}{2}}v_{i-1,j}+\lambda\cdot\lambda^{\frac{i+j-1}{2}}v_{i,j-1}+\lambda^{\frac{i+1+j}{2}}v_{i+1,j}+\lambda^{\frac{i+j+1}{2}}v_{i,j+1}\right)\\ &=\frac14\lambda^{\frac{i+j}{2}+\frac12}\left(v_{i-1,j}+v_{i,j-1}+v_{i+1,j}+v_{i,j+1}\right) \end{aligned} \]

    于是有

    \[ \lambda^{1}v_{i,j}=\frac14\left(v_{i-1,j}+v_{i,j-1}+v_{i+1,j}+v_{i,j+1}\right) \]

    回忆起 Jacobi 迭代法应用到二维 Poisson 问题得到的迭代公式，我们知道迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的特征值 $\mu$ 满足

    \[ \begin{cases}\mu v_{i,j}=\frac14\left(v_{i-1,j}+v_{i,j-1}+v_{i+1,j}+v_{i,j+1}\right)&(i,j=1,\dots,n)\\v_{i,0}=v_{i,n+1}=v_{0,j}=v_{n+1,j}=0\end{cases} \]

    对比发现（Young 关系式的特例）

    $\lambda\ne 0$ 是 Gauss-Seidel 迭代矩阵 $B^{(2)}=(D-L)^{-1}U$ 的非零特征值，当且仅当 $\mu=\lambda^{\frac12}$ 是 Jacobi 迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的非零特征值。

    也就是 $\lambda=\mu^2$：Gauss-Seidel 的特征值是 Jacobi 特征值的平方。取模之后谱半径自然也平方。

    回忆 Jacobi 迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的谱半径 $\rho(B^{(1)})=\cos\left(\frac{\pi}{n+1}\right)=\cos(h\pi)$，因此 Gauss-Seidel 迭代法求解模型问题的渐近收敛速度为

    \[ \begin{aligned} R_\infty(B^{(2)}) &=-\log\left(\rho(B^{(2)})\right)=-\log\left(\rho^2(B^{(1)})\right)\\ &=-2\log\left(\rho(B^{(1)})\right)=-2\log\left(\cos(h\pi)\right)\\ &\sim 2\cdot\frac12\pi^2h^2=\pi^2h^2\qquad(h\to0) \end{aligned} \]

    结论：Gauss-Seidel 恰好快一倍

    $\rho(B^{(2)})=\rho^2(B^{(1)})$ 这个关系很漂亮：谱半径平方，等价于渐近收敛速度翻倍。所以

    \[ R_\infty(B^{(2)})=2R_\infty(B^{(1)}) \]

    即「Gauss-Seidel 迭代法求解模型问题的渐近收敛速度是 Jacobi 迭代法的两倍」。

    把三种方法排在一起

    方法谱半径 $\rho$渐近收敛速度 $R_\infty$量级
    Jacobi$\cos(h\pi)$$\frac12\pi^2h^2$$O(h^2)$
    Gauss-Seidel$\cos^2(h\pi)$$\pi^2h^2$$O(h^2)$（常数 ×2）
    SOR（最佳 $\omega$）$\dfrac{1-\sin(h\pi)}{1+\sin(h\pi)}$$2\pi h$$O(h)$

    前两个都是 $O(h^2)$，只是常数差 2 倍；而 SOR 是 $O(h)$——量级不同。这解释了为什么 SOR 在实际中如此重要：$h$ 越小（网格越细），差距越大。$h=10^{-2}$ 时，SOR 的收敛速度大约是 Gauss-Seidel 的 $64$ 倍。

    3.13 超松弛迭代法（SOR）讲义 §3.4

    上一节看到 Gauss-Seidel 只比 Jacobi 快一倍，而且两者都是 $O(h^2)$——网格加密一倍，迭代次数就要增加四倍，这个代价在高分辨率下无法接受。SOR 的思路是：既然 Gauss-Seidel 每一步都朝「正确的方向」走，那就干脆多走一点。这个「多走一点」的系数就是松弛因子 $\omega$，而最优的 $\omega$ 能把收敛速度从 $O(h^2)$ 提升到 $O(h)$。

    3.13.1 迭代格式

    考虑一个满足「$A$ 对角元均非零」的非奇异线性方程组 $Ax=b$。Gauss-Seidel 迭代法的迭代格式为

    \[ x^{(k)}=(D-L)^{-1}Ux^{(k-1)}+(D-L)^{-1}b \;\Longleftrightarrow\; x^{(k)}=D^{-1}Lx^{(k)}+D^{-1}Ux^{(k-1)}+D^{-1}b \]

    现令修正项 $\Delta x^{(k-1)}=x^{(k)}-x^{(k-1)}$，则我们有

    \[ \Delta x^{(k-1)}=x^{(k)}-x^{(k-1)}=\left(D^{-1}Lx^{(k)}+D^{-1}Ux^{(k-1)}+D^{-1}b\right)-x^{(k-1)} \]

    若我们在修正项 $\Delta x^{(k-1)}$ 的前面加上一个系数 $\omega\gt 0$，便得到松弛迭代法的迭代格式：

    \[ \begin{aligned} x^{(k)} &=x^{(k-1)}+\omega\Delta x^{(k-1)}\\ &=x^{(k-1)}+\omega\left[\left(D^{-1}Lx^{(k)}+D^{-1}Ux^{(k-1)}+D^{-1}b\right)-x^{(k-1)}\right]\\ &=(1-\omega)x^{(k-1)}+\omega\left(D^{-1}Lx^{(k)}+D^{-1}Ux^{(k-1)}+D^{-1}b\right) \end{aligned} \]

    松弛因子 $\omega$ 的三种取值

    • 当 $\omega\gt 1$ 时，称为超松弛迭代法（简称为 SOR 迭代法）
    • 当 $\omega=1$ 时，就是 Gauss-Seidel 迭代法
    • 当 $\omega\lt 1$ 时，称为低松弛迭代法

    直观：Gauss-Seidel 每步只走「到中间解」的那一段，$\omega\gt1$ 就是朝着同一个方向多走一段（外推）；$\omega\lt1$ 则是少走一点（阻尼）。

    显然 $I-\omega D^{-1}L$ 是下三角，且对角元均非零（前提条件是 $A$ 对角元均非零），因此它是可逆的。于是我们可以改写松弛迭代法的迭代格式：

    \[ \begin{aligned} x^{(k)} &=(I-\omega D^{-1}L)^{-1}\left[\left(D^{-1}U+(1-\omega)I\right)x^{(k-1)}+\omega D^{-1}b\right]\\ &=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]x^{(k-1)}+\omega(D-\omega L)^{-1}b \end{aligned} \] \[ \Longleftrightarrow\quad x^{(k)}=B_\omega x^{(k-1)}+c_\omega \]

    其中

    \[ \begin{cases}B_\omega=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]\\c_\omega=\omega(D-\omega L)^{-1}b\end{cases} \]

    为什么 $I-\omega D^{-1}L$ 可逆就够了

    把 $x^{(k)}$ 从右边解出来的那一步，需要求 $(I-\omega D^{-1}L)^{-1}$。而 $I-\omega D^{-1}L$ 是对角元全为 1 的下三角阵，它的逆就是做一次前代——和 Gauss-Seidel 里 $(D-L)^{-1}$ 是同一件事，成本一样低。这就是为什么 $\omega$ 的引入不增加每步的计算量：SOR 每步的代价和 Gauss-Seidel 相同，只是「走的距离」变了。

    3.13.2 收敛性分析

    先记住这个最重要的结论

    对一般矩阵，$\omega$ 的取值范围是 $0\lt\omega\lt2$（超出这个范围一定发散）；对对称正定矩阵，$\omega\in(0,2)$ 是充要的。

    定理（超松弛迭代法收敛的必要条件, 数值线性代数, 定理 4.4.2）

    超松弛迭代法收敛的必要条件是 $0\lt\omega\lt 2$。

    证明

    设超松弛迭代法收敛，即等价于 $\rho(B_\omega)\lt 1$。设 $\lambda_1,\dots,\lambda_n$ 是 $B_\omega$ 的 $n$ 个特征值，则我们必须有

    \[ \begin{aligned} \left|\det(B_\omega)\right| &=\left|\det\left\{(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]\right\}\right|\\ &=\left|\det\left\{(I-\omega D^{-1}L)^{-1}\left[(1-\omega)I+\omega D^{-1}U\right]\right\}\right|\\ &=\left|\det\left\{(I-\omega D^{-1}L)^{-1}\right\}\right|\cdot\left|\det\left\{(1-\omega)I+\omega D^{-1}U\right\}\right|\\ &=|1^n|\cdot|(1-\omega)^n|\\ &=|(1-\omega)^n|\\ &=|\lambda_1\cdots\lambda_n|\\ &=|\lambda_1|\cdots|\lambda_n|\\ &\lt 1^n=1 \end{aligned} \]

    根据 $|(1-\omega)^n|\lt 1$ 可知 $|1-\omega|\lt 1$，即有 $0\lt\omega\lt 2$，命题得证。

    这个证明只用了一个事实：行列式 = 特征值之积

    推理链条是：收敛 ⟹ 所有 $|\lambda_i|\lt1$ ⟹ $|\det B_\omega|=\prod|\lambda_i|\lt1$；另一方面直接算行列式得 $|\det B_\omega|=|1-\omega|^n$（因为 $(I-\omega D^{-1}L)^{-1}$ 是单位下三角，行列式为 1；$(1-\omega)I+\omega D^{-1}U$ 是上三角，对角元全是 $1-\omega$）。两边一夹就得到 $|1-\omega|\lt1$。

    注意它只给出必要条件：$0\lt\omega\lt2$ 是「必须满足」，不保证一定收敛。

    定理（超松弛迭代法收敛的充分条件, 数值线性代数, 定理 4.4.3）

    若系数矩阵 $A$ 严格对角占优或不可约对角占优，且松弛因子 $\omega\in(0,1)$，则超松弛迭代法收敛。

    证明

    「$A$ 严格对角占优或不可约对角占优」的条件保证了 $A$ 的对角元均非零，于是下三角阵 $D-\omega L$ 的对角元也均非零，因而是可逆的。

    考虑超松弛迭代法 $\begin{cases}B_\omega=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]\\c_\omega=\omega(D-\omega L)^{-1}b\end{cases}$。（反证法）假设超松弛迭代法发散，即 $\rho(B_\omega)\ge 1$，即存在 $B_\omega$ 的某个特征值 $\lambda$ 满足 $|\lambda|\ge 1$。于是

    \[ \omega A+(\lambda-1)(D-\omega L)=(\omega+\lambda-1)D-\omega L-\omega U \]

    也是严格对角占优或不可约对角占优的，因此 $(\omega+\lambda-1)D-\omega L-\omega U$ 非奇异。由

    \[ \lambda I-B_\omega=\lambda I-(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]=(D-\omega L)^{-1}\left[(\omega+\lambda-1)D-\omega L-\omega U\right] \]

    可知 $\lambda I-B_\omega$ 也是非奇异的。这与「$\lambda$ 是 $B_\omega$ 的特征值」矛盾，因而超松弛迭代法收敛。

    定理（正定情形下超松弛迭代法收敛的充要条件, 数值线性代数, 定理 4.4.4）

    若系数矩阵 $A$ 对称正定，则当且仅当松弛因子 $\omega\in(0,2)$ 时超松弛迭代法收敛。

    证明

    由于系数矩阵 $A$ 对称，故 $U=L^{\mathsf T}$。设 $\lambda$ 是 $B_\omega$ 的任一特征值（不一定是实数），$x$ 是对应的特征向量，则有

    \[ B_\omega x=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]x=\lambda x \] \[ \Updownarrow \] \[ \left[(1-\omega)D+\omega L^{\mathsf T}\right]x=\lambda(D-\omega L)x \] \[ \Updownarrow \] \[ x^{\mathsf H}\left[(1-\omega)D+\omega L^{\mathsf T}\right]x=\lambda x^{\mathsf H}(D-\omega L)x \]

    记 $\begin{cases}\gamma=x^{\mathsf H}Dx\\\alpha+i\beta=x^{\mathsf H}Lx\ \Rightarrow\ x^{\mathsf H}L^{\mathsf T}x=\alpha-i\beta\end{cases}$，则我们有

    \[ (1-\omega)\gamma+\omega(\alpha-i\beta)=\lambda\left[\gamma-\omega(\alpha+i\beta)\right] \] \[ \Updownarrow \] \[ (1-\omega)\gamma+\omega\alpha-i\omega\beta=\lambda(\gamma-\omega\alpha-i\omega\beta) \]

    两边取模可得

    \[ |\lambda|^2=\frac{\left[(1-\omega)\gamma+\omega\alpha\right]^2+(\omega\beta)^2}{(\gamma-\omega\alpha)^2+(\omega\beta)^2} \]

    分子减分母可知

    \[ \begin{aligned} &\left\{\left[(1-\omega)\gamma+\omega\alpha\right]^2+(\omega\beta)^2\right\}-\left\{(\gamma-\omega\alpha)^2+(\omega\beta)^2\right\}\\ &\quad=\left[(1-\omega)\gamma+\omega\alpha\right]^2-(\gamma-\omega\alpha)^2\\ &\quad=\left[(1-\omega)\gamma+\omega\alpha-(\gamma-\omega\alpha)\right]\cdot\left[(1-\omega)\gamma+\omega\alpha+(\gamma-\omega\alpha)\right]\\ &\quad=(2\omega\alpha-\omega\gamma)(2-\omega)\gamma\\ &\quad=\gamma(\gamma-2\alpha)\omega(\omega-2) \end{aligned} \]

    由于 $A$ 正定，故我们有（注意到 $x$ 作为 $B_\omega$ 的特征向量，一定不是零向量）

    \[ \begin{cases} \delta=x^{\mathsf H}Dx\gt 0\\[4pt] \delta-2\alpha=\delta-(\alpha+i\beta)-(\alpha-i\beta)=x^{\mathsf H}Dx-x^{\mathsf H}Lx-x^{\mathsf H}L^{\mathsf T}x=x^{\mathsf H}(D-L-U)x=x^{\mathsf H}Ax\gt 0 \end{cases} \]

    因此 $|\lambda|^2\lt 1$（即 $|\lambda|\lt 1$）当且仅当 $\omega(\omega-2)\lt 0$，即 $\omega\in(0,2)$。根据 $\lambda$ 是 $B_\omega$ 的任意特征值可知，$\rho(B_\omega)\lt 1$ 当且仅当 $\omega\in(0,2)$。这表明超松弛迭代法收敛当且仅当 $\omega\in(0,2)$，命题得证。

    正定情形的证明为什么能做得这么干净

    关键有两点：

    • $U=L^{\mathsf T}$（对称性）把两个矩阵块联系起来了，于是 $\alpha\pm i\beta$ 这一对共轭数同时出现；
    • $D$ 和 $A$ 都正定给出 $\gamma\gt0$ 和 $\gamma-2\alpha\gt0$，于是分子减分母的符号 $\gamma(\gamma-2\alpha)\omega(\omega-2)$ 完全由 $\omega(\omega-2)$ 决定。

    于是 $|\lambda|^2\lt1\iff\omega(\omega-2)\lt0\iff\omega\in(0,2)$——$\lambda$ 是任意的，所以这个等价对所有特征值成立，直接给出 $\rho(B_\omega)\lt1$。

    3.13.3 最佳松弛因子

    现在解决最实际的问题：$\omega$ 取多少最好。

    要研究收敛速度在 $\omega$ 为何值时最快，我们考虑特征值问题

    \[ B_\omega x=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]x=\lambda x \] \[ \Updownarrow \] \[ \left[(\lambda+\omega-1)D-\lambda\omega L-\omega U\right]x=0_n \]

    设 $\lambda_1,\dots,\lambda_n$ 是 $B_\omega$ 的 $n$ 个特征值，则我们有

    \[ \begin{aligned} \det(B_\omega) &=\det\left\{(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]\right\}\\ &=\det\left\{(I-\omega D^{-1}L)^{-1}\left[(1-\omega)I+\omega D^{-1}U\right]\right\}\\ &=\det\left\{(I-\omega D^{-1}L)^{-1}\right\}\det\left\{(1-\omega)I+\omega D^{-1}U\right\}\\ &=1^n\cdot(1-\omega)^n=(1-\omega)^n \end{aligned} \]

    因此当 $\omega\ne 1$ 时，$B_\omega$ 无零特征值。

    第一步：找出 Jacobi 迭代矩阵与 SOR 迭代矩阵特征值之间的关系。

    在自然次序排列下，$\left[(\lambda+\omega-1)D-\lambda\omega L-\omega U\right]x=0_n$ 可写成

    \[ \begin{cases}(\lambda+\omega-1)u_{ij}-\frac{\omega}{4}\left(\lambda u_{i-1,j}+\lambda u_{i,j-1}+u_{i+1,j}+u_{i,j+1}\right)=0&(i,j=1,\dots,n)\\u_{i,0}=u_{i,n+1}=u_{0,j}=u_{n+1,j}=0\end{cases} \]

    假设 $\omega\ne 1$（这保证了 $B_\omega$ 没有零特征值），对 $B_\omega$ 的特征值 $\lambda$ 作变换 $u_{i,j}=(\pm\lambda^{\frac12})^{i+j}v_{i,j}$ 可得

    \[ \begin{aligned} (\lambda+\omega-1)u_{i,j} &=(\lambda+\omega-1)\cdot(\pm\lambda^{\frac12})^{i+j}v_{i,j}\\ &=\frac{\omega}{4}\left(\lambda u_{i-1,j}+\lambda u_{i,j-1}+u_{i+1,j}+u_{i,j+1}\right)\\ &=\frac{\omega}{4}\left[\lambda\cdot(\pm\lambda^{\frac12})^{i-1+j}v_{i-1,j}+\lambda\cdot(\pm\lambda^{\frac12})^{i+j-1}v_{i,j-1}+(\pm\lambda^{\frac12})^{i+1+j}v_{i+1,j}+(\pm\lambda^{\frac12})^{i+j+1}v_{i,j+1}\right]\\ &=\frac{\omega}{4}(\pm\lambda^{\frac12})^{i+j+1}\left[v_{i-1,j}+v_{i,j-1}+v_{i+1,j}+v_{i,j+1}\right] \end{aligned} \]

    因此有

    \[ \begin{cases}\mu v_{i,j}=\frac14\left[v_{i-1,j}+v_{i,j-1}+v_{i+1,j}+v_{i,j+1}\right]&(i,j=1,\dots,n)\\v_{i,0}=v_{i,n+1}=v_{0,j}=v_{n+1,j}=0\end{cases}\qquad\text{其中}\quad\mu=\pm\frac{\lambda+\omega-1}{\omega\lambda^{\frac12}} \]

    回忆起 Jacobi 迭代法应用到二维 Poisson 问题得到的迭代公式，我们知道迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的特征值 $\mu$ 满足完全相同的方程。对比发现，在 $\omega\ne1$ 的前提条件下，

    特征值之间的桥梁

    $\lambda$ 是松弛迭代矩阵 $B_\omega=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]$ 的特征值，当且仅当

    \[ \mu=\pm\frac{\lambda+\omega-1}{\omega\lambda^{\frac12}} \]

    是 Jacobi 迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的特征值。

    也就是说：SOR 的特征值完全由 $\omega$ 和 Jacobi 的特征值 $\mu$ 确定——这正是能求出最佳 $\omega$ 的原因。

    实际上，前面关于 $\omega\ne1$ 的限制是可以去掉的：我们可以将 $\omega=1$ 的情况视作 $\omega\to1$ 的极限情况，此时 $\mu=\pm\dfrac{\lambda+\omega-1}{\omega\lambda^{\frac12}}$ 退化成 $\mu=\pm\lambda^{\frac12}$。可知 $B^{(1)}$ 的每对特征值 $\pm\mu_i$，都对应 $B_\omega$ 的特征值 $0$ 和 $\mu_i^2$。（这也再次给出了 §3.12 里的 $\lambda=\mu^2$。）

    第二步：确定谱半径 $\rho(B_\omega)$ 随 $\omega$ 变化的情况。

    设 $0\le\mu\lt 1$ 是 Jacobi 迭代矩阵 $B^{(1)}$ 的一个特征值，$\omega\in(0,2)$。则由 $\mu=\pm\dfrac{\lambda+\omega-1}{\omega\lambda^{\frac12}}$（即二次方程 $\lambda+\omega-1=\pm\omega\mu\lambda^{\frac12}$）可得松弛迭代矩阵 $B_\omega$ 的两个特征值分别为

    \[ \lambda_+(\omega,\mu)=\left[\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\right]^2 \] \[ \lambda_-(\omega,\mu)=\left[\frac{\mu\omega}{2}-\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\right]^2 \]

    记这两个特征值模长的最大值为 $M(\omega,\mu):=\max\left\{|\lambda_+(\omega,\mu)|,|\lambda_-(\omega,\mu)|\right\}$。记二次方程 $\lambda+\omega-1=\pm\omega\mu\lambda^{\frac12}$ 的判别式为 $\Delta=(\mu\omega)^2-4(\omega-1)$，判别式 $\Delta$ 在 $(0,2)$ 的唯一零点是

    \[ \omega_\mu=\frac{2}{1+\sqrt{1-\mu^2}}\in(0,2) \]
    • 当 $0\lt\omega\lt\omega_\mu$ 时 $\Delta\gt 0$，从而有 $\lambda_+(\omega,\mu)\gt\lambda_-(\omega,\mu)\gt 0$
    • 当 $\omega=\omega_\mu$ 时 $\Delta=0$，从而有 $\lambda_+(\omega,\mu)=\lambda_-(\omega,\mu)\gt 0$
    • 当 $\omega_\mu\lt\omega\lt 2$ 时 $\Delta\lt 0$，故 $\lambda_+(\omega,\mu)$ 和 $\lambda_-(\omega,\mu)$ 为一对共轭复数，且 $|\lambda_+(\omega,\mu)|=|\lambda_-(\omega,\mu)|=\omega-1$

    综上所述

    \[ M(\omega,\mu)=\max\left\{|\lambda_+(\omega,\mu)|,|\lambda_-(\omega,\mu)|\right\}=\begin{cases}\lambda_+(\omega,\mu)&0\le\omega\le\omega_\mu\\\omega-1&\omega_\mu\lt\omega\lt 2\end{cases} \]

    固定 $0\le\mu\lt 1$，令 $\omega$ 从 0 变到 2，考虑 $M(\omega,\mu)$ 的变化情况：

    • 首先我们有 $M(\omega,\mu)\lt 1$，这是因为：
      • 当 $0\le\omega\le\omega_\mu$ 时，我们有 \[ \begin{aligned} M(\omega,\mu) &=\lambda_+(\omega,\mu)=\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\\ &\le\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2+1-0^2}\\ &\lt\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2+1-\mu\omega}\\ &=\frac{\mu\omega}{2}+\left(1-\frac{\mu\omega}{2}\right)=1 \end{aligned} \]
      • 当 $\omega_\mu\lt\omega\lt 2$ 时，我们有 $M(\omega,\mu)=\omega-1\lt 2-1=1$
    • 其次，当 $0\le\omega\le\omega_\mu$ 时，我们有 \[ \begin{aligned} \frac{\partial M(\omega,\mu)}{\partial\omega} &=\frac{\partial}{\partial\omega}\left\{\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\right\}\\ &=2\left[\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\right]\cdot\left[\frac{\mu}{2}+\frac{\frac12\mu^2\omega-1}{2\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}}\right]\\ &=M(\omega,\mu)^{\frac12}\cdot\frac{\mu M(\omega,\mu)^{\frac12}-1}{\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}}\\ &\lt 0 \end{aligned} \] （分子为负、分母为正，所以导数严格小于 0。）

    于是当 $\omega\to\omega_\mu-0$ 时，我们有（注意到 $\omega_\mu$ 是方程 $(\mu\omega)^2-4(\omega-1)=0$ 的解）

    \[ M(\omega,\mu)=\left[\frac{\mu\omega}{2}+\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}\right]^2\to\left(\frac{\mu\omega_\mu}{2}\right)^2=\omega_\mu-1=\frac{1-\sqrt{1-\mu^2}}{1+\sqrt{1-\mu^2}} \] \[ \frac{\partial M(\omega,\mu)}{\partial\omega}=M(\omega,\mu)^{\frac12}\cdot\frac{\mu M(\omega,\mu)^{\frac12}-1}{\sqrt{\left(\frac{\mu\omega}{2}\right)^2-(\omega-1)}}\to\frac{-\sqrt{1-\mu^2}}{0^+}=-\infty \]

    讲义这里留了一个占位符

    讲义原文在分子位置写的是字面的 Negative Value：

    \[ \frac{\partial M(\omega,\mu)}{\partial\omega}\to\frac{\text{Negative Value}}{0}=-\infty \]

    这是作者没算完留下的占位符（不是笔误，是未完成的推导）。正确的分子是

    \[ M(\omega,\mu)^{\frac12}\left(\mu M(\omega,\mu)^{\frac12}-1\right)=\frac{1-\sqrt{1-\mu^2}}{\mu}\cdot\left(-\sqrt{1-\mu^2}\right)\lt 0 \]

    推导：在 $\omega=\omega_\mu$ 处 $M=\omega_\mu-1=\dfrac{1-\sqrt{1-\mu^2}}{1+\sqrt{1-\mu^2}}=\dfrac{\left(1-\sqrt{1-\mu^2}\right)^2}{\mu^2}$，开方取正根得 $M^{\frac12}=\dfrac{1-\sqrt{1-\mu^2}}{\mu}$，于是 $\mu M^{\frac12}-1=-\sqrt{1-\mu^2}$。所以分子是一个负常数，分母趋于 $0^+$，极限确实是 $-\infty$。

    而当 $\omega_\mu\lt\omega\lt 2$ 时，$M(\omega,\mu)=\omega-1$ 关于 $\omega$ 严格单调递增。综上所述，对于固定的 $0\le\mu\lt 1$，$M(\omega,\mu)$ 关于 $\omega$ 在 $(0,\omega_\mu)$ 上严格单调递减，在 $(\omega_\mu,2)$ 上严格单调递增，因此在 $\omega_\mu$ 处达到极小值 $\omega_\mu-1=\dfrac{1-\sqrt{1-\mu^2}}{1+\sqrt{1-\mu^2}}$。

    固定 $\omega\in(0,2)$，考虑 $M(\omega,\mu)$ 随 $0\le\mu\lt 1$ 的变化情况。可以证明，若 $0\lt\mu_1\lt\mu_2\lt 1$ 是 Jacobi 迭代矩阵 $B^{(1)}$ 的两个特征值，则有 $M(\omega,\mu_1)\le M(\omega,\mu_2)$，即 $M(\omega,\mu)$ 关于 $\mu$ 是单调递增的。（证明分三段：先由 $\omega_\mu$ 关于 $\mu$ 严格单调递增得 $\omega_{\mu_1}\lt\omega_{\mu_2}$；当 $\omega_{\mu_2}\le\omega\lt2$ 时两者都等于 $\omega-1$；当 $0\lt\omega\le\omega_{\mu_1}$ 时把差 $M(\omega,\mu_2)-M(\omega,\mu_1)$ 因式分解成两个正因子之积；当 $\omega_{\mu_1}\lt\omega\le\omega_{\mu_2}$ 时用 $M(\omega,\mu_2)\ge\omega_{\mu_2}-1\ge\omega-1=M(\omega,\mu_1)$。）

    把两条单调性合起来

    • 固定 $\mu$，$M$ 关于 $\omega$ 先减后增（V 形，谷底在 $\omega_\mu$）；
    • 固定 $\omega$，$M$ 关于 $\mu$ 单调递增。

    于是：$\mu$ 越大，对应的曲线整条越靠上。所以真正决定 $\rho(B_\omega)$ 的，是取到谱半径 $\rho(B^{(1)})$ 的那个特征值 $\mu_{\max}$——它对应的曲线是「最上方」的那条，而 $\rho(B_\omega)=\max_{0\le\mu\lt1}M(\omega,\mu)=M(\omega,\mu_{\max})$ 就是这条曲线本身。

    根据最上方的曲线 $\rho(B_\omega)=\max\limits_{0\le\mu\lt1}M(\omega,\mu)=M(\omega,\mu_{\max})$，我们得到结论：

    • 当 $0\lt\omega\le\omega_{\mathrm{opt}}=\omega_{\mu_{\max}}=\dfrac{2}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}}$ 时，$\rho(B_\omega)=\left[\frac{\mu_{\max}\omega}{2}+\sqrt{\left(\frac{\mu_{\max}\omega}{2}\right)^2-(\omega-1)}\right]^2$ 严格单调递减
    • 当 $\omega_{\mathrm{opt}}\lt\omega\lt 2$ 时，$\rho(B_\omega)=\omega-1$ 严格单调递增

    因此 $\rho(B_\omega)$ 在 $\omega_{\mathrm{opt}}$ 处取到极小值

    \[ \rho(B_{\omega_{\mathrm{opt}}})=\omega_{\mathrm{opt}}-1=\frac{1-\sqrt{1-\left(\rho(B^{(1)})\right)^2}}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}} \]

    最佳松弛因子

    \[ \omega_{\mathrm{opt}}=\frac{2}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}} \]

    对应的最佳松弛迭代矩阵记为 $B_{\omega_{\mathrm{opt}}}=(D-\omega_{\mathrm{opt}}L)^{-1}\left[(1-\omega_{\mathrm{opt}})D+\omega_{\mathrm{opt}}U\right]$。（由于 $\omega_{\mathrm{opt}}\gt 1$，故对应的松弛迭代是超松弛迭代。）

    算不出来怎么办：实践中的三个做法

    在实际计算中，我们有时无法确定 Jacobi 迭代矩阵的谱半径 $\rho(B^{(1)})$，因此最佳松弛因子 $\omega_{\mathrm{opt}}$ 也无法确定。此时如何求近似的 $\omega_{\mathrm{opt}}$ 呢？

    • 试算：选取不同的松弛因子 $\omega\in(0,2)$，然后用相同的初始向量 $x^{(0)}$ 进行试算，迭代相同次数（得到 $x^{(k_\omega)}$），比较残差向量的范数 $\left\|b-Ax^{(k_\omega)}\right\|$，最后选取使残差向量范数最小的 $\omega$ 作为松弛因子。
    • 取不准时宁可取大：根据松弛迭代矩阵 $B_\omega$ 的谱半径 $\rho(B_\omega)$ 随 $\omega$ 变化的曲线来看，当我们不能得到准确的最佳松弛因子时，宁可取稍大一些，因为 $\omega_{\mathrm{opt}}$ 左侧的曲线比右侧更加陡峭（左侧导数趋于 $-\infty$，右侧斜率只有 1）。
    • 先估 $\rho(B^{(1)})$：对二维 Poisson 这类已知模型问题，$\rho(B^{(1)})=\cos(h\pi)$ 是已知的，直接代公式即可。

    3.13.4 渐近收敛速度

    最佳松弛因子 $\omega_{\mathrm{opt}}$ 对应的（超）松弛迭代法的渐近收敛速度为（回忆起 Jacobi 迭代矩阵的谱半径 $\rho(B^{(1)})=\cos\left(\frac{\pi}{n+1}\right)=\cos(h\pi)$）：

    \[ \begin{aligned} R_\infty(B_{\omega_{\mathrm{opt}}}) &=-\log\left(\rho(B_{\omega_{\mathrm{opt}}})\right)\\ &=-\log\left(\frac{1-\sqrt{1-\left(\rho(B^{(1)})\right)^2}}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}}\right)\\ &=-\log\left(\frac{1-\sqrt{1-(\cos(h\pi))^2}}{1+\sqrt{1-(\cos(h\pi))^2}}\right)\\ &=-\log\left(\frac{1-\sin(h\pi)}{1+\sin(h\pi)}\right)\\ &=-\log\left(1-\sin(h\pi)\right)+\log\left(1+\sin(h\pi)\right)\\ &\sim-\left(-\sin(h\pi)\right)+\sin(h\pi)\\ &\sim-\left(-h\pi\right)+h\pi=2h\pi\qquad(h\to0) \end{aligned} \]

    回忆起

    \[ \begin{cases}R_\infty(B^{(1)})=R_\infty\left(D^{-1}(L+U)\right)=\frac12\pi^2h^2&(h\to0)\\[4pt]R_\infty(B^{(2)})=R_\infty\left((D-L)^{-1}U\right)=\pi^2h^2&(h\to0)\end{cases} \]

    可以看出，使用最佳松弛因子的超松弛迭代法的收敛速度比 Jacobi 迭代法和 Gauss-Seidel 迭代法快得多。

    3.13.5 超松弛理论的推广

    前面的讨论都基于二维 Poisson 问题，事实上我们可以将其推广到更一般的情形。

    定理（数值线性代数, 定理 4.4.5）

    设线性方程组 $Ax=b$ 的系数矩阵 $A$ 具有块三对角形式

    \[ A=\begin{bmatrix}D_1&K_1&&&\\H_1&D_2&K_2&&\\&H_2&D_3&\ddots&\\&&\ddots&\ddots&K_{m-1}\\&&&H_{m-1}&D_m\end{bmatrix} \]

    其中 $D_i\ (i=1,\dots,m)$ 是非奇异对角阵。我们记 $A=D-L-U$。设

    \[ \begin{cases}B^{(1)}=D^{-1}(L+U)\\B^{(2)}=(D-L)^{-1}U\\B_\omega=(D-\omega L)^{-1}\left[(1-\omega)D+\omega U\right]\end{cases} \]

    分别为 Jacobi 迭代法、Gauss-Seidel 迭代法和超松弛迭代法的迭代矩阵。若 $B^{(1)}$ 的特征值均为实数，则我们有：

    • Jacobi 迭代矩阵和超松弛迭代矩阵的特征值之间的关系：若 $\mu\ne 0$ 是 Jacobi 迭代矩阵 $B^{(1)}$ 的特征值，则由 $\mu=\pm\dfrac{\lambda+\omega-1}{\omega\lambda^{\frac12}}$（即二次方程 $\lambda+\omega-1=\pm\omega\mu\lambda^{\frac12}$）可得松弛迭代矩阵 $B_\omega$ 的两个特征值分别为 $\lambda_+(\omega,\mu)$ 与 $\lambda_-(\omega,\mu)$（同上）。反过来，若 $\lambda\ne 0$ 是超松弛迭代矩阵 $B_\omega$ 的特征值，则 $\mu=\pm\dfrac{\lambda+\omega-1}{\omega\lambda^{\frac12}}$ 是 Jacobi 迭代矩阵 $B^{(1)}$ 的两个特征值。（因此若 $\mu\ne0$ 是 $B^{(1)}$ 的特征值，则 $-\mu$ 也是 $B^{(1)}$ 的特征值。）
    • 特别地，当 $\omega=1$ 时，我们得到 Jacobi 迭代矩阵和 Gauss-Seidel 迭代矩阵的特征值之间的关系：$\lambda\ne0$ 是 Gauss-Seidel 迭代矩阵 $B^{(2)}=(D-L)^{-1}U$ 的非零特征值，当且仅当 $\mu=\lambda^{\frac12}$ 是 Jacobi 迭代矩阵 $B^{(1)}=D^{-1}(L+U)$ 的非零特征值。因此谱半径具有关系 $\rho(B^{(2)})=\left(\rho(B^{(1)})\right)^2$，渐近收敛速度 \[ R_\infty(B^{(2)})=-\log\left(\rho(B^{(2)})\right)=-2\log\left(\rho(B^{(1)})\right)=2R_\infty(B^{(1)}) \]
    • 最佳松弛因子的相关结论：若 Jacobi 迭代矩阵的谱半径 $\rho(B^{(1)})\lt 1$ 且松弛因子 $0\lt\omega\lt 2$，则超松弛迭代法收敛，且最佳松弛因子为 $\omega_{\mathrm{opt}}=\dfrac{2}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}}$，对应的谱半径 $\rho(B_{\omega_{\mathrm{opt}}})=\omega_{\mathrm{opt}}-1=\dfrac{1-\sqrt{1-\left(\rho(B^{(1)})\right)^2}}{1+\sqrt{1-\left(\rho(B^{(1)})\right)^2}}$。当 $\rho(B^{(1)})$ 从下方趋于 1 时，我们有渐近收敛速度 $R_\infty(B_{\omega_{\mathrm{opt}}})\sim 2\sqrt{2R_\infty(B^{(1)})}$。

    「对角块是非奇异对角阵」这个要求太苛刻了

    上述定理要求线性方程组的系数矩阵是块三对角阵，且对角块为非奇异对角阵。但「对角块为非奇异对角阵」的要求太苛刻了——回忆起二维 Poisson 问题中，系数矩阵 $A$ 的对角块为 $T_n+2I_n$，是三对角阵而不是对角阵：

    \[ T_n+2I_n=\begin{bmatrix}4&-1&&\\-1&\ddots&\ddots&\\&\ddots&\ddots&-1\\&&-1&4\end{bmatrix} \]

    然而我们成功对它建立了超松弛理论。实际上，超松弛理论可以适用于一类更广泛的矩阵。为此，我们引入相容性的概念。

    定义（具有相容次序的矩阵）

    设 $A$ 是 $n$ 阶方阵。我们称 $A$ 是具有相容次序的矩阵，如果存在 $\{1,\dots,n\}$ 的一个划分 $S_1,\dots,S_m$ 使得每个非零非对角元 $a_{ij}\ne0\ (i\ne j)$ 的下标 $i,j$ 满足：若 $i\in S_k$，则

    \[ j\in\begin{cases}S_{k-1}&j\lt i\\S_{k+1}&j\gt i\end{cases}\qquad(\text{其中 }k=1,\dots,m) \]

    例子：以二维 Poisson 问题的系数矩阵 $A=T_{n\times n}$ 为例，取 $n=3$ 的情况（$9\times9$ 矩阵）。我们取集合 $\{1,\dots,9\}$ 的划分为

    \[ S_1=\{1\},\quad S_2=\{2,4\},\quad S_3=\{3,5,7\},\quad S_4=\{6,8\},\quad S_5=\{9\} \]

    可以验证这个划分是满足定义的，也就是说上述矩阵具有相容性次序。（直观：这些 $S_k$ 正好是网格上的「反对角线」——$i+j$ 相等的那些点。）

    对于具有相容性次序且对角元非零的矩阵，亦可建立超松弛理论。这是因为它可以按照「相容性次序」定义中的 $\{1,\dots,n\}$ 的划分 $S_1,\dots,S_m$ 重排得到定理 4.4.5 中描述的对角块为非奇异对角阵的块三对角阵。

    定理（数值线性代数, 定理 4.4.6）

    设线性方程组 $Ax=b$ 的系数矩阵 $A$ 具有相容性次序，且对角元均不为零。设 $B^{(1)}$、$B^{(2)}$、$B_\omega$ 分别为 Jacobi 迭代法、Gauss-Seidel 迭代法和超松弛迭代法的迭代矩阵。若 $B^{(1)}$ 的特征值均为实数，则定理 4.4.5 中的三条结论全部成立（特征值关系、$\rho(B^{(2)})=\left(\rho(B^{(1)})\right)^2$、最佳松弛因子）。

    定理（数值线性代数, 定理 4.4.7）

    若线性方程组 $Ax=b$ 的系数矩阵 $A$ 对称正定，且具有相容性次序，则 Jacobi 迭代矩阵 $B^{(1)}=D^{-1}(L+U)=I-D^{-1}A$ 的特征值均为实数，且谱半径 $\rho(B^{(1)})\lt 1$。

    证明：因为 $A$ 为正定阵，所以 $D=\operatorname{diag}(a_{11},\dots,a_{nn})$ 为正定对角阵。于是

    \[ B^{(1)}=I-D^{-1}A=D^{-\frac12}\left(I-D^{-\frac12}AD^{-\frac12}\right)D^{\frac12} \]

    表明 $B^{(1)}$ 与对称阵 $I-D^{-\frac12}AD^{-\frac12}$ 相似，因而 $B^{(1)}$ 的特征值均为实数。再由定理 4.2.7（$A$ 对称正定 $\Rightarrow$ Gauss-Seidel 迭代法收敛）即可得 $\rho(B^{(1)})\lt1$。

    这一节的主线，一句话

    「Jacobi 的特征值 $\mu$ 已知 ⟹ SOR 的特征值完全由 $\omega$ 决定 ⟹ 谱半径关于 $\omega$ 是 V 形 ⟹ 谷底就是 $\omega_{\mathrm{opt}}$，此时收敛速度从 $O(h^2)$ 跳到 $O(h)$。」

    整节的技术核心只有一个变换：$u_{i,j}=(\pm\lambda^{\frac12})^{i+j}v_{i,j}$。它的作用是把 SOR 的特征值方程变形成 Jacobi 的特征值方程，从而在两个原本无关的迭代矩阵之间架起一座桥。

    3.14 迭代精化板书 6

    这一节不在任何一份讲义里（我把 8 份 PDF 全文检索过「精化」，零命中），但板书第 6 张出现了，而且它正好是「直接法 → 迭代法」之间最自然的桥。

    板书 6 原文

    A x = b
P(A+δA) = L̂ Û

┌─ Loop: ──────────────────────┐
│  r = b - A x     ← in higher precision
│  solve:  A Δx = r
│  x ← x + Δx
└──────────────────────────────┘

|fl(r) - r|  ≤  O(u) (|b| + |A| |x|)

    注意右边那行误差界——它是整个方法能work的唯一理由，见下面「为什么有效」。

    迭代精化（iterative refinement）

    设已用部分主元 Gauss 消去法（可能是在较低精度下）得到 $PA\approx\hat L\hat U$。然后循环：

    \[ \begin{aligned} &\textbf{Loop:}\\[2pt] &\quad r=b-Ax &&\text{用\bf 更高精度\rm 计算残差}\\[2pt] &\quad \text{solve } \hat L\hat U\,\Delta x=P r &&\text{用已有的低精度分解求解修正量}\\[2pt] &\quad x\leftarrow x+\Delta x \end{aligned} \]

    为什么有效

    关键在误差分析。计算残差 $\mathrm{fl}(r)$ 的误差满足

    \[ |\mathrm{fl}(r)-r|\le O(u)\big(|b|+|A||x|\big) \]

    注意右边是「逐元素」的

    右边是 $|b|+|A||x|$ —— 分量绝对值的形式，而不是 $\|b\|+\|A\|\|x\|$ 这种范数形式。

    当 $A$ 病态时，$x$ 的各个分量会发生大量相消，于是 $\|A\|\|x\|$ 可以远大于 $|A||x|$ 的实际量级。换句话说：

    \[ \underbrace{O(u)\big(|b|+|A||x|\big)}_{\text{计算残差的误差}}\ \ll\ \underbrace{O(u)\big(\|b\|+\|A\|\|x\|\big)}_{\text{解 }x\text{ 本身的误差}} \]

    所以计算出来的残差比 $x$ 本身精确得多，修正量 $\Delta x$ 里仍然携带有效信息，迭代就能真正把精度提上去。

    代价

    每一步只有「算残差 + 前代 + 回代」，即 $O(\mathrm{nnz})$ 或 $O(n^{2})$，远小于一次分解的 $O(n^{3})$。所以：

    • 用低精度（如单精度）做分解，用高精度（如双精度）算残差，就能以接近低精度的代价拿到接近高精度的结果；
    • 这是现代混合精度求解器（例如 GPU 上的稀疏直接法）的核心技术。

    和第 3 章的接口

    迭代精化已经具备了迭代法的外形：构造一个序列 $x^{(0)},x^{(1)},\dots$，每一步用「残差 + 修正」的方式逼近精确解。区别在于它是有限步收敛（几步就到位），而第 3 章的 Jacobi / Gauss-Seidel / SOR 是无穷步渐近收敛。理解了精化，再学 §3.1 会很自然。

    变体 ① 标准型的三种等价表述

    板书 5（左）原文

    $Ax=b$；$\min_x\|b-Ax\|_2$；$A^{*}Ax=A^{*}b$；$\begin{bmatrix}I&A\\ A^{*}&0\end{bmatrix}\begin{bmatrix}r\\x\end{bmatrix}=\begin{bmatrix}b\\0\end{bmatrix}$

    这四个式子其实是同一个问题的四种说法：

    1. 原问题：$Ax=b$。当 $A\in\mathbb{C}^{m\times n}$ 且 $m\gt n$ 时一般无解。
    2. 改成极小化：$\min_x\|b-Ax\|_2$——把「解不出来」换成「差得最少」。
    3. 正规方程：$A^{*}Ax=A^{*}b$。推导就是「梯度为零」：$\|b-Ax\|_2^2$ 对 $x$ 求梯度得 $-2A^{*}(b-Ax)$，令其为零即得。几何上它说的是残差 $b-Ax$ 与 $\operatorname{Ran}(A)$ 正交（$A^{*}(b-Ax)=0$）。
    4. 增广系统：把残差 $r=b-Ax$ 也当成未知量。由 $r+Ax=b$ 和 $A^{*}r=0$ 拼起来就是那个分块系统。

    易错点：增广系统的对角块是 $I$ 和 $0$，不是 $A$ 和 $A^{*}$

    把 $\begin{bmatrix}I&A\\ A^{*}&0\end{bmatrix}\begin{bmatrix}r\\x\end{bmatrix}=\begin{bmatrix}b\\0\end{bmatrix}$ 展开：第一行是 $r+Ax=b$（就是残差的定义），第二行是 $A^{*}r=0$（就是正交条件）。这个矩阵是对称不定的（鞍点结构），不是正定阵。

    为什么这个形式有用：它把一个最小二乘问题写成了一个方阵方程组，可以直接用 LU（带主元）或迭代法求解，而不必显式算出 $A^{*}A$——算 $A^{*}A$ 会把条件数平方，这是第 2 章反复强调的坑。

    变体 ② 带 $l_2$ 惩罚项的最小二乘

    讲义原文一句话带过：「带 $l_2$ 惩罚项的最小二乘问题本质上是标准的最小二乘问题」。它的定义是

    \[ \min_x\ \|b-Ax\|_2^2+\mu\|x\|_2^2 \]

    两项各管一件事：$\|b-Ax\|_2^2$ 管「拟合得好不好」，$\mu\|x\|_2^2$ 管「解别太大」，$\mu$ 是两者之间的权重。它在不同领域有三个名字，说的都是同一件事：岭回归（ridge regression，统计）、Tikhonov 正则化（反问题）、阻尼最小二乘（Levenberg–Marquardt 里那个阻尼项）。

    为什么说「本质上是标准最小二乘」。只要把 $\sqrt{\mu}I_n$ 堆到 $A$ 下面、把 $0_n$ 堆到 $b$ 下面：

    展开验证一下，看它是不是真的一样：

    \[ \left\|\begin{bmatrix}A\\ \sqrt{\mu}I_n\end{bmatrix}x-\begin{bmatrix}b\\0_n\end{bmatrix}\right\|_2^2=\|Ax-b\|_2^2+\|\sqrt{\mu}\,x-0\|_2^2=\|b-Ax\|_2^2+\mu\|x\|_2^2 \]

    易错点：堆的是 $\sqrt{\mu}$ 不是 $\mu$

    因为范数要平方，只有 $(\sqrt{\mu})^2=\mu$ 才能对上原式的系数。这也解释了为什么惩罚项写的是 $\|x\|_2^2$ 而不是 $\|x\|_2$：只有平方项才能配成范数，整个问题才还是一个最小二乘问题，而不是一般的最优化问题。

    写成标准最小二乘之后，法方程就是把 $A^{*}A$ 换成 $A^{*}A+\mu I$：

    \[ (A^{*}A+\mu I_n)\,x=A^{*}b \]

    用谱的语言说：这相当于把 $A^{*}A$ 的所有特征值整体抬高 $\mu$。大特征值几乎不动（相对变化 $\mu/\lambda$ 很小），小特征值相对变化 $\mu/\lambda$ 巨大——所以病态问题被救活了。讲义的原话是「一般我们取 $\mu\gt0$ 为一个较小的正实数，这样 $A^{*}A$ 会变得更加良态：大特征值几乎不变，而小特征值在相对程度上增大很多倍」。

    $\mu$ 到底在干什么。两个极限能说清一切：$\mu\to0$ 时退回标准最小二乘；$\mu\to\infty$ 时 $x\to0$（罚款太贵，索性什么都不要）。中间是一根旋钮。拿一个具体例子看这根旋钮的行程——取

    \[ A=\begin{bmatrix}1&0\\0&10^{-3}\end{bmatrix},\qquad b=\begin{bmatrix}1\\1\end{bmatrix} \]

    标准最小二乘（$\mu=0$）给出的解是 $x=[1;\ 10^3]$：第二个分量被放大了 1000 倍，因为那一维的方程是 $10^{-3}x_2=1$。这就是病态——$b$ 稍微抖一下，$x_2$ 就抖 $\partial x_2/\partial b_2=10^6$ 倍。加罚项后解变成

    \[ x(\mu)=\begin{bmatrix}\dfrac{1}{1+\mu} \\ \dfrac{10^{-3}}{10^{-6}+\mu}\end{bmatrix} \]

    实际用它的五类场合：数据共线（列近似线性相关）；问题欠定（$m\lt n$，本来有无穷多解，$l_2$ 惩罚帮你挑出范数最小的那个）；反问题 / 图像去噪（Tikhonov 的看家本领）；机器学习里的 weight decay；Levenberg–Marquardt 里的阻尼项。

    变体 ③ 线性等式约束的最小二乘（消元法）

    问题：

    \[ \min_{Cx=d}\|Ax-b\|_2^2,\qquad A\in\mathbb{C}^{m\times n},\ \operatorname{rank}(A)=n\le m;\quad C\in\mathbb{C}^{p\times n},\ \operatorname{rank}(C)=p\lt n;\quad d\in\mathbb{C}^p \]

    板书 1 原文

    $\min\|b-Ax\|_2$ 带等式约束 $Bx=d$ 的消元法：$[B;A]=[R\ \ 0]Q$，$[R\ \ 0]Qx=d$，$y_1=R^{-1}d$；以及 $\|b-Ax\|_2=\|b-AQ^{*}y\|_2=\|(b-\tilde A_1y_1)-\tilde A_2y_2\|_2$

    注意板书把约束矩阵记作 $B$，讲义记作 $C$——同一个东西。（顺带一提，$B$ 在本笔记 §3.9 之后是迭代矩阵，两个 $B$ 毫无关系。）

    讲义说「Lagrange 乘子法自然是一般解法，可参考 Homework 6 Problem 2」，然后介绍了消元法。设 $C$ 的 QR 分解为

    \[ [\,R\ \ 0_{p\times(n-p)}]\begin{bmatrix}Q_1\\Q_2\end{bmatrix}=C,\qquad R\in\mathbb{C}^{p\times p},\ Q_1\in\mathbb{C}^{p\times n},\ Q_2\in\mathbb{C}^{(n-p)\times n} \]

    其中 $Q_1$ 是行标准正交的（$Q_1Q_1^{*}=I_p$）。记

    \[ y:=Qx=\begin{bmatrix}Q_1\\Q_2\end{bmatrix}x=\begin{bmatrix}Q_1x\\Q_2x\end{bmatrix}=\begin{bmatrix}y_1\\y_2\end{bmatrix},\qquad x=\begin{bmatrix}Q_1\\Q_2\end{bmatrix}^{*}y=Q_1^{*}y_1+Q_2^{*}y_2 \] \[ \tilde A:=AQ^{*}=A\begin{bmatrix}Q_1\\Q_2\end{bmatrix}^{*}=[\,AQ_1^{*}\ \ AQ_2^{*}]=[\,\tilde A_1\ \ \tilde A_2]\in\mathbb{C}^{m\times n},\qquad \tilde b:=b-\tilde A_1y_1 \]

    关键是讲义原话：「当 $R$ 固定时，$Q_1$ 也是固定的，而 $Q_2$ 是自由变动的（甚至不用保证 $Q=\begin{bmatrix}Q_1\\Q_2\end{bmatrix}$ 为酉矩阵）」。所以 $y_1:=Q_1x$、$\tilde A_1:=AQ_1^{*}$、$\tilde b:=b-\tilde A_1y_1$ 都是固定的；只有 $y_2:=Q_2x$、$\tilde A_2:=AQ_2^{*}$ 依赖 $Q_2$、可以自由变动。

    约束在这个坐标系里变得极其简单：

    \[ Cx=[\,R\ \ 0]\begin{bmatrix}Q_1\\Q_2\end{bmatrix}x=RQ_1x=Ry_1=d\quad\Longrightarrow\quad y_1=R^{-1}d\ \text{（完全确定）} \]

    剩下就是把目标函数往下化简：

    \[ \|b-Ax\|_2^2=\|b-AQ^{*}y\|_2^2=\|b-\tilde Ay\|_2^2=\left\|b-[\,\tilde A_1\ \tilde A_2]\begin{bmatrix}y_1\\y_2\end{bmatrix}\right\|_2^2=\|(b-\tilde A_1y_1)-\tilde A_2y_2\|_2^2=\|\tilde b-\tilde A_2y_2\|_2^2 \]

    结论：约束被彻底消掉

    \[ \min_x\|b-Ax\|_2^2\ \Longleftrightarrow\ \min_{y_2}\|\tilde b-\tilde A_2y_2\|_2^2 \]

    原来带 $p$ 个等式约束的问题，变成了一个对 $y_2\in\mathbb{C}^{n-p}$ 的无约束标准最小二乘。这就是「消元法」三个字的含义：用 $y_1$ 吃掉约束，剩下的自由度全归 $y_2$。解出 $y_2$ 后回代 $x=Q_1^{*}(R^{-1}d)+Q_2^{*}y_2$ 即得原问题的解。

    §2.4.3 Arnoldi 过程讲义 §2.4.3

    这一节要干什么：把 $A$ 通过相似变换化成尽可能简单的形式，从而求特征值或解 $Ax=b$。整个过程只用矩阵-向量乘法，不需要对 $A$ 做任何分解。下面按「为什么需要 → 怎么来的 → 为什么成立」走一遍。

    第一步：Krylov 幂序列，以及为什么算到 $y_n$ 就停

    给定 $A\in\mathbb{C}^{n\times n}$、$b\in\mathbb{C}^n$，最自然的想法是造一串向量：

    \[ y_1=b,\quad y_2=Ay_1=Ab,\quad y_3=Ay_2=A^2b,\quad\ldots,\quad y_n=Ay_{n-1}=A^{n-1}b \]

    讲义说「我们只需计算至 $y_n=A^{n-1}b$ 即可」，理由是 Cayley–Hamilton 定理（讲义引 Matrix Analysis 定理 2.4.3.2）：设 $p_A(t)=\det(tI_n-A)$ 是 $A$ 的特征多项式，则

    \[ p_A(A)=0_{n\times n} \]

    即任意复方阵都满足自己的特征方程。把 $p_A(A)=0$ 展开，$A^n$ 就被写成 $I_n,A,\ldots,A^{n-1}$ 的线性组合；再往上同理递推。所以 $A^nb,A^{n+1}b,\ldots$ 全都落在这个 span 里，多算没有新信息。这个 span 就是 Krylov 子空间的定义来源：

    Krylov 子空间

    \[ K(A,b,k):=\operatorname{span}\{b,\ Ab,\ \ldots,\ A^{k-1}b\} \]

    第二步：堆成矩阵 $Y$，再配一个伴随矩阵 $C$

    \[ Y:=[\,y_1,y_2,\ldots,y_{n-1},y_n]\in\mathbb{C}^{n\times n},\qquad c:=-Y^{-1}A^ny_1,\qquad C:=[\,e_2,e_3,\ldots,e_n,-c] \]

    （讲义注：「其中我们暂且假定 $Y\in\mathbb{C}^{n\times n}$ 非奇异」。）$C$ 的形状就是伴随矩阵：第一列 $e_2$、第二列 $e_3$、……、第 $n-1$ 列 $e_n$，最后一列 $-c$。

    然后是核心恒等式，逐列拆开看：

    \[ AY=[\,Ay_1,Ay_2,\ldots,Ay_{n-1},Ay_n]=[\,y_2,y_3,\ldots,y_n,\ A^ny_1]=[\,Ye_2,Ye_3,\ldots,Ye_n,\ Y\cdot(-Y^{-1}A^ny_1)]=YC \]

    中间那步是题眼：$Ye_j$ 恰好就是 $Y$ 的第 $j$ 列，所以把 $e_j$ 换成 $y_{j+1}$ 完全合法。于是

    \[ AY=YC\quad\Longrightarrow\quad Y^{-1}AY=C \]

    这意味着什么：$A$ 与 $C$ 相似，所以特征多项式相同；而伴随矩阵的特征多项式几乎不用算，

    \[ p_C(t)=t^n+c_1t^{n-1}+c_2t^{n-2}+\cdots+c_n \]

    直接读出来。所以原则上，解 $p_C(t)=0$ 就拿到了 $A$ 的全部特征值；解 $Ax=b$ 也等价于解 $C(Y^{-1}x)=Y^{-1}b$。而整个构造只用了矩阵-向量乘法——讲义原话：「整个过程中我们只需使用矩阵-向量乘法就能把 $A$ 化为一个非常简单的形式」。

    第三步：为什么实际不能用——两个致命问题

    ① 稀疏性被毁：即使 $A$ 是稀疏矩阵，$Y$ 也可能是稠密的，故没有利用期望变换后的问题比原问题求解起来更容易。

    ② $Y$ 极度病态，导致 $c=Y^{-1}(A^nb)$ 算不准。讲义写了一句非常关键的话：

    讲义原文（p23）

    「可以预见（参见幂法），序列 $y_k=A^{k-1}b$ 收敛到对应于 $A$ 的模最大特征值的一个特征向量，因而 $Y$ 的列 $y_1,y_2,\ldots,y_n$ 可能会趋于线性相关，信息丢失会非常严重。」

    翻译过来：$y_k=A^{k-1}b$ 正是幂法的迭代序列。幂法（§1.2）告诉我们 $y_k/\|y_k\|\to q_1$（主特征向量），所以 $Y$ 的各列会一个接一个地倒向同一个方向、几乎平行，条件数爆炸，$Y^{-1}$ 算出来全是噪声。

    这一节最漂亮的一处呼应

    幂法在这里以「反派」的身份登场。第一部分我们用它求主特征值，这里它反过来证明了「拿 $\{A^{k-1}b\}$ 当基去求特征值」是自杀行为。同一件事，正着用是算法，反着看是警告。

    第四步：补救——换基，不换子空间

    问题的根源是基选得不好，不是子空间不好。所以保留各列张成的子空间，只把基换成正交基。讲义要求 $Q\in\mathbb{C}^{n\times n}$ 的前 $k=1,\ldots,n$ 列也张成 $K(A,b,k)$，好处有两条：

    • 酉矩阵 $Q$ 一定是良态的（$\|Q\|_2=1$），且容易求逆（$Q^{-1}=Q^{*}$）；
    • 为得到 $Ax=b$ 的精确解，我们仅仅需要计算 $Q$ 的前几列，远少于矩阵维数 $n$。

    第二条就是后来所有 Krylov 方法（第 4 章）的动机：降维。

    第五步：相似变换换到 $Q$ 上，Hessenberg 结构自己掉出来

    记 $Y$ 的 QR 分解为 $Y=QR$（$Q$ 酉、$R$ 上三角），仍暂设 $Y$ 非奇异：

    \[ Y^{-1}AY=(R^{-1}Q^{*})A(QR)=R^{-1}(Q^{*}AQ)R=C\quad\Longleftrightarrow\quad H:=Q^{*}AQ=RCR^{-1} \]

    因为 $R,R^{-1}$ 都是上三角、$C$ 是上 Hessenberg，而「上三角 × 上 Hessenberg × 上三角」仍是上 Hessenberg，所以 $H$ 是上 Hessenberg 矩阵。特殊地，若 $A$ 是 Hermite 矩阵，则 $T:=Q^{*}AQ=RCR^{-1}$ 是 Hermite 三对角阵。

    这就是全部收益所在：原本想靠相似变换把 $A$ 变简单，失败了；换成酉基之后，相似变换自动给出 Hessenberg 结构——而 Hessenberg 是「几乎上三角」，正是 10.20 §7.4 里 QR 迭代求特征值最理想的起点。

    第六步：实际计算——$AQ=QH+\text{rank-one}$

    这是讲义 p24 最后一段，也是作业里最容易卡住的地方。$Y$ 可能不满秩，所以不能真去求 $Y^{-1}$。讲义改为记 $Q:=[q_1,\ldots,q_r]$，其中 $1\le r\le\operatorname{rank}(Y)$。

    根据 $AQ=QH$（其中 $H\in\mathbb{C}^{r\times r}$ 为上 Hessenberg 阵），因而有

    \[ Aq_j=\sum_{i=1}^{j+1}h_{i,j}q_i \]

    这一步为什么成立：它就是「上 Hessenberg」的定义

    $H$ 的第 $j$ 列只有前 $j+1$ 个元素可能非零（$h_{j+2,j}=h_{j+3,j}=\cdots=0$）。把 $AQ=QH$ 按第 $j$ 列写出来：左边是 $Aq_j$，右边是 $Q$ 乘以 $H$ 的第 $j$ 列，即 $\sum_{i=1}^{j+1}h_{i,j}q_i$。所以「$Aq_j$ 只用到前 $j+1$ 个基向量」这句话，等价于「$H$ 是上 Hessenberg」。

    由于 $Q$ 列标准正交（$q_k^{*}q_i=\delta_{ki}$），故我们有

    \[ q_k^{*}Aq_j=\sum_{i=1}^{j+1}h_{i,j}\,q_k^{*}q_i=0+h_{k,j}\cdot1=h_{k,j}\qquad(1\le k\le j) \]

    也就是说：$H$ 的第 $(k,j)$ 个元素可以直接从 $q_k^{*}Aq_j$ 读出来，不需要真的做矩阵乘法。最后有

    \[ h_{j+1,j}q_{j+1}=Aq_j-\sum_{i=1}^{j}h_{i,j}q_i \]

    把它整理成矩阵形式，就得到讲义那句话：

    核心恒等式

    \[ AQ=QH+\text{rank-one} \]

    其中 rank-one 代表遗留的秩一矩阵，仅在最后一列有非零元素。

    那个 rank-one 到底是什么、为什么会有它？讲义的解释是：它的存在是因为 $Aq_r$ 不一定能完全表示为 $q_1,\ldots,q_r$ 的线性组合。换句话说，把 $AQ$ 的第 $j$ 列（$j\lt r$）写成 $\sum_{i=1}^{j+1}h_{i,j}q_i$ 是精确的；但第 $r$ 列——$Aq_r$——可能还有一个垂直于 $\operatorname{span}(q_1,\ldots,q_r)$ 的分量，这个分量落不进去，只能作为「余项」留在最后一列。

    读法：这个 rank-one 是「信号」不是「误差」

    它的长度 $\big\|Aq_r-\sum_{i=1}^{r}h_{i,r}q_i\big\|_2=h_{r+1,r}$ 就是 Hessenberg 的次对角元，也是算法里唯一的信息来源——下一小节的伪代码里，H(k+1,k)=norm(Q(:,k+1)) 算的就是它。它不为零，说明 Krylov 子空间还能继续长；它趋于零，说明子空间已经饱和了。

    第七步：Gram–Schmidt 型 Arnoldi 过程

    讲义给的伪代码（Matlab 版本见 Homework 6 Problem 4 Algorithm 1，Householder 版本是 Algorithm 2）：

    function: [Q, H] = Gram-Schmidt_Arnoldi(A, b, tolerance, modified, reorthogonalized)
    n = dim(A);  Q = zeros(n,n);  H = zeros(n,n);  delta = zeros(n,1);
    Q(1:n, 1) = b / norm(b);
    if reorthogonalized, max_iter = 2; else, max_iter = 1; end
    for k = 1 : r-1
        Q(1:n, k+1) = A * Q(1:n, k);
        if modified == TRUE                       % MGS：一个一个减
            for iter = 1:max_iter
                for i = 1 : k
                    delta(i)   = Q(1:n,i)' * Q(1:n,k+1);
                    H(i,k)     = H(i,k) + delta(i);
                    Q(1:n,k+1) = Q(1:n,k+1) - delta(i) * Q(1:n,i);
                end
            end
        else                                      % CGS：一次减完
            for iter = 1:max_iter
                delta(1:k)   = Q(1:n,1:k)' * Q(1:n,k+1);
                H(1:k,k)     = H(1:k,k) + delta(1:k);
                Q(1:n,k+1)   = Q(1:n,k+1) - Q(1:n,1:k) * delta(1:k);
            end
        end
        H(k+1,k) = norm(Q(1:n,k+1));
        if H(k+1,k) < tolerance                   % indicates linear dependence
            r = k;  break
        else
            Q(1:n,k+1) = Q(1:n,k+1) / H(k+1,k);
        end
    end
    H(1:r, r) = Q(1:n,1:r)' * (A * Q(1:n,r));     % fill the last column
    Q = Q(1:n, 1:r);  H = H(1:r, 1:r);
end

    四个必须看懂的地方：

    • H(k+1,k) = norm(Q(:,k+1)) 是 Hessenberg 的次对角元，同时它的大小正好等于「$Aq_k$ 中垂直于 $q_1,\ldots,q_k$ 的那部分有多长」。
    • if H(k+1,k) < tolerance ⇒ $Aq_k$ 落在 $\operatorname{span}(q_1,\ldots,q_k)$ 里了 ⇒ Krylov 子空间停止增长 ⇒ 令 $r=k$ 提前退出。这就是 indicates linear dependence，也是 $r\le\operatorname{rank}(Y)$ 的来源。（所以循环写的是 1:r-1 但 $r$ 得先跑出来——实现上就是「跑到 breakdown 为止」。）
    • 最后一行 H(1:r,r) = Q'*(A*Q(:,r)) 是补最后一列：前面各列靠递推得到，第 $r$ 列已经跳出循环，只能单独算一次。
    • reorthogonalized 打开时正交化做两遍（max_iter = 2），这是 Gram–Schmidt 的经典数值补救——病态时一遍正交化会丢正交性。基于 Householder 变换的版本（Algorithm 2）数值上更稳。

    §2.4.4 Lanczos 过程讲义 §2.4.4

    先纠一个印刷错误

    讲义（含目录）把 Lanczos 拼成了 「Lanzcos」。正确拼写是 Lanczos（匈牙利数学家 Cornelius Lanczos）。这是我在讲义里找到的第 5 处印刷问题。

    当 $A$ 是对称阵时，Arnoldi 过程得到的 $T:=Q^{\mathsf T}AQ$ 是一个对称三对角阵。理论上，我们可将 Arnoldi 过程简化为 Lanczos 过程（考虑到 $T$ 的很多上三角元为零）：给定对称阵 $A\in\mathbb{R}^{n\times n}$ 和单位向量 $q_1\in\mathbb{R}^n$……

    记 $Q_k:=[q_1,\ldots,q_k]$（其中 $1\le k\le\operatorname{rank}(K(A,q_1,n))$，而 $K(A,q_1,n)=\operatorname{span}\{q_1,Aq_1,\ldots,A^{n-1}q_1\}$）。根据 $AQ_k=Q_{k+1}\tilde T_k$ 可知

    \[ Aq_k=\beta_{k-1}q_{k-1}+\alpha_kq_k+\beta_kq_{k+1} \]

    也就是说 $Aq_k$ 只由三个相邻向量拼出来。由于 $q_1,\ldots,q_{k+1}$ 标准正交，两边左乘 $q_k^{\mathsf T}$ 得

    \[ \alpha_k=q_k^{\mathsf T}Aq_k\quad(\text{就是 Rayleigh 商}),\qquad \beta_kq_{k+1}=Aq_k-\alpha_kq_k-\beta_{k-1}q_{k-1} \]

    于是得到 Lanczos 过程（讲义引 Matrix Computation 9.1.2 节）：

    Given symmetric matrix A in R^(n x n) and q1 in R^n such that norm(q1, 2) = 1
k = 0;  beta_0 = 1;  q_0 = 0_n;  r_0 = q_1
while beta_k ~= 0
    q_{k+1} = r_k / beta_k
    k = k + 1
    alpha_k = q_k' * A * q_k
    r_k = A * q_k - alpha_k * q_k - beta_{k-1} * q_{k-1}
    beta_k = norm(r_k, 2)
end

    以及讲义给的 Matlab 实现（引 Homework 6 Problem 6）：

    function: [Q, T] = Lanczos(A, b, r, tolerance)
    n = size(A, 1);
    Q = zeros(n, r);  T = zeros(r, r);
    Q(:, 1) = b / norm(b);
    for j = 1:r
        z = A * Q(:, j);
        T(j, j) = Q(:, j)' * z;                                  % 对角元 = Rayleigh 商
        if j == 1
            z = z - T(j, j) * Q(:, j);                           % 第一步只减一项
        else
            z = z - T(j, j) * Q(:, j) - T(j-1, j) * Q(:, j-1);   % 之后只减两项
        end
        T(j, j+1) = norm(z, 2);
        T(j+1, j) = T(j, j+1);                                   % T 对称
        if norm(z, 2) < tolerance
            r = j - 1;  break                                    % 提前退出（breakdown）
        else
            Q(:, j+1) = z / T(j, j+1);
        end
    end
    Q = Q(:, 1:r);  T = T(1:r, 1:r);
end

    把它和 §2.4.3 的 Arnoldi 伪代码对照着看，两处差异最能说明三对角结构省了什么：

    ArnoldiLanczos
    正交化内层 for i = 1:k，减遍全部历史向量只减 Q(:,j) 和 Q(:,j-1) 两项
    breakdown 判据H(k+1,k) < tolerancenorm(z,2) < tolerance
    存储需要保存所有 $q_1,\ldots,q_k$只需保存前两个向量
    系数矩阵$H$ 上 Hessenberg$T$ 对称三对角，$\alpha_j$ 就是 Rayleigh 商

    breakdown 的含义完全一样：Krylov 子空间不再增长（$Aq_k$ 落在已张成的空间里了）。
