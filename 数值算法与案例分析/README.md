## 来源说明（重要）

这份笔记不是讲义的复述，而是**三态混合**的：

| 来源 | 说明 |
|---|---|
| **板书** | 课上真实写过的内容，笔记里附**逐字原文**（如板书 5 右半张、板书 6） |
| **讲义** | 讲义里有、但课上没讲，笔记里按讲义补全（如 §3.1–§3.13） |
| **教材补充** | 讲义只给结论、未给证明，笔记里补上推导（如 §2.6 RQI 的三次收敛、§3.10 的误差估计上界、§3.13 的最佳松弛因子） |
| **作业驱动** | 为回应作业题而写的小节（如 §1.4 的两个附注对应 `homework-20261013` 第 3、4 题），笔记里明确标注 |

每节标题右侧都有来源标签，附录里有完整的板书对照表。**引用时请注意区分。**

已核实的几个事实：

- 第 3 章在板书上**只有两行**（直接法/迭代法代价对比 + 「构造序列、极限是解」的口号式定义），**Jacobi / Gauss-Seidel / 收敛条件 / SOR 老师都没讲**；本文 §3.1–§3.13 属「按讲义提前自学」，复习时不要误当成课堂内容；
- **迭代精化**（§3.14）在 8 份讲义 PDF 全文检索「精化」**零命中**，只存在于板书第 6 张；
- 板书里的 `INVIT` / `RQIT` 是**特征值**的迭代法（第 5 章），不是第 3 章解线性方程组的迭代法；
- **第 2 章的收尾（讲义 PDF 2 §2.4）同样没在课上讲过**：其中「标准型的三种等价表述」与「等式约束的消元法」出现在板书 5（左）和板书 1 上，其余（`l₂` 惩罚项、GTH、Arnoldi、Lanczos）都是讲义独有。
- **§1.4 的两个附注不是板书内容**，是为回应 `homework-20261013` 第 3、4 题而写：第 3 题破坏「$n$ 个互不相同特征值 + $\lambda_1$ 半简单」，第 4 题破坏 $|\lambda_1|>|\lambda_2|$。对应讲义 **§5.1 幂法（PDF 5 pp.1–2）** 的收敛性定理。
