## 来源说明（重要）

这份笔记不是讲义的复述，而是**三态混合**的：

| 来源 | 说明 |
|---|---|
| **板书** | 课上真实写过的内容，笔记里附**逐字原文**（如板书 5 右半张、板书 6） |
| **讲义** | 讲义里有、但课上没讲，笔记里按讲义补全（如 §3.2–§3.5、§3.6–§3.9） |
| **教材补充** | 讲义只给结论、未给证明，笔记里补上推导（如 §2.6 RQI 的三次收敛、§3.9 的 `ρ(B) < 1`） |

每节标题右侧都有来源标签，附录里有完整的板书对照表。**引用时请注意区分。**

已核实的几个事实：

- 第 3 章在板书上**只有两行**（直接法/迭代法代价对比 + 「构造序列、极限是解」的口号式定义），**Jacobi / Gauss-Seidel / 收敛条件 / SOR 老师都没讲**；
- **迭代精化**（§3.10）在 8 份讲义 PDF 全文检索「精化」**零命中**，只存在于板书第 6 张；
- 板书里的 `INVIT` / `RQIT` 是**特征值**的迭代法（第 5 章），不是第 3 章解线性方程组的迭代法。
