    后训练：SFT、奖励模型与通用 RL

    Post-training: supervised fine-tuning, reward modeling & RL · 复旦大学数据科学学院 · Baojian Zhou · 2026-10-28

    预训练把一个模型训到「能续写任何文本」，但续写不等于回答。 后训练要解决的是把「会说话」变成「会听话」。 这节课按三级台阶走：SFT（用示范教格式与行为）、奖励模型（把人类偏好压成一个可优化的标量）、 通用 RL 算法（把那个标量当成目标去搜索）。每一级都有一次「看起来成立、其实不成立」的跳跃，笔记里都标出来了。

    主线：三句话
    1. 后训练改的是分布，不是能力。知识在预训练里已经有了，后训练只是把它条件化到一个具体的行为上：谁在说、对谁说、说到哪停、什么不该说。
    2. SFT 是行为克隆。把示范者的一条轨迹当成监督信号，逐 token 做极大似然。它决定「像不像人写的」，不决定「是不是人想要的」。
    3. 奖励模型是把偏好变成一个数。假设 Bradley–Terry，用成对比较训练一个标量打分器 $r_\phi(x,y)$，为下一步的 RL / DPO 提供目标函数。

    三级的共同结构：先有信号，再有目标函数，最后才谈优化。 SFT 的信号是示范，RM 的信号是比较，RL 的信号是那个打分器的输出。 信号本身的缺陷，优化器是修不了的——这一讲一半的篇幅在讲这件事。

    第零部分 · 先建立整体图像

    这一部分只回答一个问题

    一个已经会写字的模型，为什么还要被「再训练」三次？

    这一部分没有公式。如果你时间很紧，只读 0.2 和 0.3，就能把后面四部分的顺序立起来。

    0.1 用一个例子贯穿全讲 补充

    后面的公式很多，但它们全都在回答同一个场景。先把这个场景记住：

    贯穿全讲的例子

    用户问：「我一个月想减 5 公斤，怎么吃？」

    我们看这个模型在四个阶段分别会怎么回答。

    阶段一：预训练之后 —— 它会「接着写」，不会「回答你」

    你问它减肥，它很可能这样开头：

    「随着生活水平的提高，肥胖已经成为影响国民健康的重要公共卫生问题。近年来……」

    这不是它笨，而是它从来没被要求回答问题。它这辈子只做过一件事：看一段文字，猜下一个词。 它见过一万篇减肥文章，所以它给你续写了一篇文章的开头——这正是它被训练出来的行为。

    它甚至不知道「有人在问它」。它只知道「前面出现了这些字，后面通常接什么字」。

    阶段二：SFT 之后 —— 它学会了「回答」这个格式

    我们给它几千条「问题 + 人写的好回答」，它很快就学会了：

    「先算你的基础代谢（约 1500 千卡），每天制造 500 千卡的热量缺口，一个月大约能减 2 公斤……」

    这次像样了。但要注意它到底学到了什么：它学到的是「像示范那样写」，不是「什么是对的」。 示范里没出现过的答法，它不会。示范里如果有人写错了，它也会照着错。

    阶段三：奖励模型（RM）之后 —— 模型本身没变，我们多了一个「裁判」

    这一步很容易误解。训完奖励模型，那个回答问题的模型一点都没变。

    变的是：我们手上多了一个函数，喂给它（问题，回答），它吐一个分数。比如

    回答裁判给的分
    「少吃多动，坚持就是胜利」0.2
    「先算基础代谢，每天缺口 500 千卡，蛋白质每公斤体重 1.6 克……」0.9

    这个裁判是怎么来的？让人看几万对回答，每次只回答「这两条哪个更好」。裁判从这些「哪个更好」里， 学会了给任何一条新回答打分。它的全部本领就是把「好坏」变成一个数。

    阶段四：RL 之后 —— 模型开始「自己找更好的答案」

    现在有了裁判，就可以让模型自己练：

    1. 同一个问题，模型自己写 8 条回答（不是人写的）；
    2. 裁判给这 8 条各打一个分；
    3. 分高的那条，让它以后更容易出现；分低的，让它更不容易出现；
    4. 换下一个问题，重复几万次。

    神奇的地方在这里：模型会写出示范里根本没有的答法。因为它是随机采样的，偶尔会采到一个 「人没写过、但裁判觉得好」的回答。这种回答一旦出现，就会被强化，下次更容易出现。

    记住这一句

    四个阶段不是四个不同的模型，而是四种不同的能力： 预训练给它语言，SFT 给它格式，RM 给我们判断力，RL 让它自己变强。

    0.2 为什么必须按这个顺序 补充

    初学者最容易糊涂的地方就是「为什么不能直接上 RL」。答案很简单：每一步都是被上一步的缺陷逼出来的。

    步骤它解决了什么它又留下了什么新问题
    预训练学会了语言、事实、推理的片段只会续写，不会回答问题
    SFT学会了「看到问题就写答案」这个格式只会模仿示范，永远超不过示范；而且示范只有「对的」，没有「错的」
    奖励模型能判断两条回答哪条更好了它只能判断，不能生成；而且这个裁判是可以被骗的
    RL模型能自己搜出比示范更好的答案会钻裁判的空子；训久了会崩

    顺着这张表读一遍，整讲的顺序就出来了：

    • 因为预训练只会续写 → 所以要 SFT（§2）；
    • 因为 SFT 只有「对的示范」、没有「哪个更好」→ 所以要 奖励模型（§3）；
    • 因为奖励模型只能打分、不会写 → 所以要 RL 拿这个分数去搜（§4）。

    每一步都不是「更高级的技术」，而是上一步留下的那个窟窿，只能用这个办法补。

    易错 · 有两个 $b$，不是一回事

    §3 的 $b$ 是打分头的偏置（$r = h^\top w + b$），一个固定的常数，训练完就不动了。

    §4 的 $b$ 是baseline（参照系），是用来减掉「这道题本来该得几分」的那个量，每次更新都在变。

    板书两处都写了 $b$，这是符号复用，不是同一个东西。本文在两处都就地标了 §3 / §4。

    三个词：策略、示范、偏好

    策略 $\pi_\theta$
    就是模型本身。准确说是一个函数：给定前面所有的词，输出「下一个词是各个候选的概率」。
    示范
    人亲手写的标准答案。SFT 用的就是它。
    偏好
    人对「两条回答哪条更好」的判断。奖励模型用的就是它。

    一句话区分后两个：示范是「写给你看」，偏好是「选给你看」。写比选贵得多——这也是为什么后面要换成偏好。

    你说「有公式但看不懂」，问题通常不在数学，而在没人告诉你先看哪里。 所以从这一节开始，凡标着「这个公式怎么读」的框，都按固定的五步写：

    第一部分 · 为什么预训练不够

    这一部分只回答一个问题

    预训练模型到底缺什么？
    答完这一部分你会知道：它缺的不是知识，而是「有人在问我」这件事。

    1.1 预训练给了什么、没给什么 板书

    板书把预训练压缩成四句话：① 超大规模语料；② 巨大模型，且规模按缩放定律定；③ 擅长 next-word prediction；④ 不擅长 following instructions。 前两句解释「为什么能成」，后两句解释「为什么还不够」。后训练的全部动机都长在 ④ 上。

    预训练的目标函数是 $-\sum_t \log p_\theta(x_t \mid x_{<t})$，语料是整个互联网。 它学到的因此是一个关于「文本接下来会是什么」的分布。这个分布里同时装着：

    • 语法、拼写、标点；
    • 事实与世界知识（以及大量记错的事实）；
    • 各种「说话的人」：维基百科、论坛吵架、小说对话、代码注释、客服话术、法律条文；
    • 大量推理片段——但这些片段和「回答你的问题」这个行为没有绑定。

    Base model 的行为特征很具体。给它 法国的首都是，它会续 巴黎； 给它 请解释一下梯度下降，它很可能续出一篇关于梯度下降的文章，而不是回答你。 因为它没见过「被提问」这个角色，只见过「文本继续」这个任务。

    板书回顾：缩放定律 板书

    ② 里的「巨大模型」不是随便堆的，规模是按幂律定的。Lecture 07 讲过，这里老师只把结论写出来：

    $$ L(N) = \left(\frac{N_c}{N}\right)^{\alpha_N}, \qquad L(D) = \left(\frac{D_c}{D}\right)^{\alpha_D}, \qquad L(C) = \left(\frac{C_c}{C}\right)^{\alpha_C} $$

    取对数就是三条直线：$\log L = \alpha_N\big(\log N_c - \log N\big)$，双对数坐标下斜率是 $-\alpha_N$。 板书旁边画的那两条下降的直线就是这个。

    补充 · 这个写法和 Chinchilla 的写法差一个常数项

    板书给的是纯幂律，$N\to\infty$ 时 $L\to0$。实际拟合里通常带一个不可约项：

    $$ L(N,D) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}} $$

    $E$ 是「语言的熵下限」，再大的模型也压不下去。纯幂律在小范围内拟合得很好，外推到大区间会低估损失—— L07 讲「外推失败」时踩的就是这个坑。

    更要紧的是第三式 $L(C)$ 不能单独看。固定算力 $C\approx 6ND$ 时 $N$ 与 $D$ 此消彼长， 把 $D = C/(6N)$ 代进去：

    $$ L(N) = E + \frac{A}{N^{\alpha}} + B\left(\frac{6N}{C}\right)^{\beta} $$

    这是 $N$ 的U 形函数：$N$ 太小则参数项大，$N$ 太大则数据项大。最低点就是「给定预算下的最优模型大小」， 板书右侧那个 V 形草图画的正是这件事。所以「更大的模型一定更好」在固定算力下是错的——这正是 Chinchilla 的结论。

    这一条对后训练的意义只有一句：后训练不动 $N$，也不显著增加 $D$。 它改的是「在同样的损失下，模型更会按人的要求回答」。所以缩放律不能直接预测后训练的效果， 后训练也从来不是「再堆一次规模」。

    补充 · 「对齐」在这里的准确含义

    alignment 常被翻译成「价值观对齐」，听起来很玄。在这个语境里它有一个非常具体的数学含义：分布对齐。

    记人类在给定 prompt $x$ 下真正想要的回答分布为 $p^\star(y\mid x)$，模型的分布为 $\pi_\theta(y\mid x)$。 预训练让 $\pi_\theta$ 逼近互联网文本的边缘分布，而 $p^\star$ 是它的一个极小子集： 同样一个问题，互联网上有几十种写法（教程、论坛回帖、论文摘要），而人类想要的只有其中一小块。

    所以后训练不是「注入能力」，而是「在已有能力的支撑集上重新分配概率质量」。 这也解释了为什么后训练的数据量可以比预训练小五六个数量级：它不需要重新学分布的形状，只需要挪一下质量。

    1.3 三个分布，三种损失 板书

    把后面所有公式统一到一套记号上，可以省掉大量重复。四个对象：

    记号含义从哪来
    $\pi_\theta(y\mid x)$策略：给定 prompt 生成回答的分布要训练的东西
    $\pi_{\text{ref}}(y\mid x)$参考策略（通常是 SFT 后的模型）冻结，只用来算 KL
    $p_{\text{data}}(y\mid x)$示范分布：标注者写下的那些回答SFT 数据
    $p^\star$ / 偏好 $\succ$人类真正想要的（只能通过比较观测到）RM 数据

    三种方法对应三种「把不可观测的 $p^\star$ 换成可计算的替代品」的方式：

    方法损失它在逼近什么
    SFT$-\mathbb{E}_{p_{\text{data}}}\log \pi_\theta(y\mid x)$$p_{\text{data}}$（示范者的分布）
    RM$-\mathbb{E}\log\sigma\big(r_\phi(x,y_w)-r_\phi(x,y_l)\big)$偏好序 $\succ$（只有排序，没有数值）
    RLHF$\max_\pi \mathbb{E}\,r_\phi - \beta\,\mathrm{KL}(\pi\|\pi_{\text{ref}})$$p^\star$（用 $r_\phi$ 代理）
    易错 · 这三行不是同一个「对齐」

    SFT 逼近的是示范者，RM 逼近的是排序，RL 逼近的是打分器。 三者只有在「示范者 = 最优」且「排序无噪声」且「打分器无漏洞」时才重合。 现实中这三条都不成立，所以「SFT 做得好 → 模型就好」这个推理链在每一环都会漏。 后面 §2.9 与 §3.8 的优缺点，本质就是把这三条假设逐条拆开看。

    1.4 ground truth 在哪：四级监督信号 板书

    这一节回答一个看起来很基础、但决定了后面所有方法性格的问题：每一步训练，我们拿什么当「正确答案」？

    阶段每一步的监督信号ground truth每样本信息量
    预训练语料里的下一个 token有（自监督：文本自己就是答案）约 $\log|V|$ nats / token
    SFT人类写下的那一个 token有（示范）约 $\log|V|$ nats / token
    奖励模型人类的一次二选一有，但只有 1 bit1 bit / 一对比较
    RL奖励模型的输出 $r_\phi$没有0

    这张表有两个方向相反的趋势，值得并排看：

    • 监督信息量在单调下降：从「每个位置几 nats」→「每条 pair 1 bit」→「零」。
    • 目标却越来越接近我们真正想要的：从「文本长这样」→「助手该这么说」→「这个更好」→「让模型自己去找更好的」。

    换句话说，后训练的每一级都是用更少的监督，换更对的目标。 这就是为什么越往后越难训、越容易跑偏——不是工程问题，是信息问题。

    补充 · 奖励模型的 ground truth 到底是什么

    一条训练样本是 $(x, y_w, y_l)$，它的 ground truth 就是那个 1 bit 的标签： 「在这一次比较里，$y_w$ 被选中了」。

    但要注意它不是「$y_w$ 客观上更好」这个事实，而是一次人类判断的采样。 同一条 pair 换一个人标、或者同一个人隔一周再标，标签都可能翻。所以：

    • 标签噪声是内生的，不是标注事故；清洗不掉，也不该清洗掉；
    • RM 的准确率上限不是 100%，而是人类之间的一致率（通常 70%～80%，视任务主观程度而定）。

    这一点在 §3.7 会变成一条很实用的判据：RM 的 acc 明显超过人类一致率，先怀疑数据泄漏，而不是先庆祝。

    易错 · RL 阶段没有 ground truth，这是一条结构性事实

    预训练、SFT、RM 都能算「准确率」，因为它们各自有一个可对照的答案。RL 不能——它唯一的信号是 $r_\phi(x,y)$， 而 $r_\phi$ 本身是一个学出来的代理。于是 RL 训练中你看到的「reward 在涨」这句话， 严格来说只说明「模型越来越会讨好 $r_\phi$」，不说明「模型变好了」。

    后果是三条工程约束，后面 §4 会再回来：

    • 没有可靠的 early stopping 信号——验证集上的 reward 也是代理，它和 reward 一起涨；
    • 只能靠 KL 约束限制漂移，把「走多远」变成一个显式的超参 $\beta$；
    • 唯一不含代理的评估是人工评估，所以 RL 实验必须留一套人工评估集，且不能拿它调参。

    那什么时候 ground truth 会回来？当任务本身可验证的时候：数学题有标准答案、代码有单元测试、格式有语法检查。 这时奖励不再是学出来的 $r_\phi$，而是算出来的 $0/1$。这条路线（RLVR）是最近几年 RL 阶段最重要的变化， §4.11 会讲它为什么把「没有 ground truth」这个问题绕过去了——以及它自己带来了什么新问题。

    第二部分 · SFT：监督微调

    这一部分只回答一个问题

    怎么让它学会「回答问题」？这个办法的极限在哪？
    这一部分前半是「怎么做」（公式与工程细节），后半是「为什么它只能做到这一步」（三个结构性问题 + 优缺点）。

    SFT（supervised fine-tuning，也叫 instruction tuning）是后训练里最没有悬念的一步： 拿一批「问题 + 人类写的好回答」，当成普通的语言建模数据继续训练。 没有新损失、没有新框架，和预训练用的是同一行代码。

    但「没有悬念」不等于「没有内容」。这一节的重点是：为什么它只能做到这一步。

    2.1 SFT 在优化什么 板书

    在强化学习的语言里，SFT 就是行为克隆（behavior cloning）：把示范者的一条完整轨迹 $(x, y^{(1)}, \dots, y^{(T)})$ 当成监督信号，让模型在每一步都提高「示范者当时选的那个 token」的概率。

    它是对「对齐人类偏好」最朴素的一种实现：偏好太抽象，那就让人类直接把想要的答案写出来。 写出来的这条轨迹，就是 $p^\star$ 的一个样本。SFT 假设：如果每个 token 都像示范者，整段回答就像示范者。

    这个假设正是它全部优点的来源，也是它全部缺点的来源——§2.9 会回来算这笔账。

    补充 · 为什么先 SFT 再谈别的

    三个理由，都不是「效果最好」，而是「不可替代」：

    • 定义支撑集。RM 和 RL 都只在策略已经会生成的回答上有效。一个不会输出 JSON 的模型， 奖励模型没法告诉它「JSON 更好」——它压根采样不到。SFT 先把目标格式放进支撑集。
    • 定义参考分布。KL 约束需要 $\pi_{\text{ref}}$；DPO 需要 $\pi_{\text{ref}}$；PPO 需要初值。 这三个都是 SFT 模型。
    • 便宜。RL 的采样成本是 SFT 的几十倍，而且调参不稳。能用 SFT 解决的（格式、语气、工具调用语法），不该上 RL。

    2.2 损失函数：从序列似然到 token 级 板书

    起点是自回归分解。一条回答的概率是逐 token 条件概率的乘积：

    $$ \pi_\theta(y \mid x) \;=\; \prod_{t=1}^{|y|} \pi_\theta\big(y_t \mid x,\, y_{<t}\big), \qquad y_{<t} = (y_1,\dots,y_{t-1}) $$
    这个公式怎么读

    它在算什么：一整条回答出现的概率。比如「今天天气不错」这几个字，作为一个整体，模型认为它出现的可能性有多大。

    每个符号：$\pi_\theta$ 是模型本身；$y$ 是整条回答；$y_t$ 是第 $t$ 个字；$y_{<t}$ 是它前面的所有字；$\prod$ 是连乘。

    为什么是连乘：生成是一条路走到底——先选第 1 个字，再在「第 1 个字已知」的条件下选第 2 个， 再在「前两个字已知」的条件下选第 3 个……每一步都是一个条件概率。 走完整条路的概率，按概率的乘法法则就是每步相乘。

    代一组数字：假设只有 3 个字，模型每一步给正确答案的概率是 $0.5$、$0.2$、$0.1$， 那么整条回答的概率是 $0.5\times0.2\times0.1=0.01$。注意它比每一步都小——「整条都对」比「某一步对」难得多。

    这条式子的毛病：句子越长，乘的项越多，乘积越小。100 个字的回答，概率会小到 $10^{-30}$ 这种量级， 既存不下也没法比较。所以实际训练时两边取对数，把连乘变成连加： $\log\pi_\theta(y\mid x)=\sum_t\log\pi_\theta(y_t\mid\cdot)$。 这就是下面那个损失函数里为什么到处都是 $\log$。

    板书：前缀–回答记号与 teacher forcing 板书

    板书把它写成更一般的「前缀 $p$ + 回答 $r$」形式，这个写法在后面讲多轮对话和掩码时更好用：

    $$ LM_\theta\big(\hat y = r \mid p\big) = \prod_{i=1}^{|r|} LM_\theta\big(r_i \mid p,\, r_{<i}\big) $$

    这里 $p$ 是 prompt，$r$ 是要学的那一段。$\pi_\theta(y\mid x)$ 只是它的特例（$p=x$，$r=y$）。 好处是「多轮对话」「工具调用」「思维链」都不需要新公式——它们只是 $p$ 更长、$r$ 分成几段而已。

    板书接着写了三行，标着 teacher forcing：训练时把示范的整条回答一次性喂进去，让每个位置预测下一个 token。

    喂进去的要求模型预测
    $x,\; y_1$$y_2$
    $x,\; y_1,\; y_2$$y_3$
    $x,\; y_1,\; y_2,\; y_3$$y_4$

    关键在于「喂进去的前缀是示范的，不是模型自己写的」。这让一条序列里所有位置可以并行算—— 一次前向就得到 $|y|$ 个损失，这是 SFT 能训得动的全部原因。

    易错 · teacher forcing 的代价要等到推理时才付

    训练时模型永远站在「正确的前缀」上；推理时它站在「自己刚写的前缀」上。这两个分布一旦分叉， 后面每一步都在错误的输入上做预测，误差会累积（compounding error）。

    这不是实现问题，是目标函数本身的性质：它优化的对象里根本没有「写错了怎么救」这一项。 这就是 exposure bias，§2.9 会把它列进缺点表。

    数据集 $\mathcal{D} = \{(x^{(i)}, y^{(i)})\}_{i=1}^{N}$ 上做极大似然，等价于最小化负对数似然：

    $$ \mathcal{L}_{\text{SFT}}(\theta) \;=\; -\,\mathbb{E}_{(x,y)\sim \mathcal{D}} \left[\frac{1}{|y|}\sum_{t=1}^{|y|} \log \pi_\theta\big(y_t \mid x, y_{<t}\big)\right] $$

    里面的每一项都是一个标准的多分类交叉熵。记第 $t$ 步的 logits 为 $z_t = f_\theta(x, y_{<t}) \in \mathbb{R}^{|V|}$， softmax 之后 $p_t(v) = \dfrac{e^{z_{t,v}}}{\sum_{u} e^{z_{t,u}}}$，那么

    $$ \ell_t \;=\; -\log p_t(y_t) \;=\; -\sum_{v\in V} \underbrace{\mathbb{1}[v = y_t]}_{\text{one-hot}}\,\log p_t(v) \;=\; \log\!\sum_{v\in V} e^{z_{t,v}} \;-\; z_{t,\,y_t} $$

    最后那个等式是实际实现用的形式：log-sum-exp 减目标 logit。 它比「先 softmax 再取 log」数值稳定得多——$e^{z}$ 在 $z\approx 90$ 时就会在 fp32 里溢出， 而 log-sum-exp 可以先减去 $\max_v z_v$ 再做。

    易错 · 三个「平均」不是一回事

    $\mathcal{L}$ 里的 $1/|y|$ 只是三种归一化之一，选哪个会改变梯度的加权：

    • token 平均（除以 $\sum_t m_t$）：每个 token 权重相同。长回答被稀释 → 偏向短回答。
    • 序列求和（每条样本先加总，再对 batch 平均）：长回答主导 → 偏向长回答。
    • 序列平均（每条样本先按 token 平均，再对 batch 平均）：上面写的这种，折中。

    数值上：一个 batch 里两条样本长度 50 与 500，token 平均下前者的每个 token 权重是后者的 10 倍。 如果数据里长度分布很宽（短问答 + 长推理），这一项会悄悄决定模型学谁。

    2.3 loss mask：只算回答的 token 板书

    真实训练时，$x$ 与 $y$ 是拼成一条序列喂进去的。但我们不想让模型学「怎么生成问题」。 于是引入掩码 $m_t \in \{0,1\}$：

    $$ \mathcal{L}_{\text{SFT}}(\theta) \;=\; -\,\frac{\sum_{t=1}^{T} m_t \,\log \pi_\theta\big(x_t \mid x_{<t}\big)}{\sum_{t=1}^{T} m_t}, \qquad m_t = \begin{cases} 0, & t \le |x| \quad(\text{prompt})\\[2pt] 1, & t > |x| \quad(\text{response})\end{cases} $$
    这个公式怎么读

    它在算什么：平均每一步「模型给正确答案留了多少概率」，然后取负号。

    每个符号：$m_t$ 是开关（回答段为 1、prompt 段为 0）； 分子把所有「开关打开的位置」的 $\log$ 概率加起来；分母 $\sum_t m_t$ 是「一共打开了几个位置」，除它就是取平均； 最前面的负号是因为我们想「让概率尽量大」，而优化器只会「让损失尽量小」，所以翻个号。

    为什么要取 $\log$：接上面那条——连乘会下溢，连加不会。 而且 $\log$ 把「概率 0.9 和 0.1」变成「$-0.105$ 和 $-2.30$」，差距从 9 倍拉成 22 倍： 错得越离谱，罚得越重，这正是我们要的。

    代一组数字：模型给正确词的概率是 $0.9$ → $\ell=-\log0.9=0.105$；是 $0.5$ → $0.693$； 是 $0.1$ → $2.30$；是 $0.01$ → $4.61$。所以 loss 越小，说明模型越「笃定地答对」。

    什么时候变大：模型看到正确答案时越「惊讶」，loss 越大。完全猜中（$p=1$）时 loss 是 0， 但永远达不到——这也意味着 loss 永远不会变成 0，别拿「loss 到 0」当训练目标。

    为什么必须 mask，三个理由从轻到重：

    1. 算力浪费。prompt 通常比回答长。一个 200 token 的 prompt 配 50 token 的回答， 不 mask 的话 80% 的梯度花在「复述问题」上——而推理时问题是我们给的，模型根本不需要生成它。
    2. 多轮对话会学歪。如果把 loss 覆盖到 user turn，模型就在学「怎么扮演用户」。 推理时它可能自己接自己的话、替用户提问、甚至伪造一轮对话再回答。
    3. padding 必须 mask。右 padding 时 pad token 会占据大部分位置，不 mask 会让模型学会「输出 pad」， 直接表现为生成很短就停。

    实现上还有一个细节：位置 $t$ 的 logits 预测的是 token $t+1$（因果位移）。 所以掩码要定义在标签上，而不是输入上。写错一位，模型会把 prompt 的最后一个 token 也当成学习目标—— 效果上像是「学会了在问题结尾多说一个字」，很难 debug。

    2.4 梯度长什么样 推导

    把 $\ell_t$ 对参数求导，得到的是一个非常干净的结构。先对 logit 求导：

    $$ \frac{\partial\, \ell_t}{\partial\, z_{t,v}} \;=\; p_t(v) - \mathbb{1}[v = y_t] $$

    再链式到参数（$\partial z_{t,v}/\partial\theta$ 由反向传播给）：

    $$ \nabla_\theta\, \ell_t \;=\; \sum_{v\in V}\big(p_t(v) - \mathbb{1}[v=y_t]\big)\,\nabla_\theta z_{t,v} \;=\; \underbrace{\mathbb{E}_{v\sim \pi_\theta}\big[\nabla_\theta z_{t,v}\big]}_{\text{当前分布的期望}} \;-\; \underbrace{\nabla_\theta z_{t,\,y_t}}_{\text{示范 token}} $$

    合并起来：

    $$ \nabla_\theta \mathcal{L}_{\text{SFT}} \;=\; \frac{1}{\sum_t m_t}\sum_{t=1}^{T} m_t \left( \mathbb{E}_{v\sim\pi_\theta(\cdot\mid x,y_{<t})}\big[\nabla_\theta z_{t,v}\big] \;-\;\nabla_\theta z_{t,\,y_t} \right) $$
    这个公式怎么读

    它在算什么：往哪个方向调参数，能让「正确答案」的概率变大。

    括号里两项在打架：

    • 第二项 $\nabla_\theta z_{t,y_t}$：把正确答案的分数推高；
    • 第一项 $\mathbb{E}_{v\sim\pi}[\nabla_\theta z_{t,v}]$：按模型当前的想法， 把所有候选词的分数按概率加权平均地压低。

    为什么必须有第一项：因为 softmax 之后所有概率加起来必须等于 1。推高一个，别的必然被压低。 所以这个梯度天生是「对比」的——它不是单纯「抬高正确答案」，而是抬高它、同时压低其余的。 像跷跷板：不能只抬一头而不让另一头下去。

    一个顺带的结论：当模型已经很确定正确答案（$p\approx1$）时，括号里两项几乎相等，梯度趋近 0—— 已经学会的样本不再产生梯度。所以训练后期真正在起作用的，是那些「还不会」的样本， 以及……标注写错的样本。这也是为什么数据清洗比多训几轮更有用。

    补充 · 读这个梯度：它已经在做「对比」了，只是对比对象不对

    括号里是「把示范 token 的 logit 推高，同时把所有 token 的 logit 按当前概率加权压低」。 形式上这就是一个对比损失：正样本是示范 token，负样本是模型自己认为可能的 token。

    问题在于负样本的来源。模型从没见过「人类讨厌的回答」——它只知道「示范者没这么写」。 而「没这么写」和「这么写不好」是两件完全不同的事：示范者只是选了 A，并不等于 B 是错的。 这个信息缺口，就是后面必须引入显式负例（成对比较）的根本原因。

    还有一个常被忽略的推论：当 $p_t(y_t)\to 1$ 时，$p_t(v)-\mathbb{1}[v=y_t]\to 0$，梯度消失。 所以 SFT 在已经学会的样本上几乎不再贡献梯度——后期的训练实际上只由「还不会的那部分」驱动。 这既是好事（自动聚焦难例），也是坏事（噪声样本、标注错误的样本会一直贡献最大的梯度）。

    2.5 等价于最小化前向 KL 推导

    SFT 的损失可以改写成 KL 的形式，这个改写后面讲 DPO 时会反复用到：

    $$ \begin{aligned} \mathcal{L}_{\text{SFT}}(\theta) &= -\,\mathbb{E}_{p_{\text{data}}}\big[\log \pi_\theta(y\mid x)\big] \\[4pt] &= \mathbb{E}_{p_{\text{data}}}\left[\log \frac{p_{\text{data}}(y\mid x)}{\pi_\theta(y\mid x)}\right] - \mathbb{E}_{p_{\text{data}}}\big[\log p_{\text{data}}(y\mid x)\big] \\[4pt] &= \mathrm{KL}\big(p_{\text{data}} \,\|\, \pi_\theta\big) \;-\; \mathbb{H}\big(p_{\text{data}}\big) \end{aligned} $$

    第二项与 $\theta$ 无关，所以最小化 SFT 损失 = 最小化 $\mathrm{KL}(p_{\text{data}}\|\pi_\theta)$， 这是一个前向 KL（$p$ 在前）。前向 KL 的性质是 mass-covering：

    $$ \mathrm{KL}(p\|q)\to\infty \quad\text{只要}\quad p(y)>0 \text{ 而 } q(y)\to 0 $$

    也就是说，只要示范分布里出现过某种写法，模型就必须给它分配概率，否则惩罚无穷大。 后果很具体：同一个问题，十个标注者写了十种都对的答案，SFT 不会学其中任何一种， 而会学出一个把十种揉在一起的第十一种——读起来四平八稳、什么都说了、什么都没说。

    易错 · 这就是「SFT 模型啰嗦、爱 hedging」的数学解释

    不是数据里有人写了废话，而是前向 KL 在多峰数据上的必然结果（mode averaging）。 对比一下：RL/DPO 里用的是反向 KL $\mathrm{KL}(\pi\|p^\star)$，它是 mode-seeking 的—— 只要抓住一个峰就行，其他的可以完全不管。这就是为什么 RL 出来的回答往往更「敢下结论」、更短、更尖锐， 同时也是为什么它更容易跑偏到某个奇怪的峰上。

    这个对比在 §4.8 还会出现一次，是理解「为什么还需要 RL」的最短路径。

    易错 · packing 的隐性 bug

    packing 把多条短样本拼成一条长序列以提高 GPU 利用率，看起来只是数据工程。 但如果只用普通的因果掩码，第 $k$ 条样本的第一个 token 会 attend 到第 $k-1$ 条样本的结尾。 模型于是学到了一个根本不存在的任务：「读一段无关文本，然后开始回答另一个问题」。 症状是：训练 loss 正常下降，线上却会在回答开头冒出奇怪的衔接词。

    正确做法是 varlen（变长）注意力，或构造块对角掩码让每条样本自成一块。position id 也要按样本重置。

    再补一个「为什么学习率必须小」的定量直觉：预训练结束时，损失已经在一个很窄的谷底。 SFT 数据的分布和预训练差得很远（对话 vs 网页），大学习率会让参数在几步之内离开谷底， 而几万条数据不足以把它拉回来——结果就是通用能力崩了、SFT 任务也没学好。 这也解释了为什么 SFT 常常伴随明显的「对齐税」。

    数据长什么样：JSONL 与 chat 模板 板书

    板书在 SFT 那一栏顺手画了数据的形状：一个 .jsonl 文件，每行一条对话，用 role 区分谁在说话。

    {"messages": [{"role": "user",      "content": "把这句话翻成英文：今天很热"},
              {"role": "assistant", "content": "It is very hot today."}]}

    训练前，这份结构会被 chat 模板渲染成一维 token 序列，模板里塞进特殊 token 标记角色边界：

    <|im_start|>user
把这句话翻成英文：今天很热<|im_end|>
<|im_start|>assistant
It is very hot today.<|im_end|>

    三个坑全在这一层，而且都不会报错，只会让模型变傻：

    • 模板不一致。训练用 A 模板、推理用 B 模板，模型看到的前缀分布变了，输出直接崩。 这是线上事故里最常见的一类。
    • 特殊 token 被切碎。如果 <|im_start|> 不在 tokenizer 的词表里， 它会被拆成十几个普通 token，模型就学不到「角色边界」这个概念，只学到一串奇怪的符号。
    • 掩码边界算错。回答从哪个 token 开始，必须按渲染之后的 token 位置算，不能按原始字符串算—— 一个中文字符可能对应 1 个也可能对应 3 个 token。

    2.8 板书点名的三个问题 板书

    讲完公式，板书在右下角写了 Problem of SFT，三条。这三条不是并列的抱怨，而是指向后面两步的路标。

    1. ground truth $y$ is hard to collect. 要一条「好回答」，得有人真的写出来。
    2. training whole model $\theta$ is expensive. 板书旁边画了 $\theta_1\to\theta_2\to\cdots$，指向参数高效微调。
    3. only one response. 一个 prompt 只有一条 $y^\star$，但我们其实想要 $y^1, y^2, \dots$ 来比较。

    (1) 数据难收集

    「写一个正确答案」的成本远高于「判两个哪个更好」。而且它有两个无法用钱解决的困难：

    • 很多任务没有唯一答案。「解释一下梯度下降」可以写 200 字也可以写 2000 字，都对。标注者写哪个，模型就学哪个。
    • 写不出比模型更好的答案时就卡住了。当模型已经接近人类水平，让标注者「写一条更好的」在物理上做不到—— 这是 SFT 的天花板，不是预算问题。

    (2) 训练整个 $\theta$ 很贵

    一个 7B 模型全参微调，除了权重本身（bf16 约 14 GB），还要存梯度和 Adam 的两个动量（fp32 各 28 GB）， 再加激活值，单卡根本放不下；70B 就更不用说。板书那串 $\theta_1\to\theta_2$ 指的就是「不整个动，只动一小块」。

    最常见的做法是 LoRA：冻结原权重 $W$，只学一个低秩增量

    $$ W' = W + \Delta W, \qquad \Delta W = BA, \qquad B\in\mathbb{R}^{d\times r},\; A\in\mathbb{R}^{r\times k},\; r\ll\min(d,k) $$

    可训练参数从 $dk$ 降到 $r(d+k)$。取 $d=k=4096$、$r=16$：

    参数量占比
    全参 $W$16,777,216100%
    LoRA $BA$131,0720.78%

    所以同样的显存可以开更大的 batch、或者在多份数据上各训一个 adapter。 代价是表达力受限（$r$ 越小越受限），而且推理时要么把 $BA$ 合并回 $W$（省延迟），要么额外算一条分支（省显存）。

    (3) 一个 prompt 只有一个回答

    这一条最要命，因为它不是资源问题，是信息问题：

    • 一条示范只说明「这样可以」，没说「那样不行」。想纠正一个具体错误，只能再写一条正确示范，不能只标「这条差」。
    • 不同标注者写的都对，而 SFT 会把它们平均掉（§2.5 的前向 KL），结果是四平八稳、什么都不表态。
    • 「哪个更好」这个信息，在一条轨迹里根本不存在——它需要至少两个候选才能表达。
    补充 · 这三条正好对应后两步

    第 (3) 条直接推出奖励模型：既然一个 prompt 只给一条不够，那就给多条、让人排序—— 这就是 §3.6 里「采样 $k$ 条再比较」的来源。

    第 (1)(2) 条解释了为什么后来的方法都在想办法「少写、少训」：RM 把「写」换成「判」， DPO 把「训一个 RM + 训一个策略」压成「训一个策略」。

    所以板书这三行，其实是整节课的目录。

    2.9 SFT 的优缺点 板书

    优点

    优点具体表现
    简单、稳定、可复现损失就是交叉熵，复用预训练全套基础设施（并行、混合精度、checkpoint），没有 RL 的方差与调参地狱
    样本效率高（对「格式」而言）JSON 输出、工具调用语法、固定模板这类硬约束，几百条就能学会；RL 反而很难学出「必须闭合括号」
    目标可诊断train/val loss、token accuracy 都能直接看，出问题能定位到数据或模板，而不是「reward 涨了但模型变差」
    没有 reward hacking 通道没有代理指标，就没有「优化指标的漏洞」这件事；行为上界就是示范者，不会更离谱
    是后续方法的必要条件RM 的初始化、DPO 的 $\pi_{\text{ref}}$、PPO 的初值，全部来自 SFT
    可解释的失败模型答错时，通常能在训练数据里找到相似的错误示范——因果链清楚

    缺点

    缺点机制
    天花板 = 示范者行为克隆的上界是专家策略。示范者写不出的，SFT 学不会。数学上：最优解是 $\pi_\theta = p_{\text{data}}$，而 $p_{\text{data}}\ne p^\star$
    似然 ≠ 偏好损失是逐 token的，人类判断是整段的。一个整体更好但用词不同的回答，NLL 可能更高
    exposure bias训练时前缀来自示范，推理时前缀来自模型自己。一旦走偏，误差累积（compounding error），而训练里没有「如何纠错」的样本
    多峰平均前向 KL 的 mass-covering 性质（§2.5）→ 输出啰嗦、hedging、不敢下结论
    只有正例不能直接说「这样不行」。想修一个具体错误，必须写一条正确示范，而不能只标「这条差」
    会模仿示范里的错误示范里的幻觉、过度拒答、markdown 滥用、固定的开场白，全部被当作「正确答案」学进去
    灾难性遗忘窄分布上微调 → 通用能力、多语言、安全性回退，即「对齐税」
    熵坍缩窄数据上多轮 SFT 会让输出分布变尖：pass@1 涨，pass@k 掉，多样性下降
    标注成本高「写一个」比「判两个」贵得多；而且不同标注者写的都对，无法平均
    补充 · 一句话总结

    SFT 决定「像不像人写的」，不决定「是不是人想要的」。

    它把「助手」这个角色装进了模型，但「好」这个概念没有被表达出来——因为示范数据里只有一个答案， 没有「为什么这个比那个好」。要表达「好」，必须让人类比较。这就是第三部分的起点。

    那为什么大家还在用 SFT

    因为上面九条缺点里，前六条都是「它做不到更多」，而不是「它做错了」。 SFT 在自己的职责范围内几乎没有替代品：它便宜、稳定、可解释，而且它的输出正是后续方法需要的起点。 工程上的正确姿势是把 SFT 用在它擅长的地方（格式、风格、工具语法、拒答边界）， 把「哪个更好」交给偏好数据。

    第三部分 · 奖励模型

    这一部分只回答一个问题

    怎么把「哪个更好」变成一个能算的数？
    这一部分的关键只有一句：让模型给两条回答各打一个分，用分差算出「谁更好的概率」，再拿人类的真实选择去纠正它。

    SFT 之后，模型会「像一个助手那样说话」了。但我们仍然没法回答一个最基本的问题： 两个都像助手的回答，哪个更好？

    这个问题 SFT 答不了，因为它的数据里每条 prompt 只有一个答案，没有「更好」这个概念。 要表达「更好」，最自然的方式是让人类比较——而这正是奖励模型的输入。

    3.1 为什么需要一个打分器 板书

    先把「好」这件事的观测形式说清楚。人类能稳定提供的信号，按可靠性排序大致是：

    1. 两个回答里选一个更好的（pairwise comparison）——最可靠，标注最快，一致性最高；
    2. 给一个回答打绝对分（1–7 分）——刻度因人而异，漂移严重；
    3. 写一个更好的回答——信息量最大，但最贵，而且写不出来的时候就卡住了。

    第 3 种就是 SFT，已经用过了。奖励模型要做的是把第 1 种变成一个函数：

    $$ r_\phi:\; (x, y) \;\longmapsto\; \mathbb{R}, \qquad\text{s.t.}\qquad r_\phi(x, y_w) > r_\phi(x, y_l) \iff y_w \text{ 比 } y_l \text{ 更受偏好} $$

    有了这个 $r_\phi$，后面几乎所有事情都能做：

    用途怎么用
    RLHF / PPO 的奖励把 $r_\phi(x,y)$ 当成 $y$ 的回报，直接做策略梯度
    best-of-$n$ / 拒绝采样采样 $n$ 条，取 $r_\phi$ 最高的一条；不需要训练
    构造 DPO 数据用 $r_\phi$ 给候选排序，自动生成 $(y_w, y_l)$
    离线评估不跑人评也能粗看模型有没有变好（有风险，见 §3.7）
    补充 · 一句话定位

    奖励模型是把「稀疏、序列级、主观、昂贵」的人类判断，压缩成一个「稠密、可复用、便宜」的标量。 它做的是一次摊销（amortization）：标注一次，之后无数次调用。 代价是——这个压缩是有损的，而损失的部分正是 §3.7 里所有问题的根源。

    板书：奖励模型怎么用 板书

    板书在 RM 那一栏的右下角画了最直接的用法：

    $$ x \;\longrightarrow\; \underbrace{\text{tuned LLM}}_{\text{采样 } n \text{ 条}} \;\longrightarrow\; y_1,\dots,y_n \;\longrightarrow\; \underbrace{\text{RM}}_{\text{逐个打分}} \;\longrightarrow\; r_1,\dots,r_n \;\longrightarrow\; \arg\max_i r_i $$

    这就是 best-of-$n$（也叫拒绝采样）：不训练、不改参数，只多花 $n$ 倍推理算力换质量。 它的收益是对数式的——$n$ 从 1 加到 4 提升明显，从 64 加到 256 就很小了， 因为要再提升就得采到比「当前最好那条」还好的样本。

    它同时是 RM 的第一个用法和第一个坑：$n$ 越大，被选中的那条越是「$r_\phi$ 眼中的最好」，而不是「人眼中的最好」。 $n\to\infty$ 时你选到的就是 $r_\phi$ 的 argmax，也就是 reward hacking 的极端形态（§3.7）。

    3.2 Bradley–Terry：从比较到概率 板书

    先把打分函数写死。课上给的奖励模型是最朴素的形态：取序列最后一个位置的隐状态 $h_t\in\mathbb{R}^d$， 接一个线性层得到一个实数，

    $$ r_\phi(x,y) \;=\; h_t^{\top} w + b, \qquad w\in\mathbb{R}^d,\;\; b\in\mathbb{R} $$

    参数 $\phi=(w,b)$；$h_t = f_\theta(x,y)$ 来自主干（通常就是 SFT 模型的最后一层，与 $w$ 一起微调，也可以冻结）。 注意 $t$ 是最后一个 token 的位置——RM 输出的是一个数，不是每个位置一个数。 这一点和语言模型头（每个位置一个 $|V|$ 维向量）正好相反。

    有了分数，还需要一个把「分数」变成「胜率」的假设。Bradley–Terry（1952）说：两个回答的胜率等于它们强度的指数之比，

    $$ P\big(y_w \succ y_l \mid x\big) \;=\; \frac{e^{\,r(x,\,y_w)}}{e^{\,r(x,\,y_w)} + e^{\,r(x,\,y_l)}} $$

    分子分母同除以 $e^{\,r_w}$，立刻得到更常见的形式：

    $$ P \;=\; \frac{1}{1 + e^{-(r_w - r_l)}} \;=\; \sigma\big(r_w - r_l\big) \;=\; \sigma(\Delta) $$

    两种写法是同一个式子。「指数之比」的好处是可以直接推广到 $K$ 个候选（§3.3 的 Plackett–Luce）， 「sigmoid 套差值」的好处是一眼就能看出它是二分类。

    代入打分函数：偏置会消失 推导

    把 $r = h^{\top}w + b$ 代进差值：

    $$ \Delta \;=\; r(x,y_w) - r(x,y_l) \;=\; \big(h_w^{\top} w + b\big) - \big(h_l^{\top} w + b\big) \;=\; w^{\top}\big(h_w - h_l\big) $$

    偏置 $b$ 被减掉了。这不是巧合，正是「平移不变」的具体表现： 给所有分数加同一个常数不改变任何一对的比较结果，而 $b$ 就是那个常数。

    补充 · 所以它就是 binary logistic regression

    定义差值特征 $\varphi = h_w - h_l \in \mathbb{R}^d$，标签 $z=1$ 表示「$y_w$ 赢」，则

    $$ P(z=1\mid \varphi) \;=\; \sigma\big(w^{\top}\varphi\big) $$

    这正是以 $\varphi$ 为输入、以 $w$ 为权重、没有偏置的标准逻辑回归。 换句话说，奖励模型在做的事是：把「两条回答的隐状态之差」映射成一个二分类概率。 训练它，就是在 $(h_w-h_l)$ 这个特征空间里找一个能把「赢的一边」分开的超平面。

    这个视角一次解释三件事：

    • $b$ 可以不要。它在 $\Delta$ 里消失了，对损失没有任何影响（梯度恒为 0）。 保留它只在你想用绝对分数做阈值（例如「低于某分就拒答」）时才有意义。
    • 打分层是凸的。逻辑回归的负对数似然关于 $w$ 是凸的，所以最后一层不会训崩； 非凸性全部来自主干 $f_\theta$。
    • 「分数」其实是「在一个方向上的投影」。$r = w^{\top}h + b$ 只关心 $h$ 在单一方向上的分量。 这与 BT 的「单一潜在维度」假设是同一件事的两种说法：有用性、安全性、语气若真的互相冲突， 一个 $w$ 就表达不了，需要多个打分头再加权。

    还有一层等价关系值得记住：$\dfrac{e^{r_w}}{e^{r_w}+e^{r_l}}$ 就是对两个 logit $(r_w,r_l)$ 做二分类 softmax。 于是「BT 二分类」与「$K$ 类 softmax」是同一套东西在 $K=2$ 与 $K>2$ 的两个特例—— 这也是为什么下一小节的 listwise 版本能无缝接上。

    为什么是指数形式 推导

    指数不是随手挑的。起点是 Luce 的选择公理：若每个选项有正权重 $v_i$，则

    $$ P(i \text{ 胜过 } j) \;=\; \frac{v_i}{v_i + v_j}. $$

    再假设「强度可加」，即权重取指数形式 $v_i = e^{r_i}$（这样两个选项的相对优势只取决于差值 $r_i-r_j$），代入即得 BT：

    $$ P(y_w \succ y_l) = \frac{e^{r_w}}{e^{r_w}+e^{r_l}} = \sigma(r_w - r_l). $$

    换掉任何一条假设，形式就变：若假设噪声是正态的，得到的是 probit $\Phi(\Delta)$；若假设强度不可加，就得不到这种简洁形式。 所以 sigmoid 在这里不是「常用的激活函数」，而是两条建模假设的推论。

    易错 · BT 的三条隐含假设
    • 只依赖差值（平移不变）。$r\to r+c$ 时 $\Delta$ 不变，损失完全不变。 所以 RM 的绝对分数没有意义，只有差值和排序有意义；训练时通常会把每个 batch 的分数中心化（§3.5）。
    • 传递性。BT 隐含 $A\succ B,\;B\succ C \Rightarrow A\succ C$。真实偏好会循环 （A 更准、B 更简洁、C 更友好，两两比较可以出现剪刀石头布），BT 表达不了。
    • 单一潜在维度。所有偏好被压到一根实数轴上，等于假设「有用性 / 安全性 / 语气」可以被同一个数排序。 这正是上面「$r$ 只是一个方向上的投影」的另一种说法。

    还有一条不那么显然的：BT 隐含地固定了 $r$ 的单位（logistic 的斜率是 1）。 若写成 $\sigma(\alpha\Delta)$ 并让 $\alpha$ 可学，就等价于加了一个温度；BT 取 $\alpha=1$。 所以不同 RM 的分数只能比方向，不能比大小——A 模型给 3.2 分、B 模型给 0.8 分，这两件事没有可比性。

    3.3 损失函数与梯度 板书

    先把「胜率」算出来：3 分和 1 分，谁更好？ 补充

    在写损失之前，必须先把一件事说清楚，否则后面每一步都看不懂：公式里的「胜率」$p$ 不是统计出来的。

    它不是「打 100 场赢了 73 场」那种频率，而是模型根据自己的打分、自己算出来的一个概率—— 「模型认为人类会选 A 的概率」，不是「A 真实赢了多少次」。整个计算只有三步。

    第一步，打分。同一个问题有两条回答，奖励模型给它们各打一个绝对分数：

    $$ r(A) = 3, \qquad r(B) = 1 $$

    第二步，算分差。

    $$ \Delta = r(A) - r(B) = 3 - 1 = 2 $$

    第三步，把分差塞进 sigmoid，变成胜率。

    $$ p = \sigma(\Delta) = \frac{1}{1+e^{-\Delta}} = \frac{1}{1+e^{-2}} = \frac{1}{1+0.135} = 0.8808 $$

    结果：模型认为「3 分 vs 1 分」这 2 分的差距，意味着 A 比 B 好的概率是 88%。

    易错 · 这个 p 是「模型的想法」，不是「事实」

    它不代表 A 在真实世界里赢了 88% 的场次。它只是模型把「2 分的差距」按一条固定规则翻译成概率的结果—— 规则就是 $\sigma$，模型改不了它，能改的只有分数本身。

    所以：模型的「信心」不是学出来的，是分数差决定的。分差 2 就一定是 88%，分差 0 就一定是 50%，与训练数据无关。 真正的「胜率」只能在评测时用大量人工比较估出来（§3.7 的 pairwise accuracy）。

    这个函数的形状：几个极端值 补充

    $\Delta$$p=\sigma(\Delta)$含义

    两点值得记住：

    • 打平就是五五开。$\Delta=0$ 时 $e^0=1$，$p=1/(1+1)=0.5$。分不出来，就只能猜。
    • 分差再大也到不了 1。$\Delta=20$ 时 $e^{-20}\approx2.1\times10^{-9}$，分母几乎是 1，$p\approx0.999999998$。 函数是饱和的：2 分对应 88%，4 分对应 98%，20 分还差那么一点点——分数差的价值递减。

    为什么非得是这个形状？因为它来自 §3.2 那条很自然的假设（Bradley–Terry）： 实力越接近，胜率越接近 50%；差距越大，强者赢的概率越无限接近 100%。 sigmoid 正好是满足这条的最小假设——中间近似线性，两端饱和。

    那么怎么用这个 $p$ 训练？极大似然：让「人类选的那一条赢」的概率尽量大。取负对数就得到下面这个损失。

    $$ \mathcal{L}_{\text{RM}}(\phi) \;=\; -\,\mathbb{E}_{(x,\,y_w,\,y_l)\sim \mathcal{D}} \Big[\log \sigma\big(r_\phi(x,y_w) - r_\phi(x,y_l)\big)\Big] $$

    用 $\Delta_\phi = r_\phi(x,y_w) - r_\phi(x,y_l)$ 简写，注意这个恒等式：

    $$ \mathcal{L} \;=\; -\log\sigma(\Delta) \;=\; \log\big(1 + e^{-\Delta}\big) \;=\; \operatorname{softplus}(-\Delta) $$
    补充 · 这个恒等式说明了两件事

    第一，它就是带 margin 的 logistic 回归。BT 损失 = softplus(−margin)， 和「二分类 + logit = 分数差」是同一个东西。所有关于 logistic 回归的直觉（凸性、梯度形式、校准）都可以直接搬过来。

    第二，它是凸的。softplus 是凸函数，$\Delta$ 是 $\phi$ 的线性（或仿射）函数时，$\mathcal{L}$ 关于 $\phi$ 凸。 当然 $r_\phi$ 是深度网络，整体非凸——但「最后一层是凸的」意味着给定特征，打分头不会训崩， 这也是为什么 RM 通常比 RL 稳定得多。

    补充 · 换成二分类的写法，它更眼熟

    带标签 $z\in\{0,1\}$ 的标准交叉熵是

    $$ \ell(z,\Delta) \;=\; -\Big[z\log\sigma(\Delta) + (1-z)\log\sigma(-\Delta)\Big] $$

    取 $z=1$ 就回到上面的 RM 损失。反过来，如果训练时把每条 pair 随机交换顺序、 同时把标签翻成 $z=0$，就得到完整的 BCE——所以「训练奖励模型」在实现上就是一个二分类任务： 输入两条回答，输出「第一条是不是更好」。它的代码和普通的文本分类几乎没有区别， 只是把 vocab 维的输出换成了一个标量。

    交换顺序这个操作还有个副作用：它顺手消掉了位置偏置——如果模型偏爱「先出现的那个」， 两种顺序各出现一半，偏置会互相抵消。这也是为什么很多实现坚持做随机交换，尽管从 BT 的形式上看它不必要。

    训练在比什么：两个「概率」别混 补充

    到这里出现了两个概率，一定要分开，否则训练过程会看错：

    记号是什么从哪来
    $z$人类标注的真实答案（1 = A 更好，0 = B 更好）标注数据

    训练就是让 $p$ 靠近 $z$。举个具体数字：人类标了「A 更好」（$z=1$），但模型算出来只有 $p=0.60$，

    $$ \mathcal{L} = -\log 0.60 = 0.511 $$

    想把这个 loss 降下来，模型只有一条路：把 $\Delta$ 拉大。它改不了 $\sigma$，只能改分数。

    $\Delta$$p$loss梯度权重 $\sigma(-\Delta)$

    把 $\Delta$ 从 $0.405$ 拉到 $2$，$p$ 就从 $0.60$ 变成 $0.88$，loss 从 $0.511$ 降到 $0.127$——降了 4 倍。 这就是「训练奖励模型」的全部内容：不是教它「3 分是高分」，而是把「好的比差的高出多少」这个差距撑开。

    注意最后一列同时发生的事：梯度权重 $\sigma(-\Delta)$ 从 $0.40$ 掉到 $0.12$。越接近「分对」，学得越慢—— 这就是下一小节那个「梯度权重 = 判错的概率」。

    补充 · 这个换算的名字：log odds

    正着用是 $\Delta \mapsto p=\sigma(\Delta)$；反过来解是

    $$ \Delta = \log\frac{p}{1-p} $$

    右边是几率（odds）取对数，所以板书在 $\Delta$ 旁边注 log odds of preference。 $\Delta$ 有三个名字：margin（间隔）、logit（逻辑回归里的线性预测值）、log odds（对数几率）——指的是同一个量。

    这也给出一把刻度尺：$p=0.5$ 要 $\Delta=0$，$p=0.75$ 要 $\Delta=\ln3\approx1.10$，$p=0.9$ 要 $\ln9\approx2.20$， $p=0.99$ 要 $\ln99\approx4.60$。越往两头，$\Delta$ 要走的距离越长——所以「分差 2 和分差 4」差得比想象中多。

    补充 · 分数差就是「偏好」的 log odds

    把 BT 反过来解。给定 $p = P(y_w\succ y_l\mid x)$，

    $$ \sigma(\Delta) = p \quad\Longrightarrow\quad \Delta = \log\frac{p}{1-p} $$

    板书在 $\Delta$ 旁边注的 log odds of preference 就是这个意思： 分数差 = 偏好胜率的对数几率。

    这条式子把三个词串起来了：$\Delta$ 是「margin」，也是「logit」，也是「log odds」—— 在逻辑回归里这三个词指的就是同一个量。所以 §3.2 那句「它就是二分类逻辑回归」，在这里拿到了第二个证据。

    它还顺便给出一把刻度尺：$\Delta=0$ 对应 50%；$\Delta=\ln 3\approx1.10$ 对应 75%； $\Delta=\ln 9\approx2.20$ 对应 90%；$\Delta=\ln 99\approx4.60$ 对应 99%。 所以 RM 的分数差从 2 涨到 4，并不是「好了一倍」，而是从「七成把握」变成「九成九把握」。

    梯度 推导

    先对 $\Delta$ 求导。用 $\sigma'(z) = \sigma(z)\big(1-\sigma(z)\big)$，或者直接用 $\log\sigma(z)$ 的导数：

    $$ \frac{d}{d\Delta}\Big[-\log\sigma(\Delta)\Big] = -\frac{\sigma'(\Delta)}{\sigma(\Delta)} = -\big(1 - \sigma(\Delta)\big) = -\sigma(-\Delta) $$

    再链式到参数。注意 $r_w$ 与 $r_l$ 对 $\phi$ 的梯度符号相反：

    $$ \nabla_\phi\, \mathcal{L}_{\text{RM}} \;=\; -\,\sigma(-\Delta_\phi)\;\Big(\nabla_\phi\, r_\phi(x,y_w) \;-\; \nabla_\phi\, r_\phi(x,y_l)\Big) $$
    补充 · 读这个梯度：权重就是「当前判错的概率」

    $\sigma(-\Delta) = 1 - P(y_w \succ y_l)$ 正好是模型认为「自己错了」的概率。于是：

    • 已经分对且差距很大（$\Delta \gg 0$）：$\sigma(-\Delta)\to 0$，这条 pair 几乎不贡献梯度；
    • 分错了（$\Delta < 0$）：$\sigma(-\Delta) > 0.5$，梯度权重接近 1，全力纠正；
    • 分不清（$\Delta \approx 0$）：权重 $0.5$，中等力度。

    这是一个自适应的难例挖掘：不用显式挑难例，损失函数自己把权重给对了。 副作用是——训练后期几乎所有 pair 都被分对，梯度趋近于零，模型开始只被少数「分不开」的 pair 驱动， 而那些 pair 往往正是标注噪声或标注者意见分歧的地方。这是 RM 训久了会掉点的原因之一（§3.5）。

    三个常见变体 补充

    (a) 带 margin 的版本。如果希望「至少赢这么多才算对」，把 $\Delta$ 平移：

    $$ \mathcal{L}_{\text{margin}} \;=\; -\log\sigma\big(\Delta - m\big), \qquad m > 0 $$

    它要求 $r_w - r_l > m$ 才算「分对」，等价于把决策边界从 $0$ 挪到 $m$。实践中用得不多， 因为 $m$ 的尺度依赖 $r$ 的单位（而 $r$ 的单位是 BT 假设固定死的），跨数据集不可迁移。

    (b) 平局（tie）。标注里「两个差不多」很常见。三种处理：

    • 丢掉：最简单，但会丢掉「难以区分」这个信息，模型在难例上得不到约束；
    • 拆成两条各半权重：$\mathcal{L}_{\text{tie}} = -\tfrac12\big[\log\sigma(\Delta) + \log\sigma(-\Delta)\big]$。 在 $\Delta=0$ 时取最小值 $0.693$，$|\Delta|$ 越大惩罚越大——语义上就是「把差距压到 0」；
    • 三分类：把输出扩成 $\{w, \text{tie}, l\}$ 三个 logit（Rao–Kupper 模型），显式建模平局概率。最干净，但要改结构。

    (c) K 路排序（Plackett–Luce）。如果一次让标注者排 $K$ 个回答，信息量是成对的 $O(K\log K)$ 倍。 把 BT 推广成「依次从剩余集合里选最好的」：

    $$ P\big(y_1 \succ y_2 \succ \cdots \succ y_K \mid x\big) = \prod_{k=1}^{K} \frac{\exp\big(r(x,y_k)\big)}{\sum_{j=k}^{K}\exp\big(r(x,y_j)\big)} $$ $$ \mathcal{L}_{\text{PL}} \;=\; -\sum_{k=1}^{K}\left[\,r(x,y_k) \;-\; \log\!\sum_{j=k}^{K} e^{\,r(x,y_j)}\right] $$

    括号里就是一个 softmax 交叉熵（$y_k$ 是「正确类」，剩下的是负类）。$K=2$ 时它退化成 BT： $r_1 - \log(e^{r_1}+e^{r_2}) = -\log\sigma(r_2-r_1)$，与 §3.3 只差一个符号约定。

    3.4 为什么是成对，而不是直接打分 板书

    最直接的想法是：让标注者给每个回答打 1–7 分，然后回归 $r_\phi \approx$ 分数。这叫做 pointwise RM，为什么不这么做？

    1. 绝对刻度不可校准。标注者 A 习惯给 4–6 分，B 只给 1 和 7。回归会去拟合标注者的刻度， 而不是偏好。两个人的「5 分」可能相差一个档次，而「A 比 B 好」这件事在两人之间是一致的。
    2. BT 只依赖差值，对平移免疫。§3.2 已经证明：$r \to r + c$ 不改变损失。 这意味着标注者的「整体偏松/偏紧」不会污染训练——只要他给的相对顺序对，刻度随便。
    3. 比较任务的一致性更高。「哪个更好」是一个二选一，认知负荷低、可复现； 「打几分」需要自己维护一把看不见的尺子，同一个人隔一周打的分都可能不一致。
    4. 噪声结构更简单。一条比较错就是一次翻转（可以用 label noise 建模）； 一条分数错可能是刻度、可能是偏移、可能是对某个维度的不同权重，噪声模型复杂得多。

    代价也要说清楚：一次比较只提供 1 bit 信息。$K$ 个候选要排全序需要 $O(K\log K)$ 次比较， 而 pointwise 一次就能给出 $K$ 个数（虽然不可比）。所以当候选很多、且需要绝对分数做阈值（比如「低于 3 分就拒答」）时， pointwise 仍有它的位置——只是它不适合作为 RLHF 的主信号。

    补充 · 一个常被忽略的细节

    BT 对平移不变，但对缩放不不变：$r\to \alpha r$ 时 $\Delta \to \alpha\Delta$，损失变了。 所以 $r$ 的单位是由 logistic 斜率固定死的。工程含义：

    • 不同 RM 的分数不能跨模型比较绝对值，只能比排序；
    • 把两个 RM 集成时，不能简单平均原始分数——要先各自标准化（减均值、除标准差），否则尺度大的那个会主导；
    • PPO 里 reward 的尺度直接影响策略更新的步长，所以通常会再乘一个归一化系数（或做 running mean/std 归一）。

    3.5 训练细节：结构、初始化、超参 补充

    这一节回答「具体怎么训」。奖励模型的结构改动只有一处，但每一步都有理由。

    结构：把语言模型头换成一个标量

    结构上只有一处改动：把 $d\times|V|$ 的语言模型头换成 $d\to1$ 的线性层，也就是 §3.2 里的 $r_\phi(x,y) = w^{\top}h_t + b$。剩下的全是细节，但每一条都有代价。

    • 丢掉 vocab 头。语言模型头是 $d\times|V|$（$|V|\approx 10^5$），RM 只需要 $d\times 1$。 这一层随机初始化，其余权重从 SFT 模型复制。
    • 取最后一个非 pad token 的隐状态，不是平均池化。 平均会把 prompt 的信息混进来，而 prompt 对「回答质量」没有贡献；更糟的是，平均池化让「长度」通过分母进入分数—— 回答越长，平均越接近某个全局均值，这本身就是一个长度偏置的来源。
    • 偏置 $b$ 可留可去。它在 $\Delta$ 里被减掉（§3.2），对损失没有任何影响。 保留它的唯一理由是你要用绝对分数做阈值；否则直接省掉，少一个无用参数。
    • 标量头用线性层就够。也有人用 $d\to d/4\to 1$ 的小 MLP，收益不明显，但多了过拟合的自由度。
    • 不要复用 lm_head 的某一维。那一维的语义是「某个 token 的 logit」，和「质量」没有任何关系， 而且它的尺度被 softmax 的竞争关系绑死，训起来会互相干扰。

    参数量 $\sim10^{9}$，pair 数据 $\sim10^{5}$。参数/样本比高达 $10^{4}$，这是一个必然过拟合的配置。 于是训练曲线有一个很典型的形状：验证集 pairwise accuracy 在前半个 epoch 快速上升到峰值（典型 65%～75%）， 然后开始缓慢下降。

    下降的那部分不是随机噪声——它是 RM 开始记忆训练 pair 的表面特征：长度、特定的礼貌用语、markdown 结构、 甚至某个标注者偏好的措辞。这些特征在训练集上与「更好」相关，在分布外不相关。 这正是后面 reward hacking 的种子：策略会去优化这些表面特征，因为那是 $r_\phi$ 真正在度量的东西。

    训练循环（伪代码）

    for (x, y_w, y_l) in loader:            # 每条样本是一个三元组
    r_w = rm(x, y_w)                    # (B,)  标量分数
    r_l = rm(x, y_l)                    # (B,)
    delta = (r_w - r_l).float()         # 用 fp32 算，避免 bf16 下饱和
    loss = -F.logsigmoid(delta).mean()  # = softplus(-delta)，数值稳定
    loss.backward()
    opt.step(); opt.zero_grad()

    三个实现要点：

    • 用 logsigmoid，不要 log(sigmoid(x))。 $\Delta$ 很负时 $\sigma(\Delta)$ 下溢到 0，$\log 0 = -\infty$；而 logsigmoid 内部走的是 $-\operatorname{softplus}(-\Delta)$，在整条实数轴上都稳定。
    • $\Delta$ 用 fp32 算。bf16 只有 8 位有效数字，两个相近的大分数相减会灾难性抵消， 而 $\Delta$ 恰恰经常是小量。
    • 不要对 $r$ 做 softmax 或归一化后再算损失。BT 只关心差值，任何单调变换都会改变梯度的尺度， 把「平移不变」这个性质破坏掉。

    3.6 数据：pair 从哪来 补充

    一条训练样本是一个三元组 $(x, y_w, y_l)$。构造方式基本是三步：同一个 prompt 采样多条 → 让人排序 → 拆成 pair。

    1. 采样。用 SFT 模型对同一个 $x$ 采样 $K$ 条（$K=4\sim9$），温度 $0.7\sim1.0$。 温度太低会得到几乎一样的回答，比较没有信息量。
    2. 标注。标注者排序，或两两比较。这一步的指导文档比标注量更重要： 如果规范没说清「简洁 vs 详尽」哪个优先，标注者会各按各的偏好，RM 学到的就是噪声的平均。
    3. 拆 pair。$K$ 条全序可以拆出 $\binom{K}{2}$ 个 pair。注意这些 pair 不独立（共享同一条回答）， 所以有效样本量远小于表面数字，这也是「一个 epoch 就够」的另一个原因。

    板书把标注协议写成两种，并在旁边标了它们各自能产出多少对：

    协议标注者要做的事得到多少 pair
    选最优（select best）从 $k$ 条里挑出一条最好的$k-1$
    全排序（ranking）把 $k$ 条排成一个全序$\dfrac{k(k-1)}{2}$

    $k=5$ 时前者 4 对、后者 10 对，差 2.5 倍。怎么选：

    • 选最优便宜（一次点击），但只用了「第一名」这一个信息，第 2 名和第 5 名的差别被丢掉了；
    • 全排序信息多，但标注者要维护一个前后一致的序，成本高且噪声大——人对中间几名的排序非常不稳定。

    折中的做法是「先选最优，再在剩下的里面选最优」，或者只要求排前 3 名。工程上还有一个隐性差别： $k-1$ 个 pair 全部包含同一条「冠军」，它们高度相关，有效样本量远小于 $k-1$；全排序拆出的 pair 相关性低一些，但也不是独立的。

    多回答 + 排序一个 prompt 采 4 条，整体排序后拆 6 个 pairUltraFeedback：64k prompts × 4

    易错 · 数据分布必须「跟得上」策略

    RM 只在训练数据覆盖的分布上可信。如果 pair 全部来自 SFT 模型的输出， 而 PPO 把策略推到了另一个区域（更长、更爱用列表、更爱加免责声明），RM 在那个区域的打分就是外推—— 它没见过这种文本，输出的分数没有意义。

    这是 RLHF 里最隐蔽的失效：训练曲线一切正常（reward 在涨），模型却在变差。 解法有三条：用 on-policy 数据迭代更新 RM；用 KL 约束把策略拴住（§4.8 的 $\beta$）；用集成 RM 取最小值来惩罚外推。

    用 AI 反馈时还有几个已知的系统性偏置，构造数据时必须对冲：

    • 位置偏置：裁判模型偏好第一个（或最后一个）出现的回答 → 训练时随机交换 $y_w$、$y_l$ 的顺序；
    • 长度偏置：更长的回答更容易被判为更好 → 显式加入「长度受控」的对比样本；
    • 自我偏好：同一家族的模型互相打分偏高 → 用多个不同家族的裁判，或人工抽检。

    3.7 评估与失效 补充

    怎么判断一个 RM 好不好

    主指标只有一个：留出集上的 pairwise accuracy——给一对回答，$r_\phi$ 的判断与人类标注一致的比例。典型值 65%～75%。

    补充 · 这个数字怎么读

    很多人第一次看到「70%」会觉得太低。但要注意人类之间的一致性本身也不高： 同一批 pair 让两组标注者分别标，一致率通常也只有 70%～80%（取决于任务的主观程度）。

    所以：

    • RM 的 acc 接近人类-人类一致率时，它已经接近「这个问题本身的可判定上限」；
    • RM 的 acc 明显超过人类一致率时，第一反应不该是「模型真强」，而是测试集泄漏、标注太简单、或者测试集和训练集同源。

    另外，总 acc 会掩盖维度间的冲突：helpfulness 上 80%、harmlessness 上 55% 的 RM，总分会显示 68%， 但它在安全性上几乎不可用。所以要分维度报。

    Reward hacking 值得单独说。它不是 bug，是结构性的：

    $$ \text{真正的目标}\; p^\star \;\xrightarrow{\text{有限数据}}\; \text{代理}\; r_\phi \;\xrightarrow{\text{优化}}\; \arg\max_\pi \mathbb{E}_\pi[r_\phi] $$

    中间那一步必然有损（有限数据、有限容量、BT 假设），最后一步是精确地优化一个有损的代理。 优化得越彻底，越会找到代理与真目标不一致的方向。这就是 Goodhart 定律的机器学习版本。 所以 RLHF 里「训练得越久越好」是错的——存在一个最优点，之后开始变差。

    第四部分 · 第三种方法：通用 RL 算法

    这一部分只回答一个问题

    有了分数，怎么让模型自己变得更好？
    这一部分先讲清「RL 和前面三步到底差在哪」（4.1），再一步步推公式。看不懂 4.6 的推导，可以先只看 4.1 和 4.7 的三步算法。

    板书上这一部分叫 General RL Algo。前两级都是「拟合一个数据集」，这一级换成「优化一个期望」—— 而且数据由模型自己在训练过程中生成。这个区别比损失函数长什么样重要得多。

    4.1 先搞清楚：RL 到底在做什么 补充

    很多人卡在这里，是因为一个错觉：SFT 是「算 loss → 反向传播 → 更新参数」，RL 也是「算 loss → 反向传播 → 更新参数」，看起来一样。

    确实一样。但那只是「怎么走」，不决定「往哪走」。两者的差别只有三件事：样本从哪来、权重从哪来、数据分布动不动。 把这三件事想清楚，后面所有公式都只是把它们写成符号。

    一、同一道题，四种「监督信号」

    把同一道题在四个阶段各训一次，模型拿到的「答案」形态完全不同：

    阶段模型看到什么拿到的信号信号密度
    预训练一段文本每个位置的下一个 token每 token 一个标签
    SFT问题 + 示范回答每个位置的示范 token每 token 一个标签（回答段）
    RM问题 + 两条回答「哪条更好」每对 1 bit
    RL问题一条回答的总分每条 1 个实数

    关键转折在第三行到第四行：信号从「每个位置该是什么」，退化成「整条值多少分」。

    一旦退化，交叉熵就算不了了——因为一个分数没法反推成「第 37 个 token 应该是什么」。 于是只能换一种问法：哪些 token 的出现，和这个分数相关？把分数当成这些 token 的对数概率的权重， 这就是策略梯度干的事。

    二、一个具体例子走一遍

    假设一个 prompt，采三条回答，RM 分别给 $0.2$、$0.5$、$0.9$。归一化（减均值、除标准差）：

    $$ \mu = \frac{0.2+0.5+0.9}{3} = 0.533, \qquad \sigma \approx 0.287 \quad\Longrightarrow\quad \hat A = \big(-1.16,\; -0.12,\; +1.28\big) $$

    更新就是把这组权重乘到各自的梯度上：

    $$ \theta \;\leftarrow\; \theta + \eta \sum_{i=1}^{3} \hat A_i \, \nabla_\theta \log \pi_\theta(y_i \mid x) $$

    展开看每一项在做什么：

    • $\hat A_3 = +1.28$：把 $y_3$ 里每一个 token 的概率都推高；
    • $\hat A_1 = -1.16$：把 $y_1$ 里每一个 token 的概率都压低；
    • $\hat A_2 = -0.12$：几乎不动（它和平均水平差不多）。
    易错 · 这就是 RL 最反直觉的地方

    模型并不知道 $y_1$ 里是哪一句写错了。它只知道「这条整体分低」，于是把整条的概率一起压低。 如果 $y_1$ 里有 90% 的句子其实是对的，那些对的句子也会被误伤。

    这就是 credit assignment（信用分配）问题的实际后果，也是 RL 需要比 SFT 多得多的样本才能学对的原因： SFT 的每个 token 都有独立标签，RL 只有一条轨迹一个分。

    三、四条本质差别

    SFTRL
    样本从哪来人写的，训练前就固定模型自己采，每一步都是新的
    权重从哪来恒为 $-1$，每条样本一样重由分数决定，可正可负
    信号密度每 token 一个每条轨迹一个
    数据分布不动随 $\theta$ 漂移
    梯度形式$-\nabla_\theta\log\pi_\theta(y^\star\mid x)$$+\hat A\,\nabla_\theta\log\pi_\theta(y\mid x)$

    最后一行最值得盯：两者的梯度长得几乎一样（都是 $\nabla\log\pi$ 乘一个系数）， 差别只在符号（一个最小化一个最大化）、样本来源（固定的 vs 自己采的）、 权重（常数 vs 分数）。第三点是全部差别的来源。

    四、那为什么还要 RL

    因为 SFT 有一个天花板：它只能复制示范。示范里没有的回答，SFT 永远不会产生。

    RL 不一样。采样是随机的，偶尔会采到示范里没有、但打分器给高分的回答。只要出现一次，这条就被强化； 下一次采样，它出现的概率就高一点。反复迭代，模型会滑向打分器喜欢的那片区域—— 那片区域可以超出人类示范的范围（§4.8 的闭式解会把这个「滑向」写成一个指数重加权）。

    补充 · 一句话

    SFT 是抄答案，RL 是考试。

    抄答案最多抄到示范者的水平，但稳；考试可以考出示范者没想到的解法，但也会因为猜错题意而掉下来。 后面所有的工程细节（baseline、KL、clip、rollout $k$）都是在让考试别考崩。

    五、代价：三个不稳定来源

    RL 为什么比 SFT 难训，答案全在上面那张表里：

    1. 信用分配。一条轨迹一个分，不知道哪一步错了（本节二）。
    2. 方差。用几条样本估一个期望，噪声可以大到盖过信号 → baseline、组内归一化都是为压它（§4.7）。
    3. 目标会动。数据分布随 $\theta$ 漂移，而打分器只在旧分布上可信 → 必须用 KL 把它拴住（§4.8）。

    所以「RL 训得好」在工程上通常不是「算法选得对」，而是这三件事各自被处理干净了。 反过来说，如果 RL 训崩了，先按这三条排查，比换算法有用。

    真正的 RL（下棋、机器人）里，环境是外部的、随机的、部分可观测的。语言模型不是：

    • 状态完全可观测：$s_t$ 就是那串 token，没有隐藏变量；
    • 转移是确定性的：$s_{t+1} = (x, y_{\le t})$，加上刚采的那个 token 就完事；
    • 唯一的随机性来自策略自己的采样（以及温度）。

    三个后果：好消息是没有「探索策略」的设计问题——温度就是探索；坏消息是没有任何外部反馈告诉模型「这一步走错了」， 奖励只在最后给一个数。所以 credit assignment 成了这个设定里最难的事（§4.5）。

    4.3 离线与在线：θ 的那条链 板书

    板书用一串 $\theta$ 把三种训练范式的区别画出来了。同一行里写了两个链条：

    $$ \theta_0 \;\xrightarrow{\;\text{SFT}\;}\; \theta_1 \;\xrightarrow{\;\text{RM}\;}\; \theta_2 \qquad\text{vs.}\qquad \theta_1 \to \theta_1' \to \theta_2' \to \cdots \to \theta_T' = \theta_2 $$

    左边是两次独立的监督训练：一次用示范数据把 $\theta_0$ 推到 $\theta_1$，一次用偏好数据把 $\theta_1$ 推到 $\theta_2$。 每一段都是「数据固定、跑完就结束」。右边是同一件事的迭代版本：$\theta_1$ 先变一点、再拿新模型去采样、 再打分、再变一点，走 $T$ 小步才到 $\theta_2$。

    而真正属于 RL 的那条链，板书单独写在下面（标了 online learning）：

    $$ \theta_1 \xrightarrow{(x_1,y_1)} \theta_2 \xrightarrow{(x_2,y_2)} \cdots \xrightarrow{(x_T,y_T)} \theta_T $$

    区别不在步数，在数据是谁产的：

    监督学习（SFT / RM）在线 RL
    数据训练前就定好，全程不变每一步由当前策略采样
    目标拟合这批数据的标签最大化这批数据上的期望奖励
    训练几轮1～3 个 epoch，之后只会过拟合可以很多轮，每轮数据都新
    数据分布固定随 $\theta$ 漂移（这就是不稳定的根源）
    易错 · 「RL 与监督的区别是损失函数」是错的

    两者的损失形式可以长得几乎一样（都是 $-\log p$ 或它的加权）。真正的区别是：RL 的训练分布依赖参数。

    这带来两个直接后果：① 奖励模型只在旧分布上可信，策略一漂移它就失效（§3.7）； ② 不能像监督那样「多训几轮总没坏处」——RL 训久了会沿着代理指标的漏洞一路滑下去。

    4.4 目标函数：最大化期望奖励 板书

    板书写的目标非常朴素：maximize expected reward of $y$ given $x$。

    $$ J(\theta) \;=\; \mathbb{E}_{x\sim\mathcal{D}}\,\mathbb{E}_{y\sim P_\theta(\cdot\mid x)}\big[r(x,y)\big] \;=\; \sum_{y} P_\theta(y\mid x)\, r(x,y) $$

    右边那个求和是关键：$y$ 的空间是 $|V|^{|y|}$，根本枚举不了。 所以这个目标写得出、算不出。整个策略梯度方法就是为了绕开这个求和——把它变成一个可以用采样估计的期望。

    4.5 Return、Value、Advantage 板书

    板书在目标函数下面接着定义了三个量，这三个量是后面所有算法（REINFORCE / PPO / GRPO）共用的零件。

    Return：从这一步起的全部奖励

    $$ G_t \;=\; \sum_{k=t}^{T} r_k $$

    板书注：total future reward from the current step。注意它从 $t$ 加到 $T$，包含当前这一步拿到的奖励。

    Value function：Return 的期望

    $$ V_\psi(s_t) \;=\; \mathbb{E}\big[\,G_t \mid s_t\,\big] $$

    板书注：expected remaining return from the current step。它由另一个网络 $\psi$ 估计—— 在 PPO 里这就是那个和策略同规模的 value head。它回答的问题是：站在这个前缀上，平均还能拿多少分？

    Advantage：比平均好多少

    $$ \hat A_t \;=\; G_t - V_\psi(s_t) $$

    板书在旁边补了它最有用的一句解读：

    补充 · A > 0 表示「比平常好」，A < 0 表示「比平常差」

    这就是 advantage 这个名字的来源。用不用它，策略梯度的期望不变（因为 $\mathbb{E}[V_\psi(s_t)\nabla\log\pi]=0$）， 但方差会差一个量级。

    更实际的区别在符号上：

    • 不减 baseline：奖励是 $0/1$ 时，所有采样到的回答权重都 $\ge 0$ —— 每一条都被「推高」，只是好的推得多；
    • 减掉 baseline：好的被推高（$A>0$），差的被压低（$A<0$）。后者才是我们真正想要的行为。

    这个差别在 §4.7 会用一组具体数字算一遍。

    在 LLM 里 $G_t$ 长什么样

    这里有一个容易被忽略的细节。如果奖励只在序列末尾给一次（奖励模型就是这种形态）：

    $$ r_1 = r_2 = \cdots = r_{T-1} = 0,\qquad r_T = r_\theta(x,y) \quad\Longrightarrow\quad G_t = r_\theta(x,y)\ \ \text{对所有 } t $$

    那么同一个回答里每个 token 的 $G_t$ 都一样。这意味着：一个 800 token 的回答，中间写错的那个 token 和最后收尾的那个 token， 拿到的信号完全相同——这就是 credit assignment 问题最赤裸的形态。

    唯一的例外是 KL 惩罚：它逐 token 都有值（§4.8），所以 $G_t$ 里唯一带位置信息的部分，其实是那个惩罚项。

    4.6 REINFORCE：log-derivative trick 板书

    板书写的第一个算法是 REINFORCE（Williams, 1992），推导只有三行，但中间那一步是整门课最值得记住的技巧。

    从 $J(\theta) = \sum_y P_\theta(y\mid x)\,r(x,y)$ 出发，直接对 $\theta$ 求导：

    $$ \frac{dJ}{d\theta} = \sum_y r(x,y)\,\frac{dP_\theta(y\mid x)}{d\theta} $$

    到这一步卡住了：$\frac{dP}{d\theta}$ 不是期望，没法用采样估。于是乘一个 $P$ 再除一个 $P$：

    $$ \frac{dJ}{d\theta} = \sum_y r(x,y)\,P_\theta(y\mid x)\cdot \boxed{\frac{1}{P_\theta(y\mid x)}\frac{dP_\theta(y\mid x)}{d\theta}} $$

    方框里那一项，正好是对数求导法则的结果：

    $$ \frac{d\log P_\theta(y\mid x)}{d\theta} = \frac{1}{P_\theta(y\mid x)}\frac{dP_\theta(y\mid x)}{d\theta} $$

    代回去，求和号里就出现了 $P_\theta$——它把「加权求和」变成了「期望」：

    $$ \boxed{\; \frac{dJ}{d\theta} = \sum_y P_\theta(y\mid x)\, r(x,y)\, \frac{d\log P_\theta(y\mid x)}{d\theta} = \mathbb{E}_{y\sim P_\theta(\cdot\mid x)} \left[\,r(x,y)\,\nabla_\theta \log P_\theta(y\mid x)\,\right] \;} $$
    补充 · 这一步到底买到了什么

    买到了「可采样」。左边要对 $|V|^{|y|}$ 个 $y$ 求和，右边只要从模型里采一条 $y$ 出来算梯度。 采一条就是一次前向 + 一次反向，代价和 SFT 完全一样。

    代价是方差。用一条样本估期望，方差可以大到让梯度几乎全是噪声。后面所有的工程技巧 （baseline、advantage、组内归一化、PPO 的裁剪）都是在不改变期望的前提下压方差。

    还有一个容易忘的前提：这个梯度是关于当前策略的。一旦 $\theta$ 更新，旧样本就不再服从 $P_\theta$， 估计就有偏了。所以朴素 REINFORCE 必须 on-policy——每更新一次就要重新采样。PPO 用重要性采样把这一点放宽了一些，但没取消。

    和 SFT 的梯度对照

    把两条梯度并排放，差别一目了然：

    梯度样本从哪来权重
    SFT$-\nabla_\theta \log \pi_\theta(y^\star\mid x)$人类写的 $y^\star$恒为 $-1$（每条都一样重）
    REINFORCE$+\,r(x,y)\,\nabla_\theta\log \pi_\theta(y\mid x)$模型自己采的 $y$由奖励决定，可正可负

    形式几乎一样（都是 $\nabla\log\pi$ 乘一个系数），但三处不同：符号（一个最小化一个最大化）、 样本来源（固定的 vs 自己采的）、权重（常数 vs 分数）。 第三点是全部差别的来源——SFT 里每条样本都「同样正确」，RL 里每条样本的好坏要自己判。

    4.7 三步算法与实践细节 板书

    板书把 REINFORCE 写成一个三步循环，非常干净：

    1. 采样。给定 prompt $x$，从当前策略采一条回答 $y \sim P_\theta(\cdot\mid x)$。
    2. 打分。用冻结的奖励模型算 $r(x,y)$。注意「冻结」两个字：RM 在这一步不更新。
    3. 更新。把 $\theta$ 沿 $\nabla_\theta\log P_\theta(y\mid x)$ 的方向推，推力大小按奖励缩放。
    $$ \theta \;\leftarrow\; \theta + \eta\; r(x,y)\;\nabla_\theta \log P_\theta(y\mid x) $$
    这个公式怎么读

    它在算什么：这条回答得了多少分，就按这个分数去调整它里面每个词的概率。

    每个符号：$r(x,y)$ 是裁判给这条回答的分数； $\nabla_\theta\log P_\theta(y\mid x)$ 是一个方向——沿着它走，这条回答会更容易被生成； $\eta$ 是步长。两者相乘 = 按分数缩放这个方向。

    四种情况，一眼看懂：

    • 分数高 → 沿这个方向走一大步：这条回答以后更常见；
    • 分数低（但为正）→ 走一小步：稍微更常见一点；
    • 分数是 0 → 一步都不走：这条回答白写了；
    • 分数是负的 → 反方向走：这条回答以后更少见。

    和 SFT 的唯一区别：SFT 的权重恒为 $-1$、样本是人写的；这里权重是分数、样本是模型自己写的。 形式几乎一模一样，差别全在「权重从哪来」。

    一句话总结这个公式的性格：它非常「粗暴」——它不知道这条回答里哪个词立了功、哪个词拖了后腿， 只知道整条得了多少分，然后把整条所有词一起按这个分数推或压。这就是为什么 RL 要喂大量样本才学得动。

    实践中的三条修正

    板书在 "In practice" 下面写了三条，每一条都对应一个真实的工程问题。

    (1) 一个 prompt 采 $k$ 条。板书给的取值是 $k\in\{1,8,16,32,64\}$。 $k=1$ 时一条样本估期望，方差大到基本训不动；$k$ 越大估计越准，但采样成本线性上升。 $k$ 同时决定了 baseline 的质量——这正是 GRPO 的出发点。

    (2) 不要直接用原始奖励。板书写的处理是

    $$ \tilde r(x,y_i) \;=\; \frac{r(x,y_i) - \mu_r}{\sigma_r} $$

    其中 $\mu_r,\sigma_r$ 是同一组样本内的均值和标准差。这一步把「奖励的绝对尺度」消掉，只留「这条比同组平均好多少」。 它与 §3.2 里 BT 的平移不变是同一个思想：只需要相对好坏，不需要绝对分数。

    (3) 逐 token 扣 KL。板书最后一行是

    $$ \text{Total}\;=\; A(x,y) \;-\; \beta\cdot \mathrm{KL}_t $$

    也就是把「比平均好多少」减去「这一步偏离参考策略多少」，作为该 token 的回报。 $\beta$ 大则模型不敢动，$\beta$ 小则很快跑飞（§4.8 会给出它的闭式含义）。

    用一组数字看 baseline 的作用 补充

    假设奖励只有 $0/1$（对 / 错），一个 prompt 采 $k=4$ 条，只有一条对。两种做法的梯度权重完全不同：

    样本$r$直接用 $r$ 当权重用 $A=r-\mu$（$\mu=0.25$）
    第 1 条（对）1.00+1.00+0.75
    第 2 条（错）00−0.25
    第 3 条（错）00−0.25
    第 4 条（错）00−0.25

    左边那一列：错的样本权重是 0，既不被推高也不被压低——它们只是「没被学到」。 右边那一列：错的样本权重是负的，被主动压低。

    这就是「只会说对的」和「知道什么是不对的」的差别。而且注意右边四条的权重之和是 $0$： 整组的平均梯度为零，只有相对好坏在起作用——这也解释了为什么归一化之后 $\mu$ 取多少不重要。

    4.8 KL 约束与闭式解 推导

    上面那个「Total = A − β·KL」不是随手加的。它来自一个有明确解的目标：

    $$ \max_{\pi_\theta}\;\; \mathbb{E}_{x\sim\mathcal{D}}\Big[ \underbrace{\mathbb{E}_{y\sim\pi_\theta(\cdot\mid x)}\big[r_\phi(x,y)\big]}_{\text{让打分器满意}} \;-\;\beta\, \underbrace{\mathrm{KL}\big(\pi_\theta(\cdot\mid x)\,\|\,\pi_{\text{ref}}(\cdot\mid x)\big)}_{\text{别走太远}} \Big] $$

    其中

    $$ \mathrm{KL}\big(\pi_\theta\|\pi_{\text{ref}}\big) = \mathbb{E}_{y\sim\pi_\theta}\!\left[\log\frac{\pi_\theta(y\mid x)}{\pi_{\text{ref}}(y\mid x)}\right] = \mathbb{E}_{y\sim\pi_\theta}\!\left[\sum_{t}\log\frac{\pi_\theta(y_t\mid x,y_{<t})}{\pi_{\text{ref}}(y_t\mid x,y_{<t})}\right] $$

    最后一个等式说明了为什么 KL 可以拆到 token 上：序列级的 log 比值就是逐 token log 比值之和。 板书那行 $\beta\cdot\mathrm{KL}_t$ 里的下标 $t$ 就是这个意思。

    $\beta$ 是这一节唯一真正重要的超参：$\beta\to0$ 退化成无约束的奖励最大化（模型会崩）； $\beta\to\infty$ 时策略完全不动，等于 $\pi_{\text{ref}}$。它同时在做三件事—— 限制 reward hacking 的空间、保住语言能力、把「走多远」变成一个可调的旋钮。

    闭式解：最优策略是参考策略的指数重加权 推导

    先固定 $x$，把问题写成对分布 $\pi(\cdot\mid x)$ 的变分问题（记 $r(y) = r_\phi(x,y)$，$\pi_{\text{ref}}(y)=\pi_{\text{ref}}(y\mid x)$）：

    $$ \min_{\pi}\;\; \sum_{y}\pi(y)\left[\log\frac{\pi(y)}{\pi_{\text{ref}}(y)} - \frac{r(y)}{\beta}\right] \quad\text{s.t.}\quad \sum_y \pi(y) = 1 $$

    拉格朗日函数 $\mathcal{J} = \sum_y \pi(y)\big[\log\frac{\pi(y)}{\pi_{\text{ref}}(y)} - \frac{r(y)}{\beta}\big] + \lambda\big(\sum_y\pi(y)-1\big)$， 对 $\pi(y)$ 求偏导并令其为零：

    $$ \frac{\partial \mathcal{J}}{\partial \pi(y)} = \log\frac{\pi(y)}{\pi_{\text{ref}}(y)} + 1 - \frac{r(y)}{\beta} + \lambda = 0 $$

    解出

    $$ \boxed{\;\pi^\star(y\mid x) \;=\; \frac{1}{Z(x)}\,\pi_{\text{ref}}(y\mid x)\,\exp\!\left(\frac{r(x,y)}{\beta}\right)\;} \qquad Z(x) = \sum_{y}\pi_{\text{ref}}(y\mid x)\exp\!\left(\frac{r(x,y)}{\beta}\right) $$
    补充 · 这个式子的三个含义
    1. RL 不发明新行为，只重新分配质量。$\pi^\star$ 是 $\pi_{\text{ref}}$ 乘上一个权重后的重归一化。 $\pi_{\text{ref}}$ 支撑集之外的回答，权重永远是 0——采样不到的回答，RL 永远学不会。 这是「SFT 决定上限」这句话最严格的版本。
    2. $\beta$ 是「温度」。$\beta$ 越小，$e^{r/\beta}$ 越尖，策略越集中在高分回答上；$\beta$ 越大越平。 所以 KL 系数和「探索强度」是同一个旋钮的两个名字。
    3. $Z(x)$ 只和 $x$ 有关。这一点在 §4.10 推 DPO 时是关键——同一个 prompt 下比较两个回答，$Z(x)$ 会被约掉。

    把上式两边取对数，可以反解出奖励：

    $$ \log\pi^\star(y\mid x) = \log\pi_{\text{ref}}(y\mid x) + \frac{r(x,y)}{\beta} - \log Z(x) $$ $$ \Longrightarrow\qquad r(x,y) \;=\; \beta\log\frac{\pi^\star(y\mid x)}{\pi_{\text{ref}}(y\mid x)} \;+\; \beta\log Z(x) $$

    这句话的信息量很大：「奖励」和「最优策略」是一一对应的。 给定 $\pi^\star$ 就能写出 $r$，给定 $r$ 就能写出 $\pi^\star$。所以「学一个奖励模型」和「直接学策略」在信息上是等价的—— 这就是 DPO 的出发点。

    4.9 PPO 与 GRPO：baseline 从哪来 补充

    回到 §4.6 的梯度。它有一个致命的实践问题：方差太大。所有后续算法都在回答同一个问题—— 用什么当 $b$，使得 $\mathbb{E}[(r-b)\nabla\log\pi]=\mathbb{E}[r\nabla\log\pi]$ 但方差更小。

    这个 $b$ 到底是什么

    它就是 baseline（基线），也叫参照系。减掉它的目的只有一个：把「绝对水平」换成「相对好坏」。 一条回答得了 0.9 分，是好是坏？要看这道题本来该得几分——$b$ 就是那个「本来」。

    为什么减它不改变梯度：

    $$ \mathbb{E}_{a\sim\pi}\big[b(s)\nabla_\theta\log\pi(a\mid s)\big] = b(s)\sum_a \nabla_\theta\pi(a\mid s) = b(s)\nabla_\theta 1 = 0 $$

    注意 $b(s)$ 被提到了求和号外面——所以 $b$ 只能依赖状态 $s$，不能依赖动作 $a$。 依赖动作的话这一步不成立，梯度会有偏。

    为什么 value 是最优的 $b$：在所有「只依赖 $s$」的函数里，让方差最小的是 $\mathbb{E}[G\mid s]$， 也就是 value 的定义。猜得越准，剩下的「意外」越少，梯度越不抖。所以 $b=V_\psi(s_t)$ 不是随手选的，是理论最优解。

    但 $b$ 不必是 value。它只是一个参照系，便宜货也能用：

    算法$b$ 是什么要额外训网络吗
    朴素 REINFORCE$0$（不减）否
    常数 baseline整个 batch 的平均分否
    PPO$V_\psi(s_t)$，逐 token 估要（与策略同规模）
    GRPO同一 prompt 一组样本的均值不要
    RLOO组内「留一」均值不要

    所以 GRPO 的 $b$ 不是 value：它不逐 token、也没有网络，只是「这道题其他几条回答的平均分」。 它照样能用，因为只要 $b$ 不依赖动作，期望就不变——只是方差压得没 value 那么狠。

    于是 advantage 有两种写法，语义完全一样，只是参照系不同：

    $$ \hat A_t = G_t - V_\psi(s_t) \quad\text{（比「这道题的预期」好多少）} \qquad \hat A_i = r_i - \operatorname{mean}(r_{1:G}) \quad\text{（比「同题其他回答」好多少）} $$

    PPO 与 GRPO 的全部区别，就是这个 $b$ 怎么算、以及要不要信任域裁剪。

    PPOGRPO
    baseline单独训一个 value 网络 $V_\psi(s_t)$，逐 token 估计同一个 prompt 采一组（$G$ 条），用组内均值当 baseline
    额外参数value head，与策略同规模无
    优势估计GAE：$\hat A_t = \sum_l (\gamma\lambda)^l \delta_{t+l}$$\hat A_i = \dfrac{r_i - \operatorname{mean}(r_{1:G})}{\operatorname{std}(r_{1:G})}$
    裁剪$\min\big(\rho\hat A,\ \operatorname{clip}(\rho,1-\epsilon,1+\epsilon)\hat A\big)$，$\rho=\pi_\theta/\pi_{\text{old}}$和 PPO 一样。真正的区别在上面那行：advantage 是整条一个数，不需要逐 token 的 GAE
    显存策略 + 参考 + 价值，三份模型策略 + 参考，两份
    适用奖励稠密、需要精细 credit assignment奖励稀疏、按整条回答打分（正是 RM 的形态）

    注意 GRPO 那一行的优势公式，就是板书 §4.7 里那条 $(r-\mu)/\sigma$ 的逐样本版本。 换句话说：GRPO = 把「组内归一化」直接当成 advantage，省掉 value 网络。 这也是为什么它对奖励模型的形态特别友好——RM 给的本来就是整条序列一个分，逐 token 的 $V_\psi$ 在这里性价比不高。

    GAE 和 clip 怎么读

    先说 GAE。它的零件只有一个：TD 误差。

    $$ \delta_t \;=\; r_t + \gamma V(s_{t+1}) - V(s_t) $$

    读法：实际拿到的奖励 + 下一步的预期 − 当前的预期，也就是「走这一步之后，预期变好了多少」。 代一组数字：$V(s_1)=0.5$、$V(s_2)=0.6$、$r_1=0$，则 $\delta_1 = 0+0.6-0.5=+0.1$—— 意思是「走了一步，预期涨了 0.1」。

    GAE 把这些「意外」按距离加权求和，越远越轻：

    $$ \hat A_t \;=\; \sum_{l=0}^{\infty} (\gamma\lambda)^l \,\delta_{t+l} $$

    $\lambda$ 是一个偏差-方差的旋钮：

    $\lambda$用了多少后果
    0只看一步的意外 $\delta_t$方差小，但完全依赖 $V$ 准不准 → 偏差大
    1所有未来的意外不依赖 $V$ 的偏差，但抖动大 → 方差大
    0.95大部分，远的打折折中，最常用

    $\lambda=1$ 时有一个漂亮的恒等式：那些 $\delta$ 会一项项抵消，最后 $\sum_l \delta_{t+l} = G_t - V(s_t)$。所以 GAE 不是新东西，它是「$G_t-V(s_t)$」和「一步 TD 误差」之间的连续插值。

    LLM 里通常取 $\gamma=1$（不做折扣），因为一条回答最多几千 token，不需要给「晚出现的奖励」打折。

    再说 clip。先问：为什么要 $\rho$？

    PPO 想拿旧策略采的一批数据反复更新几次（省采样）。但更新几次后 $\pi_\theta$ 已经不是当初采数据的 $\pi_{\text{old}}$ 了， 所以要乘一个纠正权重 $\rho=\pi_\theta/\pi_{\text{old}}$。$\rho=1.5$ 表示「新策略给这个 token 的概率是旧策略的 1.5 倍」。 问题是 $\rho$ 可以涨到很大，估计就崩了。

    clip 的办法很朴素：改到一定程度，就不再给奖励。

    看懂这张图只要两句话：

    • 左边（好回答）：我们想让 $\rho$ 变大。但涨到 $1+\epsilon$ 后曲线变平、梯度变 0——再推高也不给奖励了；
    • 右边（差回答）：我们想让 $\rho$ 变小。降到 $1-\epsilon$ 后同样变平——再压低也不给奖励了。

    所以 clip 不是「禁止更新」，而是一个单向刹车：只在「已经改够了」的方向上刹，反方向照常走。

    为什么外面还要套一个 $\min$：取「裁剪后」和「未裁剪」里更差的那个，得到的是一个悲观下界。 这样优化器永远不能靠一个被禁止的移动去骗到更高的目标值。

    $\epsilon$ 通常取 0.2，意思是「概率比最多变 ±20%」。

    易错 · 「通用 RL 算法」不等于「随便换个算法都行」

    REINFORCE、PPO、GRPO、RLOO 都能写进同一个目标函数，但它们的差别在方差。 语言模型的动作空间是 $10^5$ 维、episode 长几千步，朴素策略梯度的方差大到几乎不可用。 所谓「算法」，在这里基本就是「怎么在不算错期望的前提下把方差压下来」。

    4.10 DPO：把奖励模型隐式化 推导

    §4.8 已经得到 $r(x,y) = \beta\log\frac{\pi^\star(y\mid x)}{\pi_{\text{ref}}(y\mid x)} + \beta\log Z(x)$。 把它代回 BT 的 $\Delta$：

    $$ \Delta = r(x,y_w) - r(x,y_l) = \beta\left[\log\frac{\pi^\star(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \log\frac{\pi^\star(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\right] \;+\; \underbrace{\beta\log Z(x) - \beta\log Z(x)}_{=\,0} $$

    $Z(x)$ 被约掉了——因为两条回答共享同一个 prompt。这一步是整个推导的关键： 它让一个无法计算的配分函数消失了。于是把 $\pi^\star$ 换成待学的 $\pi_\theta$，直接得到 DPO 损失：

    $$ \mathcal{L}_{\text{DPO}}(\theta) = -\,\mathbb{E}_{(x,y_w,y_l)}\left[\log\sigma\!\left( \beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} -\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)} \right)\right] $$

    形式上它和 §3.3 的 RM 损失一模一样，只是把 $r_\phi$ 换成了「策略相对参考策略的 log 比值」。 所以 DPO 可以读成：让策略自己当奖励模型。

    RLHF（PPO）DPO
    要不要 RM要，单独训一个不要，隐式在 $\pi_\theta/\pi_{\text{ref}}$ 里
    要不要在线采样要，每步都采不要，纯离线，一个损失一次前反向
    稳定性差，超参多（$\beta$、clip、value lr…）好，就是个二分类
    上限能持续探索新回答受限于固定的偏好数据集，容易过拟合到 $y_w$ 的措辞

    4.11 ground truth 回来的时候：可验证奖励 补充

    §1.4 说过 RL 阶段没有 ground truth。但如果任务本身可验证，这句话就不成立了： 数学题有标准答案、代码有单元测试、格式有语法检查。这时奖励不需要学，算出来就行：

    $$ r(x,y) \;=\; \mathbb{1}\big[\operatorname{verify}(y) = \text{正确}\big] \;\in\;\{0,1\} $$

    这条路线（RLVR，reinforcement learning with verifiable rewards）把「奖励模型」整个换成了一个程序。 好处很直接：

    • 没有奖励模型，就没有奖励模型的 reward hacking。信号是干净的、不可贿赂的（除非贿赂验证器本身）；
    • 可以无限采样、无限训练，不受标注量限制；
    • ground truth 回来了，于是又能算准确率、又能做 early stopping。

    但它换来了另一组问题，而且这些问题是新的：

    新问题机制
    奖励极其稀疏一条 5000 token 的推理链只给一个 0/1，中间过程没有任何信号
    长度膨胀更长的推理链「碰对」的概率更高，于是长度本身被奖励了
    格式崩塌为了拿分，模型可能放弃可读性，输出只有验证器能懂的片段
    验证器可被 hack代码题里读测试文件、数学题里猜答案格式——hacking 的对象从 RM 变成了验证器
    只覆盖可验证领域写作、共情、风格、安全性都不可验证，这些能力它一点也教不了
    补充 · 一句话把整讲收起来

    三级台阶的 ground truth 分别是：示范（SFT）→ 比较（RM）→ 没有（RL）， 而 RLVR 又把「没有」换回了「有」，但换回来的是任务的答案，不是人类的偏好。

    所以「模型推理变强了」和「模型更对齐了」是两件事。前者靠可验证奖励就能做，后者仍然需要人来判断—— 这也正是奖励模型到现在还没有被淘汰的原因。

    C · 自测十题

    SFT 为什么只对 response token 算 loss？举一个不 mask 会出的具体故障。

    参考答案

    三个层次：算力上，prompt 通常比回答长，不 mask 会让大部分梯度花在「复述问题」上； 语义上，推理时 prompt 是给定的，模型不需要生成它； 多轮对话里，若把 user turn 纳入损失，模型会学「扮演用户」，推理时可能自问自答或伪造对话。

    具体故障：右 padding 且不 mask 时，pad token 占据大部分位置，模型学会「输出 pad」，表现为生成很短就停。

    写出 SFT 的梯度，并说明它为什么「已经在做对比，但负样本不对」。

    参考答案

    $\nabla_\theta\mathcal{L}=\frac{1}{\sum m_t}\sum_t m_t\big(\mathbb{E}_{v\sim\pi_\theta}[\nabla z_{t,v}]-\nabla z_{t,y_t}\big)$。

    它推高示范 token 的 logit、按当前概率压低其余 token，形式上就是对比学习。 但负样本是模型自己认为可能的 token，不是人类讨厌的回答。 「示范者没这么写」和「这么写不好」是两件事，这个信息缺口只能靠成对比较补上。

    前向 KL 与反向 KL 的差别，如何解释 SFT 模型爱 hedging？

    参考答案

    前向 $\mathrm{KL}(p\|q)$ 是 mass-covering：$p>0$ 而 $q\to0$ 时惩罚无穷大，所以 $q$ 必须覆盖 $p$ 的所有峰。 SFT 最小化的是 $\mathrm{KL}(p_{\text{data}}\|\pi_\theta)$，因此当同一个问题有多种都对的写法时， 模型会学出一个「把它们揉在一起」的平均答案——四平八稳、什么都说了、什么都没说。

    反向 $\mathrm{KL}(\pi\|p^\star)$ 是 mode-seeking：抓住一个峰就行。所以 RL/DPO 出来的回答更短、更敢下结论， 但也更容易跑偏到某个奇怪的峰。

    证明 BT 损失对 $r$ 的平移不变，并说明 $b$ 为什么可以删。

    参考答案

    令 $r'=r+c$，则 $\Delta'=(r_w+c)-(r_l+c)=r_w-r_l=\Delta$，损失 $-\log\sigma(\Delta)$ 不变。 代入 $r=h^\top w+b$：$\Delta=(h_w^\top w+b)-(h_l^\top w+b)=w^\top(h_w-h_l)$，$b$ 直接消掉， 它对损失的梯度恒为 0，所以是一个不可辨识的参数。只有用绝对分数做阈值时才需要它。

    说明 BT 就是逻辑回归：特征和标签分别是什么？

    参考答案

    特征 $\varphi=h_w-h_l\in\mathbb{R}^d$（两条回答隐状态之差），标签 $z=1$（表示 $y_w$ 赢）， 模型 $P(z=1\mid\varphi)=\sigma(w^\top\varphi)$——标准逻辑回归，无偏置。 若把 pair 随机交换顺序并把标签翻成 0，就得到完整的二元交叉熵。

    推论：打分层关于 $w$ 是凸的，不会训崩；非凸性全部来自主干。

    奖励模型为什么通常只训 1 个 epoch？验证 acc 先升后降说明什么？

    参考答案

    参数量与策略同量级（$10^9$），pair 数据只有 $10^5$ 量级，参数/样本比约 $10^4$，必然过拟合。 而且同一 prompt 拆出的 $\binom{K}{2}$ 个 pair 不独立，有效样本量比表面数字更小。

    先升后降说明模型开始记忆训练 pair 的表面特征（长度、礼貌用语、markdown 结构）， 这些特征在分布外不相关。降的那一段正是 reward hacking 的种子——策略后来会去优化这些特征。

    写出带 KL 约束的 RLHF 目标与闭式解，并解释「采样不到的回答学不会」。

    参考答案

    $\max_\pi\mathbb{E}_{x}\mathbb{E}_{y\sim\pi}[r_\phi(x,y)]-\beta\mathrm{KL}(\pi\|\pi_{\text{ref}})$， 解为 $\pi^\star(y\mid x)=\frac{1}{Z(x)}\pi_{\text{ref}}(y\mid x)e^{r(x,y)/\beta}$。

    因为 $\pi^\star$ 是 $\pi_{\text{ref}}$ 乘一个权重后重归一化，凡 $\pi_{\text{ref}}(y\mid x)=0$ 的回答， 权重永远是 0。所以 RL 只能在参考策略的支撑集内重新分配概率质量，不能凭空造出新回答。 这就是「SFT 决定上限」的严格版本。

    DPO 推导里 $Z(x)$ 为什么能约掉？如果两条回答来自不同 prompt 会怎样？

    参考答案

    反解式是 $r(x,y)=\beta\log\frac{\pi^\star(y\mid x)}{\pi_{\text{ref}}(y\mid x)}+\beta\log Z(x)$。 $\Delta=r(x,y_w)-r(x,y_l)$ 里，两项的 $Z$ 都是同一个 $Z(x)$（共享 prompt），相减为 0。

    如果 $x_w\ne x_l$，$Z(x_w)$ 与 $Z(x_l)$ 不同、无法约掉，而 $Z$ 需要对全词表求和、不可计算， DPO 的推导就不成立了。所以 DPO 数据必须是同一个 prompt 下的两个回答。

    为什么策略梯度要减一个 baseline？用 0/1 奖励、$k=4$ 采到 1 条对的例子说明差别。

    参考答案

    不减 baseline 时权重是 $r\in\{0,1\}$，错的样本权重为 0——它们既不被推高也不被压低， 只是「没被学到」。减掉组均值 $\mu=0.25$ 后，对的权重 $+0.75$、错的权重 $-0.25$—— 错的被主动压低。四者权重之和为 0，只有相对好坏起作用。

    数学上 $\mathbb{E}[b(x)\nabla_\theta\log\pi]=0$，所以减 baseline 不改期望，只降方差。

    写出 REINFORCE 的三行推导，并说明中间那一步为什么是整件事的关键。

    参考答案

    $\frac{dJ}{d\theta}=\sum_y r\frac{dP_\theta}{d\theta} =\sum_y r\,P_\theta\cdot\frac{1}{P_\theta}\frac{dP_\theta}{d\theta} =\sum_y P_\theta\,r\,\frac{d\log P_\theta}{d\theta} =\mathbb{E}_{y\sim P_\theta}[r\nabla_\theta\log P_\theta]$。

    关键是「乘一个 $P$ 再除一个 $P$」：除出来的 $\frac{1}{P}\frac{dP}{d\theta}$ 正好是 $\nabla\log P$， 而乘上的 $P$ 让求和变成了期望。期望可以用采样估计，求和不行—— $y$ 的空间是 $|V|^{|y|}$，枚举不了。所以这一步买到的是「可采样」，代价是方差。

    9(3) General RL Algo：$\theta_1\to\theta_2$ 的离线链 vs online learning 的 $\theta_1\to\cdots\to\theta_T$；$\sigma_1\cdots\sigma_k$ 是真值排名§4.3
    10RL 基本循环图：$s_t, r_t \to$ agent $\to a_t \to$ environment $\to s_{t+1}, r_{t+1}$§4.2
    11Agent = GPT policy $\pi_\theta(a_t\mid s_t)$；Environment = context $(x)$ + 当前输出 + 奖励计算；Action = 采样出的 token§4.2
    12–13对照表：Agent → GPT actor；Policy → $P_\theta(y_t\mid x,y_{<t})$；State → $s_t=(x,y_{<t})$；Action → $a_t=y_t$；Reward → $r_\theta(x,y)$；Value function§4.2
    14Value $V_\psi(s_t)$ = expected remaining return；Return $G_t=\sum_{k=t}^T r_k$；Advantage $\hat A_t=G_t-V_\psi(s_t)$§4.5
    15RL algorithm：maximize expected reward，$\max\mathbb{E}[r(x,y)]=\sum_y P_\theta(y\mid x)r(x,y)$§4.4
    16–17$\theta^{t+1}\leftarrow\theta^t-\eta\nabla_\theta J(\theta^t)$；First RL algorithm: policy gradient，REINFORCE (Williams, 1992)；$\frac{dJ}{d\theta}=\sum_y r\frac{dP_\theta}{d\theta}$；$\frac{d\log y}{d\theta}=\frac1y\frac{dy}{d\theta}$§4.6
    18log-derivative trick 三行，框出 $\frac{1}{P}\frac{dP}{d\theta}$，得 $\frac{dJ}{d\theta}=\mathbb{E}_{y\sim P_\theta}[r\nabla\log P_\theta]$§4.6
    19REINFORCE 三步：sample $y$ → 用冻结 RM 算 $r(x,y)$ → 沿 $\nabla\log P_\theta$ 按 reward 缩放调整 $\theta$§4.7
    20In practice：每个 prompt rollout $k$ 条，$k\in\{1,8,16,32,64\}$；不用原始 reward，用 $(r-\mu)/\sigma$§4.7
    21$A(x,y)=r(x,y)-b(x)$；$A>0$ better than usual；$A<0$ worse than usual§4.5、§4.7
    22$\text{Total}=A(x,y)-\beta\cdot\mathrm{KL}_t$§4.7、§4.8
