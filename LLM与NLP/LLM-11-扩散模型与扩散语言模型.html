    扩散模型与扩散语言模型

    Diffusion models and diffusion language models · 复旦大学数据科学学院 · Baojian Zhou

    这节课真正的主线只有一句：把「从噪声变回数据」写成一条可以数值模拟的随机轨迹。 先有确定性的流（ODE），再加噪声变成 SDE；把这些概念离散到 $T$ 步，就是 DDPM； 把高斯噪声换成离散转移核，就是 D3PM；再把它搬到 token 上，就是 LLaDA / Dream 这一族扩散语言模型。

    §2 Flow model：轨迹就是 ODE 的解 板书 p2–p3

    2.1 向量场：给空间每一点一个箭头 板书 p2

    先看时间参数 $t\in[0,1]$。一条轨迹就是映射

    $$X:[0,1]\to\mathbb R^d,\qquad t\mapsto X_t.$$

    决定轨迹走向的是向量场：

    $$u:\mathbb R^d\times[0,1]\to\mathbb R^d,\qquad (x,t)\mapsto u_t(x).$$

    板书在 $d=2$ 的小坐标里画了一堆箭头：每一点 $(x,t)$ 给出一个速度向量 $u_t(x)$， 轨迹就是顺着这些箭头走出来的曲线。这句话现在还只是直觉，下一步把它写成方程。

    2.2 ODE 与 flow map：解的集合叫流 板书 p3

    给定初值 $X_0=x_0$，要求轨迹在每一点都和向量场一致：

    $$\frac{\mathrm d X_t}{\mathrm dt}=u_t(X_t).$$

    把「初值 $x_0$」也当成输入，就得到流映射（板书叫 flow matching）：

    $$\varphi:\mathbb R^d\times[0,1]\to\mathbb R^d,\qquad \begin{cases} (x_t,t)\mapsto \varphi_t(x_0),\\[2pt] \varphi_0(x_0)=x_0. \end{cases}$$

    核对 手写第二行下标看着像 $T$，但那是初始条件，必须是 $t=0$； 若写成 $\varphi_T(x_0)=x_0$ 就会和后面 $\varphi_t(x_0)=e^{-\theta t}x_0$ 矛盾，故按 $0$ 校正。

    一句话区分三个词

    向量场 $u_t$ 是箭头本身；ODE 是用箭头定义曲线的方程； 流（flow）是把所有初值的 ODE 解收集起来形成的映射族 $\{\varphi_t\}_{t\in[0,1]}$。 板书原话：flow 是 collections of solution of ODEs；旁边写着「这学期读博学 diffusion model 的学生基本都卡在这个处理」。

    2.3 存在唯一性：Picard–Lindelöf 保证了什么 板书 p3–p4 核对

    板书先问了一个很实在的问题：用 ODE 做扩散模型，解到底存不存在？写下的条件是向量场有界 + 连续可微：

    $$\|u_t(x)\|\le L,\qquad u_t(x)\ \text{对 }x\text{ 连续可微且导数有界}.$$

    更标准、也是真正能推出唯一性的条件是 Lipschitz 连续：

    $$\|u_t(x)-u_t(x')\|\le L\,\|x-x'\|,\qquad \forall x,x'.$$

    核对 手写这里写成 $\|u_t(x-G)\|\le L$（$G$ 处字迹不清）， 少了右端的 $L\|x-x'\|$；只约束幅值不能排除两个初值跑出两条不同解，因此补成标准的 Lipschitz 条件。 在这个条件下，Picard–Lindelöf 定理给出：给定 $X_0=x_0$ 后 ODE 解存在且唯一，于是 flow map 存在。 这也解释了为什么后面可以放心地用网络去逼近 $u_t$：只要网络满足 Lipschitz，采样过程就是良定义的。

    2.4 线性 ODE：把公式验到底 板书 p4 推导

    最简单的向量场就是线性收缩：

    课本例子 · 手写原页

    取 $u_t(x)=-\theta x$，$\theta>0$，断言 flow 为 $\varphi_t(x_0)=e^{-\theta t}x_0$。

    验证 1（初值）：$\varphi_0(x_0)=e^{0}x_0=x_0$。

    验证 2（方程）：

    $$\frac{\mathrm d}{\mathrm dt}\varphi_t(x_0) =-\theta e^{-\theta t}x_0=-\theta\,\varphi_t(x_0)=u_t\big(\varphi_t(x_0)\big).$$

    两个条件都满足，断言成立。轨迹 $t\in[0,1]\mapsto e^{-\theta t}x_0$ 从 $x_0$ 单调收缩到 $e^{-\theta}x_0$。

    核对 手写断言一行看起来是 $e^{+\theta t}x_0$，但下一行证明用的是 $-\theta e^{-\theta t}x_0$； 且 $\theta>0$ 时 $e^{+\theta t}$ 会发散，与「扩散到噪声」方向相反，故取负号。

    §3 数值化：Euler 与学到的向量场 板书 p4–p5

    3.1 Euler：把导数换成差分 板书 p4

    大多数向量场没有解析解，只能一步一步走。把导数写成一阶近似：

    $$\frac{\mathrm d X_t}{\mathrm dt}=u_t(X_t) \quad\Longleftrightarrow\quad X_{t+h}=X_t+h\,u_t(X_t)+h\,R_t(h),\qquad h\to 0,\ R_t(h)\to 0.$$

    丢掉余项就是 Euler 方法。板书给的输入是 $(u_t,\text{init},X_0,n)$，令 $t=0$、$h=1/n$、$X_0=x_0$，循环：

    $$X_{t+h}\leftarrow X_t+h\,u_t(X_t),\qquad t\leftarrow t+h.$$

    算一遍误差

    仍用 $u_t(x)=-0.5x$、$x_0=1$、$t\in[0,1]$。精确解 $e^{-0.5}=0.6065307$； 取 $n=10$、$h=0.1$，Euler 每步乘 $1-0.5\times0.1=0.95$， 十步得 $0.95^{10}=0.5987369$，误差约 $0.0078$。 步长越小误差越小，但步数越多——这个「质量—速度」矛盾后面会反复出现。

    3.2 学到的向量场 $u_t^\theta$ 板书 p5

    把真实的 $u_t$ 换成神经网络 $u_t^\theta:\mathbb R^d\times[0,1]\to\mathbb R^d$，训练目标就是让它给出正确的去噪方向：

    $$X_{t+h}\leftarrow X_t+h\,u_t^\theta(X_t).$$

    生成时从简单分布 $x_0\sim P_{\rm init}$ 出发，用 Euler 反复调用网络模拟 ODE，最后得到 $P_{\rm data}$ 的样本。 板书在文本上写的是 $x_0:[\mathrm{EM}],\dots,[\mathrm{EM}]\to x_1:\text{text}$（EM = Euler method）， 并画了 $x_0$ 到 $x_1$ 的一条弧线和几条短折线。

    3.3 确定性轨迹的两个问题 板书 p5 课件

    板书用中文补了一句关键判断：「不确定性 smooth：为了让模型更 robust，要引入 uncertainty」。 课件从「生成一张图很难，加噪却很容易」讲起（树莓图逐步变噪声，再逐步恢复）， 恰好点出确定性 ODE 的短板：

    问题机制后果解法
    轨迹过平滑ODE 解由初值唯一确定，$x_0\mapsto x_1$ 是一条确定映射从同一噪声只能得到同一输出，缺少多样性加布朗噪声，ODE → SDE
    对扰动不鲁棒向量场某处微小误差会沿整条轨迹累积，没有随机性「抹平」采样结果对数值误差敏感噪声项提供探索与容错

    课件还展示了「Different starts, different trajectories」「Many paths from noise to images」： 开始点不同、同一开始点也可以走不同路径，这些图对应到数学上就是下一节的随机过程。

    §4 SDE：把随机性写进微分方程 板书 p5–p8

    4.1 随机微分方程 板书 p6

    板书先讲「随机过程不是确定的，而是随机轨迹」：$X_t$ 是随机变量 $(0\le t\le 1)$， $X:[0,1]\to\mathbb R^d,\ t\mapsto X_t$ 是一条随机轨迹。然后在 ODE 右边加上噪音项：

    $$\mathrm dX_t=u_t(X_t)\,\mathrm dt+\sigma_t\,\mathrm dW_t.$$

    其中 $\sigma:[0,1]\to\mathbb R,\ t\mapsto\sigma_t$ 叫扩散系数 / noise schedule：

    • $\sigma_t=0$：退化为 $\dfrac{\mathrm dX_t}{\mathrm dt}=u_t(X_t)$，即上一节的 ODE；
    • $\sigma_t\ne 0$：把随机性注入轨迹，$W_t$ 是布朗运动（Wiener 过程）。

    4.2 布朗运动的三条性质 板书 p6

    取 $s=0.1$、$t=0.3$。板书写下的性质是

    $$W_t-W_s\sim\mathcal N\big(0,(t-s)I_d\big),\qquad s\le t.$$

    代入数值：$W_{0.3}-W_{0.1}\sim\mathcal N(0,0.2 I_d)$，一维时标准差 $\sqrt{0.2}=0.4472136$。 这就是「噪声随时间累积」的精确含义：时间跨度越大，增量方差越大。板书列的三条性质：

    1. $W_0=0$：永远从零开始；
    2. 高斯增量：$W_t-W_s\sim\mathcal N(0,(t-s)I_d)$；
    3. 独立增量：$W_{t_1}-W_{t_0},\ W_{t_2}-W_{t_1},\ \dots$ 互相独立。

    核对 手写的 $\mathcal N(0,(t-s)I_d)$ 中 $I_d$ 写得像 $I_{d}|$，按标准布朗运动记号整理。

    4.3 $\mathrm dX_t$ 到底是什么意思 板书 p7

    板书特别解释了记号：$\mathrm dX_t$ 是记号，不是「在某个点求导」（旁边标注 Itô integral）。 它表示一小段时间内的增量，要按积分方程理解：

    $$X_{t+h}=X_t+\int_t^{t+h}u_s(X_s)\,\mathrm ds+\int_t^{t+h}\sigma_s\,\mathrm dW_s.$$

    把它拆成可计算的形式：

    $$X_{t+h}\approx X_t+h\,u_t(X_t)+\sigma_t\,(W_{t+h}-W_t)+\underbrace{h\,R_t(X_t)}_{\text{高阶余项}}, \qquad W_{t+h}-W_t\sim\mathcal N(0,hI_d).$$

    所以 SDE 里的随机项在数值上就是 $\mathcal N(0,hI_d)$ 的样本乘 $\sigma_t$， 标准差随 $\sqrt h$ 增长，而不是 $h$。

    4.4 Euler–Maruyama：真正用来采样的算法 板书 p7

    板书先给 SDE 写存在唯一性条件：$u_t$ 与 $\sigma_t$ 满足 $\|u_t\|\le L$ 及 Lipschitz； 然后把 Euler 升级成 Euler–Maruyama（板书写成「Euler. Morugamen method」，输入 $(u_t,n,\sigma_t)$）：

    $$t=0,\quad h=\frac1n,\quad X_t=x_0\sim P_{\rm init}.$$
    $$\text{for }t=1,2,\dots,n-1:\quad \varepsilon\sim\mathcal N(0,I_d),\qquad X_{t+h}\leftarrow X_t+h\,u_t(X_t)+\sigma_t\sqrt h\,\varepsilon,\qquad t\leftarrow t+h.$$

    最后 $X_0,X_1,\dots,X_1$ 就是采样出来的图像 / 文本。核对 手写把 $\varepsilon\sim\mathcal N(0,I_d)$ 写在循环里，更新式写 $\sigma_t\sqrt h\cdot\varepsilon$， 与 $W_{t+h}-W_t=\sqrt h\,\varepsilon$ 一致；板书末尾的 $X_1$ 是终点记号，下标 $1$ 指 $t=1$。

    4.5 OU 过程：一个能解出来的例子 板书 p8

    把 §2.4 的线性向量场加进噪声，就是 Ornstein–Uhlenbeck 过程：

    $$\mathrm dX_t=-\theta X_t\,\mathrm dt+\sigma\,\mathrm dW_t .$$

    板书画了三幅小轨迹图，随着 $\theta$ 增大，曲线越来越快地被拉回中心、抖动幅度相对变小。 机制：漂移项 $-\theta X_t$ 把状态往 0 拉，扩散项 $\sigma\,\mathrm dW_t$ 往外推，二者平衡出稳态分布。

    4.6 生成模型 = 学 $(u_t^\theta,\sigma_t)$ 板书 p8

    板书写下 $x_0\sim P_{\rm init}\xrightarrow{\rm SDE}P_{\rm data}$， 并明确「by using neural network to model vector field」：

    $$\big(u_t^\theta,\ \sigma_t\big),\qquad \sigma_t:\text{noise schedule},\qquad u_t^\theta:\text{learned vector field}.$$

    神经网络只学漂移项 $u_t^\theta$，噪声强度 $\sigma_t$ 由人事先规定。更一般的写法是

    $$\mathrm dX_t=f(X_t,t)\,\mathrm dt+g(t)\,\mathrm dW_t,\qquad X_{t+h}=X_t+h\,u_t^\theta(X_t)+\sigma_t\sqrt h\,\varepsilon,\quad \varepsilon\sim\mathcal N(0,I_d).$$

    板书最后强调 $X_t$ 可以是 text / image / audio， 并画了「text、image → backbone → image」的简图；旁边中文记的是：转载时可以把不同模态的 projector 变成 token， 所有模态先输入到 backbone。这正是扩散模型能跨模态的统一接口。

    §5 DDPM：从 AE 到离散扩散 板书 p9

    5.1 先有 latent：AE → VAE → VQ-VAE 板书 p9 课件

    板书在 DDPM 标题下先写了一段「history」：AE: Autoencoder → VAE: Variational Autoencoder， 配了 $x\to[f,g]\to f(x)\to g(f(x))$ 的小图，并写下 (V)AE 的两条分支： continuous ↔ image、discrete ↔（文字）。 课件用整整十页补上了这段：

    模型latent能采样吗机制 / 局限
    AE确定向量 $z=g_\phi(x)$不能只学到重构；latent 空间没有规定分布，随便采样得不到合法图像
    VAE连续分布 $q_\phi(z\mid x)$能把 latent 约束成易采样的分布；文本上插值常产生不通顺句子
    VQ-VAE离散 code $e\in\mathbb R^{K\times D}$能最近邻查表得到 $K$ 类离散表示，更适合语言 / 语音 / 推理

    5.2 两条马尔可夫链 课件 板书 p9

    板书把 DDPM 画成 $x_0\leftrightarrow x_1\leftrightarrow\cdots\leftrightarrow x_T$ 的链： 上箭头写 $P(x_i\mid x_{i-1})$，下箭头写 $P_\theta(x_{i-1}\mid x_i)$。 课件把它形式化为两条 Markov 链：

    $$q(x_t\mid x_{t-1},\dots,x_0)=q(x_t\mid x_{t-1}),\qquad p_\theta(x_{t-1}\mid x_t,\dots,x_T)=p_\theta(x_{t-1}\mid x_t).$$

    前向固定、反向学习：前向是已知的 Gaussian 转移，反向的 $p_\theta$ 才是神经网络要逼近的东西。

    5.3 D3PM：把高斯换成离散转移核 课件

    板书只写了一条线索：DDPM → D3PM: Discrete，然后 DDPM → D3PM → {LLaDA, Dream, Mercury}。 课件补上了动机：高斯噪声取任意实值，适合像素强度这类连续数据；文本、类别是离散状态，需要换噪声。

    模型状态空间噪声机制适用数据
    DDPM连续 $\mathbb R^d$加高斯：$x_t=\sqrt{1-\beta_t}x_{t-1}+\sqrt{\beta_t}\varepsilon$图像、音频波形
    D3PM有限离散状态 $\{1,\dots,K\}$结构化转移矩阵：翻 bit、换 token、吸收态 [MASK]文本、类别、离散符号

    机制差别：连续扩散靠「幅度衰减 + 高斯抖动」，离散扩散靠「按转移矩阵换状态」。 D3PM 的关键设计是转移核怎么选——课件 source-054…058 展示了吸收态、均匀转移等核，以及在 text8 / LM1B 上的困惑度与采样速度曲线。

    5.4 LLaDA：先算一个被 mask 的句子 课件

    先看课件 source-062 的预训练描述：随机把比例 $t\sim U[0,1]$ 的 token 遮住； SFT 时只遮 response token；采样时从 $t=1$（全遮）走到 $t=0$（全露出）， 每一步同时预测所有 mask，再灵活重遮。

    一个 8-token 的手算例子

    句子 The cat sat on the mat .（7 个词 + 标点）。设 $t=0.5$，按比例遮一半：

    t=0 → The cat sat on the mat .
    t=0.5 → [M] cat [M] on [M] mat .　（3/7 ≈ 0.43 被遮）
    t=1 → [M] [M] [M] [M] [M] [M] [M]

    训练时模型只看被遮版本，要同时填回所有 [M]；采样时反过来，从全 [M] 开始一步步填。 这和自回归「只能从左往右、一次一个 token」形成直接对比。

    课件 source-031…032 的结论：LLaDA 的规模化趋势与同数据下的 AR baseline 有竞争力； source-065 的可视化里，颜色越深表示越晚被预测出来的 token——说明生成顺序不是左到右，而是由置信度决定。

    5.5 Dream 与 Mercury：任意顺序与产品化 课件

    • Dream：扩散模型不受顺序约束，可任意顺序合成输出，从而支持更多样的用户查询（source-033）；还能控制解码行为（source-034）、复用已有自回归模型的权重做初始化（source-066/068）。
    • Mercury：Inception Labs 的产品化扩散语言模型（source-060），说明这条路线已经从论文走向可用产品。

    5.6 质量—速度权衡 课件

    课件 source-035 直接给了质量—速度曲线，source-034 给了解码行为控制。把机制写成表：

    维度自回归 LM扩散语言模型机制

    §6 前向加噪与反向去噪（板书 ① ②） 板书 p9–p10

    6.1 Forward：板书公式的参数化核对 板书 p9–p10 核对

    补充版 p9 在 DDPM 链上新增了两个标注：$x_0\sim P_{\rm data}$ 写在链首， $x_T\leftarrow P_{\rm init}$ 写在链尾，并在转移式上方注明 Each step is generated by a fixed Gaussian transitional kernel。板书写的公式是：

    $$x_0\sim P_{\rm data}\ \longrightarrow\ x_T\sim P_{\rm prior}:=\mathcal N(0,I_d),$$ $$P(x_i\mid x_{i-1})=\mathcal N\!\left(\sqrt{1-\beta_i^2}\; x_{i-1},\ \beta_i^2 I_d\right),\qquad i=1,\dots,T.$$

    随后定义 $\{\beta_i^2\}_{i=1}^T$（pre-determined or learned，$\beta_i\uparrow$ 时 $\beta_i\in(0,1)$）与

    $$\alpha_i=\sqrt{1-\beta_i^2},\qquad x_i=\alpha_i x_{i-1}+\beta_i\varepsilon_i,\qquad \varepsilon_i\sim\mathcal N(0,I_d).$$

    这里要特别小心：老师写的 $\beta_i$ 扮演的是「噪声标准差」的角色， 所以方差是 $\beta_i^2$，均值系数是 $\sqrt{1-\beta_i^2}$。 主流 DDPM 文献里的 $\beta_t$ 则直接就是方差。两套记号逐项对照：

    含义板书（$\beta_i$ = 标准差）标准 DDPM（$\beta_t$ = 方差）
    单步噪声方差$\beta_i^2 I_d$$\beta_t I_d$
    单步均值系数$\alpha_i=\sqrt{1-\beta_i^2}$$\alpha_t=1-\beta_t$
    累计系数$\bar\alpha_i=\prod_{k=1}^i\sqrt{1-\beta_k^2}$$\bar\alpha_t=\prod_{s=1}^t(1-\beta_s)$
    一步转移$\mathcal N(\sqrt{1-\beta_i^2}x_{i-1},\beta_i^2I_d)$$\mathcal N(\sqrt{1-\beta_t}x_{t-1},\beta_t I)$
    闭式采样$x_i=\bar\alpha_i x_0+\sqrt{1-\bar\alpha_i^2}\,\varepsilon$$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon$

    令 $\beta_i^{2}=\beta_t^{\text{std}}$，两列完全重合：$\alpha_i^2=\alpha_t^{\text{std}}$， $\bar\alpha_i^2=\bar\alpha_t^{\text{std}}$。板书没有错，只是换了一套记号，后面推导一律沿用板书。

    6.2 从递推到闭式：逐步展开 板书 p10 推导

    板书先用一句话说明「从高斯采样」的事实：

    $$X\sim\mathcal N(\mu,\sigma^2 I_d)\quad\Longrightarrow\quad X=\mu+\sigma\varepsilon,\ \ \varepsilon\sim\mathcal N(0,I_d).$$

    然后把 $x_1\to x_2\to\cdots\to x_i$ 的递推展开。 由于各步噪声独立，线性组合仍是高斯；板书在每一步下方标了「有 $\alpha$ 成分」：

    $$x_i=\Big(\prod_{j=1}^{i}\alpha_j\Big)x_0 +\sum_{k=1}^{i}\beta_k\Big(\prod_{j=k+1}^{i}\alpha_j\Big)\varepsilon_k .$$

    记 $\bar\alpha_i=\prod_{k=1}^i\alpha_k=\prod_{k=1}^i\sqrt{1-\beta_k^2}$。 噪声部分的方差为

    $$\sum_{k=1}^{i}\beta_k^2\prod_{j=k+1}^{i}\alpha_j^2 =\sum_{k=1}^{i}\Big(1-\alpha_k^2\Big)\prod_{j=k+1}^{i}\alpha_j^2 =\sum_{k=1}^{i}\Big(s_{k+1}-s_k\Big)=1-\bar\alpha_i^2,$$

    其中 $s_k=\prod_{j=k}^{i}\alpha_j^2$，最后一步是裂项相消（$s_{i+1}=1$, $s_1=\bar\alpha_i^2$）。 于是多个独立高斯的加权和可以合并成一个高斯：

    $$\boxed{\;x_i=\bar\alpha_i\,x_0+\sqrt{1-\bar\alpha_i^2}\,\varepsilon,\qquad \varepsilon\sim\mathcal N(0,I_d).\;}$$

    不要先背定义。设一个一维数据点 $x_0=1$，每一步只做

    可以手算的例子

    取 $\beta=0.1$，递推 $x_i=\sqrt{1-\beta^2}\,x_{i-1}+\beta\varepsilon_i$， $\varepsilon_i\sim\mathcal N(0,1)$。忽略随机项，只看确定性的衰减：

    • $\alpha=\sqrt{1-0.1^2}=\sqrt{0.99}=0.9949874$；
    • 一步后 $x_1=0.9949874\times 1=0.9950$，噪声标准差 $0.1$；
    • 三步后 $\bar\alpha_3=0.99^{1.5}=0.9850376$，累计噪声系数 $\sqrt{1-\bar\alpha_3^2}=\sqrt{0.029701}=0.1723398$；
    • 十步后 $\bar\alpha_{10}=0.99^5=0.9509900$，累计噪声系数 $0.3092215$。

    也就是说：加噪十次以后，原始信号只剩 $95.10\%$ 的幅度，噪声的标准差已经到 $0.3092$。 「数据变噪声」容易，因为每一步都是固定的线性变换加固定分布的高斯；反过来要从 $0.3092$ 的噪声里恢复 $1$，就必须学。

    这时再给名字：这一串操作叫前向扩散（forward diffusion），要学的反方向叫去噪（denoising / reverse process）。整节课都在把这两句话写成公式。

    这一步就是 DDPM 的核心便利：不必模拟中间所有步骤，可以直接跳到任意噪声水平 $i$。 上面手算的 $\bar\alpha_{10}=0.9509900$、噪声系数 $0.3092215$ 正是这个公式在 $\beta=0.1$ 时的数值。

    6.3 Reverse：要学的是什么 板书 p10 课件

    板书最后一行只写了开头：$P_\theta(x_{i-1}\mid x_i)$（Reverse Denoising）。 课件 source-016…029 用一整段动画把它讲清楚：训练一个去噪网络，在不同噪声水平预测「该往哪个方向走」； 采样时从 $x_T\sim\mathcal N(0,I_d)$ 出发，反复预测 + 走一步，最后得到图像。

    与 §4 的衔接

    连续时间 SDE 的 $\mathrm dX_t=u_t(X_t)\mathrm dt+\sigma_t\mathrm dW_t$ 离散到 $T$ 步， 再把漂移换成去噪网络，就是 DDPM 的反向链。DDPM 不是另一套理论，而是 §4 的一个离散版本。

    6.4 反向转移为什么难：Bayes 分解 板书补页 p11

    补充笔记把「⑤ Reverse Denoising Process of DDPMs (learnable decoder)」写清楚了：

    $$x_T\sim P_{\rm prior}\ \xrightarrow{\ \text{denoising}\ }\ x_0:\ \text{meaningful image}.$$

    难点是 $P(x_{i-1}\mid x_i)$ 未知。板书把它按 Bayes 拆开：

    $$p(x_{i-1}\mid x_i)=p(x_i\mid x_{i-1})\cdot\frac{p_{i-1}(x_{i-1})}{p_i(x_i)},$$ $$p_i(x_i)=\int p(x_i\mid x_0)\,p_{\rm data}(x_0)\,\mathrm dx_0 .$$

    分子「easy」（前向已知），分母「intractable」（要对整个数据分布积分）。所以退化成近似反向转移核：

    $$P_\theta(x_{i-1}\mid x_i)\approx P(x_{i-1}\mid x_i),\qquad \min_{\theta\in\Theta}\mathrm{KL}(P\parallel P_\theta).$$

    沿着 $x_T\sim\cdots\sim x_0$ 这条路径，板书特意区分了带 $x_0$ 与不带 $x_0$ 的两种核： $p_i(x_{i-1}\mid x_i,x_0)$ 与 $p_\theta(x_{i-1}\mid x_i)$。 中文批注：「$x_0$ 是初始，指导去噪过程」——即训练时可以把已知的无噪数据当成额外条件。

    把 $x_0$ 作为条件代入 Bayes（Markov 性使 $p(x_i\mid x_{i-1},x_0)=p(x_i\mid x_{i-1})$）：

    $$p(x_{i-1}\mid x_i,x_0)=\frac{p(x_i\mid x_{i-1})\,p(x_{i-1}\mid x_0)}{p(x_i\mid x_0)}.$$

    6.5 用 $x_0$ 条件化得到可处理的目标 板书补页 p11–p12 推导

    板书的三步（1° / 2° / 3°）是把「对未知 $p(x_{i-1}\mid x_i)$ 求 KL」换成「对已知后验求 KL」：

    $$\mathbb E_{p_i(x_i)}\!\left[D_{\rm KL}\big(p(x_{i-1}\mid x_i)\parallel p_\theta(x_{i-1}\mid x_i)\big)\right] =\mathbb E_{p_{\rm data}(x_0)}\mathbb E_{p(x_i\mid x_0)} \!\left[D_{\rm KL}\big(p(x_{i-1}\mid x_i,x_0)\parallel p_\theta(x_{i-1}\mid x_i)\big)\right]+C .$$

    常数 $C$ 与 $\theta$ 无关。最优反向核是后验的边际化：

    $$p^*(x_{i-1}\mid x_i)=\mathbb E_{p(x_0\mid x_i)}\big[p(x_{i-1}\mid x_i,x_0)\big].$$

    而 $p(x_{i-1}\mid x_i,x_0)$ 是高斯，有闭式表达。把它写成

    $$p(x_{i-1}\mid x_i,x_0)=\mathcal N\!\left(x_{i-1};\,M(x_i,x_0,i),\ \sigma_i^2 I_d\right).$$

    板书给的两个系数（沿用老师的 $\alpha_i=\sqrt{1-\beta_i^2}$、$\bar\alpha_i=\prod_{k=1}^i\alpha_k$）：

    $$M(x_i,x,i)=\frac{\bar\alpha_{i-1}\beta_i^2}{1-\bar\alpha_i^2}\,x +\frac{(1-\bar\alpha_{i-1}^2)\,\alpha_i}{1-\bar\alpha_i^2}\,x_i,$$ $$\sigma_i^2=\frac{1-\bar\alpha_{i-1}^2}{1-\bar\alpha_i^2}\,\beta_i^2 .$$

    复算一遍

    取 $\bar\alpha_{i-1}=0.9$、$\beta_i=0.1$，则 $\alpha_i=\sqrt{0.99}=0.9949874$、 $\bar\alpha_i=0.8954886$、$\sigma_i^2=0.0095911$。 令 $x_0=1.7$、$x_i=0.4$，由闭式反推 $\varepsilon=(x_i-\bar\alpha_i x_0)/\sqrt{1-\bar\alpha_i^2}$； 代入 $M$ 得 $0.4589553$，而用 §6.7 的 ε 形式 $\frac1{\alpha_i}\big(x_i-\frac{1-\alpha_i^2}{\sqrt{1-\bar\alpha_i^2}}\varepsilon\big)$ 得 $0.4589553$，两者一致。

    6.6 建模反向核与 DDPM 损失 板书补页 p12 推导

    把均值换成可学习网络 $M_\theta:\mathbb R^d\to\mathbb R^d$，方差沿用上式的 $\sigma_i^2$：

    $$p_\theta(x_{i-1}\mid x_i)=\mathcal N\!\left(x_{i-1};\,M_\theta(x_i,i),\ \sigma_i^2 I_d\right).$$

    于是每一步的 KL 变成两个同协方差高斯的 KL：

    $$L_{\rm diff}(x_0;\theta)=\sum_{i=1}^{L}\mathbb E_{p(x_i\mid x_0)} \!\left[D_{\rm KL}\big(p(x_{i-1}\mid x_i,x_0)\parallel p_\theta(x_{i-1}\mid x_i)\big)\right].$$

    板书写了通用的高斯 KL（$P_1\sim\mathcal N(\mu_1,\Sigma_1)$、$P_2\sim\mathcal N(\mu_2,\Sigma_2)$）：

    $$D_{\rm KL}(P_1\parallel P_2)=\frac12\Big[\operatorname{tr}(\Sigma_2^{-1}\Sigma_1) +(\mu_2-\mu_1)^\top\Sigma_2^{-1}(\mu_2-\mu_1)-d+\ln\frac{|\Sigma_1|}{|\Sigma_2|}\Big].$$

    这里两者方差同为 $\sigma_i^2 I$：迹项 $=d$、行列式项 $=0$，只剩均值差：

    $$D_{\rm KL}=\frac{1}{2\sigma_i^2}\,\|M(x_i,x_0,i)-M_\theta(x_i,i)\|^2,$$ $$L_{\rm DDPM}(\theta)=\sum_{i=1}^{L}\frac{1}{2\sigma_i^2}\, \mathbb E_{x_0\sim p_{\rm data}}\!\left[\mathrm{SE}\big(M,M_\theta\big)\right].$$

    核对 板书把 $\operatorname{tr}(\Sigma_2^{-1}\Sigma_1)$ 旁的红字写成 $\frac1{\sigma_i^2}L\cdot I$（即 $d$），行列式项旁写 $0$；数值复算（$d=2,\sigma_i^2=0.0095911$）得 KL $=13.0329$，与 $\|M-M_\theta\|^2/(2\sigma_i^2)$ 完全相同。

    6.7 预测参数化与采样 板书补页 p13

    板书第 ⑦ 条「Practical choices of predictions and loss」：训练 $M$ 等价于训练 $\varepsilon$ prediction，实际用的就是 ε-pred。

    $$M(x_i,x_0,i)\approx\frac{1}{\alpha_i}\left(x_i-\frac{1-\alpha_i^2}{\sqrt{1-\bar\alpha_i^2}}\,\varepsilon\right), \qquad \varepsilon\leftrightarrow\varepsilon_\theta,$$ $$M_\theta(x_i,i)=\frac{1}{\alpha_i}\left(x_i-\frac{1-\alpha_i^2}{\sqrt{1-\bar\alpha_i^2}}\,\varepsilon_\theta(x_i,i)\right).$$

    核对 手写分子是 $1-\alpha_i^2$（不是 $1-\bar\alpha_{i-1}^2$），而 $1-\alpha_i^2=\beta_i^2$；系数是 $1/\alpha_i$ 而非 $1/\bar\alpha_i$。代入 §6.5 的 $M$ 可严格化简得到上式（§6.5 的数值复算已验证）。

    因为只有 $\varepsilon$ 与 $\varepsilon_\theta$ 不同，损失变成熟悉的形式：

    $$\|M-M_\theta\|^2\propto\|\varepsilon-\varepsilon_\theta\|^2,\qquad \min_\theta\ \mathbb E\,\|\varepsilon-\varepsilon_\theta\|^2 .$$

    板书还标了 x-prediction：$\|x_\theta(x_i,i)-x_i\|^2$，即直接预测无噪数据。

    第 ⑧ 条是采样（「sampling 与 predict 方式有关」）：

    $$\varepsilon_\theta(x_i,i),\quad i=L,L-1,\dots,1;\qquad x_T\sim P_{\rm prior}=\mathcal N(0,I_d),$$ $$x_{i-1}\leftarrow\frac{1}{\alpha_i}\left(x_i-\frac{1-\alpha_i^2}{\sqrt{1-\bar\alpha_i^2}}\,\varepsilon_\theta(x_i,i)\right)+\sigma_i\varepsilon_i, \qquad \varepsilon_i\sim\mathcal N(0,I).$$

    更抽象地写成 $x_{i-1}=A\,x_i+B\,M_\theta(x_i,i)+\sigma_i\varepsilon_i$。 板书的解释是 interpolation（插值）between $x_i$ and $x_\theta(x_i,i)$： 每一步不是「跳到终点」，而是在当前带噪状态与模型预测的无噪状态之间按系数取插值，再加一点新噪声。

    板书末尾给了参考：baojian/diff-course lec2 or 1,3。

    §7 D3PM 细节：离散状态与转移矩阵 板书补页 p14–p15

    7.1 从实数向量到离散 token 状态 板书补页 p14

    补充笔记第 ① 条把 D3PM（Discrete DDPM, NeurIPS 2021）写成了严格的离散形式：

    $$X_t\in\mathbb R^d\quad\Longleftrightarrow\quad S_t\in V^L,\qquad L:\text{length},\quad V:\text{vocab}.$$

    每个位置是一个 token 状态；$X_t=e_{X_t}$ 是 one-hot 行向量。 转移由矩阵 $Q_t$ 给出：

    $$[Q_t]_{ij}=q(X_t=j\mid X_{t-1}=i),\qquad [Q_t]_{ij}\ge 0,\qquad \sum_j[Q_t]_{ij}=1 .$$

    $Q_t\in\mathbb R^{|V|\times|V|}$ 是行随机矩阵，取第 $i$ 行就得到从状态 $i$ 走一步的分布 $q(x_t\mid x_{t-1})=\mathrm{cat}(x_t;\,x_{t-1}Q_t)$。板书画了链路 $x_0\to Q_1\to x_1\to Q_2\to\cdots$ 并定义

    $$\bar Q_0=I,\qquad \bar Q_t=Q_1Q_2\cdots Q_t,\qquad q(x_t\mid x_0)=\mathrm{cat}(x_t;\,x_0\bar Q_t).$$

    各位置独立时，整句的联合转移是逐位置相乘：

    $$q(S_t\mid S_{t-1})=\prod_{\ell=1}^{L}[Q_t]_{s_{t-1}^{(\ell)},\,s_t^{(\ell)}},\qquad q(S_t\mid S_0)=\prod_{\ell=1}^{L}[\bar Q_t]_{s_0^{(\ell)},\,s_t^{(\ell)}} .$$

    7.2 两种噪声核：均匀替换与吸收掩码 板书补页 p14–p15

    ① Uniform replacement. 令 $U=\frac{1}{|V|}\mathbf 1\mathbf 1^\top$（每个元素都是 $1/|V|$）， $\bar\beta_t=\prod_{s=1}^{t}(1-\beta_s)$：

    $$Q_t=(1-\beta_t)I+\beta_t U,\qquad U^2=U,$$ $$\bar Q_t=\bar\beta_t I+(1-\bar\beta_t)U .$$

    手算检验

    取 $|V|=5$、$\beta=0.2$，则 $Q_t$ 每行和为 1， 对角元 $0.8+0.2/5=0.84$，换成别的 token 的概率 $\beta(1-1/|V|)=0.16$。 连做三步 $\bar\beta_3=0.8^3=0.512$，$\bar Q_3$ 对角元 $0.512+0.488/5=0.6096$，与直接算 $Q_t^3$ 的对角元一致。

    ② Absorbing masking. 令 $m=[\text{MASK}]$，$I_{e_m}=\mathbf 1 e_m^\top$（每行都是 mask 的 one-hot）：

    $$Q_t=(1-\beta_t)I+\beta_t I_{e_m},\qquad \bar Q_t=\bar\beta_t I+(1-\bar\beta_t)I_{e_m}.$$
    $$[Q_t]_{ij}=\begin{cases} 1, & i=j=m,\\ 1-\beta_t, & i=j\neq m,\\ \beta_t, & j=m,\ i\neq m,\\ 0, & \text{otherwise}. \end{cases}$$

    于是从干净的 $X_0=a$ 走到 $X_t$ 的分布是 $q(X_t\mid X_{t-1}=a)=\bar\beta_t\delta_a+(1-\bar\beta_t)\delta_m$（$S_a$ 为指示函数）。 板书旁边写「不用显示存[?]」——字迹难辨，按原样保留；数学上掩码核确实只靠一个吸收状态即可表示，不需要显式枚举所有 $|V|$ 列。

    7.3 反向去噪：从 $(X_t=b,\,X_0=a)$ 推 $X_{t-1}$ 板书补页 p15 推导

    问题：已知干净 token $X_0=a$ 与带噪 token $X_t=b$，中间状态 $X_{t-1}$ 该服从什么分布？板书分四步：

    1. Bayes：$q(X_{t-1}=j\mid X_t=b,X_0=a)=\dfrac{q(X_t=b\mid X_{t-1}=j,X_0=a)\,q(X_{t-1}=j\mid X_0=a)}{q(X_t=b\mid X_0=a)}$；
    2. 分子第一项由 Markov 性写成 $q(X_t=b\mid X_{t-1}=j)\,q(X_{t-1}=j\mid X_0=a)$；
    3. 用前向核 $q(X_t=b\mid X_{t-1}=j)=[Q_t]_{jb}$，以及 $q(X_{t-1}=j\mid X_0=a)=[\bar Q_{t-1}]_{aj}$；
    4. 归一化分母是对所有可能中间状态求和。
    $$q(X_{t-1}=j\mid X_t=b,X_0=a) =\frac{[Q_t]_{jb}\,[\bar Q_{t-1}]_{aj}} {\sum_i [Q_t]_{ib}\,[\bar Q_{t-1}]_{ai}} .$$

    板书画了两条直觉线索：① 到时刻 $t-1$ 时 $a\to j$ 有多可能；② 最后一步 $j\to b$ 有多可能。 这两个概率相乘再归一化，就是离散版「后验」——和 §6.5 连续高斯的 $p(x_{i-1}\mid x_i,x_0)$ 扮演完全相同的角色，只是把密度换成了类别概率。

    §8 一页主线 推导

    从向量场到语言模型
    1. 向量场 $u_t(x)$ 给出每点的速度；ODE $\mathrm dX_t/\mathrm dt=u_t(X_t)$ 定义轨迹，解的集合叫流 $\varphi_t$。
    2. Euler $X_{t+h}=X_t+h u_t(X_t)$ 让轨迹可数值模拟；把 $u_t$ 换成网络 $u_t^\theta$，就得到生成模型。
    3. SDE $\mathrm dX_t=u_t\mathrm dt+\sigma_t\mathrm dW_t$ 注入随机性；Euler–Maruyama 用 $\sigma_t\sqrt h\,\varepsilon$ 采样。
    4. DDPM 把时间离散成 $T$ 步，前向固定为高斯；闭式 $x_i=\bar\alpha_i x_0+\sqrt{1-\bar\alpha_i^2}\varepsilon$ 允许跳步训练；反向用 $x_0$ 条件化得到高斯后验 $M,\sigma_i^2$，再训练 $\varepsilon_\theta$，采样时按 $x_i$ 与 $x_\theta(x_i,i)$ 插值。
    5. D3PM / dLLM 把高斯换成行随机矩阵 $Q_t$，均匀替换或 [MASK] 吸收核都只是 $Q_t$ 的不同取法；反向类别后验 $\propto[Q_t]_{jb}[\bar Q_{t-1}]_{aj}$。再把它搬到 token 上，就是 LLaDA / Dream / Mercury——把「去噪」改写为「填回被遮的 token」。

    如果只记住一个对照：ODE 是确定性的「一步到位」，SDE 是带随机性的「多步探索」，DDPM 是把 SDE 离散成可训练、可跳步的算法，扩散语言模型是把这套算法施于 token 序列。
