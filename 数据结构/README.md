## 配套代码

`code/` 下是两个可直接运行的演示程序，用来把复杂度结论**实测**出来：

| 文件 | 内容 |
|---|---|
| [`code/insertion_sort.py`](./code/insertion_sort.py) | 带逐轮过程追踪的插入排序；统计比较次数验证最坏 `n(n−1)/2`、最好 `n−1`（适应性） |
| [`code/merge_sort.py`](./code/merge_sort.py) | 带递归过程追踪的归并排序；比较次数对比 `n log₂ n` 验证 `Θ(n log n)`；与插入排序在同一批数据上计时对比 |

运行：

```bash
python code/insertion_sort.py
python code/merge_sort.py
```

实测结论（本机）：

- 插入排序最坏比较次数 = `n(n−1)/2`，最好 = `n−1`，比值与理论完全吻合
- 归并排序比较次数 / `n log₂ n` 比值稳定在 0.84~0.93（`n` 越大越趋近 1）
- `n` 翻倍时：插入排序耗时约 ×4（`n²`），归并排序约 ×2.2（`n log n`）
- `n = 4000` 时归并已快 28.8 倍，且差距随 `n` 继续拉大
