1 · 二叉搜索树：五件事，一条主线 CLRS 12.1–12.3

BST 的全部内容其实只有一句话：中序遍历是递增序列。所有操作（查找、插入、删除、前驱后继） 都是这句话的推论 —— 它们干的都是「沿着一条从根到叶的路径往下走」，所以代价都是 $O(h)$。

1.1 定义与中序遍历

对任意结点 $x$：左子树所有关键字 $\le x.key$，右子树所有关键字 $\ge x.key$。 （CLRS 允许相等；下面 §7 的思考题 12-1 就是专门讨论「关键字相等」会出什么问题。）

TREE-WALK(x)                 # 中序：左 → 根 → 右，输出即递增序列
    if x ≠ NIL
        TREE-WALK(x.left)
        print x.key
        TREE-WALK(x.right)

为什么中序一定是递增的（一句话证明）：对根 $x$，左子树全部 $\le x.key$、右子树全部 $\ge x.key$， 而中序恰好是「左子树全部 → $x$ → 右子树全部」，由归纳假设左右子树内部也递增，拼起来就递增。

三种遍历的用途（顺手记）：前序 = 复制一棵树（先建根）；中序 = 输出有序序列； 后序 = 释放内存 / 算子树大小（先处理孩子）。

1.2 查找：为什么写成 while 而不是递归

ITERATIVE-TREE-SEARCH(x, k)
    while x ≠ NIL and k ≠ x.key
        if k < x.key  x = x.left
        else          x = x.right
    return x

递归版和它等价，但递归版多一个 $O(h)$ 的栈空间；尾递归可以改写成循环，这是 BST 查找的标准写法。 代价 $O(h)$：每比较一次就往下走一层，最多走 $h$ 层。

1.3 最小 / 最大：一路向左 / 向右

TREE-MINIMUM(x)              TREE-MAXIMUM(x)
    while x.left ≠ NIL           while x.right ≠ NIL
        x = x.left                   x = x.right
    return x                     return x

因为「左子树更小」，所以最小值一定在最左下角。这个结论在删除里是关键的：见 1.6。

1.4 后继与前驱：两情形，别背错

$x$ 的后继（successor）是「比 $x.key$ 大的最小关键字」。分两种情形：

情形后继在哪怎么找
$x$ 有右子树右子树里的最小结点TREE-MINIMUM(x.right)
$x$ 无右子树往上找第一个「$x$ 在其左子树里」的祖先沿父指针上爬，直到某结点是它父亲的左孩子
 
TREE-SUCCESSOR(x)
    if x.right ≠ NIL
        return TREE-MINIMUM(x.right)
    y = x.p
    while y ≠ NIL and x == y.right      # 只要我还是「右孩子」就继续爬
        x = y; y = y.p
    return y

为什么第二种情形要「爬到我变成左孩子」为止：只要 $x$ 是 $y$ 的右孩子，说明 $y < x$， 而 $y$ 的整棵子树都比 $x$ 小，所以 $y$ 不可能是后继；一旦 $x$ 成了 $y$ 的左孩子，$y > x$ 且 $y$ 的左子树（含 $x$）全部 $\le y$，所以 $y$ 就是「比 $x$ 大的最小的那个」。

常见错误：把「$x$ 无右子树」时的后继写成「父结点」。反例：$x$ 是父的右孩子时， 父比 $x$ 小，不可能是后继。必须一直爬到「拐弯」的地方。

1.5 插入：走到 NIL，挂上去

TREE-INSERT(T, z)
    y = NIL; x = T.root
    while x ≠ NIL
        y = x
        x = (z.key < x.key) ? x.left : x.right
    z.p = y
    if y == NIL            T.root = z        # 空树
    else if z.key < y.key  y.left = z
    else                   y.right = z
    z.left = z.right = NIL

插入一定发生在叶子位置（走到 NIL 才停），所以新结点必然是叶结点。 这解释了为什么「按顺序插入 $1,2,\dots,n$」会退化成一条右斜链。

1.6 删除：三种情形，只有第三种麻烦

删除 $z$ 之前先想清楚一件事：摘掉 $z$ 之后，谁坐它的位置？

$z$ 的孩子数谁顶替 $z$要做什么
0 个（叶）NIL直接把父的对应孩子置 NIL
1 个那个唯一的孩子孩子整棵子树搬上来（子树内部结构不用动）
2 个后继 $y$（右子树最小值）先把 $y$ 从原位摘掉（$y$ 顶多只有右孩子），再让 $y$ 坐到 $z$ 的位置
 
TRANSPLANT(T, u, v)          # 用子树 v 替换子树 u（只改父指针，不动 v 的孩子）
    if u.p == NIL        T.root = v
    else if u == u.p.left   u.p.left = v
    else                    u.p.right = v
    if v ≠ NIL              v.p = u.p

TREE-DELETE(T, z)
    if z.left == NIL                 TRANSPLANT(T, z, z.right)       # 情形 1、2 合并
    else if z.right == NIL           TRANSPLANT(T, z, z.left)
    else
        y = TREE-MINIMUM(z.right)     # 后继：右子树最小 → 它没有左孩子
        if y.p ≠ z
            TRANSPLANT(T, y, y.right) # 先把 y 摘出来（y 只有右孩子）
            y.right = z.right; y.right.p = y
        TRANSPLANT(T, z, y)
        y.left = z.left; y.left.p = y
为什么情形 3 一定要用「后继」而不是随便找个结点？
因为后继 $y$ 是右子树的最小值，所以它一定没有左孩子。 把它搬到 $z$ 的位置后，$y$ 的左子树 = $z$ 的左子树（全部 $\le z.key \le y.key$ ✓）， 右子树 = $z$ 的右子树去掉 $y$ 之后的部分（全部 $\ge y.key$ ✓），BST 性质自动成立，不用任何调整。
换成前驱也一样成立（前驱一定没有右孩子）。只有「中间某个结点」不行，那会破坏性质。

树：15(6(3(2,4),7(·,13(9))), 18(17,20))，删 15（有两个孩子）。

步动作当前树（中序）
0—2, 3, 4, 6, 7, 9, 13, 15, 17, 18, 20
1求后继：$z.right=18$ 一路向左 → $y=17$$y=17$ 无左孩子，只有右孩子？没有（17 是叶）

2 · BST 的复杂度：为什么只能写 $O(h)$ CLRS 12.4

BST 的每一个操作都是「从根往下走一条路径」，所以代价 $=O(h)$，$h$ 是树高。 注意这里不能写 $O(\lg n)$ —— $h$ 和 $\lg n$ 差得很远：

树的形状$h$一次查找怎么造出来
最好（完全平衡）$\lfloor\lg n\rfloor$$\Theta(\lg n)$按「中位数优先」的顺序插入
最坏（一条链）$n-1$$\Theta(n)$按 $1,2,3,\dots,n$ 顺序插入
随机插入期望 $\Theta(\lg n)$期望 $\Theta(\lg n)$随机打乱后插入

所以「BST 是 $O(\lg n)$ 的」这句话只有在「随机建树」的前提下才成立。 这也是红黑树存在的理由：它用着色规则强制保证 $h=O(\lg n)$，不依赖输入顺序。

2.1 随机建树的期望高度：和快排是同一件事

关键观察：「把 $n$ 个关键字按某个顺序插入 BST」和「用这个顺序做快排」是同一棵递归树。

  • 快排选第一个元素当 pivot，把其余元素分成「小于」和「大于」两组 —— 对应 BST 里第一个元素当根，其余分到左右子树；
  • 快排递归处理两组 —— 对应 BST 递归建左右子树；
  • 两个元素被比较 $\iff$ 其中一个是它们 LCA —— 对应 BST 里一个元素是另一个的祖先。

所以「随机排列插入得到的 BST 的期望高度」= 「随机化快排的期望递归深度」= $O(\lg n)$。 这条对应关系是 §7 里 12-3 和 12.4-5 的全部内容，也是为什么第 12.4 节的证明看起来像在抄第 7 章。

严格结论（定理 12.4）：$n$ 个互异关键字随机建树，期望高度 $\mathrm{E}[X_n]=O(\lg n)$。 更强的结论是 $X_n = O(\lg n)$ 以高概率成立（w.h.p.），即 $\Pr[X_n > c\lg n] \le 1/n^k$。

第 12.4 节的证明路线（§7 的 12.4-1 会逐步展开）：

  1. 设 $X_n$ 为高度，令 $Y_n=2^{X_n}$（把「高度」变成「指数」，好做加法）；
  2. 由 $2^x$ 凸（12.4-4），用 Jensen 不等式：$2^{\mathrm{E}[X_n]} \le \mathrm{E}[2^{X_n}] = \mathrm{E}[Y_n]$；
  3. 对 $\mathrm{E}[Y_n]$ 做归纳，得到 $\mathrm{E}[Y_n] \le \frac14\binom{n+3}{3} = O(n^3)$；
  4. 两边取对数：$\mathrm{E}[X_n] \le \lg O(n^3) = O(\lg n)$。

「先取指数、最后取对数」这个套路值得记：直接把 max 递归式拿去做期望很难，取指数后 max 变成加法上界，就好归纳了。

3 · 红黑树：五条性质与高度定理 CLRS 13.1

BST 的问题只有一个：形状不受控。红黑树的做法是「给结点染两种颜色，用染色规则把形状卡住」—— 不改变 BST 的任何操作，只是加了一层约束，让 $h$ 永远不超过 $2\lg(n+1)$。

3.1 五条性质，每条都在干一件事

#性质它在干什么（这条不能删的理由）
1每个结点是红的或黑的定义颜色，本身没约束力
2根是黑的让「黑高」有个统一的起点；删掉它不影响渐近，只是省事
3每个叶（NIL）是黑的让「所有路径都终止于黑」成立，性质 5 才能谈
4红结点的两个孩子都是黑的限制红色不能连成串 → 红结点最多占路径的一半 → 高度不会失控
5对每个结点，从它到所有后代叶的简单路径上黑结点数相同限制黑色必须均匀 → 树不会一边深一边浅 → 形状接近平衡
一句话记住分工：性质 4 管「红不能连着红」（纵向密度），性质 5 管「黑必须一样多」（横向均衡）。 这两条合起来，就把高度锁死在 $2\lg(n+1)$ 以内。
性质 1、2、3 只是「让定义能写下去」的技术条件。

3.2 黑高：本节采用的口径

先把口径钉死，否则习题的数字对不上。 本节定义：$\mathrm{bh}(x)$ = 从 $x$ 到任一后代叶的路径上，黑结点的个数（含 $x$ 自己，不含 NIL）。
于是：单个黑结点的 $\mathrm{bh}=1$；红结点的 $\mathrm{bh}$ 与它的黑孩子相同（因为不含自己）。
注意：CLRS 正文的定义是「不含 $x$」，差 1。教材习题（如 13.1-6 的 $2^{2k}-1$、13.1-1 的「黑高 2/3/4」） 用的都是本节这个「含 $x$」的口径。做题时先看题目给的数字，再换算。

由性质 5，$\mathrm{bh}(x)$ 是良定义的（不管走哪条路径，数出来都一样）。 这一点非常关键 —— 后面所有论证都靠它。

3.3 核心引理：黑高为 $k$ 的子树，至少有 $2^k-1$ 个内部结点

命题：以 $x$ 为根的子树至少含 $2^{\mathrm{bh}(x)}-1$ 个内部结点。

证明（对 $x$ 的高度归纳）：

  1. 基础：$x$ 是叶（NIL），$\mathrm{bh}=0$，子树内部结点数 $0 = 2^0-1$ ✓
  2. 归纳：设 $x$ 有孩子。每个孩子的黑高要么是 $\mathrm{bh}(x)-1$（孩子黑），要么是 $\mathrm{bh}(x)$（孩子红）。 总之每个孩子的黑高 $\ge \mathrm{bh}(x)-1$。
  3. 由归纳假设，每个孩子的子树至少 $2^{\mathrm{bh}(x)-1}-1$ 个内部结点。两个孩子加起来再加 $x$ 自己： $$n \ge \big(2^{\mathrm{bh}(x)-1}-1\big)+\big(2^{\mathrm{bh}(x)-1}-1\big)+1=2^{\mathrm{bh}(x)}-1$$
这一步的关键在哪：「红孩子的黑高不减少」—— 这正是性质 4 的用处。 如果允许红红相连，孩子可能红、孙子还红，黑高可以一路不降，结点数就可以很少而黑高很大，引理就崩了。

3.4 高度定理：$h \le 2\lg(n+1)$

证明（三句话）：

  1. 任取一条从根到叶的路径。由性质 4，红结点不能相邻，所以路径上红结点数 $\le$ 黑结点数； 于是路径长度（结点数）$\le 2\times$ 黑结点数 $=2\,\mathrm{bh}(\text{根})$。所以 $h \le 2\,\mathrm{bh}(\text{根})$。
  2. 由 3.3 的引理：$n \ge 2^{\mathrm{bh}(\text{根})}-1$，即 $\mathrm{bh}(\text{根}) \le \lg(n+1)$。
  3. 两式合并：$h \le 2\lg(n+1)$。∎
为什么这个界是紧的：取一条「黑红黑红…」交替的链，黑高 $k$、高度 $2k-1$、结点数 $2^k-1$， 代入 $2\lg(n+1)=2\lg 2^k=2k$，确实贴着上界。所以「红黑树高度不超过 $2\lg(n+1)$」不能再改进。
实务上的常数：真实红黑树的高度一般在 $1.5\lg n$ 附近，$2\lg(n+1)$ 是最坏情况的保证。

有了这个定理，BST 的所有操作立刻变成 $O(\lg n)$：

操作时间为什么
SEARCH / MIN / MAX / SUCCESSOR$O(\lg n)$走一条根到叶路径，长度 $\le 2\lg(n+1)$
INSERT / DELETE$O(\lg n)$先 $O(\lg n)$ 找位置，再修正；修正的旋转次数是常数（见 §5、§6）

4 · 旋转：唯一能改形状又不破坏 BST 的操作 CLRS 13.2

插入/删除修正时，颜色不够用（改颜色改不出黑高），必须改形状。但改形状不能破坏 BST 性质。 旋转就是唯一满足这个要求的局部操作。

左旋把 y 提上来、x 沉下去，中间那棵 β 从 y 的左孩子改成 x 的右孩子
LEFT-ROTATE(T, x)                    # 前提：x.right ≠ NIL
    y = x.right
    x.right = y.left                 # ① β 改挂到 x 右边
    if y.left ≠ NIL  y.left.p = x
    y.p = x.p                        # ② y 接管 x 的父亲
    if x.p == NIL          T.root = y
    else if x == x.p.left  x.p.left = y
    else                   x.p.right = y
    y.left = x; x.p = y              # ③ x 成为 y 的左孩子

为什么 BST 性质不变：旋转前后中序都是 $\alpha\to x\to\beta\to y\to\gamma$。 而 BST 性质等价于「中序递增」，中序没变，性质就没变。这是最省事的验证方式，比逐个比大小快得多。

结点深度变化（左旋）说明
$y$$-1$上提一层，接管 $x$ 的位置
$x$$+1$下沉一层，变成 $y$ 的左孩子
$\alpha$（$x$ 的左子树）$+1$跟着 $x$ 一起下沉
$\beta$（$y$ 的左子树）$0$从 $y$ 的左孩子换成 $x$ 的右孩子，深度不变
$\gamma$（$y$ 的右子树）$-1$跟着 $y$ 一起上提

这张表就是 13.2-3 的答案（§8 会再写一遍）。记住「$\beta$ 不动」这一条，其余四个都好推。

右旋是左旋的镜像（把 left/right 全部互换），代码不用另记：

RIGHT-ROTATE(T, y)
    x = y.left
    y.left = x.right
    if x.right ≠ NIL  x.right.p = y
    x.p = y.p
    if y.p == NIL          T.root = x
    else if y == y.p.right y.p.right = x
    else                   y.p.left = x
    x.right = y; y.p = x

5 · 插入与修正：为什么一定染红、三种情况各管什么 CLRS 13.3

5.1 第一步：新结点染红（这是 13.3-1 的答案）

新结点 $z$ 是叶结点（§1.5 已经论证过）。染成什么颜色？只有两个选择：

染色会破坏哪条性质后果
染红可能破坏性质 4（若父也是红）局部问题：只需在一条路径上往上修，能修好
染黑必然破坏性质 5（这条路径多了一个黑）全局问题：所有路径的黑高都要调，根本没法局部修
一句话：染红只会「多出一个红」，影响一条路径；染黑会「多出一个黑」，破坏整棵树的平衡关系。 破坏性质 5 是不可修复的，破坏性质 4 是可以往上推的 —— 所以必须染红。

5.2 修正的三种情况：看「叔结点」的颜色

设 $z$ 是红、$z.p$ 也是红（违反性质 4）。此时 $z.p.p$ 一定是黑（否则在插入前就已经红红相连了）。 决定走哪条路的唯一信息是叔结点 $y$（$z.p$ 的兄弟）的颜色：

情况叔 $y$ 的颜色$z$ 是左孩子还是右孩子动作
1红都行父、叔染黑，祖父染红；$z\leftarrow$ 祖父，继续循环
2黑与父不同侧（内侧）$z\leftarrow z.p$，对 $z$ 旋转一次 → 变成情况 3
3黑与父同侧（外侧）父染黑、祖父染红，对祖父反向旋转一次 → 结束
情况 1 只染色（问题向上移两层）；情况 2 是「先转成情况 3」；情况 3 是唯一真正旋转并终止的情况
三个最容易错的地方：

12.4-1证明 · 中等 证明等式 (12.3)：即 §12.4 里那条把 $\mathrm{E}[X_n]$ 压到 $O(\lg n)$ 的不等式链。

先把要证的东西摆出来。记 $X_n$ 为 $n$ 个互异关键字随机建树的高度，$Y_n=2^{X_n}$。要证的是

$$\mathrm{E}[Y_n]\le\frac14\binom{n+3}{3}=\frac{(n+3)(n+2)(n+1)}{24}$$

进而 $2^{\mathrm{E}[X_n]}\le\mathrm{E}[Y_n]\Rightarrow \mathrm{E}[X_n]=O(\lg n)$。

第一步：写 $Y_n$ 的递归式。根是第 $i$ 小的关键字的概率是 $1/n$（随机排列，每个位置等可能），此时 $X_n=1+\max(X_{i-1},X_{n-i})$，于是

$$Y_n=2^{X_n}=2\cdot\max(Y_{i-1},\,Y_{n-i})$$

把 $\max$ 放大成和（$\max(a,b)\le a+b$，代价是常数因子 2）：

$$Y_n\le 2\,(Y_{i-1}+Y_{n-i})$$

第二步：取期望。

$$\mathrm{E}[Y_n]\le\frac1n\sum_{i=1}^{n}2\big(\mathrm{E}[Y_{i-1}]+\mathrm{E}[Y_{n-i}]\big) =\frac4n\sum_{k=0}^{n-1}\mathrm{E}[Y_k]$$

（最后一步：$i$ 从 1 到 $n$ 时 $i-1$ 和 $n-i$ 都取遍 $0..n-1$，两个和相同，合起来就是 $2\times2=4$ 倍。）

第三步：归纳。猜 $\mathrm{E}[Y_k]\le\frac14\binom{k+3}{3}$，代入：

$$\frac4n\sum_{k=0}^{n-1}\frac14\binom{k+3}{3}=\frac1n\sum_{k=0}^{n-1}\binom{k+3}{3} \overset{\text{曲棍球棒}}{=}\frac1n\binom{n+3}{4} =\frac{(n+3)(n+2)(n+1)}{24}=\frac14\binom{n+3}{3}$$

恰好闭合（不是「小于等于」，是等号）—— 这说明猜的界是「刚好卡住」的，常数 $\frac14$ 和 $\binom{k+3}{3}$ 不是随便凑的。

曲棍球棒恒等式：$\sum_{k=0}^{n-1}\binom{k+r}{r}=\binom{n+r}{r+1}$。 这是这类归纳里最常用的求和工具，比硬算快得多。

第四步：取对数。由 $2^x$ 凸（见 12.4-4）得 Jensen 不等式 $2^{\mathrm{E}[X_n]}\le\mathrm{E}[2^{X_n}]=\mathrm{E}[Y_n]$，于是

$$2^{\mathrm{E}[X_n]}\le\frac{(n+3)(n+2)(n+1)}{24} \;\Rightarrow\;\mathrm{E}[X_n]\le \lg\frac{(n+3)(n+2)(n+1)}{24}=3\lg(n+3)-\lg 24=O(\lg n)\ \checkmark$$
为什么非要绕「取指数」这一圈：直接对 $X_n=1+\max(\cdot)$ 取期望做不出来 —— $\mathrm{E}[\max]$ 不好处理，两个子问题还会纠缠。取指数后 $\max$ 变成「加法上界」， 递归式就变成线性的、可以归纳的了。「指数化 → 归纳 → 取对数」是处理 max 型递归式的标准套路。

12.4-2构造 + 证明 · 中等偏难 描述一棵 $n$ 个结点的 BST：平均深度 $\Theta(\lg n)$，但高度 $\omega(\lg n)$。并给出高度的渐近上界。

构造（「扫帚」形）：取 $k=\lceil\sqrt{n\lg n}\rceil$。

  1. 先造一条长 $k$ 的链（比如一直往右）；
  2. 在链的末端挂一棵尽量平衡的子树，装下剩下的 $n-k$ 个结点（高度 $\Theta(\lg n)$）。

验证平均深度。总路径长度 = 链上结点的深度和 + 子树内结点的深度和：

$$\underbrace{1+2+\cdots+k}_{\Theta(k^2)=\Theta(n\lg n)} +\underbrace{\Theta\big((n-k)\lg(n-k)\big)}_{\Theta(n\lg n)}=\Theta(n\lg n)$$

除以 $n$ 得平均深度 $\Theta(\lg n)$ ✓。而高度 $=k+\Theta(\lg n)=\Theta(\sqrt{n\lg n})=\omega(\lg n)$ ✓。

上界（为什么不能更高）：设平均深度为 $D=\Theta(\lg n)$，总路径长度 $=nD$。 若某个结点深度为 $H$，那么从根到它的路径上就有深度为 $1,2,\dots,H$ 的 $H$ 个结点，光这些就贡献了 $\frac{H(H+1)}{2}$。于是

$$\frac{H^2}{2}\le nD=O(n\lg n)\;\Rightarrow\;H=O(\sqrt{n\lg n})$$
结论：在「平均深度 $\Theta(\lg n)$」的约束下，高度恰好可以到 $\Theta(\sqrt{n\lg n})$， 而且这个界是紧的（上面的构造达到）。所以答案是 $\Theta(\sqrt{n\lg n})$，不是 $O(n)$。
这道题想说明的事：「平均深度小」推不出「高度小」。 红黑树要保证的是高度（最坏情况），而不是平均 —— 这就是为什么不能只靠「随机建树」。

12.4-3反例 · 中等 「随机构建的 BST」（$n!$ 种插入顺序等可能）与「随机选取的 BST」（每个形状等可能）是两个不同的概念。以 $n=3$ 说明。

$n=3$ 有 $3!=6$ 种插入顺序，但只有 $b_3=5$ 种形状。逐个列出：

插入顺序得到的树形状编号概率
1, 2, 31 → 右 2 → 右 3（右斜链）A$1/6$
3, 2, 13 → 左 2 → 左 1（左斜链）B$1/6$
2, 1, 32 为根，左 1、右 3（平衡）C$2/6=1/3$
2, 3, 12 为根，左 1、右 3（平衡）C
1, 3, 21 为根，右 3，3 的左孩子 2D$1/6$
3, 1, 23 为根，左 1，1 的右孩子 2E$1/6$

对比：「随机选取」的口径下每种形状概率都是 $1/5$；而「随机插入」下平衡树 C 的概率是 $1/3$。 $1/3\ne1/5$，所以两个分布不同 —— 随机插入偏爱平衡的形状。

为什么这件事重要：定理 12.4 证的是「随机插入」的期望高度 $O(\lg n)$。 如果换成「随机选形状」，结论其实更强（均匀随机二叉树的期望高度是 $\Theta(\sqrt n)$，反而更差！）。 所以定理 12.4 不能随便换成另一种模型，模型选错结论就错。

12.4-4证明 · 简单证明 $f(x)=2^x$ 是凸函数。

求二阶导：

$$f'(x)=2^x\ln 2,\qquad f''(x)=2^x(\ln 2)^2\gt 0\quad(\forall x)$$

二阶导恒正 $\Rightarrow$ 严格凸。∎

它在这里的用途（这才是考点）：凸函数满足 Jensen 不等式

$$f\big(\mathrm{E}[X]\big)\le\mathrm{E}\big[f(X)\big]\quad\Longrightarrow\quad 2^{\mathrm{E}[X_n]}\le\mathrm{E}\big[2^{X_n}\big]$$

取 $f(x)=2^x$ 就得到 12.4-1 的第二步。这个不等式把「期望的高度」和「高度的期望」联系了起来 —— 而后者才是能归纳的那个量。

离散版（考试更好写）：对任意 $a,b$ 和 $\lambda\in[0,1]$， $2^{\lambda a+(1-\lambda)b}\le\lambda 2^a+(1-\lambda)2^b$。 两边取 $\lambda=\frac12$ 就是「中点值不超过端点平均」，即凸性的定义。

12.4-5证明 · 难 对 RANDOMIZED-QUICKSORT，证明：对任意常数 $k\gt0$，除 $O(1/n^k)$ 比例的输入排列之外，运行时间都是 $O(n\lg n)$。

思路：把「高概率」的界翻译成「排列个数」的界。

  1. 由第 7 章的随机化快排分析（习题 7-3 的另一种分析），存在常数 $c$ 使得对任意常数 $k$ 有 $$\Pr\big[T_n\gt c\,n\lg n\big]=O\!\left(\frac1{n^k}\right)$$ 这里的概率是对「随机选取的排列」取的。
  2. 设「坏排列」= 运行时间超过 $c n\lg n$ 的排列。坏排列的个数 $$=\;(\text{排列总数})\times\Pr[\text{随机排列是坏的}]\;\le\; n!\cdot O\!\left(\frac1{n^k}\right)=O\!\left(\frac{n!}{n^k}\right)$$
  3. 所以坏排列占比 $O(1/n^k)$，其余排列（绝大多数）运行时间 $O(n\lg n)$。∎
注意题目说的「$O(1/n^k)$ 种」是笔误/简写，正确说法是「占 $O(1/n^k)$ 的比例」， 即 $O(n!/n^k)$ 个排列。$1/n^k$ 本身小于 1，不可能是「种数」。
另外要强调：这里的「坏」是输入排列的坏，不是随机种子的坏 —— 随机化快排对任何固定输入都是 $O(n\lg n)$ 期望，这里说的是更强的「几乎对所有排列都确定性地快」。

思考题

12-1相同关键字 · 四小问 带相同关键字的二叉搜索树。把 $n$ 个关键字相同的数据依次插入初始为空的 BST，会发生什么？如何改进？

(a) 朴素 TREE-INSERT 的性能

朴素写法是 if z.key < x.key then 左 else 右，关键字相等时一律往右走。 于是 $n$ 个相同关键字会插成一条右斜链：

  • 第 $i$ 次插入要走 $i-1$ 步 $\Rightarrow$ 总时间 $\sum_{i=1}^n(i-1)=\Theta(n^2)$；
  • 查找任意一个：$\Theta(n)$；树高 $n-1$，完全退化成链表。

所以朴素做法在「大量重复关键字」下是 $\Theta(n^2)$ —— 这正是现实数据（比如按城市分组）会踩的坑。

(b) 布尔标志交替

每个结点 $x$ 存一个标志 $x.b$，每次访问 $x$ 就翻转它；相等时按 $x.b$ 决定往左还是往右。

效果：相等关键字均匀地分到左右两边，树长成近似完全二叉树：

  • 树高 $\Theta(\lg n)$；
  • 插入：每次 $O(\lg n)$，总共 $\Theta(n\lg n)$；最坏也是 $\Theta(n\lg n)$（树形由标志决定，不随输入变化）。

(c) 相等关键字挂成链表

结点 $x$ 上挂一个「关键字等于 $x.key$ 的所有结点」的链表，相等时把 $z$ 追加到表尾（维护尾指针）。

  • 插入：走到位置 $O(\lg n)$ + 追加 $O(1)$，若全是相同关键字则只需走到根，$\Theta(1)$ 每次，总共 $\Theta(n)$；
  • 查找：找到结点后还要扫链表，最坏 $\Theta(n)$（$n$ 个全相同）。

这是「插入极快、查找退化」的典型权衡。

(d) 随机左右

相等时抛硬币决定往左还是往右。

12-2数据结构 · 中等 基数树（radix tree）。说明如何用基数树在 $\Theta(n)$ 时间内按字典序对一组位串排序（$n$ = 所有串长度之和）。

结构：每个结点代表「某个前缀」，第 $i$ 层对应第 $i$ 位。往下走时，这一位是 0 走左、是 1 走右。 一个串结束的结点上打一个「这里有键」的标记；只为了连通路径而存在的结点不存键（教材叫「深结点」）。

排序算法：

  1. 建树：把每个串按位插入，逐位下降，缺结点就新建，末尾结点打标记。 每个串的每一位只处理一次，总代价 $\Theta(\sum \text{长度})=\Theta(n)$。
  2. 先序遍历：先走 0 分支，再走 1 分支，访问到「有标记」的结点就把对应串输出。

为什么输出就是字典序：字典序的比较规则是「找到第一个不同的位，0 的那个更小；若一个是另一个的前缀，短的更小」。 先序遍历恰好先走完所有以 0 开头的串、再走 1 开头的；而在每个子树内部递归地也这么做。 至于「前缀更小」：短串对应的结点是长串结点的祖先，先序遍历先访问祖先，所以短串先输出 ✓

复杂度：建树 $\Theta(n)$ + 遍历 $O(\text{结点数})=O(n)$，共 $\Theta(n)$。

为什么能突破 $\Omega(n\lg n)$ 的下界？因为基数树不做两两比较， 它按「位」把元素分桶 —— 比较排序的下界只约束「只靠比较」的算法。
教材图 12-5 的例子：存 {1011, 10, 011, 100, 0}，先序输出应为 0, 011, 10, 100, 1011 —— 与题面给的答案一致。

12-3证明 · 六小问 随机构建二叉搜索树的平均结点深度。定义 $P(T)=\sum_{x\in T}d(x,T)$（所有结点深度之和，根深度为 0）。

(a) 平均深度 $=\frac1n P(T)$

平均深度就是「深度之和除以结点数」，按定义直接得到： $\frac1n\sum_{x\in T}d(x,T)=\frac1n P(T)$。∎

(b) $P(T)=P(T_L)+P(T_R)+n-1$

设 $T$ 有 $n$ 个结点，左子树 $T_L$ 有 $k$ 个、右子树 $T_R$ 有 $n-1-k$ 个。 在 $T_L$、$T_R$ 内部，结点深度按子树自己的口径算；放到 $T$ 里，每个结点的深度都要加 1（多了一层根）。 所以

$$P(T)=\big(P(T_L)+k\big)+\big(P(T_R)+(n-1-k)\big)+0=P(T_L)+P(T_R)+n-1$$

（根自己深度 0，不贡献。）∎

(c) $P(n)=\frac1n\sum_{i=0}^{n-1}\big(P(i)+P(n-i-1)+n-1\big)$

根是第 $i+1$ 小的关键字（左子树 $i$ 个结点）的概率是 $1/n$，代入 (b) 再对 $i$ 取平均即得。∎

(d) 化简成 $P(n)=\frac2n\sum_{k=1}^{n-1}P(k)+\Theta(n)$

$$\frac1n\sum_{i=0}^{n-1}\big(P(i)+P(n-1-i)\big)=\frac2n\sum_{k=0}^{n-1}P(k)=\frac2n\sum_{k=1}^{n-1}P(k)$$

（$P(0)=0$，去掉不影响；两个和相同所以乘 2。）而常数项

$$\frac1n\sum_{i=0}^{n-1}(n-1)=\frac{n(n-1)}{n}=n-1=\Theta(n)\ \checkmark$$

合起来即得。∎

(e) $P(n)=O(n\lg n)$

猜 $P(n)\le cn\lg n$，对 $n$ 归纳：

$$P(n)\le\frac2n\sum_{k=1}^{n-1}ck\lg k+\Theta(n)$$

用求和界 $\sum_{k=1}^{n-1}k\lg k\le\frac{n^2}{2}\lg n-\frac{n^2}{8}$（可用积分估计证明，数值上 $n=64$ 时左边 10619 < 右边 11776）：

$$P(n)\le\frac{2c}{n}\left(\frac{n^2}{2}\lg n-\frac{n^2}{8}\right)+\Theta(n) =cn\lg n-\frac{cn}{4}+\Theta(n)$$

只要 $c$ 足够大，$\frac{cn}{4}$ 就能吃掉 $\Theta(n)$，于是 $P(n)\le cn\lg n$ ✓。 平均深度 $=\frac{P(n)}{n}=O(\lg n)$，与定理 12.4 一致。∎

(f) 让快排的比较次数与 BST 插入完全一致

做法：固定取子数组的第一个元素作 pivot（不随机化），并且 PARTITION 按数组顺序逐个与 pivot 比较。

为什么一致：BST 插入时，每个元素依次与「根、根的某个孩子、……」比较，比较的对象恰好是它的所有祖先； 而快排里，每个元素恰好与「它所在的每一层子数组的 pivot」比较一次，这些 pivot 也恰好是它的所有祖先。 两者的递归树是同一棵树，所以比较次数逐元素相等。∎

这道题的意义：它把「BST 的期望高度」和「快排的期望比较次数」变成同一个数学对象。 于是第 7 章关于快排的所有结论（包括 $2n\ln n$ 的期望比较次数、$O(\lg n)$ 的期望深度）都能直接搬过来。

12-4生成函数 · 四小问 不同二叉树的数目。设 $b_n$ 为含 $n$ 个结点的不同二叉树的数目。

(a) $b_0=1$，且 $b_n=\sum_{k=0}^{n-1}b_kb_{n-1-k}$

$b_0=1$（空树算一种）。$n\ge1$ 时，根固定，左子树有 $k$ 个结点、右子树有 $n-1-k$ 个， 两者独立，所以乘起来再对 $k$ 求和。∎

(b) $B(x)=xB(x)^2+1$，解得 $B(x)=\frac{1}{2x}\big(1-\sqrt{1-4x}\big)$

设 $B(x)=\sum_{n\ge0}b_nx^n$。则

$$xB(x)^2+1=1+\sum_{n\ge1}\Big(\sum_{k=0}^{n-1}b_kb_{n-1-k}\Big)x^n =1+\sum_{n\ge1}b_nx^n=B(x)$$

解二次方程 $xB^2-B+1=0$：

$$B=\frac{1\pm\sqrt{1-4x}}{2x}$$

取哪个符号？$x\to0$ 时 $B(x)\to b_0=1$。若取 $+$，分子 $\to2$、分母 $\to0$，发散； 取 $-$ 时用洛必达：$\frac{1-\sqrt{1-4x}}{2x}\to\frac{2}{2}=1$ ✓。所以取负号。∎

(c) $b_n=\frac{1}{n+1}\binom{2n}{n}$（Catalan 数）

把 $\sqrt{1-4x}=(1-4x)^{1/2}$ 在 $x=0$ 处展开（广义二项式）：

$$(1-4x)^{1/2}=\sum_{k\ge0}\binom{1/2}{k}(-4x)^k =1-2x-2x^2-4x^3-10x^4-\cdots$$

$k\ge1$ 时 $\binom{1/2}{k}(-4)^k=-\dfrac{2}{k}\dbinom{2k-2}{k-1}$，所以

$$1-\sqrt{1-4x}=\sum_{k\ge1}\frac{2}{k}\binom{2k-2}{k-1}x^k$$

除以 $2x$，令 $n=k-1$：

$$b_n=\frac{1}{n+1}\binom{2n}{n}\ \checkmark$$

数值核对：$b_0..b_7=1,1,2,5,14,42,132,429$ ✓（这就是 Catalan 数）。

(d) $b_n=\dfrac{4^n}{\sqrt{\pi}\,n^{3/2}}\big(1+O(1/n)\big)$

用 Stirling：$n!\sim\sqrt{2\pi n}\,(n/e)^n$。

$$b_n=\frac{(2n)!}{(n+1)!\,n!} \sim\frac{\sqrt{4\pi n}(2n/e)^{2n}}{(n+1)\cdot\sqrt{2\pi n}(n/e)^n\cdot\sqrt{2\pi n}(n/e)^n} =\frac{4^n}{(n+1)\sqrt{\pi n}}$$

再把 $\frac{1}{n+1}=\frac1n(1+O(1/n))$ 提出：

$$b_n=\frac{4^n}{\sqrt{\pi}\,n^{3/2}}\big(1+O(1/n)\big)\ \checkmark$$

数值核对（比值应趋于 1）：$n=10$ 时 0.898，$n=50$ 时 0.978，$n=100$ 时 0.989 ✓

顺带记一个结论：$b_n$ 增长得像 $4^n/n^{3/2}$，所以「随机形状的二叉树」的高度期望是 $\Theta(\sqrt n)$ （见 12.4-3 的注），比随机插入得到的 BST（$\Theta(\lg n)$）差得多。 这也是「随机插入」这个模型必须说清楚的原因。

13.1-2判断 · 简单（但容易答漏） 对教材图 13.1 的红黑树调用 TREE-INSERT 插入 36，画出结果。若插入的结点染红，结果还是红黑树吗？染黑呢？

落点：36 比 38 小，所以成为 38 的左孩子（38 是红结点）。

染红 → 不是红黑树。因为 36 红、父 38 也红，违反性质 4（红结点的孩子必须黑）。 此时其它性质都还成立，只有这一条坏了 —— 这正是 RB-INSERT-FIXUP 要修的东西。

染黑 → 也不是红黑树。因为经过 36 的路径（$36\to$NIL）上有 2 个黑（36 和 NIL）， 而 38 的右孩子是 NIL、路径上只有 1 个黑。两条路径黑高不等，违反性质 5。

结论：两种颜色都不行，必须先插入再调用 RB-INSERT-FIXUP。 这道题考的就是 §5.1 那个论点：染红只破坏性质 4（局部、可修），染黑破坏性质 5（全局、不可局部修）。
修正会怎么走：36 是「左孩子的左孩子」，属于外侧情形。若叔结点是黑 → 情况 3 （父 38 染黑、祖父染红、绕祖父右旋），36 保持红；若叔结点是红 → 情况 1（父、叔染黑，祖父染红，问题上移两层）。

13.1-3判断 · 简单 「松弛红黑树」= 只满足性质 1、3、4、5（根可以是红）的 BST。若它的根是红的，把根染黑，还是红黑树吗？

是。逐条检查：

  • 性质 1：颜色只是改了根，仍是红/黑之一 ✓
  • 性质 2：根现在是黑 ✓（这正是我们改的目的）
  • 性质 3：NIL 没动 ✓
  • 性质 4：根没有父结点，把它染黑不可能制造「红红」；它的孩子原来是黑（因为根原来是红，性质 4 要求孩子黑），现在也没变 ✓
  • 性质 5：路径上黑结点的分布只受「根以下的结点」影响，而根的兄弟路径不存在； 唯一变化是「根自己算不算黑」。按本节口径 $\mathrm{bh}(\text{根})$ 会 +1，但每条路径同时 +1，所以「相等」这个条件仍然成立 ✓

所以染黑之后是合法的红黑树。∎

顺带说明为什么性质 2 可以「可有可无」：根的颜色不影响任何路径之间的相对黑高， 它只影响「黑高的绝对值」。所以把根染黑只是为了让定义干净，不改变树的本质结构 —— 这也是为什么教材说「删掉性质 2 不影响渐近结论」。

13.1-4结构 · 中等 把红黑树里每个红结点「吸收」进它的黑父结点（红结点的孩子变成黑父的孩子）。吸收完之后，黑结点的度可能是多少？叶结点的深度如何？

度只能是 0、1、2、3、4。设某黑结点 $x$ 原来有 $b$ 个黑孩子（$b\in\{0,1,2\}$）、$r$ 个红孩子（$r\in\{0,1,2\}$，且 $b+r\le2$）。 每个红孩子吸收后贡献 2 个孩子，所以吸收后 $x$ 的度

$$\deg(x)=b+2r$$

枚举 $(b,r)$：$(0,0)\to0$，$(1,0)\to1$，$(2,0)\to2$，$(0,1)\to2$，$(1,1)\to3$，$(0,2)\to4$。所以 $\deg\in\{0,1,2,3,4\}$，五种都可能。

所有叶结点深度相同，都等于 $\mathrm{bh}(\text{根})-1$（按本节口径）。 因为吸收后，每一层恰好对应原树里的「一层黑结点」，而性质 5 保证任意路径上的黑结点数相同， 所以吸收后的树是等深的 —— 每个叶到根的距离都一样。

这道题想说的：红黑树其实是一棵 2-3-4 树的二叉树表示。 黑结点 = 2-3-4 树里的一个结点，红孩子 = 该结点里多出来的关键字。 度 2/3/4 分别对应 2-结点 / 3-结点 / 4-结点；「叶深度相同」就是 B 树的完美平衡性质。
所以红黑树的平衡性不是「凑出来的」，而是从 B 树继承来的。

13.1-5证明 · 简单（高频） 证明：红黑树中从某结点 $x$ 到其后代叶的所有简单路径中，最长的一条至多是最短的一条的 2 倍。

证明：设最短路径长 $s$、最长路径长 $\ell$（都按「边数」或「结点数」计，两边一致即可）。

  1. 由性质 5，所有路径上黑结点数相同，都等于 $\mathrm{bh}(x)$。
  2. 最短路径：全是黑结点（一个红都不出现），所以 $s\ge \mathrm{bh}(x)$（每条路径至少这么多黑）。
  3. 最长路径：由性质 4，红结点不能相邻，所以红结点最多和黑结点一样多，即红 $\le$ 黑。 于是 $\ell\le 2\,\mathrm{bh}(x)$。
  4. 合并：$\ell\le 2\,\mathrm{bh}(x)\le 2s$。∎
为什么这条结论这么重要：它是「高度 $h\le2\lg(n+1)$」的直观版本 —— 「最短路径」至少是 $\lg(n+1)$ 量级（因为黑高为 $k$ 至少有 $2^k-1$ 个结点），所以最长路径也就是 $2\lg$ 量级。 考试如果不想写完整归纳，写这个版本也能拿大部分分。

13.1-7构造 + 上界 · 难 $n$ 个关键字的红黑树，红内部结点数与黑内部结点数之比最大是多少？那棵树长什么样？

答案：比值上确界是 2，在 $n=4^k-1$ 时恰好取到 2；其它 $n$ 略小于 2。

上界证明（两句话）：

  1. 每个红结点都有黑父结点，而每个黑结点最多有 2 个红孩子，所以 $$\#\text{红}\le 2\times(\text{有孩子的黑结点数})\le 2\,\#\text{黑}$$
  2. 要取等号，必须「每个黑结点都恰有 2 个红孩子」，即黑结点全在偶数层、红结点全在奇数层， 且每个黑结点都有两个孩子 —— 这唯一确定了树形。

达到等号的构造：满二叉树，偶数层黑、奇数层红：

层颜色结点数累计 $n$
0黑11
1红23
2黑47
3红815
4黑1631
5红3263

$n=3$：黑 1、红 2 → 比值 2；$n=15$：黑 $1+4=5$、红 $2+8=10$ → 比值 2；$n=63$：黑 $1+4+16=21$、红 $2+8+32=42$ → 比值 2。

一般地 $n=4^k-1$ 时，黑 $=\frac{4^k-1}{3}$、红 $=\frac{2(4^k-1)}{3}$，比值恰好 2。

为什么其它 $n$ 达不到 2：因为「每个黑结点恰有 2 个红孩子」要求树是满的， 结点数只能是 $4^k-1$。少一个结点就必然出现「某个黑结点只有一个红孩子」或「某个红结点是叶子」， 比值就掉到 2 以下。但这不影响结论 —— 题目问的是「最大可能」，答 2 即可。

    x.right = y; y.p = x

写法要点：把 LEFT-ROTATE 里的 left 和 right 全部互换即可， 但注意「$y$ 是父的左孩子还是右孩子」这个判断也要跟着换（y == y.p.right）。

13.2-2计数 · 简单 证明：任何一棵 $n$ 个结点的 BST 中，恰有 $n-1$ 种可能的旋转。

证明：一次旋转需要「父结点 + 一个非空的孩子」，也就是一条父子边。 每条边恰好对应一次旋转（左孩子 → 右旋，右孩子 → 左旋），所以旋转的种类数 = 边数。

$n$ 个结点的树有 $n-1$ 条边（树的基本性质），故恰有 $n-1$ 种。∎

补充：「$n-1$ 种」指的是在某棵给定的树上能做的旋转位置数； 如果问「$n$ 个结点的 BST 一共有多少种不同的树形」，那是 12-4 的 Catalan 数。

13.2-3分析 · 中等 图 13-2 左边的树做左旋后，子树 $\alpha$、$\beta$、$\gamma$ 中任意结点 $a,b,c$ 的深度如何变化？

结点所在子树深度变化为什么
$a$$\alpha$（$x$ 的左子树）$+1$$\alpha$ 跟着 $x$ 一起下沉一层
$b$$\beta$（$y$ 的左子树）$0$从「$y$ 的左孩子」变成「$x$ 的右孩子」，$y$ 上移一层、$x$ 下沉一层，正好抵消
$c$$\gamma$（$y$ 的右子树）$-1$跟着 $y$ 一起上提一层

另外两个「特殊结点」：$x$ 的深度 $+1$，$y$ 的深度 $-1$。

记忆法：画一条竖线穿过 $x$ 和 $y$。左旋 = 把这条线「顺时针拧一下」： 左边的东西下沉，右边的东西上提，中间那棵 $\beta$ 原地不动。 这条「$\beta$ 不动」是检查旋转代码写没写错的最好方法。

13.2-4证明 · 中等偏难 证明：任何一棵 $n$ 个结点的 BST，都可以通过 $O(n)$ 次旋转变成任何另一棵 $n$ 个结点的 BST。

两步走：先把树「捋直」，再「搭」成目标形状。

第一步：$n-1$ 次右旋可以把任意 BST 变成一条「只有右孩子的链」。

做法：从根开始，反复对「有左孩子」的结点做右旋，直到根没有左孩子；然后递归处理右子树。 每次右旋都会让「左孩子的个数」减少 1，而左孩子总数 $\le n-1$，所以总共 $\le n-1$ 次。

（更直观的说法：中序序列是固定的，右斜链就是「按中序顺序一路往右挂」，所以任何 BST 都能拧成它。）

第二步：从右斜链出发，用 $\le n-1$ 次左旋搭出目标树。

把目标树按「自顶向下、先根后子树」的顺序构造：每次需要把某个结点「提上来」时，对它做左旋即可。 目标树有 $n-1$ 条边，每条边最多对应一次旋转，所以 $\le n-1$ 次。

合计：$\le 2(n-1)=O(n)$ 次旋转。∎

为什么这题值得做：它说明「旋转」这个操作的表达能力是完备的 —— 任意两棵同中序的 BST 之间都能互相到达，且代价只有 $O(n)$。 这也是「用旋转维护平衡」这类算法（AVL、伸展树、红黑树）能成立的理论基础。

13.3 插入

13.3-1说理 · 简单（高频） RB-INSERT 第 16 行把 $z$ 染红。若染黑，性质 4 就不会被破坏 —— 为什么不染黑？

因为染黑会破坏性质 5，而性质 5 是「修不了」的。

染成破坏哪条破坏的范围能不能修
红性质 4（若父也红）只在 $z$ 附近一条路径上能：染色 + 至多 2 次旋转
黑性质 5（经过 $z$ 的路径多一个黑）所有经过 $z$ 的路径，也就是整棵树的黑高关系不能：要么把所有路径都加一个黑（不可能），要么就得大改

更本质的说法：红结点不影响黑高，黑结点影响黑高。 插入一个红结点，只是「可能多出一处红红」，这是局部瑕疵；插入一个黑结点，是「全局黑高失衡」，没法局部补救。

13.3-4说理 · 中等 教授担心 RB-INSERT-FIXUP 会把 T.nil.color 设成 RED，导致 $z$ 为根时循环不终止。证明这个担心不必要。

核心：循环里被染色的三个结点，没有一个是 T.nil。

  1. $z.p$：循环条件是 z.p.color == RED，而 T.nil 永远是黑的， 所以能进循环就说明 $z.p\ne$ T.nil。✓
  2. $z.p.p$：它是 $z.p$ 的父结点。$z.p$ 不是 NIL 且有父（否则 $z.p$ 就是根， 而根是黑的，进不了循环），所以 $z.p.p$ 是真实结点。✓
  3. $y$（叔结点）：唯一可能是 NIL 的那个。但看代码，$y$ 只在 情况 1 里被染色，而情况 1 的条件是 y.color == RED —— T.nil 是黑的， 条件不成立，根本进不去。情况 2、3 里 $y$ 只被读、不被写。✓

另外，第 16 行的 z.color = RED 作用在刚创建的新结点上，也不是 NIL。

所以 T.nil.color 从头到尾都是 BLACK，教授的担心不成立。∎

这个细节为什么重要：哨兵 T.nil 被所有叶子共享，一旦它的颜色被改， 整棵树的黑高计算会同时错乱（所有叶子的颜色一起变），而且很难 debug。 这就是为什么代码里所有涉及 NIL 的地方都要特别小心（比如 RB-DELETE 里 x.p = y 那句）。

13.3-5证明 · 中等 用 RB-INSERT 插入 $n$ 个结点得到的红黑树，若 $n\gt1$，证明至少有一个红结点。

证明（盯住「最后插入的那个结点」）：设最后插入的是 $z_0$，它被染成红色。分两种情形：

  1. 循环一次都没执行（$z_0$ 的父是黑）：$z_0$ 仍是红色，且它不是根（$n\gt1$），所以树里有红结点 ✓
  2. 循环执行了：
    • 若以情况 1 结束（$z$ 上移后父为黑）：情况 1 把 $z$ 置为祖父，而祖父刚被染成红， 且它没有继续被改 → 树里有红结点 ✓
    • 若以情况 2/3 结束：情况 3 把 $z.p$ 染黑、$z.p.p$ 染红，而 $z$ 自己始终是红的 （代码从未改 $z$ 的颜色）→ 树里有红结点 ✓

最后一步 T.root.color = BLACK 只会把根染黑，不会把红结点变没（$n\gt1$ 时根不是唯一的红结点候选）。∎

换个说法更好记：RB-INSERT 从不「消灭」红色，它只把红色往下压或往上挪。 所以每插一个结点，红色只会变多不会变少。$n=1$ 是唯一的例外（单个根被强制染黑）。

13.3-6设计 · 中等偏难 若红黑树的结点不存父指针，如何高效实现 RB-INSERT？

思路：把「根到插入点的路径」显式存下来。

  1. 插入时用一个栈（或数组）记录从根一路走下来的所有结点，走到 NIL 时栈顶就是父结点。
  2. 修正时，$z.p$ = 栈顶、$z.p.p$ = 栈顶下面一个、叔结点 = 祖父的「另一个孩子」（由 $z.p$ 是左还是右孩子判断）。 这些都能 $O(1)$ 取到。
  3. 旋转时需要「$x$ 的父」，同样从栈里取。关键细节：旋转会改变路径上结点的父子关系， 所以旋转后要同步更新栈（把被提升的那个结点换到栈里对应位置）。

复杂度：栈的深度 $=O(\lg n)$，每次访问 $O(1)$，所以

  • 时间仍是 $O(\lg n)$（旋转次数不变）；
  • 额外空间 $O(\lg n)$（栈）。
另一种写法（更优雅）：用递归实现插入 —— 递归函数返回「新子树的根」， 于是「父」就是调用者手里的变量，天然不需要父指针。代价是 $O(\lg n)$ 的递归栈，本质和显式栈一样。
对比：存父指针 → 空间 $O(n)$、操作 $O(1)$ 取父；不存 → 空间 $O(\lg n)$（临时）、操作靠栈。 前者适合频繁修改，后者适合持久化/不可变的数据结构（函数式语言里常见）。
