### 第 83 页

**Definition:** Let $G = (V, \Sigma, R, S)$ be a grammar, and let $f : \Sigma^* \to \Sigma^*$ be a function.

- $G$ **computes** $f$, if for all $w, v \in \Sigma^*$, the following is true:

$$S w S \Rightarrow_G^* v \ \text{ iff } \ v = f(w).$$

- A function $f : \Sigma^* \to \Sigma^*$ is called **grammatically computable** iff there is a grammar $G$ that computes it.

**Theorem:** A function $f : \Sigma^* \to \Sigma^*$ is **recursive** iff and only if it is grammatically computable.

### 第 85 页

**Definition:**

- The **basic functions** are the following :

$(a)$ For any $k \ge 0$, the $k$**-ary zero function** is defined as

$$zero_k(n_1, \dots, n_k) = 0$$

for all $n_1, \dots, n_k \in \mathbb{N}$.

$(b)$ For $k \ge j > 0$, the $j$**th $k$-ary identity function** is simply the function

$$id_{k,j}(n_1, \dots, n_k) = n_j$$

for all $n_1, \dots, n_k \in \mathbb{N}$.

$(c)$ The **successor function** is defined as

$$succ(n) = n + 1$$

for all $n \in \mathbb{N}$.

### 第 86 页

**Definition**

- Two simple ways of combining functions to get slightly more complex functions.

$(1)$ For $k, l \ge 0$, let $g : \mathbb{N}^k \to \mathbb{N}$ be a $k$-ary function, let $h_1, \dots, h_k$ be $l$-ary functions. Then the **composition of $g$ with** $h_1, \dots, h_k$ is the $l$-ary function defined as

$$f(n_1, \dots, n_l) = g(h_1(n_1, \dots, n_l), \dots, h_k(n_1, \dots, n_l)).$$

$(2)$ For $k \ge 0$, let $g$ be a $k$-ary function, and let $h$ be a $(k+2)$-ary function. Then the **function defined by $g$ and $h$** is the $k+1$-ary function $f$ defined as

$$f(n_1, \dots, n_k, 0) = g(n_1, \dots, n_k)$$

$$f(n_1, \dots, n_k, m + 1) = h(n_1, \dots, n_k, m, f(n_1, \dots, n_k, m))$$

for all $n_1, \dots, n_k, m \in \mathbb{N}$.

### 第 87 页

**Definition:** (Continued)

### 第 88 页

**Example:** The following functions are primitive recursive.

$(1)$ $plus(m, n) = m + n$

$(2)$ $mult(m, n) = m \cdot n$

$(3)$ $exp(m, n) = m^n$

**Solution:**

$(1)$

$$plus(m, 0) = m$$
$$plus(m, n + 1) = succ(plus(m, n))$$

$(2)$

$$mult(m, 0) = zero(m)$$
$$mult(m, n + 1) = plus(m, mult(m, n))$$

$(3)$

$$exp(m, 0) = succ(zero(m))$$
$$exp(m, n + 1) = mult(m, exp(m, n)).$$

### 第 90 页

**Example:** Function

$$m \sim n = \max\{m - n, 0\}$$

is primitive recursive.

**Solution:** First define the <u>predecessor</u> function:

$$pred(0) = 0$$

$$m \sim 0 = m$$

### 第 92 页

**Remark:**

- The <u>negation</u> of any primitive recursive predicate is also a primitive recursive predicate.

（蓝框内）

$$p(m) \text{ is a primitive recursive predicate}$$
$$\neg p(m) = 1 \sim p(m)$$

- The **disjunction** and **conjunction** of two primitive recursive predicates are also primitive recursive.

（蓝框内）

$$p(m, n),\ q(m, n) \text{ are primitive recursive predicates}$$
$$p(m, n) \vee q(m, n) = 1 \sim iszero(p(m, n) + q(m, n))$$
$$p(m, n) \wedge q(m, n) = 1 \sim iszero(p(m, n) \cdot q(m, n))$$

$$f(n_1, \dots, n_k) = \begin{cases} g(n_1, \dots, n_k), & \text{if } p(n_1, \dots, n_k); \\ h(n_1, \dots, n_k), & \text{otherwise} \end{cases}$$

### 第 101 页

$\square$ **Minimization**

**Definition:** Let $g$ be a $(k + 1)$-ary function, for some $k \ge 0$.

- The **minimization** of $g$ is the $k$-ary function $f$ defined as follows:

$$f(n_1, \dots, n_k) = \begin{cases} \text{the least m such that } g(n_1, \dots, n_k, m) = 1 \\ \quad \text{if such m exists;} \\ 0 \quad \text{otherwise} \end{cases}$$

We shall denote the minimization of $g$ by

$$\mu\ m[g(n_1, \dots, n_k, m) = 1].$$

---

### 第 102 页

**Definition:** (Continued)

- Although the minimization of a function $g$ is always well-defined, there is no obvious method for computing it — even if we konw how to compute $g$. The obvious method

$$m := 0;$$
$$while\ g(n_1, \dots, n_k, m) \ne 1\ do\ m := m + 1;$$
$$output\ m$$

is **not** an algorithm, because it may fail to terminate.

（原文如此："konw" 为 know 的笔误。）

- A function $g$ is **minimalizable** if the above method always terminates. That is, a $(k + 1)$-ary function $g$ is minimalizable if it has the following properties:

For every $n_1, \dots, n_k \in \mathbb{N}$, $\exists m \in \mathbb{N}$ such that $g(n_1, \dots, n_k, m) = 1$.

---

### 第 103 页

**Definition:** (Continued)

- A function is $\mu$**-recursive** if it can be obtained from the basic functions by the operations of composition, recursive definition, and minimization of minimalizable functions.

**Remark:**

We cannot apply the diagonalization principle to show that there is a computable function that is not $\mu$-recursive.

— It is not clear at all whether all applications of minimization in the definition indeed acted upon minimalizable functions!

### 第 104 页

**Example:** Using minimization, we can define the $logarithm$ function:

$$\log(m, n) = \mu\ p[greater\text{-}than\text{-}or\text{-}equal((m + 2) \uparrow p, n + 1)].$$

- $\log(m, n) = \lceil \log_{(m+2)}(n + 1) \rceil$

— to avoid the mathematical pitfalls in the definition of $\log_m n$, when $m \le 1$ or $n = 0$.

- This is a proper definition of a $\mu$-recursive function, since the function $g(m, n, p) = greater\text{-}than\text{-}or\text{-}equal((m + 2) \uparrow p, n + 1)$ is minimalizable.

### 第 105 页

**Theorem:** A function $f : \mathbb{N}^k \to \mathbb{N}$ is $\mu$-recursive iff it is recursive (that is, computable by a TM).

**Proof:** $(\Rightarrow)$

If $f : \mathbb{N}^k \to \mathbb{N}$ is $\mu$-recursive.

$\Rightarrow$ $f$ is Turing Machine computable.

- $f$ is $\mu$-recursive, then it is defined from the basic functions by applications of composition, recursive definition, and minimization on minimalizable functions.

---

### 第 106 页

- The basic functions are recursive.
- The composition and the recursive definition of recursive functions and the minimization of minimalizable recursive functions are recursive.

$\Rightarrow$ all $\mu$-recursive functions are recursive.

**Remark:**

To prove the above results, we use the random access Turing machine(equivalence with standard TM).

### 第 108 页

- We will definite $f$ as a $\mu$-recursive function. Ultimately, $f$ will be defined as

$$f(n) = num(output(last(comp(n)))).$$

（原文如此："We will definite" 应为 define。）

— $num$ is a function that takes an integer whose base-$b$ representation is a string of 0's and 1's

— $output$ takes the integer representing in base $b$ a halted configuration of the form $\triangleright \sqcup hw$ and omits the first three symbols $\triangleright \sqcup h$.

— $comp(n)$ is the number whose representation in base $b$ is the juxt a position of the unique sequence of the configurations that starts with $\triangleright \sqcup sw$, where $w$ is the binary encoding of $n$, and ends with $\triangleright \sqcup hw'$, where $w'$ is the bianry encoding of $f(n)$; such sequence exists, since we assuming that $M$ computes a function $f$.

（原文如此："juxt a position"、"bianry"、"we assuming"。）

— $last$ takes an integer representing the juxtposition of configurations, and extracts the last configuration in the sequence.

### 第 109 页

- We have to define all these functions:

$$lastpos(n) = \mu\ m[equal(digit(m, n, b), \mathbb{E}(\triangleright)) \text{ or } equal(m, n)]$$

$$output(n) = rem(n, b \uparrow \log(b \sim 2, n \sim 1) \sim 2)$$

$$num(n) = digit(1, n, b) \cdot 2 + digit(2, n, b) \cdot 2 \uparrow 2 + \cdots$$
$$\qquad + digit(\log(b \sim 2, n \sim 1), n, b) \cdot 2 \uparrow \log(b \sim 2, n \sim 1)$$

$$comp(n) = \mu\ m[iscomp(m, n) \text{ and } halted(last(m))]$$

It follows that $f$ is indeed a $\mu$-recursive function.
