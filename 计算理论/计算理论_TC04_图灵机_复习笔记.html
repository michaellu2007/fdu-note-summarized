0. 这份材料是什么

这是 TC04.pdf（Elements of the Theory of Computation， Lewis & Papadimitriou, 2nd ed.，Chapter 4 Turing Machine，共 109 页）的 逐页转写稿。与第 2、3 章一样，页眉页脚已忽略，公式全部按原式重排为 LaTeX。

本章的位置：第 2 章用「有限状态」刻画正则语言，第 3 章「加一个栈」得到上下文无关语言。 本章把纸带的三条限制全部拆掉 —— 可写、可双向移动、长度无界 —— 得到的模型就是 图灵机（TM）。它不再只是「更强的自动机」，而是「可计算」这件事本身的定义： 此后所有「可计算 / 不可计算」的讨论都以 TM 为基准。

1. 本章主线：把纸带的三条限制全部拆掉

三个「拆限制」的动作，正好对应本章 4.3 的五个扩展：多带、双向无限带、多头、多维带、非确定性。 4.3 与 4.4 的全部工作就是在证明一句话 —— 这些扩展一个都不增强能力， 它们只是让「设计机器」变容易。这是本章最容易被误解的地方：扩展 ≠ 更强。

4. 三大核心证明的骨架

证明 A：$k$ 带 TM → 标准 TM（P43–P50）

一句话主轴：把 $k$ 条带「压」进一条带的 $2k$ 条 track 里 —— 上面 $k$ 条存符号， 下面 $k$ 条存「读写头在不在这格」的标记。
  1. 编码：原来第 $i$ 条带的第 $j$ 格符号，放到单带的第 $j$ 格的 track $i$； track $k+i$ 写 $1$ 表示第 $i$ 条带的头正在这一格，否则写 $0$。
  2. 模拟一步：扫一遍整条带，读出 $k$ 个头下的符号 → 查 $\delta$ 得到新状态与 $k$ 个动作 → 再扫一遍，改符号、把头标记左右挪一格。
  3. 代价：一次扫描 $\mathcal{O}(|x|+t)$（带子最多长到 $|x|+t$），共 $t$ 步 ⇒ 总计 $\mathcal{O}(t(|x|+t))$。这也是定理里那句复杂度的来源。

证明 B：NTM → 标准 TM（P61–P71）

一句话主轴：NTM 的计算是一棵树，标准 TM 用广度优先逐个遍历这棵树上的格局。
  1. 为什么必须广度优先：如果深度优先，一旦钻进一条永不停止的分支， 就永远回不来，可能错过旁边那条本来能停机的路径 —— 而 NTM 的语义是 「存在一条停机路径即接受」。
  2. 怎么实现：在带上维护一个「待探索格局的队列」，每次取出队首格局， 枚举它所有一步后继，把它们追加到队尾。
  3. 结论：若 NTM 在 $t$ 步内接受，标准 TM 只需有限（但指数级）步就能找到那条路径。 能力相同，代价不同 —— 这是后面讲复杂度时「P vs NP」的源头。

证明 C：无限制文法 ⇔ r.e.（P76–P82）

一句话主轴：文法「生成」与机器「识别」是同一件事的两种写法 —— 正方向用机器猜一条推导并验证，反方向用文法模拟机器的格局演化。
  1. Grammar ⇒ r.e.：给定 $w$，非确定地猜一个推导序列，每猜一步就检查这条规则是否合法、 当前串是否还能走到 $w$。猜对了就停机接受。
  2. r.e. ⇒ Grammar：构造文法，使得「$S\Rightarrow^* uv$」恰好对应「TM 的格局从 $uqv$ 走到终态」。用非终结符编码状态与相邻符号，规则就是 $\delta$ 的逐条翻译。
  3. 为什么重要：这条等价把「乔姆斯基层级」的第 0 层（无限制文法）与 「图灵机」钉死在一起 —— 于是「语言」和「计算」两条线在本章合流。

6. 易错点

  1. $\delta$ 的定义域是 $K-H$，不是 $K$。停机状态没有转移 —— 写成 $\delta:K\times\Sigma\to\cdots$ 是错的。
  2. 格局的第二项从 $\triangleright$ 开始。是 $\triangleright\Sigma^*$， 不是 $\Sigma^*$；左端标记永远算在「已读部分」里。
  3. 格局第三项不能以 $\sqcup$ 结尾。定义里是 $\Sigma^*(\Sigma-\{\sqcup\})\cup\{e\}$， 即「去掉尾部所有空白」，所以同一纸带状态的表示是唯一的。
  4. $\sqcup$ 与 $e$ 不是一回事。$\sqcup$ 是纸带上的空白符号（占一格）， $e$ 是空串（不占格）。格局第三项写成 $e$ 表示「头右边全是空白」。
  5. decide 与 semidecide 别混。decide 要求处处停机且答对； semidecide 只要求「$w\in L$ 时停机」。把 semidecide 当成 decide 是本章最常见的错误。
  6. 「扩展不增强能力」是结论，不是假设。4.3、4.4 每一节都在给构造性证明 （track 编码、广度优先搜索），不能只写一句「显然等价」。
  7. NTM 的接受是「存在」语义。只要有一条计算路径停机接受就算接受， 所以模拟时必须广度优先，深度优先会漏。
  8. 原始递归 ≠ 可计算。原始递归函数是真子集（P100 的 $g(n)=f_n(n)+1$ 对角线论证）， 加上最小化才得到 $\mu$-递归 = TM 可计算。

第 6 页

Definition: A Turing Machine is a quintuple $(K, \Sigma, \delta, s, H)$, where

  • $K$ is a finite set of states
  • $\Sigma$ is an alphabet
  • containing $\sqcup$ (blank symbol) and $\triangleright$ (left end)
  • not containing the symbols $\leftarrow$ and $\rightarrow$
  • $s \in K$ is the initial state
  • $H \subseteq K$ is the set of halting states
  • $\delta: (K - H) \times \Sigma \to K \times (\Sigma \cup \{\leftarrow, \rightarrow\})$ be the transition function
  • a) $\forall q \in K - H$ if $\delta(q, \triangleright) = (p, b)$, then $b \,=\, \rightarrow$.
  • b) $\forall q \in K - H$ and $a \in \Sigma$, if $\delta(q, a) = (p, b)$, then $b \neq \triangleright$.

（说明：a) 规定在左端标记处只能右移；b) 规定不能把 $\triangleright$ 写到纸带上。）

Definition: Let $M = (K, \Sigma, \delta, s, H)$ be a TM and consider two configurations of $M$ $(q_1, w_1\underline{a_1}u_1)$ and $(q_2, w_2\underline{a_2}u_2)$ where $a_1, a_2 \in \Sigma$. Then

How TMs are Used (Deciding Languages)

Question: As language recognizers or decision procedures i.e., to answer questions of the form: is $w \in L$?

Convention:

If $M = (K, \Sigma, \delta, s, H)$ is a TM and $w \in (\Sigma - \{\sqcup, \triangleright\})^*$, then the initial configuration of $M$ on input $w$ is $(s, \triangleright\sqcup w)$.

（图：纸带 $\triangleright \mid \sqcup \mid$（$w$ 占据其后各格）$\mid \sqcup \mid \sqcup \cdots$；箭头标 Tape head 指向 $\sqcup$ 之后 $w$ 的第一格。右侧注：($w$ must not contain blanks)）

第 22 页

Definition: Let $M = (K, \Sigma, \delta, s, H)$ is a TM.（原文如此）

  • $H = \{y, n\}$ consists of two distinguished halting states($y$ — "yes" and $n$ — "no").

  • Any halting configuration whose state component is $y$ — accepting configuration;

  • Any halting configuration whose state component is $n$ — rejecting configuration.

第 23 页

Definition: (continued)

  • $M$ accepts $w \in (\Sigma - \{\sqcup, \triangleright\})^*$ if $(s, \triangleright\sqcup w)$ yields an accepting configuration; $M$ rejects $w$ if $(s, \triangleright\sqcup w)$ yields an rejecting configuration.

  • Let $\Sigma_0 \subseteq (\Sigma - \{\sqcup, \triangleright\})$ be a alphabet — input alphabet of $M$.

$M$ decides $L \subseteq \Sigma_0^*$ if $\forall w \in \Sigma_0^*$ the following is true:

  • $w \in L$ iff $M$ accepts $w$;

  • $w \notin L$ iff $M$ rejects $w$.

  • A language $L$ is recursive if $\exists$ a TM that decides $L$.

How TMs are Used (Computing Functions)

TMs are often used to compute functions.

Definition: Let $M = (K, \Sigma, \delta, s, H)$ is a TM. Let $\Sigma_0 \subseteq \Sigma - \{\triangleright, \sqcup\}$ be an alphabet and $w \in \Sigma_0^*$.

Some Properties

Theorem: The complement of a recursive language is recursive.

  • Given $M$ that halts on all inputs, construct $M'$ that simulates $M$.
  • If $M$ halts and accepts, $M'$ halts and does not accept
  • If $M$ halts and does not accept, $M$ halts and accepts
  • Let $M = (K,\Sigma,\delta,s,\{y,n\})$ and $L$ is decided by $M$. $\Rightarrow M' = (K,\Sigma,\delta',s,\{y,n\})$ decides $\Sigma^* - L$. $$\delta'(q,a) = \begin{cases} n & \text{if } \delta(q,a) = y \\ y & \text{if } \delta(q,a) = n \\ \delta(q,a) & \text{otherwise.} \end{cases}$$

第 36 页

Theorem: If $L$ is a recursive language, then it is recursively enumerable.

Let $M = (K,\Sigma,\delta,s,\{y,n\})$ and $L$ is decided by $M$. $\Rightarrow$ Construct $M' = (K,\Sigma,\delta',s,\{y\})$ semidecides $L$. $$\delta'(q,a) = \begin{cases} (n,a) & \text{if } q = n \\ \delta(q,a) & \text{otherwise.} \end{cases}$$

Theorem: The union/intersection of two recursive languages is recursive.

(until $M$ would halt, if it would halt)

4.4 Nondeterministic Turing Machines

Definition: A nondeterministic Turing Machine(NTM) is a quintuple $M = (K,\Sigma,\Delta,s,H)$, where $K,\Sigma$ and $H$ are as for standard TMs, and $\Delta$ is a subset of $$((K - H) \times \Sigma) \times (K \times (\Sigma \cup \{\leftarrow,\rightarrow\})).$$

  • Like TMs, but is now a relation rather than a function.

  • Configurations and the relations $\vdash_M$ and $\vdash_M^*$ are defined in the similar way in standard TM.

  • $\vdash_M$ need not be single-valued.

第 56 页

Definition: Let $M = (K, \Sigma, \Delta, s, H)$ is a NTM.（原文如此）

  • $M$ accepts an input $w \in (\Sigma - \{\triangleright, \sqcup\})^*$ if $(s, \triangleright\sqcup w) \vdash_M^* (h, uav)$ for some $h \in H$ and $a \in \Sigma$, $u, v \in \Sigma^*$.
  • $M$ semidecides a language $L \subseteq (\Sigma - \{\triangleright, \sqcup\})^*$ if the following holds for all $w \in (\Sigma - \{\triangleright, \sqcup\})^*$: $$w \in L \text{ if and only if } M \text{ accepts } w.$$

Remark:

NTM $M$ accepts an input $w$:

  • as long as at least one halting computation exists.

第 57 页

Definition: Let $M = (K, \Sigma, \Delta, s, \{y, n\})$ be a NTM.

  • $M$ decides a language $L \subseteq (\Sigma - \{\triangleright, \sqcup\})^*$ if the following two conditions hold for all $w \in (\Sigma - \{\triangleright, \sqcup\})^*$:

$(a)$ $\exists N(M, w) \in \mathbb{N}$ such that there is no configuration $C$ satisfying $(s, \triangleright\sqcup w) \vdash_M^N C$.

$(b)$ $w \in L$ iff $(s, \triangleright\sqcup w) \vdash_M^* (y, uav)$ for $a \in \Sigma$, and $u, v \in \Sigma^*$.

  • $M$ computes a function $f : (\Sigma - \{\triangleright, \sqcup\})^* \to (\Sigma - \{\triangleright, \sqcup\})^*$ if the following two conditions hold for all $w \in (\Sigma - \{\triangleright, \sqcup\})^*$:

$(a)$ $\exists N(M, w) \in \mathbb{N}$ such that there is no configuration $C$ satisfying $(s, \triangleright\sqcup w) \vdash_M^N C$.

$(b)$ $(s, \triangleright\sqcup w) \vdash_M^* (h, uav)$ iff $ua = \triangleright\sqcup$ and $v = f(w)$.

4.5 Grammars

  • Consider language generator: regular expression, context-free grammar, $\cdots$

  • Like context-free grammars, except that if $u \to v$ is a rule, then $u$ may be any string containing a nonterminal.

  • So the rule $AXY \to AYX$ where $A, X, Y \in V - \Sigma$, "means" that the two-symbol substring $XY$ can be replaced by $YX$ whenever it appears with an $A$ to its left.

第 73 页

Definition: A grammar (or unrestricted grammar) is a quadruple $G = (V, \Sigma, R, S)$, where

  • $V$ is an alphabet;
  • $\Sigma \subseteq V$ is the set of terminal symbols, and $V - \Sigma$ is called the set of nonterminal symbols;
  • $S \in V - \Sigma$ is the start symbol; and

  • $R$ is the set of rules, a finite subset of $(V^*(V - \Sigma)V^*) \times V^*$.

  • $u \to_G v \iff (u, v) \in R$.

  • $u \Rightarrow_G v \iff \exists w_1, w_2 \in V^*$, and some rule $u' \to_G v'$ such that $u = w_1 u' w_2$, $v = w_1 v' w_2$.

第 74 页

  • $\Rightarrow_G^*$ is the reflexive, transitive closure of $\Rightarrow_G$.

  • The language generated by $G$, $$L(G) = \{w \in \Sigma^* : S \Rightarrow_G^* w\}.$$

  • $w_0 \Rightarrow_G w_1 \Rightarrow_G \cdots \Rightarrow_G w_n$ — a derivation in $G$ of $w_n$ from $w_0$. $n$ be the length of the derivation.

Remark:

Any context-free grammar is a grammar.

  • $R = \{S \to ABCS,\ S \to T_c$

(Thus $S \Rightarrow (ABC)^n T_c$, for any $n \ge 0$).

$BA \to AB,\ CA \to AC,\ CB \to BC$

$$f(n_1, \dots, n_k, 0) = g(n_1, \dots, n_k)$$

$$f(n_1, \dots, n_k, m + 1) = h(n_1, \dots, n_k, m, f(n_1, \dots, n_k, m))$$

for all $n_1, \dots, n_k, m \in \mathbb{N}$.

第 101 页

$\square$ Minimization

Definition: Let $g$ be a $(k + 1)$-ary function, for some $k \ge 0$.

  • The minimization of $g$ is the $k$-ary function $f$ defined as follows:

$$f(n_1, \dots, n_k) = \begin{cases} \text{the least m such that } g(n_1, \dots, n_k, m) = 1 \\ \quad \text{if such m exists;} \\ 0 \quad \text{otherwise} \end{cases}$$

We shall denote the minimization of $g$ by

$$\mu\ m[g(n_1, \dots, n_k, m) = 1].$$

第 102 页

Definition: (Continued)

  • Although the minimization of a function $g$ is always well-defined, there is no obvious method for computing it — even if we konw how to compute $g$. The obvious method

$$m := 0;$$ $$while\ g(n_1, \dots, n_k, m) \ne 1\ do\ m := m + 1;$$ $$output\ m$$

is not an algorithm, because it may fail to terminate.

（原文如此："konw" 为 know 的笔误。）

  • A function $g$ is minimalizable if the above method always terminates. That is, a $(k + 1)$-ary function $g$ is minimalizable if it has the following properties:

For every $n_1, \dots, n_k \in \mathbb{N}$, $\exists m \in \mathbb{N}$ such that $g(n_1, \dots, n_k, m) = 1$.

第 103 页

Definition: (Continued)

  • A function is $\mu$-recursive if it can be obtained from the basic functions by the operations of composition, recursive definition, and minimization of minimalizable functions.

Remark:

We cannot apply the diagonalization principle to show that there is a computable function that is not $\mu$-recursive.

— It is not clear at all whether all applications of minimization in the definition indeed acted upon minimalizable functions!

第 104 页

$$\log(m, n) = \mu\ p[greater\text{-}than\text{-}or\text{-}equal((m + 2) \uparrow p, n + 1)].$$

  • $\log(m, n) = \lceil \log_{(m+2)}(n + 1) \rceil$

— to avoid the mathematical pitfalls in the definition of $\log_m n$, when $m \le 1$ or $n = 0$.

  • This is a proper definition of a $\mu$-recursive function, since the function $g(m, n, p) = greater\text{-}than\text{-}or\text{-}equal((m + 2) \uparrow p, n + 1)$ is minimalizable.
