2. 五种模型的核心定义对照

模型形式定义转移的“形状”一句话理解
DFA
确定性有限自动机		 $(K,\Sigma,\delta,s,F)$ $\delta:K\times\Sigma\to K$（函数） 每个状态、每个符号，下一状态唯一确定。
NFA
非确定性有限自动机		 $(K,\Sigma,\Delta,s,F)$ $\Delta\subseteq K\times(\Sigma\cup\{e\})\times K$（关系） 允许“猜”，允许不读输入就跳（$e$-转移）。
正则表达式
语言的生成式描述		 由 $\emptyset$、$\{a\}$ 经 $\cup,\circ,{}^*$ 生成 — 用“并 / 连接 / 星号”三种运算写出的表达式。
PDA
下推自动机		 $(K,\Sigma,\Gamma,\Delta,s,F)$ $\Delta\subseteq(K\times(\Sigma\cup\{e\})\times\Gamma^*)\times(K\times\Gamma^*)$ 有限状态 + 一个栈（LIFO），因此能“记住”嵌套结构。
CFG
上下文无关文法		 $(V,\Sigma,R,S)$ $R\subseteq(V-\Sigma)\times V^*$ 每条规则左部都是单个非终结符，与上下文无关。
关键直觉：FA 的全部“记忆”就是当前状态，所以只能记住有限多种情况； 一旦需要记住任意深度的嵌套（如配平括号 $a^nb^n$），FA 就不够用了。 PDA 加了栈，于是能处理嵌套；但栈只有一个、且是后进先出，所以又出现了 $a^nb^nc^n$ 这种“需要两个计数器”的语言——它连 CFL 都不是。

第 2 章

7FA 就是算法 DFA 判定 $w\in L$ 用 $\mathcal{O}(|w|)$；NFA 用 $\mathcal{O}(|K|^2|w|)$。 P94

#结论要点 / 代价页码
1所有正则语言都是 CFL 两条路：PDA 泛化 FA（栈不用）；或直接由 DFA 造文法 $q\to ap\ (\delta(q,a)=p)$、$q\to e\ (q\in F)$。 P13–P16
2分析树 = 推导的等价类 $A\Rightarrow^*w$ ⟺ 存在以 $A$ 为根、产出 $w$ 的分析树 ⟺ 存在最左推导 ⟺ 存在最右推导。 P24
3PDA 与 CFG 等价 CFG→PDA：用栈模拟最左推导（2 个状态即可）； PDA→CFG：先规约到 simple PDA（$\beta\in\Gamma,|\gamma|\le2$）， 再用非终结符 $\langle q,A,p\rangle$ 编码“从 $q$ 弹出 $A$ 到 $p$”。 P38–P57
4CFL 封闭于并、连接、Kleene 星 文法层面加规则：$S\to S_1\mid S_2$、$S\to S_1S_2$、$S\to e\mid SS_1$。 P58–P60
5CFL 与正则语言的交仍是 CFL PDA 与 DFA 并行模拟：状态取乘积 $K=K_1\times K_2$。 P61–P62

8CNF + 动态规划判成员 任何 CFG 可多项式时间转 CNF（去长规则 / $e$-规则 / 短规则）； 再用 $N[i,i+s]$ 自底向上填表，即 CYK 思想。 P77–P89

4. 易错点与考点提醒

  1. “空串”写作 $e$ 而不是 $\varepsilon$。读课件时别把它当成某个字母 $e$； 例如 $q_0\xrightarrow{e}q_1$ 是空转移。
  2. NFA 的 $\Delta$ 是关系不是函数。$\delta(q_0,b)=\emptyset$ 与“未定义”是两回事， 空集本身也是子集构造里的合法状态。
  3. 子集构造要算 $e$-闭包 $E(q)$。初始状态是 $E(s)$ 而不是 $\{s\}$； $\delta(Q,a)=\bigcup\{E(p):(q,a,p)\in\Delta,\ q\in Q\}$。
  4. 补运算必须用在 DFA 上。NFA 不能简单地“把终态取反”——那会把“存在一条接受路径”变成“不存在接受路径”， 语义完全变了。
  5. 证明非正则 / 非 CFL 的套路。先假设是，拿到常数 $n$（或 $\phi(G)^{|V-\Sigma|}$）， 再精心挑选一个长串，最后分情况讨论 $v,y$（或 $y$）的落点造矛盾。 注意泵引理只是必要条件，不能用来证明语言是正则的。
  6. CFL 与正则语言求交是安全的，求并/连接/星号也安全；但求交、求补对两个 CFL 不封闭。 很多“证明某语言是 CFL”的题就靠“CFL ∩ 正则”这条。
  7. CNF 表达力的缺口。转 CNF 后会丢掉长度 < 2 的串，定理写的是 $L(G')=L(G)-(\Sigma\cup\{e\})$，别记成完全相等。
  8. 单字母表上的 CFL 一定是正则的（P72 的 Remark），这是一个常考的“意外”结论。

2.1 Deterministic Finite Automata

Introduction to DFA

（示意图描述）

  • Input tape（输入带）：一行方格，内容为 $a\ b\ b\ a\ b\ a$。
  • Reading head（读头）：moves left to right, one square at a time（从左向右、每次移动一格）。
  • Finite-state control（有限状态控制器）：一个方框内含有 4 个状态 $\{1,2,3,4\}$：
  • 状态 $1$：Start state（初态，用指向它的箭头表示）。
  • 状态 $2$、$4$：Double-circled states are accepting or final（双圈表示接受态/终态）。
  • 状态 $3$：普通状态。
  • Finite-state control changes state depending on:
  • current state
  • next symbol

第 4 页

Definition: A deterministic finite automata(DFA) is a quintuple $(K,\Sigma,\delta,s,F)$, where

  • $K$ is a finite set of states
  • $\Sigma$ is an alphabet
  • $s \in K$ is the initial state
  • $F \subseteq K$ is the set of final states
  • $\delta$: transition function, $K \times \Sigma \to K$.

Remarks: Transition function will determine unique next state based on current input and state.

第 5 页

Remark:

1) A configuration of a DFA $(K,\Sigma,\delta,s,F)$ is any element of $K \times \Sigma^*$.

2) The binary relation $\vdash_M$ between two configurations of $M$:

$$(q,w) \vdash_M (q',w') \Leftrightarrow \exists a \in \Sigma,\ w = aw',\ \text{and}\ \delta(q,a) = q'.$$

— say $(q,w)$ yields $(q',w')$ in one step.

第 6 页

3) The reflexive, transitive closure of $\vdash_M$, denoted as $\vdash_M^*$: $(q,w) \vdash_M^* (q',w') \Leftrightarrow (q,w)$ yields $(q',w')$ after some number, possibly zero, of steps.

4) A string $w \in \Sigma^*$ is said to be accepted by $M$ iff there is a state $q \in F$ such that $(s,w) \vdash_M^* (q,e)$. The language accepted by $M$, $L(M)$ is the set of all strings accepted by $M$.

第 7 页

Example: $\Sigma = \{a,b\}$

$$K = \{q_0,q_1\}$$ $$s = q_0$$ $$F = \{q_0\}$$ Transition function

Definition: A nondeterministic finite automata(NFA) is a quintuple $(K,\Sigma,\Delta,s,F)$, where

  • $K$ is a finite set of states
  • $\Sigma$ is an alphabet
  • $s \in K$ is the initial state
  • $F \subseteq K$ is the set of final states
  • $\Delta$, transition relation, is a subset of $K \times (\Sigma \cup \{e\}) \times K$.

Remark: For DFA, the transition function $\delta$ is a function, but for NFA, $\Delta$ only a relation.

第 15 页

  • triple $(q,u,p) \in \Delta$ — transition of $M$:
  • $u \neq e$

  • $u = e$: no input symbol

  • configuration — an element of $K \times \Sigma^*$.

  • binary relation $\vdash_M$ and its reflexive transitive closure $\vdash_M^*$.

  • A string $w \in \Sigma^*$ is accepted by $M$ iff there is a state $q \in F$ such that $(s,w) \vdash_M^* (q,e)$. The language accepted by $M$, $L(M)$ is the set of all strings accepted by $M$.

NFA/DFA Equivalence

Definition: Two FA $M_1$ and $M_2$ (deterministic or non deterministic) are equivalent iff $L(M_1) = L(M_2)$.

  • To prove equivalence of DFAs and NFAs we must do two things:

I: For each DFA, produce an NFA that accepts the same language

II: For each NFA, produce a DFA that accepts the same language

We'll do part II; part I is immediate.

Theorem: For each NFA, there is an equivalent DFA.

Proof:

Key idea: Every subset of $K$ becomes a single state in our new machine!

$$(q, w) \vdash_M^* (p, e) \iff (E(q), w) \vdash_{M'}^* (P, e)$$

$$w \in L(M) \iff (s, w) \vdash_M^* (f, e) \text{ for some } f \in F \quad \text{[definition]}$$ $$\iff (E(s), w) \vdash_{M'}^* (Q, e) \text{ for some } f \in Q \quad \text{[claim]}$$ $$\iff (s', w) \vdash_{M'}^* (Q, e) \text{ with } Q \in F'$$ $$\iff w \in L(M')$$

From the claim, $M'$ is equivalent to $M$.

第 58 页

Theorem: (Pumping Theorem) Let $L$ be a regular language. $\exists$ an integer $n \geq 1$ such that any string $w \in L$ with $|w| \geq n$ can be written as $w = xyz$ such that

  • $y \neq e$
  • $|xy| \leq n$
  • for each $i \geq 0 \;\; xy^i z \in L$

第 59 页

Proof:

Let $L$ be a regular language, accepted by a DFA $M$ with $n$ states, and string $w$, $|w| \geq n$.

$$(q_0, a_1 \cdots a_n) \vdash_M (q_1, a_2 \cdots a_n) \vdash_M \cdots \vdash_M (q_n, e)$$

红框：Pigeonhole Principle

$\Rightarrow \exists i, j,\ 0 \leq i < j \leq n$, such that $q_i = q_j$

Let $y = a_i \cdots a_j$, $x = a_1 \cdots a_{i-1}$, $z = a_{j+1} \cdots a_m$.

第 60 页

Example: Show $L = \{\,a^i b^i \mid i \geq 0\,\}$ is not regular.

Proof:

Assume $L$ regular. By Pumping Theorem, $\exists$ integer $n$. Consider the string $w = a^n b^n \in L$.

It can be written as $w = xyz$ such that

  • $|xy| \leq n$
  • $y \neq e$

$\Rightarrow y = a^i$ for some $i > 0$

But $xz = a^{\,n-i}\,b^n \notin L$

红框：contradiction!!

  • There is some $n$, by the pumping lemma
  • Choose a string $s$, longer than $n$ symbols, in the language $L$
  • Using the pumping lemma, construct a new string $s'$ that is not in the language

第 5 页

Definition: A context-free grammar(CFG) is a quadruple $G = (V, \Sigma, R, S)$, where

  • $V$ is an alphabet;
  • $\Sigma \subseteq V$ is the set of terminal symbols;（slide 中 "terminal" 带下划线）
  • $S \in V - \Sigma$ is the start symbol;（slide 中 "start" 带下划线）and
  • $R$ is the set of rules,（slide 中 "rules" 带下划线）a finite subset of $(V - \Sigma) \times V^*$.

Remark:

  • The member of $V - \Sigma$ are called nonterminals. For any $A \in V - \Sigma$ and $u \in V^*$, $$A \to_G u \iff (A, u) \in R.$$

第 6 页

  • For any strings $u, v \in V^*$, $$u \Rightarrow_G v \iff \exists x, y \in V^*,\ \text{and } A \in V - \Sigma,\ \text{such that } u = xAy,\ v = xv'y,\ \text{and } A \to_G v'.$$

  • $\Rightarrow_G^*$ is the reflexive, transitive closure of $\Rightarrow_G$.

  • $w_0 \Rightarrow_G w_1 \Rightarrow_G \cdots \Rightarrow_G w_n$ — a derivation in $G$ of $w_n$ from $w_0$. $n$ be the length of the derivation.

  • The language generated by $G$, $$L(G) = \{w \in \Sigma^* : S \Rightarrow_G^* w\}.$$

$L$ is a context-free language(CFL) $\iff \exists$ a context-free grammar(CFG) $G$, such that $L = L(G)$.

□ Derivations D and D' are similar: formal definition

Let $G = (V, \Sigma, R, S)$ be a CFG,

$$D = x_1 \Rightarrow x_2 \Rightarrow \cdots \Rightarrow x_n$$ $$D' = x_1' \Rightarrow x_2' \Rightarrow \cdots \Rightarrow x_n'$$

be two derivations, where $x_i, x_i' \in V^*$ for $i = 1 \cdots n$, $x_1, x_1' \in V - \Sigma$, and $x_n, x_n' \in \Sigma^*$.

1) $D$ precedes $D'$ ($D \prec D'$) $\iff \exists\, 1 < k < n$, such that

  • for all $i \ne k$, we have $x_i = x_i'$.
  • $x_{k-1} = x_{k-1}' = uAvBw$, where $u, v, w \in V^*$, and $A, B \in V - \Sigma$.

第 23 页

  • $x_k' = uAvzw$, where $B \to z \in R$.
  • $x_{k+1} = x_{k+1}' = uyvzw$.

2) $D$ and $D'$ are similar $\iff (D, D')$, belong in the reflexive, symmetric, transitive closure of $\prec$.

结构示意（文字描述）：

第 29 页

Definition: A pushdown automata (PDA) is a sextuple $M = (K, \Sigma, \Gamma, \Delta, s, F)$, where

  • $\Gamma$ is an alphabet (the stack symbols)

Definition of Simple PDA

A PDA is simple if the following is true: Whenever $((q,a,\beta),(p,\gamma))$ is a transition of the PDA and $q$ is not the start state, then $\beta\in\Gamma$ and $|\gamma|\le 2$.

In other words, A simple PDA always

  • consults its topmost stack symbol, and
  • replace it either $e$, or with single stack symbol, or with two stack symbols.

  • the transition $((s',e,e),(s,Z))$ (start transition)
  • for each $f\in F$, $((f,e,Z),(f',e))$ (final transition)
  • all transition of $\Delta$ — replace with equivalent transitions that satisfy the simplicity condition.

Definition: A grammar is in Chomsky normal form(CNF) iff $$R \subseteq (V - \Sigma) \times V^2.$$

Remark:

Theorem: For any CFG $G$ there is a CFG $G'$ in CNF such that $L(G') = L(G) - (\Sigma \cup \{e\})$. Furthermore, the construction of $G'$ can be carried out in time polynomial in size of $G$.

Proof: We shall show how to transform any given CFG $G = (V, \Sigma, R, S)$ into CNF.

We eliminate the following in order:

  1. Long rules: of the form $A \to \alpha$ where $|\alpha| > 2$
  2. e-rules: of the form $A \to e$
  3. Short rules: of the form $A \to a$ or $A \to B$

第 80 页

$\square$ Transforming a CFG into CNF

Step 1: Chop up all long rules

Let $A \to B_1 B_2 \cdots B_n \in R$, where $B_1, \cdots B_n \in V$ and $n \ge 3$. Replace this rules with $n - 1$ new rules, namely: $$A \to B_1 A_1,$$ $$A_1 \to B_2 A_2,$$ $$\cdots$$ $$A_{n-2} \to B_{n-1} B_{n-2}.$$ where $A_1, \cdots , A_n$ are newly introduced nonterminals.

第 81 页

Step 2: To eliminate $e$-rules

a. Determine the set of erasable nonterminals $$\mathcal{E} = \{A \in V - \Sigma : A \Rightarrow^* e\}$$ — is the set of all nonterminals that may drive the empty string.

Algorithm: Computing the set of erasable nonterminals

$\mathcal{E} := \emptyset$ While there is a rule $A \Rightarrow \alpha$ with $\alpha \in \mathcal{E}^*$ and $A \notin \mathcal{E}$ do     add $A$ to $\mathcal{E}$

第 82 页

b. For each rule of form $A \to BC$ or $A \to CB$ with $B \in \mathcal{E}$ and $C \in V$, we add the rule $A \to C$.

e.g. $$A \to BC \quad \Rightarrow \quad A \to BC$$ $$B \in \mathcal{E} \text{ and } C \in V. \qquad\quad A \to C$$

c. Eliminate all $e$-rules.

Remark: Any derivation in the oringinal grammar can be simulated in the new, and vice versa — with one exception: $e$ can not be derived in the language any longer. (Since we may have omitted the $S \to e$ in this process.)

第 83 页

For each $A \in V$ we compute by a simple closure algorithm, the set $\mathcal{D}(A)$ of symbols that can de derived from $A$ in grammar, $\mathcal{D}(A) = \{B \in V : A \Rightarrow^* B\}$

$\mathcal{D}(A) := \{A\}$ While there is a rule $B \to C$ with $B \in \mathcal{D}(A)$ and $C \notin \mathcal{D}(A)$ do     add $C$ to $\mathcal{D}(A)$

  • If $a$ be a terminal, then $\mathcal{D}(a) = \{a\}$.
