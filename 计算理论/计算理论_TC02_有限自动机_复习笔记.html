核心定义速查

对象形式定义一句话
DFA$M=(K,\Sigma,\delta,s,F)$ $\delta:K\times\Sigma\to K$ 是函数，下一状态唯一确定。
NFA$M=(K,\Sigma,\Delta,s,F)$ $\Delta\subseteq K\times(\Sigma\cup\{e\})\times K$ 是关系，可以「猜」。
子集构造$K'=2^K$ 把 $K$ 的每个子集当新状态；初态 $E(s)$，终态 $\{Q: Q\cap F\neq\emptyset\}$。
正则表达式由 $\emptyset,\{a\}$ 经 $\cup,\circ,{}^*$ 生成 正则语言 = 含平凡语言、且对三种运算封闭的最小语言类。
泵引理$w=xyz,\ y\neq e,\ |xy|\le n,\ xy^iz\in L$ 长串中有一段「可任意重复」的短片段。
Myhill-Nerode$\approx_L$ 等价类 最小 DFA 状态数 = 等价类个数。

易错点

  1. 空串写作 $e$，不是 $\varepsilon$。$q_0\xrightarrow{e}q_1$ 是空转移。
  2. NFA 的 $\Delta$ 是关系不是函数。$\delta(q_0,b)=\emptyset$ 与「未定义」是两回事， 空集本身是子集构造里的合法状态。
  3. 子集构造要算 $e$-闭包 $E(q)$。初态是 $E(s)$ 而不是 $\{s\}$。
  4. 补运算必须用在 DFA 上。NFA 直接「把终态取反」会把 「存在一条接受路径」变成「不存在接受路径」，语义完全变了。
  5. 泵引理不能用来证明语言是正则的，它只给必要条件。证非正则的套路是 「假设正则 → 拿常数 $n$ → 精心挑长串 → 分 $v,y$ 落点造矛盾」。
  6. 最小化要分两步：先删不可达状态，再划分等价类。跳过第一步会得到错误结果。

2.1 Deterministic Finite Automata

Introduction to DFA

（示意图描述）

  • Input tape（输入带）：一行方格，内容为 $a\ b\ b\ a\ b\ a$。
  • Reading head（读头）：moves left to right, one square at a time（从左向右、每次移动一格）。
  • Finite-state control（有限状态控制器）：一个方框内含有 4 个状态 $\{1,2,3,4\}$：
  • 状态 $1$：Start state（初态，用指向它的箭头表示）。
  • 状态 $2$、$4$：Double-circled states are accepting or final（双圈表示接受态/终态）。
  • 状态 $3$：普通状态。
  • Finite-state control changes state depending on:
  • current state
  • next symbol

第 4 页

Definition: A deterministic finite automata(DFA) is a quintuple $(K,\Sigma,\delta,s,F)$, where

  • $K$ is a finite set of states
  • $\Sigma$ is an alphabet
  • $s \in K$ is the initial state
  • $F \subseteq K$ is the set of final states
  • $\delta$: transition function, $K \times \Sigma \to K$.

Remarks: Transition function will determine unique next state based on current input and state.

第 5 页

Remark:

1) A configuration of a DFA $(K,\Sigma,\delta,s,F)$ is any element of $K \times \Sigma^*$.

2) The binary relation $\vdash_M$ between two configurations of $M$:

$$(q,w) \vdash_M (q',w') \Leftrightarrow \exists a \in \Sigma,\ w = aw',\ \text{and}\ \delta(q,a) = q'.$$

— say $(q,w)$ yields $(q',w')$ in one step.

第 6 页

3) The reflexive, transitive closure of $\vdash_M$, denoted as $\vdash_M^*$: $(q,w) \vdash_M^* (q',w') \Leftrightarrow (q,w)$ yields $(q',w')$ after some number, possibly zero, of steps.

4) A string $w \in \Sigma^*$ is said to be accepted by $M$ iff there is a state $q \in F$ such that $(s,w) \vdash_M^* (q,e)$. The language accepted by $M$, $L(M)$ is the set of all strings accepted by $M$.

第 14 页

Definition: A nondeterministic finite automata(NFA) is a quintuple $(K,\Sigma,\Delta,s,F)$, where

  • $K$ is a finite set of states
  • $\Sigma$ is an alphabet
  • $s \in K$ is the initial state
  • $F \subseteq K$ is the set of final states
  • $\Delta$, transition relation, is a subset of $K \times (\Sigma \cup \{e\}) \times K$.

Remark: For DFA, the transition function $\delta$ is a function, but for NFA, $\Delta$ only a relation.

第 15 页

  • triple $(q,u,p) \in \Delta$ — transition of $M$:
  • $u \neq e$

  • $u = e$: no input symbol

  • configuration — an element of $K \times \Sigma^*$.

  • binary relation $\vdash_M$ and its reflexive transitive closure $\vdash_M^*$.

  • A string $w \in \Sigma^*$ is accepted by $M$ iff there is a state $q \in F$ such that $(s,w) \vdash_M^* (q,e)$. The language accepted by $M$, $L(M)$ is the set of all strings accepted by $M$.

第 21 页

NFA/DFA Equivalence

Definition: Two FA $M_1$ and $M_2$ (deterministic or non deterministic) are equivalent iff $L(M_1) = L(M_2)$.

  • To prove equivalence of DFAs and NFAs we must do two things:

I: For each DFA, produce an NFA that accepts the same language

II: For each NFA, produce a DFA that accepts the same language

We'll do part II; part I is immediate.

第 22 页

Theorem: For each NFA, there is an equivalent DFA.

Proof:

Key idea: Every subset of $K$ becomes a single state in our new machine!

For Example: NFA $M$, $K = \{q_0,q_1,q_2,q_3,q_4\}$, after reading a certain input string, $M$ could be in $\{q_0,q_2,q_3\}$, not in $\{q_1,q_4\}$, then DFA $M'$ is in state $\{q_0,q_2,q_3\}$.

第 23 页

NFA $\Rightarrow$ DFA construction

Consider an arbitrary NFA $M = (K,\Sigma,\Delta,s,F)$. To construct an equivalent DFA $M' = (K',\Sigma,\delta,s',F')$.

Definition:

$$E(q) = \{p \in K : (q,e) \vdash_M^* (p,e)\}$$

Remark: $E(q)$— the set of all states of $M$ that are reachable from state $q$ without reading any input.

□ Finding $\equiv$

  • $\equiv_0$ has just two equivalence classes: $F$ and $K - F$

  • $p \equiv_{n+1} q$ iff

  • $p \equiv_n q$
  • For all $a \in \Sigma$, $\delta(q, a) \equiv_n \delta(p, a)$

（方框）$\equiv_{n+1}$ is a refinement of $\equiv_n$.

Since $K$ is finite, eventually there is an $n$ such that $\equiv_n$ and $\equiv_{n+1}$ are the same: this is $\equiv$.

$\equiv_0$ 分划（将 $K$ 分为 $F$ 与 $\overline{F}$）：

$\equiv_1$ 分划（类 $A, C, D, E$）：

  • 类 $A$：含 $q_1, q_3$
  • $q_1$：$a \to C$，$b \to D$
  • $q_3$：$a \to C$，$b \to D$
  • 类 $C$：含 $q_2$（单独节点，无展开）
  • 类 $D$：含 $q_4, q_6$

第 89 页

Example: The language $L \subseteq \{a_1, \cdots, a_n\}^*$ of all strings that do not contain occurrences of all $n$ symbols, and corresponding DFA with $2^n$ states.

  • $\approx_L$ has $2^n$ equivalence classes.

  • Let $A \subseteq \Sigma$, $L_A = \{w : w \in \Sigma^*, w \text{ contains occurrences of all symbols in } A, \text{ and of no symbols in } \Sigma - A\}$.

The $2^n$ sets $L_A$ are precisely the equivalence classes of $\approx_L$.

第 90 页

2.6 Algorithms for Finite Automata*

Question: Convert a NFA $(K, \Sigma, \Delta, s, F)$ to a DFA.

  • Computation of all $E(q)$ $\cdots\cdots \mathcal{O}(|K|^3)$

（方框） For each $Q \subseteq K$, $\forall a \in \Sigma$, $$\delta(Q, a) = \cup\{E(p) \mid p \in K \text{ and } (q, a, p) \in \Delta \text{ for some } q \in Q\}$$

  • Computation of all $\delta(Q, a)$ $\cdots\cdots \mathcal{O}(|\Delta||K|^2)$

The total complexity: $\mathcal{O}(2^{|K|}|K|^3|\Sigma||\Delta||K|^2)$.

(c) There is an exponential algorithm which, given a NFA, constructs an equivalent regular expression. (d) There is a polynomial algorithm which, given a DFA, constructs an equivalent DFA with the smallest possible number of states.

第 94 页

□ FA as Algorithms

A DFA $M$ is an efficient algorithm for deciding whether a given string is in $L(M)$.

Theorem If $L$ is a regular language, then there is an algorithm which, given $w \in \Sigma^*$, tests whether it is in $L$ in $\mathcal{O}(|w|)$ time.

Theorem If $M = (K, \Sigma, \Delta, s, F)$ is a NFA, then there is an algorithm which, given $w \in \Sigma^*$, tests whether it is in $L$ in $\mathcal{O}(|K|^2|w|)$ time.
