## 覆盖范围

**总览与分析**（HTML 首屏，为这份笔记额外撰写的导读）

0. 这份材料是什么　·　1. 两章的知识地图（乔姆斯基层级 + 识别/生成对偶）　·　2. 五种模型核心定义对照（DFA / NFA / 正则表达式 / PDA / CFG）　·　3. 定理与构造清单（两章共 15 条，附页码）　·　4. 易错点与考点提醒　·　5. 使用说明

**第 2 章 · Finite Automata**（TC02.pdf，P1–P94）

2.1 确定性有限自动机（DFA 五元组、格局、$\vdash_M$、接受的定义）　·　2.2 非确定性有限自动机（NFA、$e$-转移、NFA → DFA 子集构造及正确性证明）　·　2.3 有限自动机与正则表达式（五种闭包性质、正则表达式 ⇄ FA 双向等价、状态消去法）　·　2.4 正则与非正则语言（泵引理、$\{a^nb^n\}$、素数长度语言、Myhill–Nerode 定理）　·　2.5 状态最小化（$\approx_L$ 等价类、标准 DFA、$\equiv_n$ 逐步细化算法）　·　2.6 有限自动机的算法（各转换的复杂度、FA 作为算法）

**第 3 章 · Context-Free Languages**（TC03.pdf，P1–P89）

3.1 上下文无关文法（CFG 四元组、推导、$L(G)$、正则语言 ⊂ CFL）　·　3.2 分析树（分析树定义、相似推导、歧义文法、最左/最右推导）　·　3.3 下推自动机（PDA 六元组、格局、接受条件、若干语言的设计实例）　·　3.4 PDA 与 CFG 等价（CFG → PDA 模拟最左推导；PDA → CFG 经 simple PDA 与 $\langle q,A,p\rangle$ 构造）　·　3.5 上下文无关与非上下文无关语言（闭包性质、与正则语言的交、CFL 泵引理）　·　3.6 上下文无关文法的算法（Chomsky 范式转换三步、$N[i,i+s]$ 动态规划成员判定）

## 来源说明（重要）

这份笔记是**两套课件 PDF 的逐页忠实转写**，不是教材内容的复述，也没有从教材补充任何推导。

课件的 PDF 是**图片型**的（没有文字层，直接抽取文本得到 0 个字符），因此转写流程是：
先把 183 页逐页渲染成图片 → 逐页阅读 → 转写为 Markdown + LaTeX → 汇总成单文件 HTML。

因此有两点需要说明：

| 项目 | 处理方式 |
|---|---|
| **公式** | 全部按原式重新排版为 LaTeX（KaTeX 渲染）。课件里的空串写作斜体 $e$，笔记**保留原写法**，未改成 $\varepsilon$ |
| **状态转移图** | 无法直接截图，一律转写为**「文字描述 + 转移表」**两套等价形式（状态集合、初态、终态、每条边的起点/终点/label） |
| **看不清处** | 标注 `[?]`，不猜测、不补写。少数几处（如 TC02 P13 的 $e$ 边、P44 的长 $e$ 边、P66 的 $q_7/q_8$ 边）已在笔记中标注 |
| **课件笔误** | 按原样保留，不擅自改正（如 TC03 P80 的 $A_{n-2}\to B_{n-1}B_{n-2}$） |
| **教材内容** | **不补充**。课件没讲的内容笔记里也没有 |
