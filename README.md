# FDU Note Summarized

把复旦课程的**讲义、板书、课堂照片**整理成**可离线阅读**的数学笔记。

笔记以单文件 HTML 交付，公式用 [KaTeX](https://katex.org/) 本地渲染（不依赖 CDN，断网也能正常显示），
示意图用内联 SVG（深浅色自动适配）。每一节都标注了**来源**：

| 标记 | 含义 |
|---|---|
| `板书 N` | 老师课上确实写过（附板书逐字原文） |
| `讲义 §x.y` | 讲义里有，但课上没讲 |
| *（无标记）* | 讲义没写、板书没有，是我按教材补的推导 |

这样缺课时能立刻判断「哪块现在必须看、哪块可以等老师讲到再回来」。
